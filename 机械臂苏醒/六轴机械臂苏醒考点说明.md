# 六轴机械臂苏醒考点说明

> 内部校验用，不交给制作方，不属于制作输入。

**主类目**：产品动画/工业设备/机械传动

**题目档位**：上限档（配方：L3 + L2，附带 1 个 L1）

**档位来源**：默认

**耦合链**：同一台机械臂上，组件按装配顺序瀑布式落下、从下往上装好，底座留出一个空孔；装好后指示灯变绿，六个关节协同伸出，在半空接住最后落下的螺栓，再用第六轴的旋转把它拧进空孔。

| 编号 | 考点 | 分级 | 作用对象与时段 | 在片中的体现 |
|---|---|---|---|---|
| 5 | 多关节联动与抓取交互 | L3 | 机械臂六个关节和夹爪，7–12 秒 | 转身迎上下落的螺栓，三指在约 80 厘米高处夹住六角头；螺栓由下落 → 跟随夹爪 → 拧入锁定，状态切换清楚；拧入时每转一圈进一个螺距 |
| 9 | 结构爆炸拆解与渐进式生长建造 | L2 | 12 个组件，0–7.6 秒 | 零件从画面上缘外不断落下，空中始终 2–6 件，按底座 → 转台 → 肩座 → 大臂 → 肘关节 → 小臂 → 腕部 → 夹爪 → 电机盖和线缆的顺序装好，落位锁定不漂移 |
| 16 | 光影流转与材质外观演变 | L1 | 指示灯环、安全光栅灯，1.5–12 秒 | 指示灯环组装时亮红色，第 7.2 秒一圈圈变成绿色，安全光栅灯同步变绿 |

**最高分级**：L3

## 制作底线清单

**二级类目**：工业设备

**技术模块**：T6

**本片要用的专业术语**：硬表面建模、细分曲面、支撑边、倒角修改器、加权法线、布尔运算、程序化凹凸细节、父子级绑定、骨骼约束、齿轮传动比、驱动器、反向动力学、曲率遮罩、环境光遮蔽

**推荐插件**：MACHIN3tools（开源）、Extra Mesh Objects（内置）

**通用底线**：PBR 贴图或程序化纹理（近景 4K）、倒角、接触阴影、AgX 色彩管理、足够采样、100% 查看细节、尺度参照（扭矩扳手）、防重复

**重模拟**：无

## 类目与标签

**归类理由**：主体是一台工业机械臂，片子通过瀑布式组装、关节内部结构和自主抓取拧螺栓展示它的结构和功能，属于工业设备里的机械传动。

| 标签组 | 选定标签 | 必要说明 |
|---|---|---|
| 视觉造型 | 写实 | 照片级写实 |
| 材质质感 | 金属、塑料橡胶 | 主材质是喷涂铸铝和钢件；其次是橡胶线缆和指尖垫 |
| 渲染风格 | 真实渲染 | 常规物理渲染 |
| 动态节奏 | 机械节奏 | 零件分段精确落位，关节动作干脆 |
| 动画行为 | 主行为：结构与装配/拆解组装/拼接归位 | 组件瀑布式落下、逐件归位 |
| 动画行为 | 辅助行为：结构与装配/开合联动/机械传动 | 六个关节联动、夹爪开合 |
| 动画行为 | 辅助行为：位移与运动/规律运动/旋转 | 第六轴旋转拧入螺栓 |
| 动画行为 | 辅助行为：显隐与外观变化/材质变化/发光亮灭 | 指示灯由红转绿 |
| 灯光氛围 | 低调暗黑 | 夜里的车间，检测台局部被工作灯照亮 |
| 背景环境 | 完整场景 | 工厂检测区和远处的装配线完整搭建 |
| 色彩基调 | 不填 | 白、深灰和钢色为主，没有单一的色彩基调 |
| 时序结构 | 多段序列 | 底座落位 → 转台与大臂 → 小臂与腕部 → 苏醒接螺栓 → 拧入与待机 |
| 复杂度等级 | 多元编排 | 多组件错时落位、骨骼反向动力学和驱动器编排 |
| 应用场景 | 电商展示 | 适合作为工业设备的产品展示视频 |
