# 雨夜楼群间的重型货运机吊运考点说明

> 内部校验用，不交给制作方，不属于制作输入。

**主类目**：载具动画/幻想载具/飞船

**题目档位**：上限档（配方：单个 L4，附带 1 个 L2 和 2 个 L1）

**档位来源**：默认

**规范版本**：进阶版 1.9

**视觉基调**：夜景都市

**耦合链**：同一台货运机和它吊着的集装箱：侧风吹得集装箱在四根 15 米长的吊缆下摆起来，吊缆上端先动、集装箱慢半拍；货运机按摆动右倾、偏转导流叶片、前后倾转涵道去抵消和刹车；悬停后绞车按放出长度转动，集装箱下降、转角对准定位桩，角件落进桩里，吊钩打开脱开；下洗气流吹斜雨、吹开积水，镜头一镜到底跟完全程。

| 编号 | 考点 | 分级 | 作用对象与时段 | 在片中的体现 |
|---|---|---|---|---|
| 12 | 薄面垂坠与绳索悬挂 | L4 | 四根吊缆、吊具框和集装箱，0–12 秒 | 四根约 15 米长的钢丝吊缆挂着约 20 吨的集装箱；侧风吹来先往左摆出约 2 米、吊缆倾斜约 8°，再一下比一下小地荡回；上端先动、下端慢半拍；放下后吊缆变松、被拉起时在雨里晃 |
| 4 | 部件联动与运动匹配｜防打滑 | L2 | 四个涵道、导流叶片、绞车和吊钩，2.5–12 秒 | 涵道前后转 ±30°、导流叶片左右偏 ±20°，跟着机身姿态联动；绞车卷筒按钢丝放出长度转、排线器左右走；吊钩打开约 40° 后退出角件孔 |
| 16 | 光影流转与材质外观演变 | L1 | 泛光灯、航行灯和湿蒙皮，0–12 秒 | 航行灯一闪一闪；霓虹在湿机身上滑过；悬停时暖橙泛光灯照亮集装箱 |
| 17 | 单镜头运镜构图 | L1 | 镜头，全片 | 一镜到底：中心构图仰拍 → 三分法 → 引导线 → 层次纵深 → 负空间 |

**最高分级**：L4

## 制作底线清单

**二级类目**：幻想载具

**技术模块**：T6、T7、T10、T9

**本片要用的专业术语**：变形绑定、骨骼绑定、骨骼约束、硬表面建模、细分曲面、支撑边、倒角修改器、加权法线、布尔运算、父子级绑定、驱动器、旋转限制约束、阻尼追踪、拉伸到约束、刚体模拟、铰链约束、碰撞形状、碰撞边距、粒子系统、风力场、动态绘画波纹、局部体积雾、运动模糊、自发光

**推荐插件**：MACHIN3tools（开源）、Building Tools（开源）、Rigify（内置）

**通用底线**：PBR 贴图或程序化纹理（近景 4K）、倒角、接触阴影、AgX 色彩管理（Medium High Contrast）、足够采样、100% 查看细节、尺度参照（平台栏杆、1 米高的定位桩、6 米长的集装箱）、防重复

**重模拟**：刚体模拟（只用在吊缆和集装箱上）

## 类目与标签

**归类理由**：主体是一台原创的四涵道重型货运飞行器吊运集装箱，按类目表归到幻想载具里的飞船。

| 标签组 | 选定标签 | 必要说明 |
|---|---|---|
| 视觉造型 | 写实 | 按写实电影质感做的飞行器和城市 |
| 材质质感 | 金属、塑料橡胶 | 主材质是铆接蒙皮、碳纤维涵道、钢丝和波纹钢集装箱；其次是密封条和胶条 |
| 渲染风格 | 真实渲染 | 常规物理渲染 |
| 动态节奏 | 自然流畅 | 重物的摆动和飞行器的修正都按惯性来 |
| 动画行为 | 主行为：物理与特效/柔性运动/毛发绳索 | 吊缆和集装箱的摆动 |
| 动画行为 | 辅助行为：位移与运动/路径运动/沿线移动 | 货运机穿过楼群 |
| 动画行为 | 辅助行为：结构与装配/开合联动/机械传动 | 涵道、导流叶片、绞车和吊钩的联动 |
| 动画行为 | 辅助行为：物理与特效/流体粒子/粒子 | 被吹斜的雨和溅开的水花 |
| 灯光氛围 | 霓虹赛博 | 泛光灯、航行灯和霓虹灯箱 |
| 背景环境 | 完整场景 | 楼群、平台和远处车流完整搭建 |
| 色彩基调 | 冷色科技 | 蓝黑和深灰为主，暖橙泛光灯，红绿和品红青点缀 |
| 时序结构 | 多段序列 | 压过来 → 侧风 → 擦楼 → 悬停下放 → 放下脱钩 |
| 复杂度等级 | 物理模拟 | 含刚体模拟 |
| 应用场景 | 不填 | 用于考察载具制作 |
