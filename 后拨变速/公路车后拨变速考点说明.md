# 公路车后拨变速考点说明

> 内部校验用，不交给制作方，不属于制作输入。

**主类目**：产品动画/工业设备/零部件

**题目档位**：上限档（配方：单个 L4，附带 1 个 L2 和 2 个 L1）

**档位来源**：默认

**规范版本**：进阶版 1.5

**视觉基调**：产品广告

**耦合链**：同一套公路车后半截传动系统上，电机带着曲柄转动牙盘，牙盘拉动链条，链条带动飞轮和后轮，整条按固定转速比走、链节不打滑（4）；链条作为一条线性柔体，上段张紧、下段经后拨笼下垂，后拨的平行四边形往里摆、上导轮把链条往侧向推，链节借变速斜坡一节节爬上大一号的齿盘，换到大齿时包角变大、后拨笼靠 B 张力弹簧转动收紧（12 和 4 耦合）；钢蓝光带扫过、链油膜随角度泛出亮痕、齿面接触带的材质外观随之变化（16）；镜头一镜到底从起转跟到爬齿特写、升降和大齿慢转（17）。

| 编号 | 考点 | 分级 | 作用对象与时段 | 在片中的体现 |
|---|---|---|---|---|
| 12 | 薄面垂坠与绳索悬挂 | L4 | 链条，0–12 秒 | 链条当作一条线性柔体：上段被牙盘和飞轮拉紧，下段经后拨笼下垂弯下，换档时被上导轮往侧向推约 3.9 毫米、一节节爬上大一号的齿尖，换到大齿时包角变大、下垂变少 |
| 4 | 部件联动与运动匹配｜防打滑 | L2 | 曲柄—牙盘—链条—飞轮—后轮，以及后拨平行四边形—导轮—链条，0–12 秒 | 曲柄每分钟 60–80 转，按齿轮传动比带动牙盘、链条、飞轮和后轮，链节滚子坐进齿谷不打滑；平行四边形往里摆、上导轮推链侧移，链节不从齿尖滑过 |
| 16 | 光影流转与材质外观演变 | L1 | 钢蓝光带、链油膜、齿面接触带，0–12 秒 | 钢蓝窄光带来回扫两次；链油膜随角度泛出亮痕；齿面被链条磨亮的接触带闪动；碳纤维斜纹随角度一明一暗翻转 |
| 17 | 单镜头运镜构图 | L1 | 镜头，全片 | 一镜到底：对角线（起转）→ 层次纵深（第一次爬齿）→ 三分法（连升两档）→ 后拨上方视角（升降）→ 负空间与特写（大齿慢转） |

**最高分级**：L4

## 制作底线清单

**二级类目**：工业设备

**技术模块**：T6

**本片要用的专业术语**：硬表面建模、细分曲面、支撑边、倒角修改器、加权法线、布尔运算、程序化凹凸细节、曲线绕轴旋转、几何节点实例化、父子级绑定、驱动器、骨骼约束、齿轮传动比、限制旋转约束、环境光遮蔽、曲率遮罩

**推荐插件**：MACHIN3tools（开源）、Extra Mesh Objects（内置扩展）

**通用底线**：PBR 贴图或程序化纹理（近景 4K）、倒角、接触阴影、AgX 色彩管理（Medium High Contrast）、足够采样、100% 查看细节、尺度参照（后轮直径约 67 厘米）、防重复

**重模拟**：无（传动和链条跑动用驱动器和几何节点实例化，后拨和导轮笼用骨骼约束，微尘和油点用粒子系统）

## 类目与标签

**归类理由**：主体是公路车的后拨变速传动这一组具体的自行车零部件，展示的是曲柄—链条—飞轮的传动和后拨换档爬齿这些机械运作，属于工业设备里的零部件，而不是整车载具或抽象的物理原理模型。

| 标签组 | 选定标签 | 必要说明 |
|---|---|---|
| 视觉造型 | 写实 | 照片级写实的产品广告 |
| 材质质感 | 金属、塑料橡胶 | 主材质是镀镍钢链条、钢飞轮和阳极氧化铝后拨；碳纤维车架和橡胶外胎归到塑料橡胶一类 |
| 渲染风格 | 真实渲染 | 常规物理渲染 |
| 动态节奏 | 机械节奏 | 传动匀速、换档动作干脆、停顿明确 |
| 动画行为 | 主行为：结构与装配/开合联动/机械传动 | 曲柄带牙盘和链条、链条带飞轮和后轮 |
| 动画行为 | 辅助行为：物理与特效/柔性运动/毛发绳索 | 链条作为线性柔体张紧、下垂、侧移爬齿 |
| 动画行为 | 辅助行为：位移与运动/规律运动/旋转 | 飞轮、后轮和导轮持续旋转 |
| 灯光氛围 | 低调暗黑 | 深灰暗棚、钢蓝条形光勾边 |
| 背景环境 | 无缝影棚 | 弯成弧形的深灰无缝背景板 |
| 色彩基调 | 冷色科技 | 钢蓝为主、只留一处暖金点缀 |
| 时序结构 | 多段序列 | 起转 → 爬齿升档 → 连升 → 升降 → 大齿慢转 |
| 复杂度等级 | 多元编排 | 多部件驱动器联动、链条几何节点实例化和错时换档 |
| 应用场景 | 电商展示、品牌片头 | 适合运动器材的产品展示和品牌片 |
