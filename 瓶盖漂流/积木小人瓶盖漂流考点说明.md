# 积木小人瓶盖漂流考点说明

> 内部校验用，不交给制作方，不属于制作输入。

**主类目**：角色动画/简易人形/积木小人

**题目档位**：进阶档（配方：L2 + L2，附带 2 个 L1）

**档位来源**：默认

**规范版本**：进阶版 1.3

**视觉基调**：温馨童话

**耦合链**：同一只载着小人的瓶盖，被水龙头推出的浪抬起、打转，沿着水流冲向碗沿、窄缝和海绵，轨迹和转速随水流的急缓变化；每次碰到碗、勺子和海绵，瓶盖都贴着它们的轮廓弹开或停住，不穿进去；小人跟着瓶盖一晃一晃，头和手臂晚半拍跟上。

| 编号 | 考点 | 分级 | 作用对象与时段 | 在片中的体现 |
|---|---|---|---|---|
| 3 | 复杂轨迹与姿态自适应 | L2 | 瓶盖和小人，2–10 秒 | 瓶盖被浪抬起打转，撞碗沿弹开，冲过窄缝，越转越慢，卡在海绵边；小人随瓶盖后仰、晃动、坐稳 |
| 10 | 体积碰撞与边界阻挡｜真实轮廓接触与防穿模 | L2 | 瓶盖和碗、勺子、海绵，小人和瓶盖，2–12 秒 | 瓶盖贴着碗沿、勺子和海绵的轮廓弹开或停住；小人一直坐在瓶盖里，不穿过、不飘起 |
| 16 | 光影流转与材质外观演变 | L1 | 水面上的窗光，2–12 秒 | 开闸后水面的光被打碎成晃动的光斑，最后又慢慢铺平 |
| 17 | 单镜头运镜构图 | L1 | 镜头，全片 | 一镜到底：三分法 → 引导线 → 对角线 → 前景框景特写 → 中心构图 |

**最高分级**：L2

## 制作底线清单

**二级类目**：简易人形

**技术模块**：T6、T7

**本片要用的专业术语**：父子级绑定、关节约束、正向动力学、二级动画、硬表面建模、细分曲面、支撑边、倒角修改器、加权法线、程序化凹凸细节、次表面散射、FLIP 液体模拟、二次粒子、路径跟随

**推荐插件**：Rigify（内置）、MACHIN3tools（开源）、Mantaflow 液体（内置）

**通用底线**：PBR 贴图或程序化纹理（近景 4K）、倒角、接触阴影、AgX 色彩管理（Base Contrast）、足够采样、100% 查看细节、尺度参照（瓶盖、勺子）、防重复

**重模拟**：液体模拟（只包住镜头能看到的那块水槽）

## 类目与标签

**归类理由**：主体是一个由几个关节件拼成的原创积木小人，表演的是坐瓶盖在水槽里漂流，属于简易人形里的积木小人。

| 标签组 | 选定标签 | 必要说明 |
|---|---|---|
| 视觉造型 | 写实 | 照片级写实的玩具摄影 |
| 材质质感 | 塑料橡胶、液体冰晶、金属 | 主材质是积木小人和瓶盖的塑料；其次是水和泡沫，以及不锈钢水槽 |
| 渲染风格 | 真实渲染 | 常规物理渲染 |
| 动态节奏 | 自然流畅 | 漂流随水流忽急忽缓 |
| 动画行为 | 主行为：位移与运动/路径运动/沿线移动 | 瓶盖随水流漂流 |
| 动画行为 | 辅助行为：物理与特效/流体粒子/液体 | 水流、浪和水花 |
| 动画行为 | 辅助行为：物理与特效/刚体运动/碰撞弹跳 | 瓶盖撞碗沿、勺子弹开 |
| 动画行为 | 辅助行为：位移与运动/规律运动/摆动 | 小人跟着瓶盖晃 |
| 灯光氛围 | 自然日光 | 清晨从窗户斜照进来的阳光 |
| 背景环境 | 完整场景 | 水槽、碗、勺子、海绵和窗台完整搭建 |
| 色彩基调 | 不填 | 银白的水面加一点暖黄和小人的黄红，没有单一的色彩基调 |
| 时序结构 | 多段序列 | 平静 → 开闸 → 撞碗 → 冲出窄缝 → 举手 |
| 复杂度等级 | 物理模拟 | 含液体模拟 |
| 应用场景 | 不填 | 没有明确的用途依据 |
