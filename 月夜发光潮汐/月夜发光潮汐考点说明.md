# 月夜发光潮汐考点说明

> 内部校验用，不交给制作方，不属于制作输入。

**主类目**：场景动画/自然环境/水域海洋

**题目档位**：上限档（配方：单个 L4，附带 1 个 L2 和 2 个 L1）

**档位来源**：默认

**规范版本**：进阶版 1.5

**视觉基调**：梦幻奇景

**耦合链**：同一组涨潮的浪上，斜着来的浪按相位差一道接一道在礁坎和近岸碎开，碎点沿浪线从左往右跑，浪白里的发光浮游生物被搅亮；近岸三道浪的上冲流冲上黑沙坡，在湿沙上留下湿痕和一圈圈按渗水时间衰减的蓝纹；回流露出湿沙后，沙蟹出洞横跑，脚尖在同一张湿沙上压出凹坑、点亮光点；最大的第三道浪追着蟹冲上来，漫过足迹把凹坑抹平、把光点重新搅亮，最后退下去，蓝纹从上往下一圈圈暗掉；月光不变，蓝光的亮灭和湿沙的深浅随浪变化，镜头一镜到底跟完全程。

| 编号 | 考点 | 分级 | 作用对象与时段 | 在片中的体现 |
|---|---|---|---|---|
| 15 | 接触留痕与表面动态反馈 | L4 | 湿沙面，与上冲流、回流和沙蟹的脚尖接触，2.5–12 秒 | 三道上冲流各在约 5.5 米、3 米、6 米处留下一圈弧形蓝纹，三四秒暗掉一半、再拖七八秒才熄，越往上越先暗；冲过的沙变湿变深、一直不干；沙蟹每一步压出 1–2 毫米的凹坑和约 1 厘米的光点，亮约一秒再两三秒暗下去；第三道浪漫过足迹，凹坑被抹平、光点被重新搅亮；结尾看得出新亮旧暗的一圈圈 |
| 14 | 集群协同与波浪相位差 | L2 | 礁坎和近岸的浪线、浪白里的发光浮游生物，0–12 秒 | 浪斜着来、周期两三秒，每道浪线左头先碎，碎点每秒约 6 米往右跑，蓝光沿浪线依次亮起；相邻两道差一个周期，礁坎和近岸两条线按相位差错开，结尾礁坎上还有新的一道从左头亮起 |
| 16 | 光影流转与材质外观演变 | L1 | 发光生物的蓝光和湿沙，0–12 秒 | 蓝光只在被搅动处亮起、按真实时长衰减，用颜色渐变从青蓝褪到深蓝再到黑；冲过的沙从粗糙度约 0.7 的干黑沙变成约 0.2 的湿沙，泛起月光；色彩脚本从细线到亮边、点点、满片再退暗 |
| 17 | 单镜头运镜构图 | L1 | 镜头，全片 | 一镜到底：中心构图（24 毫米朝海）→ 引导线（水舌亮边指向海蚀拱）→ 三分法特写（50 毫米跟拍沙蟹）→ 对角线（升起、拉回 28 毫米）→ 负空间俯看 |

**最高分级**：L4

## 制作底线清单

**二级类目**：自然环境

**技术模块**：T1、T3、T4（另用 T7 的反向动力学和骨骼绑定做法）

**本片要用的专业术语**：侵蚀模拟、几何节点散布、海洋修改器、物理天空、颜色渐变、高度图地形、置换修改器、自适应细分、多重分辨率细分、雕刻、体素重构网格、岩石节理、空气透视、三平面投影贴图、坡度遮罩、随机旋转与缩放、二级摆动、FLIP 液体模拟、模拟域与分辨率、网格化液面、二次粒子、障碍物、实体化、碰撞距离、焦散、体积吸收、折射率、体积散射、动态绘画、湿图、骨骼链、反向动力学、缩裹约束、限制旋转约束、次表面散射、接触阴影

**推荐插件**：Mantaflow 液体（内置）、海洋修改器（内置）、动态绘画（内置）、A.N.T. Landscape（内置扩展）、Rigify（内置）

**通用底线**：PBR 贴图或程序化纹理（近景 4K）、倒角（落石的棱用倒角修改器磨圆）、接触阴影、AgX 色彩管理（Base Contrast）、足够采样、100% 查看细节、尺度参照（约 1.5 米的浮木和 1–1.5 厘米的藤壶）、防重复

**重模拟**：液体模拟 1 种（近岸上冲流和回流，Mantaflow FLIP）；远海用海洋修改器，留痕用动态绘画，海草和沙蟹用骨骼

## 类目与标签

**归类理由**：主体是满月夜涨潮时一片黑沙滩上的浪和潮水，以及浪在湿沙上留下的发光痕迹，沙蟹只是在同一片湿沙上的配角，属于自然环境里的水域海洋。

| 标签组 | 选定标签 | 必要说明 |
|---|---|---|
| 视觉造型 | 写实 | 照片级写实的夜间海滩 |
| 材质质感 | 液体冰晶、自发光、木石天然 | 主材质是浪和回流的水；其次是发光浮游生物的蓝光；黑沙、玄武岩礁石和浮木 |
| 渲染风格 | 真实渲染 | 常规物理渲染 |
| 动态节奏 | 自然流畅 | 浪的上冲和回流、蓝光的亮灭和沙蟹的横跑都符合真实物理 |
| 动画行为 | 主行为：物理与特效/流体粒子/液体 | 近岸的浪冲上沙滩又退回 |
| 动画行为 | 辅助行为：显隐与外观变化/材质变化/发光亮灭 | 浪线、蓝纹和足迹光点的亮起和衰减 |
| 动画行为 | 辅助行为：物理与特效/流体粒子/粒子 | 泡沫、气泡和水花等二次粒子 |
| 动画行为 | 辅助行为：位移与运动/路径运动/沿线移动 | 沙蟹沿湿沙带横跑、冲回洞口 |
| 灯光氛围 | 夜景月光 | 满月主光加冷天光，发光生物作实用光 |
| 背景环境 | 完整场景 | 沙滩、礁石、海蚀拱、岬角和远海完整搭建 |
| 色彩基调 | 不填 | 近黑蓝灰加一点青蓝，标签里没有贴切的一项 |
| 时序结构 | 多段序列 | 浪线点亮 → 第一道浪上滩 → 沙蟹出洞 → 大浪追蟹 → 水退光熄 |

| 应用场景 | 不填 | 没有明确的用途依据 |
