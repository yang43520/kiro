## 一、制作 Prompt

```text
使用 Blender 5.0.0 制作一条约 12 秒（允许 11–13 秒，不得少于 8 秒）的水滴飞溅超慢动作动画，照片级写实渲染，一镜到底。画面内容、动作和镜头以《水滴皇冠飞溅剧本》为准。

核心效果：微距影棚里，一个盛满清水的黑色浅盘水面平静如镜。一滴直径约 4 毫米的清水从画面上方缓慢落下，撞进水面，砸出一个凹坑，凹坑边缘掀起一圈薄薄的水壁，张开成皇冠形的水冠；冠沿长出一圈尖齿，齿尖拉成水丝，断开成一颗颗小水珠飞散出去。水冠塌落后，凹坑回弹，中心弹起一根细长的水柱，柱顶的水头拉断成一颗水珠。水柱缩回，水珠落下再激起一个小水冠，飞散的小水珠也陆续落回水面，一圈圈同心的涟漪向外扩散、互相交叠。全片是均匀的超慢动作，真实过程约 0.15 秒，放慢约 80 倍。镜头从水面略上方微距侧视，绕撞击点缓慢转动并轻微推近。

质感要求：
- 整体：画面像用高速摄影机和微距镜头在影棚里实拍的水滴飞溅，任意暂停一帧都应该像一张高速摄影作品。
- 尺寸：水冠高约 2 厘米，直径约 2.5 厘米；中心弹起的水柱高约 3 厘米；飞出的小水珠直径 0.3–1 毫米；画面宽度对应的真实范围约 8 厘米。
- 时间：画面里所有的运动都按同一个倍率放慢，不能有的快、有的慢；水滴、水冠、水珠和水柱都按重力减速、加速，升到最高点时有明显的停顿感。
- 液面：水冠和水柱的表面是光滑的液面，由表面张力拉成平滑的曲面，不是一团团的块状或颗粒，也不是融球拼出来的形状。
- 透明：水是完全透明的，透过水滴能看到背景被折射、上下颠倒的影像；水冠的薄壁很薄，边缘最薄，透光、折射背景。
- 水珠：每颗飞出的小水珠都是透明的小球，带一个清晰的高光点，飞行时轻微地振荡变形；下落的大水滴也会轻微地压扁、拉长，来回振荡。
- 气泡：撞击的一瞬间，水面下会卷入一圈细小的气泡，随后在水中缓慢上浮。
- 波纹：主波纹前方有一圈更细、更密的小波纹，比主波纹跑得更快；小水珠落回水面激起的涟漪和主涟漪互相交叠。
- 水质：水是干净的清水，不起白色的泡沫，也没有浑浊。
- 场景：盛满清水的黑色浅盘，水面向画面后方延伸，远处自然虚化，看不到盘子的边缘；背景是一块深色的渐变背景板，上方接近黑色，靠近水面的部分是很暗的深蓝色；水面映出背景板的渐变和上方柔光箱的长条形亮带。
- 灯光：一块长条形柔光箱在水滴的正后方偏上，作为逆光，勾出水冠、水柱和水珠的亮边；上方一块大面积柔光箱在水面和水冠的外壁上映出柔和的长条亮带；左前方一盏很弱的柔光，让朝向镜头的水面仍有细节。
- 高光：液面上的高光随水的形状流动、变形，不是固定在某个位置的亮点。
- 曝光与清晰度：高光不过曝成大片白色，水冠薄壁的透明感和背景的折射清楚可见；画面清晰锐利，水冠边缘、水珠和细小波纹的细节都能看清，没有因降噪过度或采样不足造成的发糊、涂抹或噪点。
- 空气与辉光：画面中没有雾，不加大片的辉光。
- 镜头成像：微距的浅景深，焦点始终在撞击点上，水冠、水柱和近处的水珠清晰，远处的水面和背景自然虚化；高速摄影的极短快门，水珠清晰锐利，没有运动拖影。

不可改变的内容：全片是一个连续镜头，中间没有剪辑或转场；按“下落 → 撞击成冠 → 水冠回落 → 水柱弹起 → 回落与涟漪”的顺序进行；冠沿的尖齿拉成水丝后断开成小水珠；中心弹起的水柱顶部拉断出一颗水珠，这颗水珠落回时再次激起小水冠；全片是均匀的超慢动作；水柱和断出的水珠升到最高时仍完整地位于画面中；画面在涟漪仍在向外扩散时结束。

可调整范围：剧本中的尺寸、距离、角度、数量、速度和时间都是参考值，可在保持比例和观感的前提下调整；各段时间点可以微调，但段落的顺序不变。冠沿尖齿和小水珠的具体数量、背景渐变的颜色深浅、镜头转动的方向，都可以自行设计。

可选增强：水冠薄壁上出现细微的干涉纹理般的亮度变化；一两颗飞散的水珠落在镜头附近的水面上，激起近景的小涟漪。

禁止：剪辑、转场或跳帧；水的表面是块状、颗粒状或融球拼出来的样子；水不透明、像凝胶或玻璃，或起白色泡沫；画面中的运动快慢不一致；水珠凭空出现或消失，而不是从水丝断开；水冠或水柱没有重力感，像漂在空中；高光固定不动；出现雾或大片的辉光；水柱或水珠被画面边缘裁掉；出现人物或任何文字；镜头突然加速、急停或抖动；用停帧或重复片段凑时长；画面闪烁、破面或非设计性的卡顿。

输出规格：16:9，1280×720，30 帧/秒，无声音。最终输出一条完整的动画视频。
```

## 三、类目与标签

**主类目**：现象动画/液体流动/飞溅

**归类理由**：
- 本片以水本身为主角，表现一滴水落入水面后的飞溅过程，属于「液体流动」；「飞溅」的示例“液体冠状飞溅、水滴落下溅起”与本片一致。
- 片中没有任何商品，所以不归「产品动画/食品饮料」。
- 涟漪只是飞溅之后的余波，主要篇幅是水冠和水柱，所以不选「涟漪波面」。

| 标签组 | 选定标签 | 必要说明 |
|---|---|---|
| 视觉造型 | 写实 | 照片级写实 |
| 材质质感 | 液体冰晶 | 透明的清水 |
| 渲染风格 | 真实渲染 |  |
| 动态节奏 | 自然流畅 | 均匀的超慢动作，所有运动都按重力平滑地加速和减速 |
| 动画行为 | 主行为：物理与特效/流体粒子/液体 | 水滴撞击水面，形成水冠和水柱，涟漪扩散 |
| 动画行为 | 辅助行为：物理与特效/流体粒子/粒子 | 冠沿和水柱顶部断开的小水珠，以及水下的细小气泡 |
| 动画行为 | 辅助行为：形变与生长/形态变化/挤压拉伸 | 下落的水滴和飞行中的水珠来回振荡变形 |
| 灯光氛围 | 低调暗黑 | 深色背景，逆光和顶光局部勾出水的轮廓，对比强 |
| 背景环境 | 无缝影棚 | 水面向后延伸并虚化，和深色背景板之间看不到分界；表中没有“水面加暗背景”一项，这是最接近的 |
| 色彩基调 | 不填 | 画面以黑色和很暗的深蓝为主，加上白色的高光，色彩信息很少，依据不充分 |
| 时序结构 | 多段序列 | 下落、撞击成冠、水冠回落、水柱弹起、回落与涟漪按顺序衔接 |
| 复杂度等级 | 物理模拟 | 水冠、水柱和断开的水珠需要液体模拟 |
| 应用场景 | 不填 | 没有明确用途依据 |

## 五、考点与分级

**耦合链**：所有考点都作用在同一滴水和它撞击的这片水面上，并串成一条因果链：水滴受重力下落、撞进水面（2）→ 水面形变成水冠和水柱（8）→ 冠沿和柱顶断开成离散的水珠（13）→ 水珠落回水面，和主涟漪一起形成层层交叠的波纹（14）；镜头一镜到底地跟着这条链（17）。

| 编号 | 考点 | 分级 | 作用对象与时段 | 在片中的体现 |
|---|---|---|---|---|
| 2 | 运动节奏与重量质感｜加减速 | L1 | 水滴、水冠、水柱和水珠，0–12 秒 | 全片统一的慢动作倍率；水柱上升越来越慢、到顶停顿、下落越来越快 |
| 8 | 柔性形变与形态演变 | L3 | 水面，1.5–9 秒 | 水面被砸出凹坑，掀起薄壁张开成水冠，塌落后回弹成细长的水柱 |
