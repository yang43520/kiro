# 温室枝头的机械变色龙考点说明

> 内部校验用，不交给制作方，不属于制作输入。

**主类目**：角色动画/仿生机器人/四足机器人

**题目档位**：上限档（配方：L3 + L2，附带 2 个 L1）

**档位来源**：默认

**规范版本**：进阶版 1.8

**视觉基调**：剧情电影

**机器人规范**：机器人版 1.1

**原型**：高冠变色龙

**外观**：机械朋克

**耦合链**：同一只机械变色龙：两束对握的趾和卷起的尾巴把它固定在枯枝上；两只眼睛炮塔由各自的齿轮驱动，先后锁住飞虫；锁定引出鳞片下的凸轮轴转动，相邻两排凸轮错开约 18°，鳞片从头往尾一排排翻成绿；擒纵一松，卷尺钢带舌头弹出，吸盘粘住飞虫，发条再把它卷回嘴里；收舌一顿引出前脚重抓、尾巴卷紧和第二次翻色；温室的光在黄铜和玻璃鳞片上流转，镜头一镜到底跟完全程。

| 编号 | 考点 | 分级 | 作用对象与时段 | 在片中的体现 |
|---|---|---|---|---|
| 5 | 多关节联动与抓取交互 | L3 | 四只脚的两束趾、15 节尾巴、卷尺舌头和吸盘，0–12 秒 | 两束趾从枝条两侧对握，每趾 3 节，指尖贴住树皮；舌头弹出约 30 厘米，吸盘按在飞虫背上压扁约 1 毫米粘住，再卷回嘴里；收舌后前脚重新抓紧，尾巴从尾尖一节节卷起缠紧枯枝 |
| 4 | 部件联动与运动匹配｜防打滑 | L2 | 眼睛炮塔的齿轮、鳞片下的凸轮轴、舌头卷盘，0–12 秒 | 炮塔按传动比转动、光圈叶片一起开合；20 排鳞片按凸轮相位依次翻转，两秒从头传到尾；卷盘的转角决定钢带的伸出长度，一格格放出和收回 |
| 16 | 光影流转与材质外观演变 | L1 | 温室天光、煤气灯和玻璃鳞片，0–12 秒 | 鳞片从铜色翻成透光的绿、再翻成橙红、最后翻回铜色 |
| 17 | 单镜头运镜构图 | L1 | 镜头，全片 | 一镜到底：中心构图特写 → 三分法 → 对角线 → 层次纵深 → 负空间 |

**最高分级**：L3

## 机器人设定卡

| 项目 | 内容 |
|---|---|
| 原型 | 高冠变色龙（侧扁身体、高头冠、两束对握的趾、能卷的尾巴、各自转动的眼睛、弹射的长舌） |
| 尺寸和比例 | 体长约 25 厘米（不含尾），尾长约 22 厘米，舌头最多伸出约 35 厘米 |
| 外观路线 | 机械朋克 |
| 主要材料 | 黄铜肋片和头冠、彩色玻璃鳞片、铸铁脊椎环、发蓝钢舌带、皮革护套和吸盘 |
| 驱动方式 | 躯干里的发条盒经齿轮和连杆分到四肢和眼睛；鳞片由凸轮轴驱动；舌头由擒纵锁住、弹簧弹出、发条卷回 |
| 自由度 | 眼睛各 2（水平约 ±90°、上下约 ±45°）、下颌 1（约 35°）、肩 2（约 ±60°）、肘 1（0–120°）、腕 1、趾每节 1（0–90°）、尾巴 15 节（每节约 ±25°） |
| 原创说明 | 原创设计，不像任何现有的机器人或影视游戏里的机械生物 |

## 制作底线清单

**二级类目**：仿生机器人

**技术模块**：T14、T15、T16（另用进阶版 T9 的粒子做法）

**本片要用的专业术语**：硬表面建模、细分曲面、支撑边、倒角修改器、加权法线、父子级绑定、旋转限制约束、反向动力学、极向目标、缩裹约束、驱动器、二级摆动、骨骼链、自由度、传动比、发条、擒纵机构、凸轮、形态键、子级约束、体积吸收、折射率、粒子系统、湍流力场、生命周期、动态绘画、曲率遮罩、环境光遮蔽、法线朝向遮罩

**推荐插件**：MACHIN3tools（开源）、Extra Mesh Objects（内置扩展）、Rigify（内置）

**通用底线**：PBR 贴图或程序化纹理（近景 4K）、倒角、接触阴影、AgX 色彩管理（Base Contrast）、足够采样、100% 查看细节、尺度参照（约 2 厘米的发条小飞虫、兰花、枯枝上的地衣）、防重复

**重模拟**：无（全部用骨骼、驱动器、约束、几何节点和粒子系统）

## 类目与标签

**归类理由**：主体是一只以高冠变色龙为原型、机械朋克外观的原创四足机器人，在温室枝头锁定、弹舌、捕虫、变色，属于本 skill 机器人类目里的仿生机器人/四足机器人。

| 标签组 | 选定标签 | 必要说明 |

| 视觉造型 | 写实 | 按写实电影的质感做的黄铜机械和温室 |
| 材质质感 | 金属、玻璃透明、织物皮革 | 主材质是黄铜和发蓝钢；其次是彩色玻璃鳞片；皮革护套和吸盘 |
| 渲染风格 | 真实渲染 | 常规物理渲染 |
