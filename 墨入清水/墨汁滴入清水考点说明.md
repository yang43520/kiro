# 墨汁滴入清水考点说明

> 内部校验用，不交给制作方，不属于制作输入。

**主类目**：现象动画/液体流动/倾倒注入

**题目档位**：上限档（配方：单个 L4，附带 1 个 L2 和 2 个 L1）

**档位来源**：默认

**规范版本**：进阶版 1.5

**视觉基调**：东方意境

**耦合链**：同一缸水里，笔尖的墨珠拉长断开、钻进水里砸开小坑和涟漪，卷成往下走的涡环；涡环下沉失稳、裂成小墨环和墨丝，后一滴的墨环钻进前一朵的尾迹追上去缠住；墨带起的水流卷住金箔让它翻身，离壁最近的那朵被玻璃挡住、贴壁卷开，不穿过玻璃；最细的墨丝化开，上半缸被染成淡灰，纸屏透来的逆光随云明暗，镜头一镜到底跟着这条链走。

| 编号 | 考点 | 分级 | 作用对象与时段 | 在片中的体现 |
|---|---|---|---|---|
| 13 | 破碎崩解与离散粒子 | L4 | 三滴墨、墨环、墨丝、金箔和气泡，0–12 秒 | 4 毫米的墨珠拉出细颈断开、钻进水里；涡环沉到四五厘米后失稳，裂成 4–6 个小墨环和一根根墨丝；5 片金箔和几十颗 0.5 毫米的气泡作为离散物被流场带着翻身、上升 |

**最高分级**：L4

## 制作底线清单

**二级类目**：液体流动

**技术模块**：T3（另用 T4 的体积做法、T9 的粒子做法）

**本片要用的专业术语**：FLIP 液体模拟、模拟域与分辨率、网格化液面、表面张力、黏度、二次粒子、折射率、体积吸收、焦散、动态绘画波纹、烟雾模拟、涡度、体积散射、空气透视、物理天空、粒子系统、生命周期、实例化、力场、形态键、多边形建模、支撑边、细分曲面、曲线绕轴旋转、曲线毛发、体素重构网格、雕刻、实体化修改器、骨骼、二级摆动

**推荐插件**：Mantaflow 液体与烟火（内置）、动态绘画（内置）、几何节点（内置）

**通用底线**：PBR 贴图或程序化纹理（近景 4K）、倒角、接触阴影、AgX 色彩管理（Medium Low Contrast）、足够采样、100% 查看细节、尺度参照（毛笔、砚台）、防重复

**重模拟**：液体模拟（只包住墨珠落点和那一小块水面）、烟雾模拟（只包住水缸里面，做墨的翻卷和缠绕）

## 类目与标签

**归类理由**：主角是滴进一缸静水里的墨汁，展示墨滴注入水中后翻卷、下沉、碎裂和化开的液体流动过程，没有具体商品，属于液体流动里的倾倒注入。

| 标签组 | 选定标签 | 必要说明 |
|---|---|---|
| 视觉造型 | 写实 | 真墨真水的照片级写实 |
| 材质质感 | 液体冰晶、玻璃透明、金属 | 主材质是清水和墨；其次是玻璃水缸和金箔 |
| 渲染风格 | 真实渲染 | 常规物理渲染 |
| 动态节奏 | 自然流畅 | 按高速摄影放慢一倍，墨的翻卷和下沉都连贯舒缓 |
| 动画行为 | 主行为：物理与特效/流体粒子/液体 | 墨珠滴入、墨花在水中翻卷下沉 |
| 动画行为 | 辅助行为：物理与特效/流体粒子/烟火 | 墨在水里的涡旋和扩散用烟雾模拟的体积做 |
| 动画行为 | 辅助行为：物理与特效/流体粒子/粒子 | 金箔翻身和缸底气泡上升 |
| 动画行为 | 辅助行为：显隐与外观变化/材质变化/颜色渐变 | 清水被染成淡灰 |
| 灯光氛围 | 自然日光 | 午后天光透过纸屏的逆光 |
| 背景环境 | 完整场景 | 书房木桌、纸屏、砚台和毛笔完整搭建 |
| 色彩基调 | 低饱和柔和 | 米白、墨黑和暖灰，饱和度压得很低 |
| 时序结构 | 多段序列 | 墨珠坠下 → 墨花下沉 → 三滴相缠 → 贴壁卷开 → 一缸淡灰 |
| 复杂度等级 | 物理模拟 | 含液体模拟和烟雾模拟 |
| 应用场景 | 不填 | 没有明确的用途依据 |
