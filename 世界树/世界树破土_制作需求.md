# 世界树破土动画 · 制作需求

制作时同时提供「一、制作 Prompt」和完整的《世界树破土剧本》（见 `世界树破土剧本.md`）。「三、类目与标签」和「四、试做验收要点」不属于制作输入。

## 一、制作 Prompt

```text
使用 Blender 5.0.0 制作一条约 12 秒（允许 11–13 秒，不得少于 8 秒）的巨树生长动画，写实渲染风格，一镜到底。画面内容、动作和镜头以《世界树破土剧本》为准。

核心效果：日出时一片干涸龟裂的荒原上，一颗种子落进地面的裂缝。种壳裂开，根扎进土里，嫩芽顶开土块钻出地面；嫩茎迅速变粗、长出树皮，一边拧转一边拔高，根系像网一样爬过地面，把干裂的土块撑起、掀翻、碎裂，根系经过的地方长出一片向外扩散的绿地；主干分出主枝，树叶一簇簇长满树冠；最后满树开出粉白色的花，花瓣随风飘散。镜头从贴近种子的地面开始，跟着向上生长的树梢一边后退一边升高，同时绕树环绕，结束时整棵参天巨树完整地出现在画面中。树的生长是极度加速的，像压缩了数百年的延时摄影；风、尘土和花瓣的运动保持正常速度。

质感要求：
- 整体：以接近实拍纪录片的质感为目标，树、土地和植被都按真实的结构和材质来做。
- 树形：成树高约 80 米，主干粗壮、带扭转，底部有高大的板根和向四周爬开的地表根；主干分出主枝，主枝逐级分出次级枝和细枝，粗细自然变细；树冠由许多枝叶团块组成，团块之间有透光的空隙，不是实心的球或外壳。
- 树皮：有很深的纵向沟壑和扭转的纹路，老皮翘起、剥落，凹处带青苔；不能是光滑或纹理重复的表面。
- 树叶和花：树叶成簇长在枝梢，深浅不一，新叶偏嫩黄绿；花成簇长在枝梢；不能出现肉眼可辨的重复叶簇或复制的枝条。
- 土地：干涸龟裂的泥土裂成大小不一的土块，边缘微微翘起，裂缝里有细沙，散落碎石；土块被根系撑裂时有真实的碎裂、翻落和扬尘。
- 树下植被：青草、苔藓、低矮蕨类和零星野花组成的绿地，边缘不规则，沿根系和裂缝向外延伸得更远。
- 光影：日出的低角度暖光，土块和树投下长长的影子；侧光和逆光下嫩芽、新叶和花瓣边缘透光，飞扬的尘土被阳光照亮。
- 渲染：天空靠近太阳的部分不过曝，暗部仍能看清纹理；画面清晰锐利，没有因降噪过度、贴图精度低或采样不足造成的发糊、涂抹或噪点。

不可改变的内容：全片是一个连续镜头，中间没有剪辑或转场；生长按“种子落地 → 破土 → 主干拔高 → 分枝长叶 → 开花”的顺序进行，每个阶段连续衔接，没有跳变；根系撑裂地面的土块；绿地随根系向外扩散，绿地以外仍是荒地；树叶和花都长在枝梢；生长最快的部分始终在画面中；画面在花瓣仍在飘落、树叶仍在晃动时结束；结束时整棵树完整位于画面中。

可调整范围：剧本中的尺寸、距离、速度和时间都是参考值，可在保持比例和观感的前提下调整；各段时间点可以微调，但生长的顺序不变。树的具体形态、枝干的走向、叶形和花形、远处山脊的样子、镜头环绕的方向，都可以自行设计。

可选增强：树影在地面上扫过时，被遮住的晨雾颜色变冷；花瓣落在绿地上。

禁止：剪辑、转场或跳帧；出现人物、动物或任何人造物，或任何文字和标志；照搬现有电影或游戏中的神树造型；出现发光、符文、光点等魔法效果；树或枝叶突然出现，而不是生长出来；树枝或树根穿过彼此或穿过地面；生长停住或倒退；明显的建模感，如光滑无细节的大块表面、塑料感的高光、肉眼可辨的重复复制物体或重复贴图；镜头突然加速、急停或抖动；用停帧或重复片段凑时长；画面闪烁、破面或非设计性的卡顿。

输出规格：16:9，1280×720，30 帧/秒，无声音。最终输出一条完整的动画视频。
```

## 三、类目与标签

**主类目**：场景动画/自然环境/森林植被

**归类理由**：
- 本片表现的是一片荒原上长出巨树和绿地的自然景观变化，主体是树木和植被，属于「自然环境」，纳入范围明确包含“森林植被”。
- 分类表规定“单棵植物生长讲解→科教演示 或 图形动画”。本片不做讲解或示意，生长的结果是一整片带巨树和绿地的环境，所以不按这一条归类。
- 画面写实，没有发光、符文、法阵等魔法元素，不选「幻想世界/魔法场景」。

| 标签组 | 选定标签 | 必要说明 |
|---|---|---|
| 视觉造型 | 写实 | |
| 材质质感 | 木石天然 | 树皮、泥土和碎石占画面的大部分；树叶、花和青草没有对应的材质标签 |
| 渲染风格 | 真实渲染 | |
| 动态节奏 | 自然流畅 | 生长、镜头后退和升高都是平滑的连续运动 |
| 动画行为 | 主行为：形变与生长/生长展开/植物生长 | 种子发芽、拔高、分枝、长叶和开花 |

| 应用场景 | 不填 | 没有明确用途依据 |

根系沿地面爬开对应“形变与生长/生长展开/路径延伸”，受动画行为最多 4 个的上限所限，不单独列出。
