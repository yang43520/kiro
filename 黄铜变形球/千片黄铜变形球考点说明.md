# 千片黄铜变形球考点说明

> 内部校验用，不交给制作方，不属于制作输入。

**主类目**：产品动画/工业设备/机械传动

**题目档位**：上限档（配方：L3 + L2，附带 2 个 L1）

**档位来源**：默认

**规范版本**：进阶版 1.9

**视觉基调**：产品广告

**耦合链**：同一颗变形球：约 1,200 片鳞片从北极开始按纬度相位一圈圈翻开，每片冲过约 5° 再弹回停住，露出冷银背面和发蓝骨架；中轴里的丝杠一转，南北轮毂往中间收拢，24 根剪式连杆骨架一齐撑开，鳞片跟着节点散开，球展开成直径约 40 厘米的扁冠；冠心三层齿轮环由中轴经伞齿轮带动、各自绕不同的轴转，钢珠映出整圈鳞片；丝杠反转，骨架收回，鳞片从南极往北极一圈圈合上；扫光和钢珠里的倒影在镀金和钢上流转，镜头一镜到底跟完全程。

| 编号 | 考点 | 分级 | 作用对象与时段 | 在片中的体现 |
|---|---|---|---|---|
| 6 | 次级跟随与惯性滞后 | L3 | 约 1,200 片鳞片，2–4.5 秒、10–12 秒 | 每片鳞片翻到位时冲过约 5° 再弹回停住，合上时轻轻一磕再停；回弹跟着波前一圈圈传过去 |
| 14 | 集群协同与波浪相位差 | L2 | 约 1,200 片鳞片，2–4.5 秒、10–12 秒 | 鳞片按纬度错开相位，翻开的波从北极传到南极，合上的波从南极传回北极；同一圈里再按骨架编号带一点随机错开 |
| 16 | 光影流转与材质外观演变 | L1 | 镀金鳞片、钢珠和背景光斑，0–12 秒 | 扫光让镀金鳞片一片片亮过去；翻鳞时暖金变成冷银和蓝紫；钢珠里的倒影跟着齿轮环流动 |
| 17 | 单镜头运镜构图 | L1 | 镜头，全片 | 一镜到底：中心构图 → 对角线 → 对称 → 层次纵深 → 负空间 |

**最高分级**：L3

## 制作底线清单

**二级类目**：工业设备

**技术模块**：T6（另用 T9 的粒子做法）

**本片要用的专业术语**：硬表面建模、倒角修改器、加权法线、几何节点、实例化、浮点曲线、二级摆动、相位差、父子级绑定、驱动器、剪式连杆、丝杠、齿轮传动比、伞齿轮、各向异性、拉丝金属、环境光遮蔽、折射率、粒子系统、湍流力场、生命周期、运动模糊、灯光树

**推荐插件**：Extra Mesh Objects（内置扩展）、MACHIN3tools（开源）、Bool Tool（内置扩展）

**通用底线**：PBR 贴图或程序化纹理（近景 4K）、倒角、接触阴影、AgX 色彩管理（Medium High Contrast）、足够采样、100% 查看细节、尺度参照（台面上一片约 8 × 6 毫米的鳞片、直径约 8 毫米的黄铜中轴）、防重复

**重模拟**：无（鳞片用几何节点，骨架和齿轮环用驱动器，浮尘用粒子系统）

## 类目与标签

**归类理由**：主体是一颗由丝杠、剪式连杆和齿轮环驱动、上千片鳞片联动开合的黄铜机械摆件，展示的是机械结构的展开、收回和传动，归到工业设备里的机械传动。

| 标签组 | 选定标签 | 必要说明 |
|---|---|---|
| 视觉造型 | 写实 | 照片级写实的金属摆件和黑棚 |
| 材质质感 | 金属、木石天然 | 主材质是镀金、拉丝钢、发蓝钢和抛光黄铜；其次是大理石底座 |
| 渲染风格 | 真实渲染 | 常规物理渲染 |
| 动态节奏 | 机械节奏 | 丝杠、剪叉和齿轮按几何关系和传动比联动 |
| 动画行为 | 主行为：结构与装配/开合联动/机械传动 | 丝杠带动剪式连杆和齿轮环 |
| 动画行为 | 辅助行为：结构与装配/开合联动/打开翻盖 | 鳞片翻开和合上 |
| 动画行为 | 辅助行为：位移与运动/规律运动/旋转 | 球自转、齿轮环转动 |

| 背景环境 | 无缝影棚 | 近黑背景和大理石底座 |
| 色彩基调 | 不填 | 颜色来自材料本身 |
| 时序结构 | 多段序列 | 合球 → 翻鳞 → 撑开 → 冠心 → 收拢 |
| 复杂度等级 | 多元编排 | 约 1,200 片鳞片的几何节点相位编排和剪式连杆驱动器联动，不含模拟 |
| 应用场景 | 不填 | 没有明确的用途依据 |
