# 飞书大图书馆考点说明

> 内部校验用，不交给制作方，不属于制作输入。

**主类目**：场景动画/幻想世界/魔法场景

**题目档位**：上限档（配方：单个 L4，附带 1 个 L2 和 1 个 L1）

**档位来源**：默认

**耦合链**：同一批书上，铜轨的光按路程依次到达每本书，书按光到达的顺序依次离架（相位波），离架后书页在扇动中翻卷起伏、落位时收拢压平；书群盘旋带起的风又掀起散页；镜头从近景升起、绕行，最后退到书塔前。

| 编号 | 考点 | 分级 | 作用对象与时段 | 在片中的体现 |
|---|---|---|---|---|
| 12 | 薄面垂坠与绳索悬挂 | L4 | 书页、散页、丝带书签，2–12 秒 | 书页随封面扇动一片片翻卷起伏，边缘透光；散页被风掀起在空中翻转弯曲；书落位时书页一层层收拢压平；塔顶大书书页慢慢翻过两三页停下；丝带书签拖曳和余晃 |
| 14 | 集群协同与波浪相位差 | L2 | 约 5,000 本书，2–10 秒 | 书按铜轨光到达的时间再晚约 0.1 秒依次离架，从顶层往下、沿环形一圈圈传开；书群保持间距、不重叠地逆时针盘旋，再收拢落位 |
| 17 | 单镜头运镜构图 | L1 | 镜头，0–12 秒 | 从阅读桌后近景前推、上抬，升到 6 米随书群绕行约 60°，再退到书塔前 12.5 米处，书塔占画面高度约八成，无剪辑 |

**最高分级**：L4

## 制作底线清单

**二级类目**：幻想世界

**技术模块**：T1、T4、T10（另借用 T5 的建筑做法、T8 的布料做法）

**本片要用的专业术语**：模块化建模、阵列修改器、几何节点实例化、雕刻、多重分辨率细分、置换修改器、三平面投影贴图、体积光、体积散射、局部体积雾、自发光强度、IES 灯光、光度单位、辉光阈值、粒子拖尾、布料模拟、曲率遮罩、环境光遮蔽、次表面散射

**推荐插件**：几何节点（内置）、Bloom 辉光（内置）、Archimesh（内置）、Building Tools（开源）

**通用底线**：PBR 贴图或程序化纹理（近景 4K）、倒角、接触阴影、AgX 色彩管理、足够采样、100% 查看细节、尺度参照（阅读桌、木梯、单本书）、防重复

**重模拟**：布料模拟（只用在近景约 40 本书、散页和塔顶大书上，中远景书页用形态键和骨骼）

## 类目与标签

**归类理由**：主体是整座图书馆和在里面发生的魔法事件（书自己飞起、盘旋、筑塔），属于幻想世界里的魔法场景。

| 标签组 | 选定标签 | 必要说明 |
|---|---|---|
| 视觉造型 | 写实 | 照片级写实，真实比例和材质 |
| 材质质感 | 纸艺、织物皮革、木石天然 | 主材质是书页的旧纸；其次是皮革封面，以及胡桃木书架和石砖地面 |
| 渲染风格 | 真实渲染 | 常规物理渲染 |
| 动态节奏 | 自然流畅 | 扇动、盘旋和落位都带缓入缓出 |
| 动画行为 | 主行为：位移与运动/群体运动/群集 | 约 5,000 本书汇成书群盘旋，是全片的核心事件 |
| 动画行为 | 辅助行为：物理与特效/柔性运动/布料 | 书页和散页用布料模拟翻卷 |
| 动画行为 | 辅助行为：形变与生长/生长展开/逐步生成 | 书塔从下往上逐本搭成 |
| 动画行为 | 辅助行为：显隐与外观变化/材质变化/发光亮灭 | 星盘和铜轨按顺序亮起 |
| 灯光氛围 | 夜景月光 | 冷色月光主光加烛光点光源 |
| 背景环境 | 完整场景 | 七层回廊、穹顶和中庭完整搭建 |
| 色彩基调 | 不填 | 冷月光和暖烛光对比，没有单一的色彩基调 |
| 时序结构 | 多段序列 | 月照星盘 → 光沿铜轨 → 书群盘旋 → 筑塔 → 书塔成形 |
| 复杂度等级 | 物理模拟 | 含布料模拟，且有约 5,000 个对象的群组 |
| 应用场景 | 不填 | 没有明确的用途依据 |
