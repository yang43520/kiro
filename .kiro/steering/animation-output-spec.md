# 动画制作需求：默认输出规格

自 2026-11-15 起，新写的动画剧本、制作 Prompt 和效果图统一使用以下规格：

- 分辨率：1280×720（720P），横屏 16:9。
- 帧率：30 帧/秒。
- 剧本「基本设定」、Prompt「输出规格」和验收表中的分辨率、帧率要写成同样的数值，例如“16:9，1280×720，30 帧/秒，无声音”。
- 用 Blender 渲染效果图时，默认也按 1280×720 出图。

已有的任务文档（浑天仪、陀飞轮、无人机、赛博朋克雨夜俯冲、悬浮山入夜）仍保留原来的 1920×1080，除非用户要求修改。
