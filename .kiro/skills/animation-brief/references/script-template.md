# 剧本模板

文件名：`<标题>剧本.md`（不带版本号），UTF-8 带 BOM。剧本里只写画面内容，不写标签、类目或验收内容。

```markdown
# <标题>剧本

## 基本设定

- 时长约 12 秒（30 帧/秒下约 360 帧），单一连续镜头，一镜到底，中间没有任何剪辑。
- 横屏 16:9，1280×720，30 帧/秒。
- 写实渲染，无声音。
- 场景按真实尺寸搭建，单位为米。下文中的尺寸、角度、数量、速度和时间都是参考值，用来说明比例、布局和节奏。
- 画面以接近 <实拍纪录片 / 电影实拍加视效> 的质感为目标。<主体> 和 <场景> 都按真实的结构和材质来做，不能有 <建模感 / 玩具感 / 塑料感>。
- <其他全局规则，例如：运动符合真实重量感；不发生碰撞、爆炸；造型原创>

## 整体画面

### 场景：<场景名>

- <空间、尺寸、地面、天气、时间>
- <远景与氛围>
- 画面中没有人物、文字或标志。

### 主体：<主体名>

**<形态一 / 开场状态>**

- <尺寸、造型、材质、颜色、细节>

**<形态二 / 结束状态>**

- <……>

### 光影与色彩

- <光源从哪来、主色、反射、光晕>
- 曝光：<亮部不过曝；暗部仍能看清纹理>
- 清晰度：画面清晰锐利，<主体> 的细节都能看清；不能因为降噪过度、贴图精度低或采样不足而发糊、出现涂抹感或噪点。

## 动作展开

### 段落与时间节点（时间为参考）

| 段落 | 时间 | 主要动作 |
|---|---|---|
| <段落一> | 0–3 秒 | <……> |
| <段落二> | 3–6 秒 | <……> |
| <段落三> | 6–9 秒 | <……> |
| <段落四> | 9–12 秒 | <……> |

### 分段动作

**1. 约 0–3 秒，<段落一>**

- 第一帧 <主体或镜头> 已经在运动。
- <具体动作，带时间点和数字>

**2. ……**

**4. 约 9–12 秒，<段落四>**

- <……>
- 画面在 <主体仍在运动> 时结束。

## 镜头

单一连续镜头，一镜到底，中间没有剪辑，也没有转场。

- **路径**：<开场位置、高度、距离 → 中段 → 结束位置>
- **速度**：第一帧已在移动。<快慢变化>，全程没有突然加速或急停。
- **构图**：<最重要的动作始终在画面中；结束时主体占画面的比例>
- **镜头感**：相当于 <24/28/35> 毫米镜头。
- **平稳度**：没有抖动。
- **景深**：<……>
```

## 写作要点

- 每个数字都要前后一致，例如时间节点表、分段标题和镜头说明里的秒数要对得上。
- 用"约 X 秒"标时间点，方便验收时定位。
- 结尾必须停在仍在运动的时刻，不能停在静止画面。
- 涉及空间关系的地方（谁在谁的前方、镜头从哪边超过），要检查前后逻辑是否成立。
