# 画面丰富度与动态形式（最低要求）

目标：画面元素足够丰富、动态形式足够多，同时主次清楚、每个动态都有来源。下面的数字是**最低要求**，创意阶段和写文件时都要逐条满足。

## 一、画面元素

### 写实类（角色、场景、载具、现象、科教）

1. **三层空间**：前景、中景、远景各至少 2 类元素，写清它们的位置、尺寸和数量。前景元素用来制造纵深和视差，远景用来交代环境和尺度。
2. **主题元素不少于 8 类**：都要和题材有关，例如海上题材有浪、冰、船、鸟群、鱼群、远山、天空、极光。每类写数量、尺寸、颜色和状态，不写"一些""若干"。
3. **至少 1 个尺度参照**：人造物、动植物或载具，让大小一眼可辨。
4. **主体细节分三层**：大形 → 部件和结构 → 小细节（纹理、磨损、接缝、附着物），近景时第三层必须看得见。
5. **故事细节 5–10 个**：能体现这个地方和时间的小东西，例如船舱里的油灯、冰上的鸟、木桩上的缆绳。
6. **材质不少于 4 种**，彼此的反射、粗糙度和透明度明显不同。

### 产品类

丰富度主要放在产品身上：结构分层（外壳 → 内部组件 → 小零件）、材质不少于 4 种、展示过程不少于 2 种（例如拆解 + 功能运行）。环境只放支撑产品的展台、灯光和少量辅助元素，不要把背景堆满。

### 图形类

元素分组不少于 3 组，层级不少于 3 级（主图形、辅助图形、背景纹理），每组有自己的运动规则，彼此之间有跟随或触发关系。

## 二、动态形式

### 分类表

| 代号 | 动态形式 | 例子 |
|---|---|---|
| A | 主体位移与轨迹 | 冲出水面、沿弧线爬升、过弯 |
| B | 主体形变 | 鳍变成翅膀、挤压拉伸、生长 |
| C | 部件联动与相对运动 | 车轮转动、齿轮咬合、开合、组装 |
| D | 次级跟随 | 尾巴、须、披风、吊坠的滞后和余摆 |
| E | 液体 | 水幕、飞溅、浪、涟漪 |
| F | 烟雾气体 | 烟、蒸汽、水雾、翼尖涡流 |
| G | 粒子与离散物 | 水珠、火花、落叶、雪、灰尘 |
| H | 布料、柔体与绳索 | 旗、帆、纸垂、缆绳 |
| I | 刚体碰撞 | 碎块、冰块互碰、物体被撞倒 |
| J | 群集 | 鸟群、鱼群、车流、阵列波浪 |
| K | 光影变化 | 光扫过、闪光、昼夜变化 |
| L | 材质外观变化 | 湿变干、发光、结冰、褪色 |
| M | 环境响应 | 主体引起的水波、扬尘、压弯的草、被惊起的动物 |
| N | 氛围持续动态 | 云、风、极光、远处的烟、摇曳的灯 |

镜头运动不算在动态形式里。

### 最低要求

1. **不少于 6 种动态形式**（不计镜头），并且下面四层每层至少 1 种：
   - 主体主动作层（A、B、C 之一）：主体自己的位移、形变或部件运动；
   - 次级层（D 或主体身上的 G、E）：跟着主体动作产生的滞后、甩出、滴落；
   - 环境响应层：**至少 2 个**由主体动作直接引起的环境变化（M，或被主体触发的 E、F、I、J）；
   - 氛围层（N 或 K）：持续存在、低调的背景动态，让画面不死板。
2. **每种动态都写出来源和时间**："谁引起的、第几秒开始、怎么变化、怎么结束"。不能有各动各的、和事件无关的效果。
3. **每 2–3 秒至少一个新变化**：新动作、新事件、新的光影变化或新的环境响应。不能有超过 3 秒没有新信息的段落。
4. **因果链至少 3 环**：起因 → 主体动作 → 环境响应 → 结果，前一环直接引起后一环。

## 三、防止堆叠

丰富不等于堆满，验收会扣"效果堆叠淹没内容"：

- 关键时刻主体在画面里要够大，一般不小于画面宽度的三成；
- 氛围层的亮度和密度低于主体，不能抢视线；
- 烟、雾、粒子、水花不能遮住关键接触、关键形变和最终结果；
- 关键过程不能出画，也不能被景深或运动模糊掩盖；
- 灯光不能过曝或眩光，暗部仍能看清结构。

## 四、在创意表里怎么写

"画面元素"一列按"前景：…；中景：…；远景：…"写，每层 2–3 个，并标出尺度参照。

"动态形式"一列按代号列出，并把主动作放在最前，例如：

> B 鳍化翼与鳞化羽（主动作）、A 出水爬升、D 须与尾羽余摆、E 水幕水帘、M 下压环形波纹与鸟群惊飞、I 碎冰互碰、L 湿鳞变干羽、K 晨光扫过、N 极光飘动。
