# 成片验收标准（写 Prompt 时必须提前落实）

> 来源：项目的动画成片验收标准（2026-11-21 收录）。成片按这份标准验收，rubric.json 也按它来写。写创意和 Prompt 时，要让每一条"合格表现"都能在画面里看到，每一条"扣分表现"都在 Prompt 里提前堵住。

## 一、所有类目通用

动画要围绕一个有**明确起因、发展过程和最终结果**的可视化事件展开：叙事逻辑清楚、因果衔接完整、动作自然可信、结果表达明确。光影、材质质感、场景丰富度和整体完成度是加分项；穿模、结构或接触关系不合理、动作错位或漂移、播放卡顿、因果逻辑断裂是重点扣分项。

| 维度 | 合格表现 | 扣分表现 | 写 Prompt 时怎么落实 |
|---|---|---|---|
| 主体与目标 | 必要主体、数量、识别特征和核心结果符合要求 | 主体被替换、关键对象缺失、结果没出现或被别的效果代替 | 写清主体数量和识别特征；结果写成一个能看见的终态 |
| 时长 | 在约定区间内，通常 8–12 秒，必要时约 15.6 秒，不少于 8 秒 | 超出区间 | 开头写目标时长和允许区间 |
| 主体自身运动 | 主体真的发生位移、旋转、形变或部件相对运动 | 主体静止，只靠镜头、剪辑或亮灭制造动态 | 主动作必须是主体自己的动作 |
| 动作完整性 | 关键动作、先后或并行关系、结束状态完整可见 | 缺动作、顺序错、跳过关键过程、没做完就结束 | 按秒写每个动作；结尾留 1–1.5 秒展示结果 |
| 动作逻辑与质量 | 起因、交互、运动方向和变化规则自洽 | 抽搐、滑步、乱跳、错位、无依据的速度或方向突变 | 每个变速、转向都写出原因；用缓入缓出 |
| 接触与空间关系 | 接触、支撑、遮挡、连接和间距稳定可信 | 明显穿透、连接脱开、错误接触、无依据悬空 | 每个关键接触写"对准、贴住、不能穿" |
| 造型及视觉一致性 | 特征、材质、配色、光影和风格连续一致，设计性变化有依据 | 无故换形、部件消失、材质突变、亮度跳变 | 设计性的变化写清起止时间和原因 |
| 画面完整与清晰 | 无明显破面、闪烁、噪点、模糊 | 核心轮廓破损、大面积闪烁、关键细节看不清 | 写采样、降噪、清晰度要求 |
| 构图与镜头 | 主体、关键动作和结果清楚可见，镜头服务于表达 | 关键过程出画、被遮挡、被景深或运动模糊掩盖、切镜回避动作 | 写清关键时刻主体在画面中的位置和大小 |
| 灯光、材质与呈现 | 材质特征可辨，明暗和色彩层次支持主体 | 材质与要求相反、强光或黑影遮住主体、效果堆叠淹没内容 | 写主光方向、曝光基准和防眩光要求 |
| 节奏与有效时长 | 动作有发展和结果展示，停顿有表达作用 | 长时间无意义停帧、重复填充，或太快看不懂 | 每 2–3 秒至少有一个新变化 |
| 规格与参考 | 画幅、分辨率、帧率和参考要求都满足 | 规格不符，遗漏要保留的参考内容 | 规格全文统一；参考保留项逐条写出 |

场景动画的"主体"可以是场景本身和它的核心动态；现象动画的"主体"可以是液体、烟雾、粒子等效果。

## 二、按一级类目的专项标准

每条任务按类目树选一个三级主类目，执行所属一级类目的标准。

### 2.1 角色动画（幻想生物、动物、拟物角色、简易人形）

看造型完整、行为可读、动作连贯和基本表演感。不能用整体平移、旋转或机械摆动代替角色表演。

| 维度 | 合格表现 | 扣分表现 |
|---|---|---|
| 造型与完整度 | 身份清楚，轮廓、比例、必要肢体和识别特征完整 | 肢体缺失、拼接突兀、比例失衡、难以识别 |
| 造型与风格一致性 | 运动中面部、身体、服饰和关键特征稳定 | 无故换脸、肢体增减、服饰消失、风格割裂 |
| 行为清楚且完整 | 一看就懂在做什么，起动、过程和结束状态清楚 | 要跳却只是整体上下平移，动作没做完就结束 |
| 身体协调与衔接 | 相关部位协调参与，姿态转换连续 | 单个肢体机械转动，躯干四肢不配合，突跳、关节扭曲 |
| 重心、支撑与交互 | 行走、跳跃、落地、抓取有可信的支撑和接触 | 滑步、脚穿地、没碰到就拿起、无依据悬空 |
| 基本表演与生命感 | 姿态、节奏、朝向或表情体现意图和状态，有主动性 | 像被外力拖动的模型，看不出意图 |
| 形变与附属部位 | 挤压拉伸回弹符合风格；尾巴、耳朵、翅膀与主动作协调 | 身体塌陷、拉断，附属部位穿插或脱离 |
| 镜头与成片呈现 | 关键姿态和接触清楚，画面稳定统一 | 镜头遮住关键肢体，特效掩盖表演 |

写法要点：写出角色的**意图**（它想做什么、对什么做出反应）；起动前要有预备动作；附属部位写二级跟随；每个支撑和接触写清。

### 2.2 产品动画（消费电子、家居日用、美妆配饰、食品饮料、工业设备）

看产品精细度、展示充分性和商业呈现。除非明确是转台展示，必须有**至少一种超出整体旋转或运镜的展示过程**：开合、拆解、组装、功能运行、内部显露、使用过程或材质变化。

| 维度 | 合格表现 | 扣分表现 |
|---|---|---|
| 造型与精细度 | 比例、轮廓、关键部件和连接结构准确，近景经得起看 | 基础几何体拼装感、结构缺失、放大后没细节 |
| 材质与表面 | 金属、玻璃、塑料、织物等差异可辨 | 材质都一样、透明件浑浊、金属像塑料 |
| 展示充分性 | 有旋转之外的有效展示 | 只有旋转、平移、缩放或环绕 |
| 卖点表达 | 有明确重点，整体—局部—过程层层递进 | 动作多却看不懂展示什么，重复展示外观 |
| 结构与动作可信 | 开合、拆装符合结构，最终状态清楚 | 零件乱散、互穿、组装错位、靠替换跳过过程 |
| 灯光与商业呈现 | 灯光塑造体积和材质，氛围统一精致 | 平光、反射杂乱、过曝、特效喧宾夺主 |
| 镜头与节奏 | 景别服务卖点，关键细节有观看时间 | 单一角度、无意义绕行、太快或没展示完 |
| 一致性与收尾 | 造型材质全程稳定，结尾有清楚的产品终态 | 无故变形、部件消失、没展示完就结束 |

案例：耳机只有升降、旋转和变色，结构细节、材质层次和重点特写不足，算精细度与展示深度不足。

### 2.3 场景动画（建筑空间、自然环境、城市街景、幻想世界、微缩模型）

看场景建设的完整度、丰富度和整体视觉完成度。不能只是一个简单主体加通用背景。

| 维度 | 合格表现 | 扣分表现 |
|---|---|---|
| 建设完整度 | 主体、周边环境和配套内容共同成立，有场所感 | 一个简单主体加通用地面、水面或天空 |
| 内容丰富度 | 有足够的结构、环境元素和细节可看 | 内容单一，大面积重复纹理 |
| 主体与局部细节 | 主要对象有内部结构和部件 | 只有基础几何外形，近处粗糙空泛 |
| 空间层次与布局 | 前后景、尺度、疏密、遮挡、明暗形成纵深，有主次 | 元素挤在同一平面，或堆满却杂乱 |
| 材质、光影与氛围 | 材质可辨，光影支持空间和重点，氛围明确 | 材质单调、平光或高光过强 |
| 整体融合 | 尺度、风格、精细度和接触关系协调 | 拼贴感、精细度悬殊、突兀悬空或穿插 |
| 基础动态与展示 | 有与主题相符的自然动态，镜头充分展示场景 | 场景完全静止，只靠运镜 |

案例：只有海面、天空和一个救生圈，主题细节和空间层次不足，算场景建设单薄。

### 2.4 载具动画（陆地、水上、航空航天、幻想载具）

看运行行为完整、运动姿态可信、载具与环境协调。不能用静态陈列、原地旋转或运镜代替运行。

| 维度 | 合格表现 | 扣分表现 |
|---|---|---|
| 识别与结构 | 类型、比例、轮廓和关键部件清楚，运动中稳定 | 轮组、机翼、船体缺失，运动中散架 |
| 运行过程完整 | 行驶、转向、起降、航行等清楚完成 | 原地旋转；转弯只有车身转没有路径变化；起飞跳过离地 |
| 路径与姿态协调 | 位置、朝向、速度、姿态互相匹配，有重量感 | 横滑、瞬移、突然翻转、方向与朝向矛盾 |
| 部件联动 | 车轮、履带、旋翼、螺旋桨与运行状态协调 | 行驶时车轮不转或不匹配 |
| 与环境关系 | 接地、浮航、离地、接触可信 | 车轮穿路、船穿岸、无依据悬浮 |
| 动态响应与辅助效果 | 起伏、侧倾、摇摆协调；尾迹、水花、扬尘、喷焰来源和方向合理 | 姿态不响应环境；尾迹脱离主体；特效遮住运行 |
| 功能部件 | 舱门、起落架等按需完成动作，时机合理 | 穿插、脱开、终态错误、时机矛盾 |
| 镜头与呈现 | 交代形态、路径和环境关系 | 镜头炫但看不懂方向，长期只拍局部 |

### 2.5 图形动画（文字标志、几何图形、抽象形态、信息可视化、界面图标）

看设计完成度、运动编排层次和变化规则清晰度。不能只靠一种基础动作重复撑满全片。

| 维度 | 合格表现 | 扣分表现 |
|---|---|---|
| 设计与完成度 | 轮廓、配色、排列、间距、比例统一设计，有视觉重点 | 随意堆放，配色间距无组织 |
| 运动编排层次 | 错时、递进、聚散、组合、形变形成有组织的发展 | 全程同一种平移、旋转、缩放或起伏 |
| 变化规则与关系 | 跟随、传播、触发、组合关系清楚，服务同一逻辑 | 各动各的，先后混乱，特效和主体无关 |
| 节奏与重点 | 快慢、停顿、错时、幅度有安排，有推进感 | 机械匀速、全部同步，或太快太密 |
| 形态转换质量 | 生成、拆分、重组、形变连续清楚 | 直接切换前后状态，断裂、错位、闪烁 |
| 结果与信息准确 | 目标形态、文字、标志、数据准确出现并看得清 | 过程热闹但目标没形成，看清前就消失 |
| 呈现与循环 | 光效支持图形，循环首尾自然 | 光效掩盖轮廓，循环跳变，靠停顿填时长 |

案例：整段只围绕一次波浪传播，缺少进一步的形态转换和节奏发展，算运动编排单一。

### 2.6 现象动画（液体、烟火气体、布料软体、破碎碰撞、粒子群集、光效能量）

现象的发生、发展和结果清楚，时空连续，与环境的关系自洽，材质和动态特征可辨。

| 维度 | 合格表现 | 扣分表现 |
|---|---|---|
| 现象与结果 | 效果类型正确，触发、发展、结果或持续状态清楚 | 要飞溅却只有静止水面；只展示连锁的终态 |
| 时间连续性 | 流动、扩散、变形、聚散可连续追踪 | 无故重置、跳帧、整块消失或换形 |
| 接触、碰撞与边界 | 液体与容器、布料与支撑、碎块与地面关系可信 | 流体穿壁、布料穿透、碎片沉进地面 |
| 动态与质感 | 形态和运动符合目标材质 | 布料像硬板平移，黏稠物没有黏稠特征 |
| 传播与相互作用 | 波纹、冲击、连锁、群体、能量的方向和先后成立 | 波纹与触发点脱离，没碰就连锁 |
| 密度与可读性 | 轮廓层次可辨，密度服务任务 | 粒子遮住形态，烟火遮住交互，光效过曝 |
| 后续状态 | 汇聚成形、落稳、回弹、消散等结果出现 | 结果没完成或偏离要求 |

### 2.7 科教演示（天文宇宙、微观结构、物理原理、地理地貌）

看知识准确、关键关系可观察、解释过程完整。不能只让模型旋转、漂浮或发光。

| 维度 | 合格表现 | 扣分表现 |
|---|---|---|
| 对象与必要结构 | 组成、层次和关键结构完整 | 只有概括外形，关键组成错误 |
| 科学准确性 | 运动方向、结构、因果和规律正确 | 自转公转混淆，传播方向错，因果颠倒 |
| 知识目标与重点 | 看得出在说明什么，重点突出 | 只是旋转发光，看不出要说明什么 |
| 关键过程与关系 | 展示发生、发展和结果，能追踪变化 | 只展示外观或终态，跳过过程 |
| 演示方法 | 用剖切、分层、放大、对比、轨迹让关系看得清 | 核心结构藏在里面，运镜多却没帮助理解 |
| 辅助标识 | 有需要时用箭头、颜色、引导线准确指示 | 标识指错，颜色对应混乱 |
| 节奏与完整度 | 速度和停留支持观察，在时长内完成目标 | 太快看不懂，重复运动占主要时长 |

本项目默认不出现可读文字，科教类用箭头、颜色和引导线做辅助标识；用户要求时才加文字标签。案例：固定视角只展示地球自转，缺少多角度、景别变化和细节，算展示维度单一。
