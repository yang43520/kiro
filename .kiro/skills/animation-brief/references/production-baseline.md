# 制作方法底线、专业术语与推荐插件（按动画类型）

用途：写写实类任务时，从对应类型里挑出"制作方法底线"，用"专业术语"写进 Prompt 的重点效果要求和"另外"一段；"推荐插件与素材"在用户确认制作环境可以使用插件或素材库后，用一句"可借助……等插件或素材库"写进"另外"一段。

规则：
- 只写画面、方法和效果，可以用专业术语，不写代码、API 名或属性名。
- 插件名可以写，但只能作为"可借助"的建议，不能写成必须安装的前提；同类工具可以替换。
- 插件和 Blender 5.0.0 的兼容性、商业插件的授权、素材的许可证（CC0、CC BY 等）都要由制作方自行确认。下表中的"内置"指 Blender 自带或官方扩展平台（extensions.blender.org）上的扩展。

---

## 通用底线（所有写实任务）

- **禁止基本几何体拼凑**：主体和主要道具不能用立方体、圆柱、球体、圆锥加噪波拼出来；要有真实的结构分件、倒角和厚度。
- **细节密度**：以 100% 尺寸查看画面中任意一块主体表面，都能看到可辨认的细节（纹理、颗粒、划痕、接缝、颜色变化），不能是大块的纯色平面。
- **尺度参照**：写清主体的真实尺寸，并给出一个画面里能对比的参照物（人造物、植物、车辆），让大小一眼可辨。
- **材质**：基于物理的材质（PBR），颜色、粗糙度、法线和置换贴图齐全；贴图分辨率与镜头距离匹配，近景用 4K 以上；大面积表面做防重复处理。
- **风化与使用痕迹**：按真实规律分布：边角磨损、凹处积灰、朝上的面积水渍、下沿溅泥。
- **灯光**：用 HDRI 或物理天空作环境光，再加有方向的主光；有接触阴影和间接反弹光。
- **成像**：AgX 色彩管理，曝光以主体为准；足够的采样再降噪，不能靠强降噪抹掉细节；按需要加景深和运动模糊。

**通用术语**：PBR 材质、法线贴图、置换贴图、粗糙度变化、环境光遮蔽、曲率遮罩（边缘磨损）、防重复贴图、HDRI 环境光照、物理天空、全局光照、接触阴影、AgX 色彩管理、景深、运动模糊、缓入缓出、运动曲线。

**通用插件与素材**

| 名称 | 类型 | 用途 |
|---|---|---|
| Poly Haven | 免费素材（CC0） | 扫描贴图、HDRI、模型 |
| BlenderKit | 插件 + 素材库（免费 / 付费） | 材质、模型、HDRI 直接拖进场景 |
| Quixel Megascans（通过 Fab） | 扫描素材（授权需确认） | 高精度岩石、地表、植物扫描 |
| Photographer | 商业插件 | 物理相机：曝光、白平衡、光圈 |
| Gaffer | 商业插件 | 灯光管理 |
| Camera Shakify | 免费插件 | 真实的手持和跟拍抖动 |

## 1. 自然地形与山岳

适用：云海奇峰、悬浮山、世界树（地面）、废墟巨人（地面）。

**制作方法底线**
- 山体用高精度地形网格，经过置换和侵蚀处理，有山脊、沟壑、断崖和碎石坡；或者使用真实的地形高度图、扫描岩石。
- 岩石有地质结构：花岗岩的竖向节理和石柱、砂岩的水平层理、风化剥落的块状面；不是一个个光滑的锥体或球体。
- 多层细节叠加：大形（山体轮廓）→ 中形（岩块、断层）→ 小形（裂隙、颗粒），三层都要看得到。
- 山峰之间相连成山脉，有前景、中景、远景三层，远景按空气透视变淡、偏蓝。
- 岩缝和峰顶有植被、碎石和积土，与岩体自然衔接，不是贴上去的。

**专业术语**：高度图地形、置换修改器、侵蚀模拟（水蚀、热蚀）、多重分辨率细分、雕刻、岩石节理、空气透视、三平面投影贴图、坡度遮罩（按坡度分配岩石和植被）。

**推荐插件与素材**

| 名称 | 类型 | 用途 |
|---|---|---|
| Infinigen | 开源（BSD-3） | 程序化生成照片级的山地、岩石、地表、云，含侵蚀 |
| A.N.T. Landscape | 内置扩展 | 噪波地形，带基础侵蚀 |
| World Creator、Gaea | 外部商业软件 | 专业地形与侵蚀，导出高度图和贴图 |
| Poly Haven、Megascans | 素材 | 扫描岩石模型和岩面贴图 |

## 2. 植物与植被

适用：世界树、中式庭院、自然街角、云海（古松）、锦鲤（荷叶）。

**制作方法底线**
- 树木由真实的分枝结构生成（主干 → 主枝 → 次枝 → 细枝），树冠是一片片单独的叶子组成的叶簇，有透光空隙；不能是球体堆或一整块外壳。
- 叶片有叶脉、正反两面颜色不同，逆光时透光（次表面散射）；颜色深浅不一，夹杂枯叶。
- 草和地被用散布系统铺满，高矮、朝向、颜色随机变化，密度按坡度、光照和路径变化。
- 生长动画按生长的先后逐步展开，不能整体放大。
- 随风摆动：枝干、叶片按柔韧度分层摆动，有相位差。

**专业术语**：分枝生成、几何节点散布、实例化、随机旋转与缩放、叶片次表面散射、半透明背光、风力场、二级摆动、生长遮罩、路径生长。

**推荐插件与素材**

| 名称 | 类型 | 用途 |
|---|---|---|
| Sapling Tree Gen | 内置扩展 | 参数化树木生成 |
| IvyGen | 内置扩展 | 藤蔓沿表面攀爬 |
| The Grove | 商业插件 | 按生长规律模拟真实树木，支持生长动画 |
| Botaniq | 商业素材插件 | 大量写实树木、灌木、花草，带风动画 |
| Geo-Scatter | 商业插件 | 大面积植被散布，按坡度、遮罩分布 |
| Poly Haven、BlenderKit | 素材 | 扫描植物模型和贴图 |

## 3. 水与液体

适用：锦鲤跃荷塘、中式庭院（水池）、水滴飞溅、溪谷水车、巨浪拍礁。

**制作方法底线**
- 飞溅、水幕、水柱用液体模拟生成连续的液面网格；不能用融球、粒子球或贴图拼出来。
- 模拟分辨率要足够：水幕边缘拉丝、破碎成水珠的过程能看清。
- 水珠、白沫、气泡由模拟生成的二次粒子产生，从液面上断开，不能凭空出现。
- 水的材质：透明、有折射和焦散，按水深吸收颜色；水面有细小的涟漪和倒影。
- 大面积水面用海洋或波纹置换，靠近物体的地方再叠加局部模拟。

**专业术语**：FLIP 液体模拟、模拟域与分辨率、网格化液面、表面张力、二次粒子（水花、泡沫、气泡）、焦散、体积吸收、海洋修改器、动态绘画波纹、折射率。

**推荐插件与素材**

| 名称 | 类型 | 用途 |
|---|---|---|
| Mantaflow 液体 | 内置 | 基础液体模拟 |
| 海洋修改器 | 内置 | 大面积波浪水面 |
| 动态绘画 | 内置 | 物体触水产生的涟漪 |
| FLIP Fluids | 商业插件 | 高质量液体模拟，含白沫、气泡、水花 |

## 4. 天空、云与大气

适用：云海奇峰、悬浮山、中式庭院（雨雪）、黑洞（星空）。

**制作方法底线**
- 云海、云层用体积云：有厚度、有内部散射、边缘有卷须；不能用平面贴图、半透明面片或棉花球。
- 云按真实的光照散射：逆光透亮、背光变暗、顶部受光、底部发暗。
- 天空用物理天空或 HDRI，太阳的方向、高度和颜色与场景主光一致。
- 雾只在需要时用，局部、稀薄，不能让整个画面发灰。

**专业术语**：体积散射、体积云、VDB 体积、物理天空（太阳高度、大气浊度）、多重散射、银边、空气透视、局部体积雾。

**推荐插件与素材**

| 名称 | 类型 | 用途 |
|---|---|---|
| 物理天空纹理 | 内置 | 按太阳高度生成真实的天空颜色 |
| Disney Moana 云数据集 | 开放数据（CC BY-SA） | 真实的高精度体积云 |
| Physical Starlight and Atmosphere | 商业插件 | 物理大气、日出日落、星空 |
| Infinigen | 开源 | 程序化云和天气 |

## 5. 建筑与古建

适用：中式庭院、自然街角、废墟巨人（废城）、赛博朋克城市、斗拱楼阁。

**制作方法底线**
- 建筑按真实的构造做：墙有厚度，门窗有框和窗台，屋顶有檐口和排水；古建有柱、梁枋、斗拱、椽子和瓦垄，比例符合营造规制。
- 瓦片、砖块、地砖用阵列或实例逐块排布，带随机的错位、缺损和色差；不能用一张平面贴图代替。
- 风化按规律分布：雨水痕从窗台和檐口往下流，墙根返潮长苔，屋脊和瓦当破损。
- 楼群不能复制同一个盒子：高度、立面、破损和附属物（空调外机、管线）都要变化。

**专业术语**：模块化建模、阵列修改器、几何节点实例化、斜切倒角、木作与瓦作、雨水流痕、返潮遮罩、顶点颜色混合、贴花。

**推荐插件与素材**

| 名称 | 类型 | 用途 |
|---|---|---|
| Building Tools | 免费插件 | 楼层、门窗、阳台等建筑构件 |
| Archimesh | 内置扩展 | 墙体、门窗、楼梯等室内外构件 |
| SceneCity | 商业插件 | 程序化城市、道路和楼群 |
| BlenderKit、KitBash3D | 素材（免费 / 商业） | 现成的建筑和城市模型 |

古建：目前没有找到成熟、可靠的中式古建生成插件。建议用高质量的古建模型资产，瓦垄、椽子和斗拱再用阵列、几何节点实例化逐个排布。

## 6. 硬表面机械与载具

适用：机甲、战斗机、直升机、无人机、赛博飞车、电脑主机、浑天仪、陀飞轮、废墟巨人。

**制作方法底线**
- 外形按设计图或实物照片建模：曲面连续、面片布线干净，板件之间有真实的分缝和厚度；还原真实机型时使用该机型的精细模型，对照实物照片核对。
- 所有硬边都有小倒角，能接到细细的高光；不能是锋利的完美直角，也不能整体糊成圆角。
- 细节分层：大板件 → 分缝、口盖 → 螺钉、铆钉、贴花、警示标识（无文字），近景时第三层必须看得到。
- 机械联动按真实约束：齿轮咬合比、连杆铰点、螺丝的旋入速度与螺距匹配；部件用父子级绑定或约束，不能各自漂移。
- 材质区分：漆面、阳极氧化铝、钛、镀铬、橡胶、玻璃、碳纤维各有不同的粗糙度和反射。

**专业术语**：硬表面建模、细分曲面、支撑边、倒角修改器、加权法线、布尔运算、贴花、父子级绑定、驱动器、骨骼约束、齿轮传动比、拆解组装、爆炸图。

**推荐插件与素材**

| MACHIN3tools | 免费插件 | 硬表面建模辅助 |
| Hard Ops、Boxcutter | 商业插件 | 布尔切割、倒角、硬表面细节 |
| DECALmachine | 商业插件 | 分缝、螺钉、标识等贴花细节 |
| Extra Mesh Objects | 内置扩展 | 齿轮等标准机械零件 |

## 7. 角色、生物与机器人

适用：锦鲤、初号机、机器狗、怪兽、史莱姆。

**制作方法底线**
- 生物有解剖结构：骨骼、肌肉起伏、鳞片或皮肤纹理，皮肤有次表面散射。
- 动作用骨骼绑定驱动，关节旋转中心准确；身体弯曲时体积保持，不能像橡皮管一样被拉细。
- 足式移动：支撑期的脚贴地不滑动，躯干重心随步伐上下起伏、左右平衡。
- 尾巴、鳍、披风、天线等附属物有二级跟随和惯性滞后。

**专业术语**：骨骼绑定、反向动力学（IK）、正向动力学（FK）、权重绘制、形态键、步态循环、支撑相与摆动相、重心转移、二级动画、次表面散射。

**推荐插件与素材**

| 名称 | 类型 | 用途 |
|---|---|---|
| Rigify | 内置 | 人形、四足、鱼类等骨骼模板 |
| Auto-Rig Pro | 商业插件 | 快速绑定，含 IK、足部锁定 |
| Wiggle 2 | 免费插件 | 尾巴、附属物的二级跟随 |

## 8. 布料、绳索与线缆

适用：宝船扬帆、揭幕、旗帜、电线、电脑线缆。

**制作方法底线**
- 布料用布料模拟：有重力、风力、碰撞和自碰撞，褶皱自然产生，不能是固定的波浪形变。
- 布料有厚度，边缘有缝线或卷边；材质区分丝绸、帆布、棉布的光泽和硬度。
- 绳索、电线、线缆用柔体或曲线模拟：悬挂时成悬链线弧度，受力时绷直，有摆动和余振。

**专业术语**：布料模拟、钉固顶点组、自碰撞、风力场、实体化修改器、悬链线、柔体模拟、曲线挤出、缆线物理。

**推荐插件与素材**

| 名称 | 类型 | 用途 |
|---|---|---|
| 布料模拟、柔体模拟 | 内置 | 布料和绳索的物理模拟 |
| Simply Cloth | 商业插件 | 布料模拟的快捷设置 |

## 9. 破碎、刚体与离散粒子

适用：青花瓷碎裂、书房机关、世界树（土块）、雨雪、落叶、锈屑。

**制作方法底线**
- 碎裂用破碎工具按材质生成碎块：瓷器是锋利的片状碎块，混凝土是带颗粒的块状碎块，碎块大小不一；碎块内部有断面材质。
- 碰撞用刚体模拟，有质量、摩擦和弹性；碎块落地后弹跳、滑行、静止，不能悬空或穿进地面。
- 连锁反应按真实的力量传递：每一次碰撞都由上一次引起，节奏符合物理。
- 雨、雪、落叶、火花用粒子系统，受重力、风力和湍流影响，有生命周期和自然消亡。

**专业术语**：刚体模拟、破碎、Voronoi 碎块、断面材质、约束（铰链、弹簧）、质量与摩擦、碰撞形状、粒子系统、力场（风、湍流、涡流）、生命周期。

**推荐插件与素材**

| 名称 | 类型 | 用途 |
|---|---|---|
| Cell Fracture | 内置扩展 | 按碎块数量和分布破碎物体 |
| RBDLab | 商业插件 | 高质量破碎、碎块细节、碎屑和尘土 |
| Bullet 刚体 | 内置 | 刚体模拟 |

## 10. 光效、发光体与太空

适用：黑洞、赛博朋克霓虹、机甲眼灯、电脑主机灯带。

**制作方法底线**
- 发光体用自发光材质，按真实灯具的亮度设置，光要照亮周围、在表面形成反射；不能只是一个亮色、不照亮任何东西的面片。
- 辉光只在高光点上出现，范围克制，不糊住物体边缘。
- 太空：星点大小、亮度和颜色不一；引力透镜、吸积盘等效果做到"看起来合理"，有层次和亮度梯度。

**专业术语**：自发光强度、IES 灯光、光度单位、辉光（Bloom）阈值、体积光、引力透镜、多普勒增亮、吸积盘。

**推荐插件与素材**

| 名称 | 类型 | 用途 |
|---|---|---|
| Physical Starlight and Atmosphere | 商业插件 | 星空、大气 |
| Poly Haven HDRI | 素材 | 夜景和城市环境光 |
