# 制作方法底线、专业术语与推荐插件（按类目表）

> 项目规定：只用内置和开源插件；允许使用贴图；除贴图以外的外部素材（模型、环境贴图 HDRI、扫描模型、体积数据、素材库里的成品资产）都不能使用。

用途：写任务时，先在第一部分按类目表找到本片的二级类目，再到第二部分找到对应的技术模块，挑出"制作方法底线"，用"专业术语"写进 Prompt 的重点效果要求和"另外"一段；"推荐插件"用一句"可借助……等插件"写进"另外"一段。

规则：
- **贴图可以用**：材质可以使用外部的图像贴图（颜色、粗糙度、法线、置换、高度等 PBR 贴图），也可以用程序化纹理，或两者叠加。
- **贴图以外的素材都不能用**：不能导入现成的模型、环境贴图（HDRI）、扫描模型、体积数据，或素材库里的成品资产；所有模型都要在 Blender 里建出来，环境光用物理天空或场景里的灯光。
- **只允许使用插件**：只用插件的建模、生成、模拟和绑定功能；插件自带的模型库、生物群落预设等成品资产也不能用（插件附带的贴图可以用）。
- 只写画面、方法和效果，可以用专业术语，不写代码、API 名或属性名。
- 插件名可以写，但只能作为"可借助"的建议，不能写成必须安装的前提；同类工具可以替换。
- **只用内置和开源插件**：只推荐 Blender 内置功能、官方扩展平台（extensions.blender.org）上的免费扩展，以及开源免费的插件；收费的商业插件一律不考虑，也不写进 Prompt。
- 插件和 Blender 5.0.0 的兼容性由制作方自行确认。下表中的"内置"指 Blender 自带或官方扩展平台上的扩展，"开源"指公开源码、免费使用的插件。

## 通用底线（所有写实任务）

- **禁止基本几何体拼凑**：主体和主要道具不能用立方体、圆柱、球体、圆锥加噪波拼出来；要有真实的结构分件、倒角和厚度。
- **细节密度**：以 100% 尺寸查看画面中任意一块主体表面，都能看到可辨认的细节（纹理、颗粒、划痕、接缝、颜色变化），不能是大块的纯色平面。
- **尺度参照**：写清主体的真实尺寸，并给出一个画面里能对比的参照物（人造物、植物、车辆），让大小一眼可辨。
- **材质**：基于物理的材质（PBR），颜色、粗糙度、法线和置换齐全；可以用照片扫描的 PBR 贴图，也可以用程序化纹理，或两者叠加；贴图分辨率与镜头距离匹配，近景用 4K 以上；大面积表面做防重复处理。
- **风化与使用痕迹**：按真实规律分布：边角磨损、凹处积灰、朝上的面积水渍、下沿溅泥。
- **灯光**：用物理天空或场景里搭建的灯光作环境光，再加有方向的主光；有接触阴影和间接反弹光。
- **成像**：AgX 色彩管理，曝光以主体为准；足够的采样再降噪，不能靠强降噪抹掉细节；按需要加景深和运动模糊。

**通用术语**：PBR 材质、PBR 贴图（颜色、粗糙度、法线、置换）、程序化纹理、噪波与沃罗诺伊纹理叠加、凹凸与置换、粗糙度变化、环境光遮蔽、曲率遮罩（边缘磨损）、纹理烘焙、防重复处理、物理天空、全局光照、接触阴影、AgX 色彩管理、景深、运动模糊、缓入缓出、运动曲线。

**通用插件（内置 / 开源）与贴图来源**

| 插件 | 类型 | 用途 |
|---|---|---|
| Poly Haven（只取贴图） | 免费贴图（CC0） | 扫描的 PBR 贴图；不使用它的模型和 HDRI |
| ambientCG | 免费贴图（CC0） | 扫描和程序化的 PBR 贴图 |
| Camera Shakify | 开源插件 | 真实的手持和跟拍抖动 |

# 第二部分：技术模块

下面的技术模块是第一部分各类目共用的详细底线、术语和插件。

## 技术模块 T1：自然地形与山岳

适用类目：场景动画/自然环境/地形山地、场景动画/幻想世界/浮空岛屿与异星地表、科教演示/地理地貌。

**制作方法底线**
- 山体用高精度地形网格，在 Blender 里经过程序化置换和侵蚀处理，有山脊、沟壑、断崖和碎石坡。
- 岩石有地质结构：花岗岩的竖向节理和石柱、砂岩的水平层理、风化剥落的块状面；不是一个个光滑的锥体或球体。
- 多层细节叠加：大形（山体轮廓）→ 中形（岩块、断层）→ 小形（裂隙、颗粒），三层都要看得到。
- 山峰之间相连成山脉，有前景、中景、远景三层，远景按空气透视变淡、偏蓝。
- 岩缝和峰顶有植被、碎石和积土，与岩体自然衔接，不是贴上去的。

**专业术语**：高度图地形、置换修改器、侵蚀模拟（水蚀、热蚀）、多重分辨率细分、雕刻、岩石节理、空气透视、三平面投影贴图、坡度遮罩（按坡度分配岩石和植被）。

**推荐插件**

| 插件 | 类型 | 用途 |
|---|---|---|
| Infinigen | 开源（BSD-3） | 完全程序化地生成照片级的山地、岩石、地表、云，含侵蚀，不依赖外部素材 |
| A.N.T. Landscape | 内置扩展 | 噪波地形，带基础侵蚀 |

## 技术模块 T2：植物与植被

适用类目：场景动画/自然环境/森林植被与四季变化、场景动画/微缩模型、产品动画/食品饮料/生鲜食材。

**制作方法底线**
- 树木由真实的分枝结构生成（主干 → 主枝 → 次枝 → 细枝），树冠是一片片单独的叶子组成的叶簇，有透光空隙；不能是球体堆或一整块外壳。
- 叶片有叶脉、正反两面颜色不同，逆光时透光（次表面散射）；颜色深浅不一，夹杂枯叶。
- 草和地被用散布系统铺满，高矮、朝向、颜色随机变化，密度按坡度、光照和路径变化。
- 生长动画按生长的先后逐步展开，不能整体放大。
- 随风摆动：枝干、叶片按柔韧度分层摆动，有相位差。

**专业术语**：分枝生成、几何节点散布、实例化、随机旋转与缩放、叶片次表面散射、半透明背光、风力场、二级摆动、生长遮罩、路径生长。

**推荐插件**

| 插件 | 类型 | 用途 |
|---|---|---|
| Sapling Tree Gen | 内置扩展 | 参数化树木生成 |
| IvyGen | 内置扩展 | 藤蔓沿表面攀爬 |
| 几何节点散布 | 内置 | 按坡度、遮罩散布自建的植物 |
| Infinigen | 开源 | 程序化树木、灌木和地被 |

## 技术模块 T3：水与液体

适用类目：现象动画/液体流动、场景动画/自然环境/水域海洋、产品动画/食品饮料、载具动画/水上载具。

**制作方法底线**
- 飞溅、水幕、水柱用液体模拟生成连续的液面网格；不能用融球、粒子球或贴图拼出来。
- 模拟分辨率要足够：水幕边缘拉丝、破碎成水珠的过程能看清。
- 水珠、白沫、气泡由模拟生成的二次粒子产生，从液面上断开，不能凭空出现。
- 水的材质：透明、有折射和焦散，按水深吸收颜色；水面有细小的涟漪和倒影。
- 大面积水面用海洋或波纹置换，靠近物体的地方再叠加局部模拟。

**专业术语**：FLIP 液体模拟、模拟域与分辨率、网格化液面、表面张力、二次粒子（水花、泡沫、气泡）、焦散、体积吸收、海洋修改器、动态绘画波纹、折射率。

**推荐插件**

| 插件 | 类型 | 用途 |
|---|---|---|
| Mantaflow 液体 | 内置 | 液体模拟，含水花、泡沫、气泡等二次粒子 |
| 海洋修改器 | 内置 | 大面积波浪水面 |
| 动态绘画 | 内置 | 物体触水产生的涟漪 |

## 技术模块 T5：建筑与古建

适用类目：场景动画/建筑空间、场景动画/城市街景、场景动画/微缩模型。

**制作方法底线**
- 建筑按真实的构造做：墙有厚度，门窗有框和窗台，屋顶有檐口和排水；古建有柱、梁枋、斗拱、椽子和瓦垄，比例符合营造规制。
- 瓦片、砖块、地砖用阵列或实例逐块排布，带随机的错位、缺损和色差；不能用一张平面贴图代替。
- 风化按规律分布：雨水痕从窗台和檐口往下流，墙根返潮长苔，屋脊和瓦当破损。
- 楼群不能复制同一个盒子：高度、立面、破损和附属物（空调外机、管线）都要变化。

**专业术语**：模块化建模、阵列修改器、几何节点实例化、斜切倒角、木作与瓦作、雨水流痕、返潮遮罩、顶点颜色混合、贴花。

**推荐插件**

| 插件 | 类型 | 用途 |
|---|---|---|
| Building Tools | 开源插件 | 楼层、门窗、阳台等建筑构件 |
| Archimesh | 内置扩展 | 墙体、门窗、楼梯等室内外构件 |

古建：目前没有找到成熟、可靠的中式古建生成插件。柱、梁枋、斗拱等构件按营造比例单独建模，瓦垄、椽子和斗拱再用阵列、几何节点实例化逐个排布。

## 技术模块 T6：硬表面机械与载具

适用类目：载具动画（全部）、产品动画/消费电子与工业设备、角色动画/简易人形/小型机器人。

**制作方法底线**
- 外形按设计图或实物照片在 Blender 里建模：曲面连续、面片布线干净，板件之间有真实的分缝和厚度；还原真实机型时，对照多角度的实物照片逐项核对比例和细节。
- 所有硬边都有小倒角，能接到细细的高光；不能是锋利的完美直角，也不能整体糊成圆角。
- 细节分层：大板件 → 分缝、口盖 → 螺钉、铆钉、警示标识（无文字），近景时第三层必须看得到；分缝和螺钉用建模或程序化凹凸做出来。
- 机械联动按真实约束：齿轮咬合比、连杆铰点、螺丝的旋入速度与螺距匹配；部件用父子级绑定或约束，不能各自漂移。
- 材质区分：漆面、阳极氧化铝、钛、镀铬、橡胶、玻璃、碳纤维各有不同的粗糙度和反射。

**专业术语**：硬表面建模、细分曲面、支撑边、倒角修改器、加权法线、布尔运算、程序化凹凸细节、父子级绑定、驱动器、骨骼约束、齿轮传动比、拆解组装、爆炸图。

**推荐插件**

|---|---|---|
| MACHIN3tools | 开源插件 | 硬表面建模辅助 |
| Extra Mesh Objects | 内置扩展 | 齿轮等标准机械零件 |
| Rigacar | 开源扩展 | 汽车绑定：车轮滚动、悬挂 |

## 技术模块 T7：角色、生物与机器人

适用类目：角色动画（全部）、载具动画/幻想载具/机甲。

**制作方法底线**

## 技术模块 T9：破碎、刚体与离散粒子

适用类目：现象动画/破碎碰撞与粒子群集、图形动画/几何图形/堆叠翻滚。

**制作方法底线**
- 碎裂用破碎工具按材质生成碎块：瓷器是锋利的片状碎块，混凝土是带颗粒的块状碎块，碎块大小不一；碎块内部有断面材质。
- 碰撞用刚体模拟，有质量、摩擦和弹性；碎块落地后弹跳、滑行、静止，不能悬空或穿进地面。
- 连锁反应按真实的力量传递：每一次碰撞都由上一次引起，节奏符合物理。
- 雨、雪、落叶、火花用粒子系统，受重力、风力和湍流影响，有生命周期和自然消亡。

**专业术语**：刚体模拟、破碎、Voronoi 碎块、断面材质、约束（铰链、弹簧）、质量与摩擦、碰撞形状、粒子系统、力场（风、湍流、涡流）、生命周期。

**推荐插件**

| 插件 | 类型 | 用途 |
|---|---|---|
| Cell Fracture | 内置扩展 | 按碎块数量和分布破碎物体 |
| Bullet 刚体 | 内置 | 刚体模拟、约束、碰撞 |

## 技术模块 T10：光效、发光体与太空

适用类目：现象动画/光效能量、场景动画/城市街景/夜景霓虹、场景动画/幻想世界/科幻空间、科教演示/天文宇宙。

**制作方法底线**
- 发光体用自发光材质，按真实灯具的亮度设置，光要照亮周围、在表面形成反射；不能只是一个亮色、不照亮任何东西的面片。
- 辉光只在高光点上出现，范围克制，不糊住物体边缘。
- 太空：星点大小、亮度和颜色不一；引力透镜、吸积盘等效果做到"看起来合理"，有层次和亮度梯度。

**专业术语**：自发光强度、IES 灯光、光度单位、辉光（Bloom）阈值、体积光、引力透镜、多普勒增亮、吸积盘。

**推荐插件**

|---|---|---|
| 物理天空纹理 | 内置 | 日光、星空背景的基础照明 |
| 几何节点 | 内置 | 程序化星空、电弧分支、全息扫描线 |
| Bloom 辉光（合成器） | 内置 | 克制的高光辉光 |
