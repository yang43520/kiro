# 鲲化为鹏考点说明

> 内部校验用，不交给制作方，不属于制作输入。

**主类目**：角色动画/幻想生物/元素生物

**题目档位**：上限档（配方：L3 + L2，附带 2 个 L1）

**档位来源**：默认

**规范版本**：进阶版 1.4

**视觉基调**：奇幻史诗

**耦合链**：同一只鲲鹏上，出水的弧线和姿态决定身体何时离开水面；形变在出水过程中连续发生，翅膀展开后才能振翅，振翅又决定腾空的轨迹；鳞化为羽的进度同时驱动材质从湿鳞变成干羽，爬升到晨光高度后羽缘才被照亮；镜头跟着出水和爬升绕行、升高。

| 编号 | 考点 | 分级 | 作用对象与时段 | 在片中的体现 |
|---|---|---|---|---|
| 8 | 柔性形变与形态演变 | L3 | 鲲鹏身体，4–9.5 秒 | 胸鳍一节节伸长成翼，鳍膜裂成飞羽，翼展展开到约 800 米；鳞片从头到尾依次翻起化为覆羽；尾鳍分成十二根尾羽；鱼吻成钩喙；体积看起来守恒，不整体缩放 |
| 3 | 复杂轨迹与姿态自适应 | L2 | 鲲鹏身体，2–12 秒 | 约 35° 仰角斜冲出水，沿上弯弧线抬起，头顺着切线、脊背顺弧弯曲；第 7.5 秒仰角约 25°、右倾约 8°；振翅时前进方向先转平再抬起，最后约 20° 仰角右上爬升并滑翔 |
| 16 | 光影流转与材质外观演变 | L1 | 鳞羽，2–12 秒 | 湿透的墨蓝黑镜面鳞片随形变过渡成带绒感的深青灰羽毛；第 10 秒后晨光从翼尖扫到背上，羽缘泛出暖金色亮边 |
| 17 | 单镜头运镜构图 | L1 | 镜头，0–12 秒 | 从 1.3 公里外近海面前推，向左后方绕行、升高、上转，停在左后下方约 900 米处仰视，双翼约占画面宽度六成，不碰画面边缘，无剪辑 |

**最高分级**：L3

## 制作底线清单

**二级类目**：幻想生物

**技术模块**：T7、T10

**本片要用的专业术语**：骨骼绑定、权重绘制、形态键、体积守恒、柔体、次表面散射、预备与跟随动作、二级动画、反向动力学、自发光强度、辉光阈值

**推荐插件**：Rigify（内置）、Wiggle 2（开源）

**通用底线**：PBR 贴图或程序化纹理（近景 4K）、倒角、接触阴影、AgX 色彩管理、足够采样、100% 查看细节、尺度参照（帆船）、防重复

**重模拟**：液体模拟（只包住鲲身周围；碎冰跟着海面起伏，不另算刚体模拟）

## 类目与标签

**归类理由**：主体是一只从水中的鲲化为空中的鹏的神话生物，最贴近幻想生物里的元素生物。

| 标签组 | 选定标签 | 必要说明 |
|---|---|---|
| 视觉造型 | 写实 | 照片级写实，结构像真实生物 |
| 材质质感 | 液体冰晶、木石天然 | 主材质是海水、水幕和碎冰；其次是帆船的木板 |
| 渲染风格 | 真实渲染 | 常规物理渲染 |
| 动态节奏 | 自然流畅 | 出水、振翅和爬升都有重量感和缓入缓出 |
| 动画行为 | 主行为：形变与生长/形态变化/形状转换 | 由鱼形连续变成鸟形，是全片的核心事件 |
| 动画行为 | 辅助行为：位移与运动/路径运动/沿线移动 | 沿弧线出水和爬升 |
| 动画行为 | 辅助行为：物理与特效/流体粒子/液体 | 水幕、水帘和环形波纹 |
| 动画行为 | 辅助行为：位移与运动/群体运动/群集 | 鱼群跃出、海鸥惊飞 |
| 灯光氛围 | 灯光动画 | 晨光从翼尖扫到背上，光照随时间变化 |
| 背景环境 | 完整场景 | 北冥海面、碎冰、帆船、远山和天空完整搭建 |
| 色彩基调 | 不填 | 冷蓝为主、晨光处暖金，没有单一的色彩基调 |
| 时序结构 | 多段序列 | 暗涌 → 破水 → 化羽 → 扇翅 → 入光 → 滑翔 |
| 复杂度等级 | 物理模拟 | 含液体模拟和群集 |
| 应用场景 | 不填 | 没有明确的用途依据 |
