# rubric.json 写法

每个任务都要输出一份 `rubric.json`，放在任务文件夹里，和主文件一起交付验收。成片按 `references/acceptance-standards.md` 验收，rubric 把这些标准落到本任务的具体画面上。

## 一、基本规则

- 只依据主文件（Prompt）、明确采用的参考附件和通用质量要求来写。**不新增 Prompt 里没写的隐性要求**，不重复扣分，也不因为成片表现而删项、降权或放宽标准。
- 每一项都必须能在画面里观察到。
- 每项只能用两种评分方式：
  - `binary`：只有 `0` 和 `100` 两档；
  - `discrete`：只有 `0`、`50`、`100` 三档，每档都写具体表现。
- 权重是正数，全部合计 100。
- 关键项：`critical` 为 `true`，`pass_threshold` 为 `100`；非关键项：`critical` 为 `false`，`pass_threshold` 为 `null`。所有"必须做到"的条件都要映射到关键项。
- 总分 = Σ（权重 × 得分 ÷ 100）。所有关键项都得 100 分，且没有四舍五入的总分不低于 85 分，才算通过。
- 编号从 `R01` 开始连续编号；以后修改时，已有编号保持不变，新增项接在最后。
- 必须是合法的 JSON，用不带 BOM 的 UTF-8，不能有注释、占位提示或省略号。实际得分和验收结论另外记录，不写进这个文件。
- 不写考点编号、分级和档位。

## 二、评价项怎么组成

一般 20–26 项，分八部分：

1. **通用项**（每个任务都有）：
   - 主体与目标（关键）：主体、数量、识别特征和核心结果；
   - 时长（关键，binary）：写出 Prompt 里的允许区间，例如"动画时长处于 10–12 秒区间，含边界"；
   - 主体自身运动（关键，binary）；
   - 动作完整性（关键）：关键动作的先后和结束状态；
   - 接触与空间关系（关键）；
   - 造型及视觉一致性（关键）；
   - 画面完整与清晰（关键）；
   - 构图与镜头（关键）；
   - 节奏与有效时长；
   - 规格（关键，binary）：画幅、分辨率、帧率、无声音。
2. **数量硬指标项**（关键项，binary 或 discrete 均可）：按主类目所属的一级类目，把 SKILL.md 3.7 表里适用的每一行各列一项，`dimension` 必须和表里的维度名完全一致（例如“结构分件”“布光层次”“资产种类”），`criterion` 里写出要求的数量和本片的具体内容，例如“鲲鹏有头颈、左翼、右翼、躯干、尾羽组和两根长须共 6 个独立分件，各自有可见的运动（≥ 4 个）”。
3. **类目专项**：从所属一级类目的标准里挑 1–3 条最相关的，例如角色类的"形变与附属部位"，载具类的"部件联动"，产品类的"展示充分性"。
4. **材质与制作底线**（关键项，discrete，约 6–8 分）：检查主文件"关键效果和做法"里那条材质做法写的内容是否做到，例如硬边倒角、透明件的折射和厚度、模拟分辨率足够、PBR 贴图精度、接触阴影。`dimension` 固定写"材质与制作底线"。1.6 起，主文件写了植物、动物或建筑的表面分层时，criterion 里也列出来（例如树皮沟深和青苔位置、墙根返潮和窗台流痕），0 分锚点加上"表面只有一种颜色和一层法线凹凸、看得出贴图重复"。
5. **任务项**：主文件"关键效果和做法"里的每一条至少对应一项，把那一条的"要看到什么"和"别怎样"写进锚点。
6. **加分项**（非关键）：灯光材质与氛围、场景丰富度，各 2–6 分。
7. **动物形体与动作**（进阶版 1.7 起，写实场景里动物是主要元素时的关键项，discrete，约 4 分）：criterion 写主文件里的体长比例、附肢数量、表皮和沾的环境、动作数值和接触；0 分是比例像玩具、腿数或关节方向不对、滑步或穿进地面、毛羽像一层均匀的绒；50 分是都成立但有一处轻微不对；100 分是形体、表皮和动作都按真实物种做到。
8. **接触与防穿模**（进阶版 1.5 起，关键项，discrete）：`dimension` 写"接触与防穿模"，criterion 列出主文件接触清单里的每处接触；0 分是任何一处关键接触明显穿模，50 分是都没穿但有一处轻微穿插、悬空或打滑，100 分是每处都贴合、不穿不浮。权重约 4 分，从其他项里匀出来。
8. **电影级关键项**（3.4 起，关键项，discrete，接在最后编号）：`dimension` 固定写"动态密度"（约 4 分）、"电影级画面"（约 5 分）、"细节精致度"（约 4 分）。criterion 里写出主文件的具体内容：动态总表的各类动态；光的层次、色温、光比、每段的构图方式、配色和色彩脚本；三级细节、微细节和特写。权重从核心效果项和加分项里匀出来，合计仍为 100。
8. **海报帧与视觉基调**（进阶版，关键项，discrete，约 5 分，接在最后编号）：criterion 里写出每个海报帧的时刻和看点，以及选定基调的要点（明暗调性、光比、焦距、运镜和调色）；0 分锚点写"海报帧明显不对或犯了基调禁忌"。权重从核心效果项和动作完整性里匀出来。评分表是内部文件，可以比主文件写得细，但不能要求主文件里没写的东西。

## 三、权重建议

- 关键项合计约 85–92，非关键项合计约 8–15。
- 核心结果和核心效果（例如形变、主要交互）各 10–14；时长、规格、自身运动这类容易判断的项各 3–5。
- 单项不超过 15。

## 四、锚点写法

- `100`：完整达到 Prompt 的要求，用 Prompt 里的具体内容写，例如"鳞片从头顶到尾根依次翻起化为覆羽"。
- `50`（discrete）：主要内容成立，但局部有明显问题，写清是什么问题，并注明"且未达到 0 分状态"。
- `0`：要求没有成立，或问题严重到破坏主体识别或结果。
- 锚点之间不能重叠，也不能留空档。

## 五、格式

```json
{
  "task": "<标题>",
  "scoring_policy": {
    "aggregation": "weighted_sum",
    "total_weight": 100,
    "total_threshold": 85,
    "require_all_critical_pass": true
  },
  "criteria": [
    {
      "criterion_id": "R01",
      "dimension": "主体与目标",
      "criterion": "……",
      "weight": 10,
      "critical": true,
      "pass_threshold": 100,
      "scoring_type": "binary",
      "score_anchors": {
        "0": "……",
        "100": "……"
      }
    }
  ]
}
```

完整示例见 `references/example/rubric.json`。写完后用 `scripts/check_brief.py` 检查主文件，脚本会同时检查同一文件夹里的 `rubric.json`。
