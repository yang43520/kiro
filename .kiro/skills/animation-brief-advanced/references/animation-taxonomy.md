# 动画类目与标签规则（2026-11-12）

> 本文件依据类目表 CSV 与“标签”工作表截图整理。正式类目名称、标签名称和规则以源表为准；Blender 实现参考提示仅供实现参考，不构成强制制作方法或验收要求。

## 一、执行总则

- 每条动画任务只选择一个三级主类目，填写完整的“一级/二级/三级”类目路径；主类目互斥。
- 主类目依据主要表现对象、主要动作和表达目的确定，不能只按画面中出现的物体关键词匹配。
- 风格、材质、动作、灯光、节奏、复杂度和应用场景通过标签表达，不替代主类目。
- 优先遵守类目定义、纳入范围、归属边界和明确的“不纳入”说明。
- 参考视频的分类描述参考本身；重新设计后如主要主体、表达目的、风格或动作改变，应按目标方案重新分类。
- 只能把实际可观察内容写成事实；缺少依据的必填标签应标为待确认，不得虚构。
- 用户创意未规定的内容可以提出建议，但必须标明为建议。

## 三、标签体系总览

标签组共 11 组。标签定义/示例用于判断是否有足够依据，Blender 提示不限制实现方式。

### 3.1 视觉造型

| 标签名称 | 定义 / 示例 | Blender 实现参考提示 |
|---|---|---|
| 写实 | 接近真实比例、材质与光照，追求照片级效果；常用于产品广告、建筑表现 | Cycles + PBR + HDRI |
| 半写实 | 保留真实结构与质感，造型适度简化或风格化；常用于游戏、品牌宣传 | Eevee/Cycles，倒角圆润 |
| 卡通 | 夸张比例、圆润造型、鲜明配色；接近 3D 动画电影或 Q 版风格 | 细分曲面 + 纯色材质 |
| 低多边形 | Low Poly，少量面片构成简约的造型，配合纯色或渐变着色 | Decimate / 平直着色 |
| 体素 | Voxel，小立方体堆叠的三维像素风格，类似积木/方块世界 | Remesh(Blocks) / 几何节点 |

## 五、项目适用约束（不改变正式类目定义）

- 动画通常为 8–12 秒，必要时最长约 15.6 秒，不得少于 8 秒。
- 主体自身需要有真实可见的运动或形变，不能仅靠镜头运动制造动态。
- 可以使用镜头运动、变焦和镜头切换。
- 不考虑声音。
- 本流程不要求代码、工程文件、复现或打包交付。
