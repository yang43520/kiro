# 视觉基调表

每个任务按使用场景选**一种**视觉基调，写进主文件"灯光和画面"的第一句："视觉基调：<基调名>。"，并在考点说明里写"**视觉基调**：<基调名>"。

选定以后，光比、焦距、运镜速度和 AgX 观感都要落在这一行的范围里，检查脚本会逐项核对。表里没有的内容（构图偏好、禁忌）由写作者自己落实，验收时按"海报帧与视觉基调"一项检查。

- **主辅光比**：主光照到的地方和只有补光的地方的亮度比，写成"约 N:1"。
- **镜头转动上限**：按关键机位表算，镜头朝向每秒最多转多少度。超过就容易显得急、晃，画面也容易出现频闪。
- **镜头移动上限**：按关键机位表算，镜头每秒移动的距离最多占它到主体距离的百分之几。离主体越近，移动越要慢。
- **AgX 观感**：只能从这一格里选，写 Blender 里的英文名称。
