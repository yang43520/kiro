# 材质细节：植物、动物、建筑（进阶版 1.6）

`anti-primitive.md` 管"形"，这份管"面"。渲染出来有建模感，很多时候形状已经对了，毛病出在表面：一种颜色、一层粗糙度、只靠法线贴图、贴图方向和尺寸不对、每个个体一样、接触的地方没有过渡。主文件写到植物、动物、建筑时，按这份把表面写到能落地。

风格不变：写实任务按真实规律写风化和磨损；风格化任务按第六节写，别把写实的风化叠到卡通上（见 SKILL.md 3.8"风格不叠加"）。

## 一、通用六条（每种对象都适用）

1. **真起伏**：近景会掠过的表面（树皮、石墙、砖墙、甲壳、粗皮肤），用高度图接置换修改器配自适应细分推出真实几何，法线贴图只补最细的一层。主文件写出起伏的实际深度，例如"栎树纵沟深 2–4 厘米""砖缝凹进约 5 毫米"。
2. **贴图的尺寸和方向**：写清一张贴图在物体上覆盖多大（例如"一张 4K 树皮贴图覆盖约 1 米高的树干"）；纹理顺着生长或施工方向走（树皮沿树干、木纹沿板长、砖按砌法错缝）；分叉、转角、根张这类展不开 UV 的地方用三平面投影贴图防止拉伸。
3. **分层**：表面按"底色 → 结构 → 风化 → 生物 → 湿和脏"一层层叠，每层用遮罩控制位置，写清它出现在哪、为什么在那：
   - 曲率遮罩：凸起和棱被磨浅、磨亮；
   - 环境光遮蔽：凹处、缝里积暗、积灰；
   - 法线朝向遮罩：朝上的面积灰积雪、背阴面长苔；
   - 高度遮罩：离地几十厘米的泥溅带、返潮带、水位线；
   - 顶点颜色或手绘遮罩：流水痕、修补、个别伤痕。
4. **接触带**：两种东西接触的地方要有过渡，别是一条干净的交线：树根埋进土和落叶、墙根和地面之间的返潮和泥、蹄子周围被踩下去的泥、石头半埋在沙里时周围的沙堆。
5. **个体差异**：同一种东西每个都不一样，按对象随机给颜色、置换强度、贴图偏移和旋转、磨损程度；同一张贴图别在画面里同时出现两次一样的位置。
6. **掠射光自查**：起伏要靠侧光或侧逆光擦过表面才显得出来，主文件至少一段让主光擦过这些表面；近景放大到 100% 检查，看得出沟脊的阴影才算做到。

## 二、植物

### 树干的形状

| 部位 | 真树的样子 | 主文件要写的 |
|---|---|---|
| 根张 | 树干贴地处张开到胸径的 1.5–2 倍，几条板根伸进土里，越往外越扁 | 根张多宽、几条板根、伸出多远，怎么埋进土和落叶层 |
| 截面和收分 | 截面不是正圆，向阳面、迎风面更鼓；越往上越细，中间有一两处弯 | 截面大致多扁、在哪里收细、弯在哪里 |
| 枝领 | 分枝处鼓起一圈，树皮在分叉上方挤出一道"枝皮脊" | 枝领鼓起多少、分叉处的皱褶 |
| 伤痕 | 断枝残桩、愈合的疤、树洞、开裂、虫孔 | 每棵 2–3 处，位置和大小 |

做法：先用 Sapling Tree Gen 或开源的 Modular Tree（MTree）生成枝干，再用体素重构并成一体，雕刻根张、枝领和伤疤；灰模自查时多看一张贴地的根张特写和一张分叉特写。

### 树皮的分层

| 层 | 规律 | 做法 |
|---|---|---|
| 沟和脊 | 按树种（见下表）；脊被风化磨浅，沟里深而潮 | 置换推出真沟；曲率遮罩提亮脊、环境光遮蔽压暗沟，沟里粗糙度更高 |
| 青苔和地衣 | 背阴面和朝上的分叉多，沟里多脊上少；地衣是一块块灰绿色的圆斑 | 法线朝向遮罩加沟槽遮罩；青苔用曲线毛发或几何节点散布做出短绒 |
| 流水痕 | 雨水从分叉处顺树干往下流，留下深色条带 | 写清从哪个分叉流下；湿处颜色变深、高光变窄 |
| 泥溅带 | 离地 30–50 厘米一圈被溅脏 | 高度遮罩，越往下越重 |
| 个体差异 | 每棵颜色、沟深、苔量都不同 | 按对象随机 |

### 常见树种的树皮

| 树种 | 树皮 |
|---|---|
| 栎树（橡树） | 深纵沟，脊宽 2–5 厘米、沟深 2–4 厘米，灰褐，脊顶磨成浅灰 |
| 松树 | 红褐色鳞状块，每块 5–15 厘米，块边翘起，块间露出更红的内皮；有树脂流痕 |
| 白桦 | 白色，表皮横着一卷卷剥开，横向皮孔成黑色短线；断枝处是黑色菱形疤，老树树干基部发黑龟裂 |
| 樱树 | 深褐发亮，横向长条皮孔，老皮成环状剥落 |
| 山毛榉 | 光滑银灰，有横疤，枝痕下面有八字形皱褶 |
| 悬铃木 | 大片剥落，露出灰、绿、米白三色斑块 |
| 榕树 | 气生根垂下，落地后和主干缠成一团，根与根之间有夹缝 |
| 竹 | 每节约 30 厘米，节下一圈白粉，老竹发黄带黑斑 |

### 叶、花、草

- 叶：叶脉分主脉和侧脉，写出侧脉对数；叶缘的锯齿或波浪；叶面沿叶脉起伏；虫眼、枯边、褪色的叶尖；正面亮、背面浅而带绒，加叶片次表面散射；同一棵树上新老叶颜色不同。
- 花：花瓣数、瓣尖形状、瓣根和瓣边的颜色差；花瓣薄而透光；花蕊的数量和花粉颗粒；开败的花瓣边发褐卷起。
- 草和地被：长短不齐、有枯黄的夹在里面；草根处有一层枯草和土；苔藓吸水发亮、干了发灰。

## 三、动物

| 表皮 | 规律 | 主文件要写的 |
|---|---|---|
| 毛 | 底绒加针毛两层；背部长、腹部短、四肢末端更短；有梳理方向和旋，毛成簇不成均匀的绒；湿了成绺；毛尖在逆光里发亮 | 各部位毛长（厘米）、梳理方向、毛簇大小；曲线毛发先梳理再加毛发动力学 |
| 羽毛 | 一片片层叠，每片有羽轴、羽枝和羽缘；飞羽、覆羽、绒羽大小和硬度不同；颈部和翼镜有结构色；羽片会蓬起和收拢 | 每区羽片多大、羽缘颜色、哪里有结构色；几何节点沿身体或翅膀骨骼一片片实例化 |
| 鳞片 | 沿身体从头到尾大小渐变，背大腹小；排列成斜行；边缘有磨损，鳞缝里有泥或藻 | 鳞片大小和排列方向；几何节点实例化或置换，别用一张平铺贴图 |
| 甲壳 | 有刻点、纵沟、生长纹；凸处被磨亮，凹处积泥；关节处颜色浅、膜质 | 刻点或纵沟的尺寸、磨损位置 |
| 皮肤 | 褶皱集中在关节、颈和眼周；毛孔、疤、蜕皮；湿处高光碎而亮 | 褶皱位置、粗细；次表面散射的深浅 |
| 喙、爪、蹄、角 | 角质，有生长纹，尖端和边缘被磨损、发浅；蹄缝和爪根有泥 | 磨损和脏的位置 |
| 眼 | 角膜有清楚的高光，眼周有一圈湿边；眼睑有厚度 | 眼睛的颜色和眼睑结构 |

动物在环境里还要沾环境：泥地上的腿下半截带泥，水鸟的胸口挂水珠，沙地上的动物身上沾沙。

## 四、建筑

### 材料和构造

| 对象 | 主文件要写的 |
|---|---|
| 砖墙 | 砖的尺寸和砌法（顺砖、丁砖、错缝），灰缝凹进多深，砖与砖颜色有差、有烧黑的过火砖，个别砖缺角 |
| 石墙、石垣 | 石块大小和形状，干砌还是浆砌，石缝凹进多深，塞着的小间石 |
| 灰泥、粉刷墙 | 抹灰厚度，剥落处露出底下的砖或更早的颜色，裂纹的走向 |
| 木构 | 木纹顺着构件长度走，榫卯和钉子的位置，端头开裂，木头被晒成银灰或被漆盖住；漆面起皮露出下层漆 |
| 瓦和屋面 | 瓦片一片片看得出边，压着上一片，颜色在两三种之间变；屋脊、檐口、排水沟；瓦缝长苔、积落叶 |
| 门窗 | 窗洞往里凹多深，窗框、窗台、过梁、滴水线；玻璃有轻微的波纹和脏迹 |
| 金属构件 | 栏杆、管线、招牌架的锈从螺栓和焊缝开始，往下拖出锈痕 |

### 风化按高度和朝向分布

| 位置 | 规律 |
|---|---|
| 墙根 0–50 厘米 | 返潮带、泥溅、长苔，颜色最深 |
| 窗台、檐口、阳台下面 | 雨水流痕往下拖，两端多中间少 |
| 檐下、凹进去的角落 | 雨淋不到，干净但积灰、挂蛛网 |
| 墙顶和压顶 | 被雨冲得最浅，长苔或草 |
| 北面、背阴面 | 青苔和霉斑更多 |
| 常被摸、被踩的地方 | 门把手、台阶中间、栏杆顶被磨亮、磨凹 |
| 修补过的地方 | 新砖、新灰泥、补的木板颜色不一样，看得出年代 |

每栋楼的年代、材料和破旧程度都不同；远处的楼也要看得出灰缝、色差和流痕，别只是一种干净的灰。

## 五、写进主文件到什么程度

- 每种主要的植物、动物和建筑材料，写出**一个可测的起伏或尺寸**（带单位）、**至少两层风化或附着**（写清出现在哪、为什么）、**接触带**和**个体差异**。
- 出现树时：根张、截面或收分、枝领或伤痕至少写两样；树皮写树种特征、沟深、贴图方向或三平面投影。
- 出现建筑时：按"风化按高度和朝向分布"表至少写两处。
- 出现动物时：表皮按上表写到尺寸，并写它沾了什么环境。
- 有一段让主光擦过这些表面。

## 六、风格化任务的对应写法

风格化任务（写实地拍的玩具、卡通、低多边形、图形动画）不写写实的风化，但也不能是光秃秃的一层颜色，按"设计质量"写：

| 风格 | 要写的表面细节 | 别写 |
|---|---|---|
| 写实地拍的玩具（积木、胶囊人、木偶、微缩模型） | 按真实玩具的材料写：注塑件的分模线、浇口痕和轻微的缩痕；木玩具的木纹、漆面和磕碰掉漆；毛毡的纤维；微缩模型的手涂笔触和干扫的旧化 | 真实世界的风化（玩具上长苔、返潮） |
| 卡通 | 统一的细节密度：倒角大小一致，纹理用手绘或程序化的大块变化，色块内有轻微的明暗渐变，边缘有一圈统一的高光 | 照片级的毛孔、写实毛发、照片贴图 |
| 低多边形、体素 | 每个面的颜色有轻微差别，用顶点颜色做渐变；面的大小有主次 | PBR 写实材质和置换（会暴露折面） |
| 图形动画 | 材质按产品或设计质量写，倒角一致、高光干净 | 无依据的风化 |

## 七、例子

> 老栎树胸径约 1 米，贴地处张开到约 1.8 米，四条板根往外伸出一米多，越往外越扁，埋进落叶层里只露出一道道脊。截面向阳的南面更鼓，约 4 米高处往左弯一点，6 米处分成三根主枝，分叉上方挤出几道枝皮脊；北面 3 米高有一个断枝留下的残桩，周围长了一圈愈合的鼓包。树皮是深纵沟，脊宽 2–5 厘米、沟深 2–4 厘米，用树皮照片贴图的高度图接置换修改器配自适应细分推出真沟，一张 4K 贴图覆盖约 1 米高的树干，贴图顺着树干往上走，根张和分叉用三平面投影贴图。脊顶被风化磨成浅灰，沟里深褐发潮；北面和分叉朝上的地方长着青苔，沟里多、脊上少；左边主枝的分叉往下拖着一道雨水流痕；离地半米内被雨溅得发黑。

> 这排三层砖楼每栋都不一样：左边那栋是顺丁砖砌法，灰缝凹进约 5 毫米，夹着几块烧黑的过火砖；中间那栋外面抹了约 1 厘米厚的灰泥，二层窗下剥落了一块，露出红砖和更早的一层黄漆。每个窗台下面都拖着两道雨水流痕，墙根半米内返潮发深、长着一层薄苔，檐下雨淋不到的一条比墙面干净，但积着灰；门口台阶的中间被踩得发亮、微微凹下去。
