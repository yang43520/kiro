# 进阶版写法（1.5）：电影级要求，用人写得出来的话

主文件最终交给模型，由模型在 Blender 里把动画做出来。进阶版要把镜头、构图、光线、颜色和渲染都交代清楚，但**写法要像一位懂行的导演当面交代**：口语化、数字取整、能笼统的地方笼统，适当缩写。

**口语化不等于省掉专业术语。** 倒角修改器、加权法线、次表面散射、体积散射、几何节点散布、三分法、负空间、色彩脚本、AgX、辉光阈值这类词一律照原样写进句子里，只改句式，不改术语。

## 一、不要写的东西（像机器算出来的）

| 不要写 | 改成 |
|---|---|
| 坐标、坐标系、看向点，例如 (0.3, -0.66, 0.24) | "镜头在唱机右前方约 70 厘米、比唱片高一点" |
| 主体在画面的精确位置，例如横向 0.67、纵向 0.42 | "唱头放在画面右边三分之一的地方" |
| 传感器参数、精确的对焦距离，例如 1.21 米、2712 米 | "焦点在灯泡上""焦点从柱顶移到风车" |
| 十六进制色值，例如 #1E2C46 | "深蓝""暖橙""奶油白" |
| 每层光的瓦数 | 只写颜色和冷暖，主光写一个色温，再写一个光比 |
| 零点几秒、0.15 秒这样的间隔，精确到 0.1 秒的时刻 | 时刻取到 0.5 秒；间隔写"紧接着""一个接一个" |
| 三位以上的小数、推导出来的物理量，例如 9.95 m/s² | 取整写结论："水往上喷十几米，落点往旋转方向偏六七米" |
| 一条条带时段的动态清单 | 一句总述，用顿号列出来，说法每条自己定（示意："这场雨里一直没停过的有：……"） |
| 每段都用同一个句式开头，例如"构图：……" | 把构图写进那一段的话里，句式可以变 |
| "微细节共 8 处""组件共 16 个"这类计数开头 | 直接列，说法每条自己定（示意："凑近了能看到：……"） |
| 每条都一样的套话，例如"画面要照片级写实，像……""一句话讲内容""建模和材质的做法""所有东西都在 Blender 里自己建……""尺寸和时间都是参考……""别莫名其妙地卡一下" | 意思保留，换成这条片子自己的说法；检查脚本看到原样的套话会提醒 |

主文件一般控制在 6,000 字以内。

## 二、要写的东西

下面的例句都只是示意，写主文件时换成这条片子自己的话，别照抄。

### 1. 视觉基调（"灯光和画面"第一句）

按 `references/visual-tones.md` 选一种："视觉基调：<基调名>。"再用一句话说它在本片怎么体现。光比、焦距和 AgX 观感要在这一行的范围里，运镜的快慢按"运镜"一格写。

### 2. 镜头和构图（写进每个"第 X–Y 秒"段落）

每段用一两句话交代：镜头在哪、离主体大概多远、用多少毫米、怎么动、为什么这样动；主体放在画面哪里；用了哪种构图（三分法、引导线、框景、负空间、对角线、对称、中心构图、S 形、剪影、层次纵深）。例如：

> 镜头推到唱头跟前，焦距拉到 100 毫米，唱头放在画面右边三分之一，左边是转动的唱片，按三分法摆。

全片至少一次近景特写，至少一次写清焦点从哪里移到哪里，写出光圈（f/ 数值）。

### 3. 一直在动的东西（"动作和镜头"最后一句）

用一句话总述，说法每条片子自己定，例如"这场雨里一直没停过的有：……""整盘东西始终在动：……""风暴里一刻不停的有：……"。至少 8 样，用顿号隔开，其中要有远处在动的东西。不用写时段。

### 4. 关键效果

每条写"真的是什么样（带一个取整的真实数值）+ 用什么方法做（带术语）+ 别怎样"。难做的效果（至少 2 条）补一句"实在做不出来，可以……"。不用在标题里标优先级，改在"底线和限制"里用一句话说做不完时先顾哪几条，例如"时间不够的话，最要紧的是第 1、2、3 条""保不住全部的话，优先保证……"。

### 5. 灯光和画面

- 光分几层，每层是什么光、从哪照、起什么作用；主光写一个色温（K），写一个主辅光比（"光比约 4:1"）；至少有轮廓光、逆光或实用光中的一种。
- 一层克制的大气效果：体积光、空气透视、局部体积雾、微尘或水汽。
- 主色、辅色、点缀色用颜色词写，再用一句"色彩脚本上，……"说颜色怎么随剧情变。
- 一句话说画面里最亮的是什么。
- 海报帧：一句话列出全片最好看的 2–3 个画面在第几秒、为什么好看，并写明开工前先渲小图自查（说法自己定，示意："开工前先把这三帧各渲一张小图对一下"）。
- 渲染：一句话写引擎、采样、透射反弹，有体积时写体积步长，再写 AgX 观感；例如"用 Cycles，采样一千左右，透射反弹给到 12 次，体积步长按场景大小设，AgX 选 Punchy 观感，加一点暗角和极轻的颗粒"。

### 6. 细节

"场景和主体"里写"大形、中形、小形"三级（这三个词是术语，要出现），句式随这条片子变；再用一句话列出近看要看得到的小细节，说法自己定（示意："离得近时要经得起看的：……"），至少 8 样，每样写到"什么东西上的什么痕迹"。

### 7. 画面七要素（1.2 新增）

1.1 只要求"写到"，1.2 要求"写到能落地"：模型拿到主文件，不用再猜软硬、比例、大小和占比。

| 要素 | 写什么 | 例子 |
|---|---|---|
| 风格 | 开头一句风格参照，用片种说，不点名具体作品；禁忌从基调表里挑 2–3 条写进"底线和限制" | "像自然纪录片里的航拍穿行""像高端腕表广告的黑棚"；"不要夸张调色、不要手持乱晃" |
| 打光 | 每层光：方位、软硬、动机、作用；主光怎么随剧情变 | "主光是窗外的太阳，从镜头右后方斜着进来，光源小、影子边很硬；补光是天光，整面窗一样大的柔光，影子几乎没有边" |
| 色彩 | 主色、辅色、点缀色的面积比例（一般六成、三成、一成）；饱和度上限；冷暖关系 | "主色青灰占六成，辅色赭红占三成，点缀的绿和红加起来不到一成；只有点缀色允许高饱和，大面积的颜色都压着" |
| 色调 | 主体和背景谁亮谁暗、差几档；哪里允许接近纯黑、哪里不能爆白 | "主体是画面里最亮的中间调，背景比它暗两档；最深的阴影可以接近黑，但要认得出轮廓" |
| 粒子 | 大小（带单位）、密度、生命周期、前后分层、怎么被光照到 | "浮尘直径不到半毫米，只在逆光的光柱里看得见；前景的少而大、虚成一个个光点，远处的密而细" |
| 构图 | 至少 2 段写主体在画面里占多大；对角线和三分法同一条片子各最多一段；写视线和留白往哪边 | "大钟只占画面上方一小半，下面全是往上收的梁架""鸽群往右飞，画面右边留出一大片天" |
| 材质 | 至少 3 种主材料各一个可测特征；每种的高光宽窄、锐糊 | "黄铜只有齿面 2–3 毫米的接触带是亮的，高光又窄又锐；铸铁的高光宽而糊，几乎看不出来" |

这七项都要用这条片子自己的话写，不要整句搬别的任务；检查脚本对 1.2 的任务按 ERROR 检查，对 1.1 的任务只提醒。

### 8. 风格不叠加（1.3 新增）

风格词互相打架时，模型不会二选一，而是两头各取一半，参数也会取中间值（景深、运镜、饱和度），结果两种风格都不像。所以：

- 开头只写一个片种参照，不写"像 A，又有 B""只是颜色再暖一点""带一点……的气魄"。
- 最多借一种手法，只借镜头或光的做法，不借渲染风格。
- 视觉基调、风格参照、色彩基调标签和灯光氛围标签是一套，比如奇幻史诗不配纪录片参照，也不配"黑金奢华"标签。
- 禁配表见 SKILL.md 3.8"风格不叠加"。写实地拍玩具可以接受。

### 9. 去掉建模感（1.4 新增）

每个主体的建模做法写清起形方法、轮廓变化、部件交接、三级起伏和个体差异，再加一句灰模自查。规则和常见对象的做法见 `references/anti-primitive.md`。

### 10. 防止穿模（1.5 新增）

每条有接触的效果写清谁和谁接触、用什么方法防、安全距离多大；用了重模拟的那条写碰撞体或障碍物的做法；"底线和限制"里加一句接触清单（3–5 个"第 S 秒 + 谁和谁"，用线框和 X 射线视图逐帧看）。做法和数值见 `references/anti-clipping.md`。

### 11. 大量镜面或玻璃物体的噪点（按渲染反馈补充）

几百上千个镜面球、玻璃珠、水珠一起出现时，噪点主要来自这几处，主文件要写清对应做法：
- 大面积的亮光源被成百上千个镜面反射：柔光箱别太大，用边缘变暗的柔光布，四周加黑旗，让物体之间映到黑而不是一整片白；曝光宁可压低一档。
- 贴着表面的低机位：大光源会在远排每个物体上映成连成片的白带，镜头俯角留 15° 左右，或把光源往镜头一侧倾斜。
- 互反射次数太多：光泽反弹 4–6 次就够，再多只添噪点。
- 完全为零的粗糙度加景深或运动模糊：最容易出亮噪点，粗糙度给到 0.02–0.05；失焦镜面高光多的段落别把光圈开得太大。
- 渲染设置：自适应采样、间接光钳制、光泽过滤、关掉反射焦散、灯光树，降噪用带反照率和法线数据的降噪器，只压噪点不抹细节。



在"**档位来源**"一行后面写：

> **规范版本**：进阶版 1.9
>
> **视觉基调**：<基调名>

## 四、验收评分表

在 3.4 的基础上加关键项"海报帧与视觉基调"（约 5 分）。评分表是内部文件，可以写得比主文件细，但不能要求主文件里没写的东西。
