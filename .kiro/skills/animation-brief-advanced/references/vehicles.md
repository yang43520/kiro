# 车辆造型和运动（进阶版 1.9）

主文件里写车只写"一辆约 4.2 米长的小轿车"，模型就会被做成一个圆角盒子加四个圆柱轮子。车辆显得真不真，看五样：**比例、车身表面、部件的内部结构、材质分层、使用痕迹**，动起来再加**车轮和车身的联动**。车辆是主体、占画面一大块或在近景出现时，按这份写；远处只是车流光点的，按群集写就行。

载具动画的主体（汽车、电车、火车、摩托、机甲、飞船、船、飞机）都按这份写。轮式车辆写全部内容；机甲、飞船、船和飞机没有轮子，写第三到第六节，以及第七节里对应的运动。

## 一、原创

不照搬任何真实车型的外形；不出现品牌标、车标、可读的车牌和车身文字。真实车型的尺寸可以当比例参考，造型要重新设计。CC0 的车模也只当比例参考，不当起形底子。

## 三、车身表面

- **大面和特征线**：车身是连续的曲面，有一两条贯穿前后的特征线（肩线、腰线），侧面有轻微的鼓起，车顶往后收；曲面用细分曲面加支撑边控制，不能是方盒子倒个大圆角。
- **分缝**：车门、引擎盖、行李箱、加油口盖之间的分缝约 3–5 毫米，四周宽度均匀；分缝里是暗的，看得到下面一层钣金的边。机甲和飞船的装甲分缝按体量放大，但也要宽度一致、顺着结构线走。
- **倒角分三档**：大曲面之间的过渡（几厘米）、钣金的折边（几毫米）、小件的边（约 1 毫米）。用倒角修改器加加权法线。
- **玻璃**：有 4–6 毫米的厚度，边缘有一圈黑色陶瓷边，车窗有黑色的密封条；前挡风玻璃有一点弧度，映出周围。
- **小件**：门把手、后视镜（镜壳和镜片分开）、雨刮、天线、车牌框（不带字）、轮眉、侧裙、进气格栅（一格格有深度，后面是暗的）。

## 四、部件的内部结构

- **车灯**：灯罩是透明的，后面能看到反射碗或透镜、灯珠阵列、灯腔的黑色内壁；尾灯的红色是有色透镜，里面有纹理；灯亮起时只照亮该照的地方，不糊成一团光。
- **轮子**：轮辋有辐条、轮辋边、气门嘴和螺栓；从辐条之间能看到刹车盘和卡钳；轮胎侧壁有鼓起和细纹理（不带字），胎面有花纹沟。
- **内饰**（透过车窗能看到时）：座椅、头枕、方向盘、仪表台的轮廓，不用细，但不能是空的或一片黑。
- **底盘**（低机位能看到时）：排气管、悬挂摆臂、减震器、护板。
- **机甲、飞船**：关节处露出的液压杆、线缆和驱动器；推进器的喷口内部有导流叶片；舱盖有铰链和锁扣。

## 五、材质分层

| 材质 | 分层和可测特征 | 高光 |
|---|---|---|
| 车漆（金属漆） | 底色漆加金属闪片（闪片约 0.05 毫米，随视角闪），外面一层清漆，清漆表面有极轻的橘皮纹 | 清漆高光窄而亮、映出周围；底下的闪片一闪一闪 |
| 车漆（纯色漆） | 底色漆加清漆 | 清漆高光窄而亮 |
| 哑光漆、机甲的装甲漆 | 底漆、色漆，有的加一层哑光清漆 | 宽而软 |
| 镀铬 | 镜面 | 锐，映出周围 |
| 塑料饰条 | 哑光黑带细皮纹，或亮面钢琴黑 | 哑光的宽而糊，亮面的锐 |
| 橡胶 | 轮胎和密封条，几乎不反光，胎面新的发黑、旧的发灰 | 极宽极糊 |
| 玻璃 | 带一点绿或灰的夹层玻璃，有厚度 | 锐 |
| 灯罩 | 透明塑料，内侧有纹理 | 锐 |

用原理化 BSDF 的涂层（Coat）做清漆，闪片用程序化的沃罗诺伊纹理控制法线和粗糙度，橘皮纹用很淡的噪波凹凸。

## 六、使用痕迹（按位置分布）

| 位置 | 痕迹 |
|---|---|
| 车身下半截、轮拱后面 | 泥点和泥带，越往下越重；雨天湿亮 |
| 轮辋 | 刹车粉积在辐条根部，发灰发褐 |
| 门把手、油箱盖、后备箱边 | 细划痕和指甲划过的痕 |
| 车头、后视镜 | 小石子打出的漆点、虫渍 |
| 玻璃 | 水渍、灰；雨天雨刮扫出的扇形 |
| 轮胎 | 侧壁沾泥，胎面磨得发灰 |
| 机甲、飞船 | 装甲边缘掉漆、关节处磨亮、油渍、积碳、焊痕 |

用高度遮罩管下半截的泥，曲率遮罩管边缘的磨损，环境光遮蔽管缝里的积灰，手绘遮罩管个别划痕。

## 七、运动

- **车轮**：车轮转速等于车速除以轮半径（例如每秒 10 米、轮半径 0.32 米，每秒约转 5 圈），接地点不打滑；高速时轮辋糊成运动模糊，不能出现倒转的频闪。
- **车身姿态**：加速时车头微抬、刹车时车头点下、转弯时车身向外侧倾几度；过颠簸时悬挂先压缩再回弹。
- **转向**：前轮按阿克曼关系转，内侧轮转得比外侧多一点；方向盘跟着转。
- **轮胎和地面**：轮胎接地处微微压扁；湿路上轮后带起水雾和水线，土路上扬起尘土。
- **做法**：用 Rigacar 生成绑定（车轮按行驶距离自动转、悬挂、车身贴地），或者用驱动器按传动关系把车轮转角挂在位移上；车身用骨骼加阻尼做姿态。
- **电车和火车**：车轮在轨道上，轮缘贴着轨道内侧；受电弓跟着接触网上下；转弯时转向架先转。
- **机甲、飞船、飞机**：起步和停止有惯性，推进器和舵面的动作和姿态变化对得上。

## 八、反射环境

车漆和玻璃靠反射显出形体。不能用环境贴图，所以车是主体或近景时，写清车身上映出什么（周围的楼、树、路灯、天空），这些东西要真的建出来，至少建到映得出轮廓；棚拍时写清柔光箱和反光板的位置，车身上会映出它们的形状。

## 九、写进主文件的例子

> 这辆原创的紧凑型轿车车长约 4.5 米，轴距约 2.7 米，前悬比后悬长一点；轮胎约 22 厘米宽、18 寸轮辋，轮拱和轮胎之间留约 4 厘米。车身侧面一条从前灯一直拉到尾灯的腰线，车门和翼子板之间的分缝约 4 毫米、四周一样宽；车窗玻璃约 5 毫米厚，边缘一圈黑色陶瓷边。前灯罩后面是三颗透镜和一排灯珠，灯腔内壁是黑的；轮辋 5 根双辐条，辐条之间看得见打孔的刹车盘和红色卡钳。车漆是深灰金属漆，清漆层映出路边的楼和树，闪片在路灯下一闪一闪；下半截溅着泥点，轮辋辐条根部积着刹车粉。它以每秒约 8 米驶过，车轮每秒约转 4 圈，刹车时车头往下点一下。车身用细分曲面加支撑边建模，硬边用倒角修改器加加权法线，用 Rigacar 绑定。
