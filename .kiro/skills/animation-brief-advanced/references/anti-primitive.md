# 去掉"建模感"：别让物体看起来是几何体拼出来的（进阶版 1.4 起）

模型在 Blender 里建东西，最省事的路子是拿球、圆柱、立方体、圆锥直接摆在一起：甲虫是一个椭球加六根细圆柱，树是一根圆柱顶着几个球，蘑菇是半球扣在圆柱上，房子是一个立方体加一个三棱柱。这样做出来的东西半径处处一样、左右完全对称、部件之间要么悬空要么硬插进去、边是刀切一样的直角，一眼就看出是"建模的"。主文件只写"别用基本体凑"不够，要把**起形方法、轮廓变化、部件怎么长在一起、表面起伏和个体差异**写出来，再要求开工前看一眼灰模。

工具、贴图和插件的限制照旧：只用 Blender 5.0 内置功能、官方免费扩展和开源插件，只用图像贴图，不用现成模型和扫描模型。下面的做法都是内置功能能完成的。

## 一、七条规则

1. **起形不从基本体直接出**：
   - 生物、果实、菌类这类有机形：先用曲线加蒙皮修改器，或用元球搭出大形，再用体素重构网格变成一整块，用雕刻和多重分辨率细分做出肌肉、节和褶皱。
   - 硬表面（机件、器皿、家具）：用多边形建模，硬边加支撑边再细分曲面，或用倒角修改器加加权法线。
   - 岩石、土坯、地形：用体素重构网格或高度图起形，再雕刻和置换修改器。
   - 植物：按生长规则生成（Sapling Tree Gen、几何节点、IvyGen），不摆球和圆柱。
2. **截面和轮廓要变**：腿、触角、树枝、尾巴都是从粗到细，关节处鼓、关节之间收；身体的截面不是正圆，背面和腹面的弧度不同。剪影里不该出现正圆和笔直的线（硬表面产品除外）。
3. **不完全对称**：生物左右差 5–10%，姿态也不是完全对称地摆；同一棵树的两侧分枝不一样多。
4. **部件要长在一起**：头和身体、枝和干、腿和胸、蘑菇盖和柄之间要有过渡，例如圆角、关节膜、褶皱、树皮的鼓包、焊缝或榫卯；不能悬空，也不能硬插进去露出穿插。有机体最好是一整块网格。
5. **每条边都有倒角**：硬物边缘至少 0.5–2 毫米的小倒角，接住一道细高光；没有刀切一样的直角。
6. **表面有三级起伏**：大形是整体的体块，中形是结构（肌肉、体节、木纹、砖缝、叶脉），小形是纹理（毛孔、刻点、裂纹，用置换修改器、法线或凹凸贴图）。这三级对应主文件里的"大形、中形、小形"。
7. **个体都不一样**：同类东西至少做 3–5 个变体，再加随机旋转与缩放和形状上的随机扰动；不能整片复制同一个。

## 二、灰模自查

材质会掩盖造型的问题，所以要先看不带材质的灰模。主文件里写一句（说法自己定）：

> 开工前先渲两张灰模，一张侧面剪影、一张四分之三角度，看主体的比例对不对、有没有哪里看得出是球和圆柱拼的，没问题再上材质。

## 三、常见对象的起形做法

| 对象 | 起形 | 去掉建模感的关键 |
|---|---|---|
| 昆虫、甲壳类 | 身体用细分曲面从低模拉出，或元球加体素重构后雕刻；腿用曲线挤出，半径按节变化 | 体节之间有缝和关节膜；腿每节粗细不同、末端有爪；甲壳有刻点和纵沟 |
| 鸟、鱼、四足动物 | 曲线加蒙皮修改器搭骨架形，体素重构后雕刻出肌肉和骨点 | 截面不是圆；肌肉和骨点在皮下鼓起；毛和羽按梳理方向成簇 |
| 蜗牛、软体 | 壳用几何节点按对数螺线生成，身体雕刻 | 壳口外翻、生长纹一圈圈；身体有颗粒和褶皱 |
| 树干和树枝 | Sapling Tree Gen 或几何节点按分枝规则生成 | 枝和干交接处鼓起；树干底部有板根或根张；树皮用置换修改器加照片贴图 |
| 叶片和花瓣 | 面片加形态键做卷曲，带透明通道的照片贴图 | 叶缘有锯齿或波浪，叶面沿叶脉起伏；没有完全平的叶子 |
| 蘑菇和菌类 | 菌盖和菌柄做成一整块，雕刻出菌褶 | 盖边内卷或开裂；柄上粗下细、有菌环；不是半球扣圆柱 |
| 岩石、土坯、砖墙 | 体素重构网格加雕刻，或模块化建模的砖块加随机扰动 | 断面有节理；每块砖大小和缺角不同；灰缝凹进去 |
| 木构和家具 | 多边形建模，硬边加倒角 | 榫卯和接缝看得见；木纹方向跟着构件走；边角磨圆 |
| 陶罐、器皿 | 用曲线绕轴旋转出截面 | 口沿厚度不均、有拉坯纹；不是正圆柱 |
| 布、帆、纸 | 布料模拟或形态键做褶皱 | 有厚度（实体化修改器）；边缘有卷边和毛边 |
| 机件 | 硬表面建模，支撑边加细分曲面，或倒角修改器加加权法线 | 有分缝、螺钉、圆角过渡；同一个零件的倒角大小一致 |

## 四、主文件里怎么写

在"场景和主体"写建模做法时，每个主体用一两句写清：

- 从什么起形（对应上表）；
- 轮廓怎么变（哪里粗、哪里细、哪里鼓）；
- 部件怎么长在一起；
- 三级起伏各是什么；
- 个体差异怎么做。

例如：

> 甲虫的身体用细分曲面从低模拉出来，头、前胸和鞘翅之间各有一道窄缝；鞘翅的截面背面拱、腹面平，上面一道道纵沟和细刻点用置换修改器做。腿用曲线挤出，每节粗细不同、关节处略鼓，末端是一对小爪，腿根和胸部之间有一圈关节膜，不是插进去的圆柱。左右两侧的腿姿态略有不同。
