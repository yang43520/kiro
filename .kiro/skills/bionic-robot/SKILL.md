# 仿生机器人动画（bionic-robot）

全程用中文和用户沟通。目标是**一次交出能通过验收的仿生机器人方案**：机器人原创、外形和身体结构以真实动物为原型、机械结构说得通、动作有真实机器人的分量，画面达到进阶版的电影级要求，没有穿模、没有建模感。

## 0. 和其他 skill 的关系

本 skill 依赖两个 skill，三个要装在同一个 `.kiro/skills/` 目录下：

- `animation-brief-advanced`（1.8）：文件格式、写法、画面要求、防穿模、材质细节、动物结构（`references/animals.md`）、校验和提交，全部沿用。
- `character-animation`（1.0）：人形机器人的比例（`references/anatomy-proportions.md`）、面部动作单元（`references/face-expression.md`）、表演和动作（`references/performance-motion.md`）、剧情电影和动画长片两种基调，借来用。

本 skill 的文件：

| 文件 | 用途 |
|---|---|
| `references/bio-mech-mapping.md` | **核心**：生物结构到机械结构的对应表；各原型的关节自由度和转动范围；驱动器怎么选、放在哪 |
| `references/humanoid-robot.md` | 人形机器人：比例、面部三条路线（无脸面罩、机械脸、仿生脸）、肩肘腕、手、髋膝踝、脚、躯干和颈 |
| `references/bionic-types.md` | 仿生机器人：四足、鸟形、鱼形和蛇形、多足；各自的结构要点和动作要点 |
| `references/robot-materials.md` | 外观路线（工业写实、消费电子白壳）、材料、分缝和紧固件、制造和使用痕迹、灯和屏 |
| `references/robot-motion.md` | 平衡和质心、电机的动作特性、机械和生物感的平衡、次级运动、绑定做法、外壳间隙和防穿模 |
| `references/robot-taxonomy.md` | 本 skill 自带的机器人类目（不改正式类目表） |
| `references/robot-baseline.md` | 机器人的制作底线、专业术语、推荐插件和技术模块 T14–T16 |
| `references/robot-tones.md` | 另加的视觉基调：科技发布 |
| `references/robot-rubric.md` | rubric 要加的关键项和锚点；机器人设定卡模板 |
| `references/open-source-refs.md` | 可参考的开源机器人设计、许可和能怎么用 |
| `references/example/` | 一个完整的示例任务，三个文件和 rubric 的 spec 都能通过校验 |

## 1. 和进阶版不同的规定

| 项目 | 规定 |
|---|---|
| 原型 | 每个机器人先选一个真实原型（人、狗、猫、马、鸟、鱼、蛇、昆虫、蜘蛛等），比例、关节数量和转动范围都从原型来，在考点说明里写"**原型**：……" |
| 原创 | 不像任何现有机器人：真实产品、研究平台、电影、游戏、动画里的都不行；不写品牌和型号；标识只用无文字的图形符号 |
| 人物 | 机器人不是人；画面里默认不出现人。人形机器人的脸按 `references/humanoid-robot.md` 的三条路线走，默认用无脸面罩或机械脸，仿生硅胶脸只在用户明确要求时用 |
| 起形 | 外壳和零件按硬表面建模自己建；人形的比例可以拿 CC0 人体基础网格当比例参考（不当外壳用），动物形的比例按 `animals.md` |
| 动作数据 | 不用动作捕捉和外部动作数据 |
| 风格 | 外观只走一条：工业写实、消费电子白壳或机械朋克（1.1 起）；不做卡通机器人（卡通机器人用进阶版的"角色动画/简易人形/小型机器人"） |

其余规定（不出现可读文字和品牌、只用内置和开源插件、只允许贴图、重模拟最多 2 种、默认进阶档、一镜到底、12 秒、1280×720、30 帧/秒、无声）都和进阶版一样。

## 2. 第一步：创意建议

用户说出想法后，先给 3–5 个方向，等用户选定。表格在进阶版的列上加两列"原型"和"外观"：

`方向｜原型｜外观｜类目路径｜起因 → 过程 → 结果｜画面元素｜动态形式｜档位与考点｜制作方法与插件｜制作难度`

- **原型**：一个真实物种，写清借了它的哪些结构（例如"原型是猎豹：细长的腿、柔韧的脊柱、长尾平衡"）。
- **外观**：工业写实、消费电子白壳或机械朋克。
- **起因 → 过程 → 结果**：要有一段能展示机械结构的过程，例如外壳打开露出驱动器、手指一节节试探着握住东西、腿在不平的地面上调整落脚。
- 推荐 1–2 个方向；人形机器人默认推荐无脸面罩或机械脸。

## 3. 定档位和考点

考点和配方和进阶版一样。机器人常用：

| 考点 | 分级 | 在机器人上体现在哪 |
|---|---|---|
| 7 足式步态与重心转移 | L4 | 人形和四足走、跑、上台阶、在不平地面调整落脚，质心在支撑面内 |
| 5 多关节联动与抓取交互 | L3 | 绳驱手指一节节合拢抓住物体，指腹贴住 |
| 4 部件联动与运动匹配 | L2 | 连杆、液压缸、同步带和关节转动匹配，传动比对得上 |
| 9 结构爆炸拆解与渐进式生长建造 | L2 | 外壳打开、零件沿装配轴线拆开再合回 |
| 6 次级跟随与惯性滞后 | L3 | 线缆、柔性护套、尾巴的滞后和余摆（刚性外壳不晃） |
| 10 体积碰撞与边界阻挡 | L2 | 关节转到限位时外壳不互穿，手和物体、脚和地面的接触 |
| 16、17 | L1 | 灯光和外壳材质的变化、单镜头运镜 |

## 4. 一次合格的设计规则（写文件前逐条落实）

进阶版 SKILL.md 第 3 节全部适用，另外做到：

1. **原型对应**：按 `references/bio-mech-mapping.md` 把原型的骨骼、关节、肌肉、肌腱、皮肤、神经血管、眼睛对应到框架、关节、驱动器、绳驱或连杆、外壳和蒙皮、线缆和管路、摄像头，主文件里逐项写出来。
2. **比例和自由度**：写原型的比例（人形写头身比和身高，动物写体长和肩高），写每个主要关节的自由度和转动范围（带度数）；关节处为了放驱动器可以加粗，但比例关系不能变。
3. **驱动器的位置**：重的驱动器靠近躯干，末端用绳驱或连杆，写清每个主要关节由什么驱动。
4. **外壳和让位**：外壳在哪里分缝、关节处怎么让位、间隙多大（一般 1–3 毫米）；转到限位时外壳不互穿。
5. **人形的面部和四肢**：按 `references/humanoid-robot.md` 写面部路线、眼睛位置和视线、肩肘腕、手（5 指、每指 3 节、拇指对掌、指腹橡胶垫）、膝和髌骨护板、脚（前掌后跟和脚趾关节）。
6. **材质和痕迹**：外观路线一条到底；材料分开写，写分缝、紧固件、加工纹或分模线、关节处的磨亮、线缆护套和少量油渍；按 `robot-materials.md` 写。
7. **动作**：质心在支撑面内；电机加速快但不突跳、到位有极小的过冲再回正、静止时有轻微的伺服修正；刚性外壳不晃，线缆和柔性件有余摆；表演沿用人物 skill 的动机、预备、视线先行，幅度更克制（`robot-motion.md`）。
8. **绑定**：刚性零件用父子级绑定在骨骼上，不刷蒙皮权重；每个关节加旋转限制约束；连杆和液压缸用阻尼追踪和拉伸到约束联动；线缆用曲线加钩挂修改器。
9. **接触清单**：脚和地面、手指和物体、外壳和外壳（关节限位处）、线缆和外壳，本片有的都写进接触清单。

## 5. 输出文件

和进阶版一样输出三个文件。另外：

- 考点说明在"**视觉基调**"那一行后面加：`**机器人规范**：机器人版 1.0`、`**原型**：<物种>`、`**外观**：工业写实`、`**外观**：消费电子白壳` 或 `**外观**：机械朋克`；人形机器人再加 `**面部路线**：无脸面罩`、`机械脸` 或 `仿生脸`。规范版本仍写 `进阶版 1.8`。并加一节 `## 机器人设定卡`（格式见 `references/robot-rubric.md`）。
- 主类目从 `references/robot-taxonomy.md` 里选；标签按正式类目表第三、四节选。
- rubric 加关键项"仿生原型与比例""机械结构与运动学"，人形机器人再加"面部与表演"。可以用 `scripts/build_rubric.py` 从一份 JSON 生成。

## 6. 校验

```bash
python3 <本 skill 目录>/scripts/check_robot.py <任务文件夹>/<标题>.md
```

脚本先按进阶版 1.8 的全部规则检查（自动换上机器人类目、机器人制作底线、人物和机器人的基调），再查机器人部分：原型和外观、机器人设定卡、原型的比例、关节自由度和转动范围、驱动器、外壳分缝和间隙、旋转限制约束和父子级绑定、人形的面部路线和手、质心和电机特性、原创和不出现现有机器人的名字、rubric 的机器人关键项。

脚本查不出来、回复前要自己核对的：自由度和转动范围是否符合原型；驱动器的位置和大小是否说得通；造型是否和任何现有机器人撞脸。

## 7. 回复用户的格式

按进阶版第 12 节，第二步的回复在"类目与标签"后面加一张**机器人设定卡**表和一张**原型对应表**（生物结构｜机械结构｜本片的做法）。
