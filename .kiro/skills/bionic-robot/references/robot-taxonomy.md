# 机器人类目（机器人版 1.0）

正式类目表（`.kiro/steering/animation-taxonomy.md`）里只有"角色动画/简易人形/小型机器人"（几何部件父子拼装的小机器人）和"载具动画/幻想载具"（可驾驶的机甲）。本 skill 自带下面这组仿生机器人类目，**只在本 skill 的任务里用，不改正式类目表**；标签仍按正式类目表第三、四节选。检查脚本会把这里的类目和正式类目表合在一起认。
