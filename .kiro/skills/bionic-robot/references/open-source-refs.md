# 可参考的开源机器人设计（机器人版 1.0，2026 年 11 月核对）

只学结构和机构，不搬造型；片子里的机器人一律原创，不写这些项目的名字。

| 项目 | 类型 | 许可 | 能参考什么 |
|---|---|---|---|
| Poppy Humanoid（https://github.com/poppy-project/poppy-humanoid） | 3D 打印的小型人形 | 硬件 CC-BY-SA，软件 GPL；名字是注册商标 | 人形各关节的舵机布置、躯干和髋的结构 |
| InMoov（https://inmoov.fr/project/） | 真人大小的 3D 打印人形 | CC BY-NC（非商用） | 绳驱手指和手腕、眼球和下颌的机构 |
| ODRI Solo-8（BSD-3 镜像：https://github.com/ToolKnox/hawkridge-odri-solo8-open-quadruped-robot） | 研究用四足 | BSD-3 | 无刷电机加同步带的腿部驱动器、腿的三段比例 |
| Rigify | Blender 内置 | 内置 | 人形和动物骨骼模板 |
| MACHIN3tools、Bool Tool | 硬表面建模 | 开源、内置扩展 | 分缝、倒角、布尔开孔 |
| AnimAide、Wiggle 2 | 动画 | 开源 | 运动曲线、线缆和尾巴的余摆 |

真实的商业机器人产品和影视游戏里的机器人不列在这里，也不能当造型参照。
