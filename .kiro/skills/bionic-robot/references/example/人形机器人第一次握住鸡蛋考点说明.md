# 人形机器人第一次握住鸡蛋考点说明

> 内部校验用，不交给制作方，不属于制作输入。

**主类目**：角色动画/仿生机器人/人形机器人

**题目档位**：上限档（配方：L3 + L2，附带 2 个 L1）

**档位来源**：默认

**规范版本**：进阶版 1.8

**视觉基调**：剧情电影

**机器人规范**：机器人版 1.0

**原型**：人

**外观**：工业写实

**面部路线**：无脸面罩

**耦合链**：同一台人形机器人的右臂和右手：前臂里五台小电机经带轮收放钢丝绳，按传动比带动五根手指一节节弯曲；手指依次试一遍后，摄像头、头、肩、肘、腕按先后伸向鸡蛋，质心前移、脚踝调整；指腹依次贴上蛋壳握住、举起、放回，带轮的转角始终和手指的弯曲对应；窗光和台灯在外壳上流转，镜头一镜到底从手的特写退到全景。

| 编号 | 考点 | 分级 | 作用对象与时段 | 在片中的体现 |
|---|---|---|---|---|
| 5 | 多关节联动与抓取交互 | L3 | 右手五根手指和鸡蛋，0.5–12 秒 | 手指每节 0–90° 依次弯曲；伸手时预先张开；拇指先贴上蛋壳，其余手指一根根贴上，指腹橡胶垫压扁约 1 毫米；蛋被推动时停住重贴；放回时从小指到拇指依次松开 |
| 4 | 部件联动与运动匹配｜防打滑 | L2 | 前臂里的五台电机、带轮、钢丝绳和五根手指，0.5–12 秒 | 带轮转半圈手指弯到底，钢丝绳随之收放；五个带轮的转角和五根手指的弯曲一一对应，钢丝不打滑、不穿过导管 |
| 16 | 光影流转与材质外观演变 | L1 | 窗光和台灯，0–12 秒 | 窗外云移动，主光稍暗又亮；台灯的暖光随伸手越来越多地落在手和蛋上 |
| 17 | 单镜头运镜构图 | L1 | 镜头，全片 | 一镜到底：中心构图特写 → 三分法 → 层次纵深 → 对角线 → 负空间全景 |

**最高分级**：L3

## 机器人设定卡

| 项目 | 内容 |
|---|---|
| 原型 | 人（成年人比例） |
| 尺寸和比例 | 身高约 175 厘米，约 7.5 个头高，肩宽约两个头宽 |
| 外观路线 | 工业写实 |
| 面部路线 | 无脸面罩（深色镀膜玻璃，后面两个摄像头模组） |
| 主要材料 | 阳极氧化铝、碳纤维、黑色工程塑料、橡胶、不锈钢钢丝绳、镀膜玻璃 |
| 驱动方式 | 肩部无刷电机加行星减速器，肘部谐波减速器，手指由前臂里的五台小电机经带轮和钢丝绳驱动，踝部两根并联直线推杆 |
| 自由度 | 颈 2、肩 3、肘 1、前臂 1、腕 2、手指每指 3 节、髋 3、膝 1、踝 2、脚趾 1 |
| 原创说明 | 原创设计，不像任何现有的机器人产品或影视游戏里的机器人 |

## 制作底线清单

**二级类目**：仿生机器人

**技术模块**：T14、T15、T16（另用进阶版 T9 的粒子做法）

**本片要用的专业术语**：硬表面建模、细分曲面、支撑边、布尔运算、倒角修改器、加权法线、父子级绑定、旋转限制约束、反向动力学、极向目标、地板约束、阻尼追踪、拉伸到约束、驱动器、钩挂修改器、二级摆动、骨骼链、形态键、自由度、行星减速器、谐波减速器、直线推杆、钢丝绳、传动比、各向异性、曲率遮罩、环境光遮蔽、粒子系统、湍流力场、生命周期

**推荐插件**：MACHIN3tools（开源）、Extra Mesh Objects（内置扩展）、Rigify（内置）

**通用底线**：PBR 贴图或程序化纹理（近景 4K）、倒角、接触阴影、AgX 色彩管理（Base Contrast）、足够采样、100% 查看细节、尺度参照（约 5.7 厘米的鸡蛋、螺丝刀、前臂盖板）、防重复

**重模拟**：无（手指用骨骼和驱动器，钢丝绳用曲线加钩挂修改器，浮尘用粒子系统）

## 类目与标签

**归类理由**：主体是一台以人为原型的原创人形机器人，用绳驱的手第一次握住鸡蛋，展示手指的抓握、驱动的联动和全身的平衡，属于本 skill 机器人类目里的仿生机器人/人形机器人。

| 标签组 | 选定标签 | 必要说明 |
|---|---|---|
| 视觉造型 | 写实 | 照片级写实的工业机器人和维修间 |
| 材质质感 | 金属、塑料橡胶、木石天然 | 主材质是阳极氧化铝、碳纤维和钢丝；其次是工程塑料和橡胶垫；工作台的橡木 |
| 渲染风格 | 真实渲染 | 常规物理渲染 |
| 动态节奏 | 机械节奏 | 电机驱动，加速快、到位干净，有极小的过冲 |
| 动画行为 | 主行为：结构与装配/开合联动/机械传动 | 带轮和钢丝绳带动手指 |
| 动画行为 | 辅助行为：位移与运动/路径运动/沿线移动 | 手臂伸向鸡蛋、举起、放回 |

| 色彩基调 | 不填 | 颜色来自材料本身 |
| 时序结构 | 多段序列 | 试手指 → 看向鸡蛋 → 试握 → 举起来看 → 放回 |
| 复杂度等级 | 多元编排 | 骨骼、驱动器和约束的联动，不含模拟 |
| 应用场景 | 不填 | 没有明确的用途依据 |
