# 机器人 rubric 和机器人设定卡（机器人版 1.0）

## 一、rubric 在进阶版基础上加的关键项

进阶版 rubric 的通用项、数量硬指标、材质与制作底线、任务项、加分项和五个关键项（动态密度、电影级画面、细节精致度、海报帧与视觉基调、接触与防穿模）都保留，另加：

| 维度 | 类型 | 权重 | 写什么 | 什么时候加 |
|---|---|---|---|---|
| 仿生原型与比例 | discrete，关键项 | 约 5 | 原型、比例、关节数量和转动范围 | 都加 |
| 机械结构与运动学 | discrete，关键项 | 约 6 | 驱动器、绳驱或连杆、联动、限位、外壳分缝和间隙、质心和电机特性 | 都加 |
| 面部与表演 | discrete，关键项 | 约 5 | 面部路线、眼睛位置和视线、表情（如果有）、动机和先后 | 人形机器人 |

锚点：

- **仿生原型与比例**：0 分是看不出原型，或比例像玩具、像一堆零件，或关节数量和方向不对（肘反折、四足腿关节方向反了）；50 分是原型和比例基本对，但有一处关节范围或比例明显失调；100 分是比例、关节数量和转动范围都按原型做到。
- **机械结构与运动学**：0 分是关节转动没有驱动器或联动、连杆和液压缸脱开、外壳互穿，或动作像生物一样软、像玩具一样弹；50 分是结构说得通，但有一处联动对不上、一处外壳轻微互穿，或电机的过冲和伺服修正缺失；100 分是驱动、联动、限位和间隙都对，动作有真实机器人的分量。
- **面部与表演**：0 分是面部路线混用、眼睛位置不对、视线没有焦点，或仿生脸进了恐怖谷；50 分是面部和表演基本成立，但视线先行或动作先后有一处缺失；100 分是面部按路线做到，视线先行、动作有动机、幅度克制。

权重从"主体与目标""动作完整性"和任务项里匀出来，合计仍是 100。

## 二、生成 rubric

`scripts/build_rubric.py <spec.json> <任务文件夹>/rubric.json`，spec 格式和人物 skill 一样；上面三个关键项和进阶版常用维度都内置了默认锚点。脚本会检查锚点齐全、权重合计 100，以及"仿生原型与比例""机械结构与运动学"都在；spec 里写 `"humanoid": true` 时还要求有"面部与表演"。

## 三、机器人设定卡（写进考点说明）

```markdown
## 机器人设定卡

| 项目 | 内容 |
|---|---|
| 原型 | 人（成年男性比例） |
| 尺寸和比例 | 身高约 175 厘米，约 7.5 个头高 |
| 外观路线 | 工业写实 |
| 面部路线 | 无脸面罩 |
| 主要材料 | 阳极氧化铝、碳纤维、黑色工程塑料、橡胶 |
| 驱动方式 | 大关节无刷电机加行星减速器，肘腕谐波减速器，手指钢丝绳 |
| 自由度 | 颈 2、肩 3、肘 1、前臂 1、腕 2、手指每指 3 节、髋 3、膝 1、踝 2 |
| 原创说明 | 原创设计，不像任何现有的机器人产品或影视游戏里的机器人 |
```
