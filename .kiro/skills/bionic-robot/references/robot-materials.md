# 机器人的外观和材质（机器人版 1.0）

## 一、外观只走一条路线

| 路线 | 特征 | 主材料 | 别混进来 |
|---|---|---|---|
| 工业写实 | 结构外露、功能优先，看得到驱动器、线缆和紧固件 | 阳极氧化铝、碳纤维、钛合金、黑色工程塑料、橡胶 | 消费电子那种整片无缝的白壳 |
| 消费电子白壳 | 大块光滑的曲面外壳包住结构，只在关节处露出一点机械 | 哑光白色工程塑料、浅灰阳极氧化铝、深色面罩玻璃、硅胶 | 外露的油管和乱走的线缆 |

两条路线都不做卡通机器人；颜色以材料本色为主，点缀色最多一种。

## 二、材料（写可测特征和高光）

| 材料 | 可测特征 | 高光 |
|---|---|---|
| 阳极氧化铝 | 细磨砂，粗糙度约 0.3–0.4 | 宽而糊 |
| 拉丝铝或钛 | 拉丝纹顺着零件长度走 | 一条沿拉丝方向的细长高光，用各向异性 |
| 碳纤维 | 2×2 斜纹编织，每格约 2–3 毫米，外面一层清漆 | 清漆的高光窄而亮，下面的编织纹随角度闪 |
| 工程塑料 | 哑光，有很细的皮纹 | 宽而软 |
| 橡胶 | 足垫、指腹、密封圈 | 几乎不反光，边缘被磨得更亮 |
| 硅胶 | 柔性蒙皮、仿生脸 | 有一点次表面散射，高光软 |
| 面罩玻璃 | 深色，弧面 | 映出环境，高光锐 |
| 液压杆 | 镀铬 | 镜面，杆上有一层油膜 |

## 三、构造细节

- **分缝**：外壳按功能分块，分缝 0.5–1 毫米，走向顺着曲面的结构线，不乱切。
- **紧固件**：沉头螺钉、卡扣、快拆销，按受力位置排；同一路线里螺钉规格统一。
- **加工痕迹**：铣削的刀纹、注塑件的分模线和浇口痕、碳纤维边缘的切口。
- **倒角**：所有硬边都有小倒角，用倒角修改器加加权法线。
- **标识**：只用无文字的图形符号（警示三角、箭头、关节编号用点数表示），不写字、不写型号。

## 四、使用痕迹（按受力和接触分布）

| 位置 | 痕迹 |
|---|---|
| 关节外壳的边 | 被反复蹭亮的一圈，漆面磨薄 |
| 足底、指腹 | 橡胶磨损不均，沾灰 |
| 手掌、前臂 | 细划痕，握工具处更多 |
| 液压缸、关节下方 | 少量油渍往下拖 |
| 线缆护套 | 弯折处褪色、起毛 |
| 外壳朝上的面 | 积灰；户外的有雨渍 |

用曲率遮罩管磨亮，环境光遮蔽管积灰，法线朝向遮罩管朝上的积灰和雨渍，手绘遮罩管油渍和个别划痕。

## 五、灯和屏

- 指示灯和面罩后的光克制：亮度低于主体的受光面，不发散、不加辉光；颜色最多一种。
- 屏幕只显示图形，不显示文字和数字。
