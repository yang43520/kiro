# 机器人的动作、绑定和防穿模（机器人版 1.0）

## 一、平衡

- 质心在支撑面（着地的脚围成的范围）内；单脚支撑时质心移到支撑脚上方。
- 人形走路时膝盖微屈、步子比人小一点，脚踝不停地微调；被推一下时先用脚踝、再用髋、最后迈一步来恢复。
- 四足慢走时三条腿着地，小跑时对角两条腿着地，靠快速换步保持平衡。

## 二、电机的动作特性

- 加速和停止都快，但不是瞬间跳到位：运动曲线有很短的缓入缓出。
- 到位时有极小的过冲再回正，幅度一两度、几帧之内。
- 静止时有轻微的伺服修正：关节有极小的、不规则的微动，不能像雕塑一样完全不动。
- 多个关节动作有先后，不是所有关节同时启动、同时停止。
- 重的部件动得慢、轻的末端动得快。

## 三、机械感和生物感的平衡

- 动作路线按原型（视线先行、预备动作、眼 → 头 → 肩 → 腰的先后、手指从尖到根依次合拢），沿用人物 skill 的 `performance-motion.md`。
- 幅度比生物克制，停顿更干净；不做挤压拉伸。
- 刚性外壳不晃不变形；线缆、波纹护套、柔性蒙皮、织物和尾巴有滞后的余摆。
- 表情（如果有）比人慢一点、少一点。

## 四、绑定

- 刚性零件用父子级绑定挂在骨骼上，不刷蒙皮权重。
- 每个关节加旋转限制约束，范围按 `bio-mech-mapping.md` 的自由度表。
- 四肢用反向动力学加极向目标；脚用地板约束锁住，手指用反向动力学钉在物体表面。
- 连杆、推杆和液压缸：缸筒用阻尼追踪对准活塞杆的另一端，活塞杆用拉伸到约束或在缸筒里滑动，两端的球铰跟着转。
- 齿轮、同步带用驱动器按传动比联动。
- 线缆用曲线加钩挂修改器挂在两端的卡扣上，中间加一点柔体或二级摆动；柔性蒙皮和仿生脸用形态键，必要时用布料模拟。

## 五、外壳间隙和防穿模

| 接触 | 做法 |
|---|---|
| 关节处的外壳 | 每个关节写清外壳间隙（一般 1–3 毫米），转到旋转限制约束的限位时外壳刚好不碰 |
| 线缆和外壳 | 线缆贴着外壳走但留几毫米，跨关节处的弯曲余量足够，最大弯曲时不穿过外壳 |
| 脚和地面 | 地板约束锁住，橡胶足垫着地时压缩一点，不陷不浮不滑 |
| 手指和物体 | 指尖反向动力学钉在表面，指腹橡胶垫压扁约 1 毫米，不穿进物体 |
| 液压杆和缸筒 | 活塞杆始终在缸筒里，伸到最长时还留一截 |
| 外壳开合 | 打开和合上时按铰链轴转，合上后分缝均匀、不错位 |

"底线和限制"里的接触清单列出本片有的接触，写"第 S 秒 + 谁和谁"，用线框和 X 射线视图逐帧看。
