# 生物结构到机械结构（机器人版 1.0）

仿生机器人先有原型，再有机械。原型的比例、关节数量和转动范围决定它像不像；机械的做法决定它说不说得通。

## 一、对应表

| 生物结构 | 机械对应 | 主文件要写清的 |
|---|---|---|
| 骨骼 | 主框架和杆件：铝合金型材、碳纤维管、钛合金件 | 骨长比例按原型；关节处为放驱动器加粗，但长度关系不变 |
| 关节 | 旋转关节（单轴）、两三个旋转关节轴线相交组成的球关节、万向节、四连杆 | 每个关节几个自由度、各转多少度（见第二节） |
| 肌肉 | 无刷电机加减速器（行星或谐波减速器）、直线推杆、液压缸、气动人工肌肉 | 每个主要关节由什么驱动、装在哪；重的靠近躯干 |
| 肌腱 | 钢丝绳加滑轮、同步带、推拉连杆 | 手指、脚趾、远端关节怎么被躯干附近的驱动器带动，绳怎么走线 |
| 皮肤 | 硬外壳（铝、碳纤维、工程塑料）、柔性蒙皮（硅胶、弹性织物）、关节处的波纹护套 | 外壳的分块和分缝、关节处怎么让位、间隙多大 |
| 神经、血管 | 线缆束、液压管、气管 | 沿四肢内侧走，跨关节处留弯曲余量，用卡扣固定 |
| 眼睛 | 摄像头模组、深度相机、带光圈叶片的镜头 | 位置和间距按原型，视线方向按原型的眼睛 |
| 耳、鼻、须 | 麦克风阵列、传感器窗口、触须式接触传感器 | 位置按原型 |
| 脚掌、肉垫、蹄 | 橡胶足垫、带力传感器的足端 | 着地时有一点压缩 |

## 二、关节自由度和转动范围（按原型取，数值是参考值）

### 人

| 关节 | 自由度 | 转动范围参考 | 机械做法 |
|---|---|---|---|
| 颈 | 3 | 低头仰头约 ±50°，左右转约 ±70°，侧倾约 ±40° | 三个旋转关节，或一个转盘加一个俯仰关节 |
| 肩 | 3 | 前举约 180°，外展约 180°，内外旋约 ±70° | 三个轴线相交于一点的旋转关节 |
| 肘 | 1 | 0–145° | 单轴铰链，有机械限位 |
| 前臂旋转 | 1 | 约 ±80° | 前臂内一个旋转关节 |
| 腕 | 2 | 屈伸约 ±70°，左右偏约 ±25° | 两个正交旋转关节 |
| 手指 | 每指 3 节，约 4 个自由度 | 每节弯曲约 0–90° | 绳驱或连杆，末两节常常联动 |
| 拇指 | 4–5 | 能和其余四指对掌 | 根部有一个斜轴关节 |
| 腰 | 1–3 | 左右转约 ±45° | 腰部转盘 |
| 髋 | 3 | 前屈约 120°，后伸约 20°，外展约 45° | 三个旋转关节 |
| 膝 | 1 | 0–135° | 单轴铰链，前面有护板 |
| 踝 | 2 | 屈伸约 +20°/−50°，内外翻约 ±20° | 两个正交关节，或两根并联推杆 |
| 脚趾 | 1 | 约 0–60° | 前掌和后跟之间一个铰链 |

### 四足（狗、猫）

| 关节 | 自由度 | 说明 |
|---|---|---|
| 肩（髋）外展 | 1 | 腿往外摆，约 ±30° |
| 肩（髋）屈伸 | 1 | 腿前后摆 |
| 肘（膝） | 1 | 前腿的"肘"向后弯，后腿往后弯的那一节其实是跗关节；真正的膝在躯干旁边 |
| 腕、跗 | 0–1 | 简化机器人常省掉，写实仿生时保留 |
| 脊柱 | 0–3 | 写实仿生时做成两三节，奔跑时一屈一伸 |
| 尾 | 2 起 | 多节，用于平衡 |

### 鸟、鱼、蛇、多足

见 `bionic-types.md`。

## 三、驱动器怎么选

| 驱动 | 用在 | 外观特征 |
|---|---|---|
| 无刷电机加行星减速器 | 髋、膝、肩这类大关节 | 扁圆的关节模组，外圈有散热筋 |
| 谐波减速器 | 肘、腕、颈这类要求精度的关节 | 薄而精的关节环 |
| 直线推杆、滚珠丝杠 | 踝、膝的并联驱动 | 一根带伸缩杆的长筒，两端是球铰 |
| 液压缸 | 大力的腿和臂 | 缸筒、活塞杆和油管，杆上有一层油膜 |
| 钢丝绳加滑轮 | 手指、脚趾、远端关节 | 细钢丝沿指节走，过滑轮和导管 |
| 同步带 | 把驱动器挪到近端 | 带齿的皮带和带轮 |
| 气动人工肌肉 | 仿生柔软的部位 | 编织网包着的气囊，充气时变粗变短 |

## 四、写进主文件的样子

> 这台机器人以人为原型，身高约 175 厘米，约 7.5 个头高。肩是三个轴线相交的旋转关节，由肩胛位置的三台扁圆无刷电机加行星减速器驱动，前举能到 180°；肘是单轴铰链，0–145°，谐波减速器装在上臂里；手指用钢丝绳驱动，钢丝从前臂里的五台小电机出来，沿手背的导管走到每节指骨，过三个小滑轮，末两节联动。关节外壳和臂壳之间留约 2 毫米的缝，肘弯到 145° 时上臂壳和前臂壳刚好不碰。
