# 路线：写实还是风格化（人物版 1.0）

每条人物片只有一条路线。路线定了，比例、皮肤、毛发、表情幅度、动作节奏和灯光都按那一列写，不混用。

## 一、两条路线对照

| 方面 | 写实路线 | 风格化路线 |
|---|---|---|
| 片种参照 | 剧情电影、纪录片里的人物镜头 | 三维动画长片 |
| 头身比 | 成人约 7–7.5 个头，儿童 4–6 个头 | 成人 4–6 个头，Q 版 2–3 个头；按设计定，全片一致 |
| 五官 | 真实大小和位置，个体差异靠骨相和软组织 | 眼睛放大到真实的 1.3–2 倍，鼻子和嘴简化，脸型几何化但保留骨点 |
| 皮肤 | 次表面散射、毛孔分区、细纹、色斑、高光碎变化 | 平滑的次表面散射，颜色有轻微的冷暖渐变（脸颊、鼻尖、耳朵偏暖），不画毛孔 |
| 头发 | 一根根的曲线毛发，成簇加碎发、飞丝 | 大块成簇的发片或粗曲线毛发，形状设计感强，少量碎发 |
| 眼睛 | 角膜凸起、虹膜纹理、角膜缘环、泪线、泪阜、湿润反光 | 虹膜大、高光清楚，角膜仍要凸起，眼睑有厚度 |
| 服装 | 真实面料的织纹、缝线、起球、磨损 | 面料简化成大块颜色和少量纹理，褶皱少而有设计 |
| 表情幅度 | 小而准，靠细微的肌肉变化 | 幅度大、形状清楚，可以有适度的挤压拉伸 |
| 动作节奏 | 真实物理，重量感，缓入缓出 | 预备、过冲和停顿更明显，姿势更有剪影感 |
| 灯光 | 按真实光源，光比按剧情电影基调 | 设计感的布光，轮廓光更明显，按动画长片基调 |
| 视觉基调 | 剧情电影、自然纪录、夜景都市、东方意境等 | 动画长片、温馨童话 |

## 二、不能混搭的组合

| 不要叠在一起 | 为什么 |
|---|---|
| 风格化比例或大眼睛 + 毛孔级写实皮肤、写实毛发 | 恐怖谷，脸像戴了面具 |
| 写实比例 + 夸张的挤压拉伸 | 骨头像断了，重量感没有了 |
| 写实人物 + 平涂、描边、三渲二 | 两套着色体系 |
| 风格化人物 + 照片贴图的皮肤和布料 | 贴图的真实细节和简化的形体打架 |
| 写实表情的细微幅度 + 风格化的大眼睛 | 表情在大眼睛上看不出来，显得呆 |
| 一个角色的脸按写实做、身体按风格化做 | 头和身体像来自两个片子 |

**例外**：写实地拍的人偶、木偶、黏土人偶按进阶版的玩具例外处理，不属于本 skill 的人物。

## 三、恐怖谷清单（写实路线逐条写进主文件）

1. 眼睛湿润，角膜上有清楚的环境反光，下眼睑有一条泪线。
2. 眼神有焦点，两只眼看向同一点；视线移动是快速的跳动加停留，不是匀速滑动。
3. 眨眼不机械：间隔不固定，几秒一次，情绪转折时多一次；上眼睑走得多，下眼睑也跟着动一点。
4. 皮肤不是蜡：次表面散射的半径按颜色分开，红色散得最远；耳朵、鼻翼、指尖背光时透红；有毛孔和细绒毛。
5. 牙齿一颗颗分开，有轻微的颜色差，牙龈有颜色；舌头湿润，嘴里不是一片黑也不是一片亮。
6. 表情不只动嘴：笑的时候眼轮匝肌收缩、眼下鼓起、眼角挤出细纹；皱眉时眉间出现竖纹。
7. 脸左右不完全对称：一边嘴角高一点，一边眉毛动得多一点。
8. 静止时也在动：呼吸带动胸口和肩，眼睛有细小的移动，头有很轻的晃动。
9. 头发和皮肤的交界自然：发际线有稀疏的过渡和短碎发，不是一条硬边。
10. 头、脖子、肩是一体的：转头时胸锁乳突肌拉出，脖子的皮肤有褶。

风格化路线也要做到第 2、3、6、8 条。
