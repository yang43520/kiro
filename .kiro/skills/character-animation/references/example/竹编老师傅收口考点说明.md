# 竹编老师傅收口考点说明

> 内部校验用，不交给制作方，不属于制作输入。

**主类目**：角色动画/写实人物/手艺劳作

**题目档位**：上限档（配方：L3 + L2，附带 2 个 L1）

**档位来源**：默认

**规范版本**：进阶版 1.6

**视觉基调**：剧情电影

**人物规范**：人物版 1.0

**路线**：写实

**耦合链**：同一位老师傅的一双手和一只竹篮：手指一节节弯曲、指腹压着竹篾一上一下地穿，篾梢弹起时手腕一翻捏住、塞进收口；竹篾被手指压弯、在上下两层篾之间穿过而不穿插；收口完成引出他举篮细看的专注表情，表情松开引出吹屑和笑；窗光在手和脸上流转，镜头一镜到底从手的特写退到脸的近景再拉开。

| 编号 | 考点 | 分级 | 作用对象与时段 | 在片中的体现 |
|---|---|---|---|---|
| 5 | 多关节联动与抓取交互 | L3 | 老师傅的两只手和竹篾、竹篮，0–5 秒和 10.5–12 秒 | 每根手指三节分别弯，指腹压着竹篾一上一下地穿；篾梢弹起时拇指和食指捏住、往回折、塞进收口再按两下；放篮子时篮底贴住凳面才松手，手搭在篮沿上越往小指弯得越多 |
| 10 | 体积碰撞与边界阻挡｜真实轮廓接触与防穿模 | L2 | 竹篾和手指、篾梢和上下两层篾、篮底和条凳，0–12 秒 | 指腹和竹篾之间约 1 毫米，被压的那段竹篾下凹；篾梢塞进缝里时和上下两层篾各留约 0.5 毫米；篮底贴住凳面；围裙不穿过大腿和竹篮 |
| 16 | 光影流转与材质外观演变 | L1 | 窗光和屋里的光，0–12 秒 | 窗光擦过手背和颧骨，地上的窗格光斑随云变暗又变亮 |
| 17 | 单镜头运镜构图 | L1 | 镜头，全片 | 一镜到底：中心构图特写 → 三分法 → 框景近景 → 表情特写 → 负空间全景 |

**最高分级**：L3

## 制作底线清单

**二级类目**：写实人物

**技术模块**：T11、T12、T13（另用进阶版 T9 的粒子做法）

**本片要用的专业术语**：雕刻、多重分辨率细分、环形布线、Rigify、反向动力学、修正形态键、形态键、驱动器、次表面散射、曲线毛发、引导毛、原理化毛发着色器、布料模拟、碰撞距离、钉固顶点组、实体化修改器、面部动作单元、皱纹法线贴图、眼轮匝肌、角膜、虹膜、泪线、骨骼链、地板约束、二级摆动、子级约束、粒子系统、湍流力场、生命周期、曲率遮罩、环境光遮蔽

**推荐插件**：Rigify（内置）、AnimAide（开源）、MPFB2（开源）

**通用底线**：PBR 贴图或程序化纹理（近景 4K）、倒角、接触阴影、AgX 色彩管理（Base Contrast）、足够采样、100% 查看细节、尺度参照（35 厘米的竹篮、篾刀、茶杯）、防重复

**重模拟**：布料模拟（只用在褂子袖口和围裙上）

## 类目与标签

**归类理由**：主体是一位原创的写实老人在作坊里完成竹篮收口的手艺表演，手指的抓取、表情和身体动作是全片重点，属于本 skill 人物类目里的写实人物/手艺劳作。

| 标签组 | 选定标签 | 必要说明 |
|---|---|---|
| 视觉造型 | 写实 | 照片级写实的人物和作坊 |
| 材质质感 | 木石天然、织物皮革 | 主材质是竹篾、木凳和木构老屋；其次是棉布褂子、麻布围裙和皮肤 |
| 渲染风格 | 真实渲染 | 常规物理渲染 |
| 动态节奏 | 自然流畅 | 手指、表情和身体都带缓入缓出 |
| 动画行为 | 主行为：结构与装配/拆解组装/组合成形 | 竹篾一格格穿完、收口，竹篮成形 |
| 动画行为 | 辅助行为：物理与特效/柔性运动/布料 | 袖口和围裙的布料 |
| 动画行为 | 辅助行为：形变与生长/形态变化/挤压拉伸 | 表情时面部软组织的挤压和拉伸 |
| 动画行为 | 辅助行为：物理与特效/流体粒子/粒子 | 被吹起的竹屑和浮尘 |
| 灯光氛围 | 自然日光 | 窗外天光为主，屋里一盏灯泡作轮廓光 |
| 背景环境 | 完整场景 | 竹编作坊完整搭建 |
| 色彩基调 | 暖色温馨 | 木头、竹篾和皮肤的暖褐 |
| 时序结构 | 多段序列 | 编最后一圈 → 篾梢弹起 → 举起来看 → 吹屑和笑 → 放下歇着 |
| 复杂度等级 | 物理模拟 | 含布料模拟和粒子 |
| 应用场景 | 不填 | 没有明确的用途依据 |
