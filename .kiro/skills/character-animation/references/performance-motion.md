# 表演和动作（人物版 1.0）

## 一、每个动作都有动机

- 先写人物想要什么、看到了什么，再写动作；动作是对动机的反应。例如"她听到门外的雨停了 → 视线先移向窗 → 头跟着转 → 放下手里的针 → 起身"。
- 一段表演分几个节拍，每个节拍有一个想法；节拍之间有短暂的停顿或视线转移，读得出人物在想。
- 表情和身体一起说话：情绪变化时，表情、肩、手和重心一起变，不能只有脸在动。

## 二、身体的基本规律

- **重心**：站着时重心落在支撑脚上方；重心换脚时髋先移、肩反向倾，读出对立平衡。
- **预备动作**：起身先身体前倾、往下沉一点；伸手前肩先动；跳之前先蹲。
- **先后**：转身按眼 → 头 → 肩 → 腰 → 髋 → 脚的顺序依次跟上，停下时按相反顺序停住。
- **跟随和余摆**：动作停下后，头发、衣角、耳环、脸颊和手臂的软组织还会继续晃一下再停。
- **动势线**：姿势有一条贯穿全身的 S 形或 C 形曲线，不是直挺挺的。
- **呼吸和小动作**：站着、坐着时也在呼吸、眨眼、手指轻动、重心轻轻转移，不能僵住。

## 三、常见动作的真实数值

| 动作 | 数值和规律 |
|---|---|
| 慢走 | 每秒约 1–1.2 米，每秒约两步；接触 → 下沉 → 经过 → 抬起四个关键姿势；髋在经过姿势最高、在下沉姿势最低，上下起伏约 3–5 厘米；手臂和腿反向摆 |
| 跑 | 每秒 3–5 米，有腾空的一刻；身体前倾，手臂弯成约 90° |
| 坐下 | 先看一眼椅子，身体前倾，髋往后找椅面，手扶扶手，坐到底后身体往后靠一下 |
| 站起 | 脚先往回收，身体前倾到重心过脚，再伸膝站起，最后挺胸 |
| 伸手拿东西 | 眼先看，肩先动，手到之前手指预先张开，手指一节节弯曲合拢，指腹贴住物体；拿起时手腕和前臂带出物体的重量 |
| 转头 | 一般要半秒到一秒，眼睛先到；转大角度时肩和上身跟着转 |
| 眨眼 | 一次几帧，上眼睑快速落下、稍慢抬起 |

## 四、手

- 五根手指长短不同，中指最长；放松时手指自然弯曲，越往小指弯得越多，不是一把直的。
- 握东西时手指包住物体的形状，指腹和手心贴住，指节有褶；拿重的东西时手腕往下沉。
- 手是最容易穿帮的地方：手指之间、手指和物体之间都写清接触，用反向动力学把指尖钉在物体表面，再逐帧看。

## 五、人物的接触和防穿模

| 接触 | 做法 |
|---|---|
| 脚和地面 | 反向动力学加地板约束，支撑脚锁住不滑；鞋底和地面之间有接触阴影，鞋底压在地面上，不陷不浮 |
| 手和物体 | 指尖用反向动力学钉在物体表面，手指和物体之间留 1–2 毫米；物体跟手时用子级约束，拿起和放下那一帧切换 |
| 衣服和身体 | 布料模拟以身体为碰撞体，碰撞距离约 5 毫米，开自碰撞；贴身的部分跟骨骼走，加修正形态键 |
| 头发和身体 | 毛发动力学开碰撞，脖子、肩、背做简化的碰撞体，碰撞距离几毫米 |
| 眼睑和眼球 | 眼睑跟眼球转，闭眼时上下眼睑合上，不穿进眼球，留不到 1 毫米 |
| 嘴唇和牙 | 闭嘴时嘴唇贴住，不穿进牙齿；张嘴时下颌带下唇和下排牙一起走 |
| 身体和椅子、门框、桌子 | 身体和家具做碰撞体或按最小间距摆关键帧，坐下时臀部和椅面贴住、衣服在椅面上压出褶 |
| 两个人物 | 握手、拥抱、递东西时，两人的手和身体都写清接触点和先后 |

"底线和限制"里的接触清单要列出本片有的人物接触，写"第 S 秒 + 谁和谁"，用线框和 X 射线视图逐帧看。

## 六、做法

- 绑定用 Rigify 人形模板，四肢用反向动力学加极向目标，手指用骨骼链；肩、肘、膝、髋加修正形态键防止变形塌陷。
- 关键帧先做关键姿势，再加中间帧，最后加跟随和余摆；用运动曲线编辑器调缓入缓出，可以借助 AnimAide。
- 头发和衣服的次级运动可以用 Wiggle 2 做骨骼的余摆，大块的布用布料模拟。
- 不用动作捕捉和外部动作数据。
