# 人物 rubric 和角色设定卡（人物版 1.0）

## 一、rubric 在进阶版基础上加的三个关键项

进阶版 rubric 的通用项、数量硬指标（结构分件、递进阶段、布光层次）、材质与制作底线、任务项、加分项和五个关键项（动态密度、电影级画面、细节精致度、海报帧与视觉基调、接触与防穿模）都保留，另加：

| 维度 | 类型 | 权重 | 写什么 |
|---|---|---|---|
| 形体与解剖 | discrete，关键项 | 约 5 | 主文件写的头身比、身高、标志点和体型；风格化写清夸张了哪几处 |
| 面部与表情 | discrete，关键项 | 约 6 | 主文件写的面部结构、眼睛、表情的动作单元组合、先后、不对称和余动 |
| 表演与动作 | discrete，关键项 | 约 6 | 主文件写的动机和节拍、重心、预备、跟随、手指、视线 |

锚点：

- **形体与解剖**：0 分是头身比或标志点明显不对、四肢长短不对、关节反折或变形时塌陷；50 分是比例基本对，但有一处明显失调或一处关节变形不自然；100 分是比例、骨相和体型都按设计做到，变形自然。
- **面部与表情**：0 分是眼睛没有角膜和反光、表情只动嘴或像贴图切换、脸完全对称、出现恐怖谷；50 分是表情读得出，但先后、不对称或余动有一处缺失；100 分是动作单元组合正确、眉眼先动、左右不对称、到位有余动，眼神有焦点。
- **表演与动作**：0 分是动作没有动机、滑步、重心不在支撑脚上方、手指穿过物体、身体僵直；50 分是表演读得懂，但有一处预备或跟随缺失、一处轻微滑动；100 分是动机和反应清楚、重心和先后对、手指贴住物体、次级运动自然。

权重从"主体与目标""动作完整性"和任务项里匀出来，合计仍是 100。人物 rubric 一般 26–29 项。

## 二、生成 rubric

`scripts/build_rubric.py <spec.json> <任务文件夹>/rubric.json`：spec 是一个 JSON，写 `task` 和 `items`（每项 `dimension`、`criterion`、`weight`、`critical`、`type`，可选 `anchors`）。常用维度的默认锚点已经内置，人物的三个关键项也内置了上面的锚点；脚本会检查编号、锚点齐全和权重合计 100。

## 三、角色设定卡（写进考点说明）

```markdown
## 角色设定卡

| 项目 | 内容 |
|---|---|
| 年龄段 | 六十岁上下 |
| 身高和头身比 | 约 168 厘米，约 7 个头 |
| 体型 | 清瘦，肩窄，微驼 |
| 脸型特征 | 颧骨高、下颌窄，法令纹深，左眉有一道旧疤 |
| 发型发色 | 花白的短寸，鬓角稀 |
| 服装和材质 | 洗旧的藏青棉布对襟褂，袖口磨毛；黑布鞋 |
| 性格 | 话少，做事专注，笑起来眼角先动 |
| 原创说明 | 原创角色，不参照任何真人或已有作品里的角色 |
```
