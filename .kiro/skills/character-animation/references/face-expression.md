# 面部和表情（人物版 1.0）

## 一、面部按三层写

1. **骨骼结构**：眉弓、颧骨、鼻梁、下颌角、下巴。决定脸型和侧面轮廓，长相的个体差异主要在这一层。
2. **软组织**：眼袋、鼻唇沟、颊脂垫、下巴的脂肪垫、嘴唇的厚度。决定年龄和胖瘦，表情时被挤压和拉伸的就是这一层。
3. **皮肤**：毛孔、细纹、色斑、汗毛（见 `skin-hair-cloth.md`）。

## 二、眼睛

- 眼球直径约 24 毫米，角膜比眼白凸出约 2–3 毫米，是一层单独的透明网格，有真实的折射；虹膜在角膜后面，略往里凹。
- 虹膜有放射状的纹理，外圈有一道深色的角膜缘环；瞳孔会随光线变化。
- 上眼睑厚约 3–4 毫米，盖住虹膜的上沿一小块，在眼球上投下一道阴影；下眼睑有一条湿润的泪线；内眼角有一块粉色的泪阜。
- 睫毛上长下短，一簇簇往外翘，不是均匀的一排。
- 两只眼的高光位置一致，指向同一个光源。

## 三、嘴、牙、舌

- 嘴唇有唇纹，上唇中间有唇珠，嘴角有一个小凹。
- 牙齿一颗颗分开，颜色从切缘的半透明到根部的暖黄；牙龈有颜色和厚度。
- 舌头湿润、有颗粒感；嘴里深处暗，但不是纯黑。
- 张嘴时下颌绕颞颌关节转动，下巴往下往后走，不是整块往下平移。

## 四、用面部动作单元写表情

表情按面部动作编码系统（FACS）的动作单元组合着写。下表是最常用的，右列是 ARKit 52 个形态键里对应的名称，做形态键时可以按这套命名。

| 动作单元 | 动作 | 常见形态键名称 |
|---|---|---|
| AU1 | 眉头内侧上抬 | browInnerUp |
| AU2 | 眉尾外侧上抬 | browOuterUp |
| AU4 | 皱眉（眉头下压并拢） | browDown |
| AU5 | 上眼睑上抬（睁大眼） | eyeWide |
| AU6 | 脸颊上提、眼轮匝肌收缩 | cheekSquint |
| AU7 | 眼睑收紧（眯眼） | eyeSquint |
| AU9 | 皱鼻 | noseSneer |
| AU10 | 上唇上提 | mouthUpperUp |
| AU12 | 嘴角上扬 | mouthSmile |
| AU14 | 嘴角内收出小坑 | mouthDimple |
| AU15 | 嘴角下拉 | mouthFrown |
| AU17 | 下巴上推（下唇往上顶） | mouthShrugLower |
| AU20 | 嘴角往两侧拉 | mouthStretch |
| AU23、AU24 | 嘴唇收紧、抿嘴 | mouthPress |
| AU25、AU26 | 嘴唇分开、下颌下垂 | jawOpen |
| AU43、AU45 | 闭眼、眨眼 | eyeBlink |

常见情绪的组合（写实路线幅度小，风格化路线幅度大）：

| 情绪 | 组合 | 容易做错的地方 |
|---|---|---|
| 真笑 | AU6 + AU12，笑大了加 AU25 | 只动嘴角（AU12）是礼貌的假笑；真笑眼下鼓起、眼角挤出细纹 |
| 悲伤 | AU1 + AU4 + AU15，常加 AU17 | 眉头内侧上抬、眉间皱起，形成"八"字眉 |
| 惊讶 | AU1 + AU2 + AU5 + AU26 | 持续很短，一两秒就回落 |
| 害怕 | AU1 + AU2 + AU4 + AU5 + AU20 | 和惊讶的区别是眉头同时下压、嘴往两侧拉 |
| 生气 | AU4 + AU5 + AU7 + AU23 | 眼睛瞪着但眼睑收紧，嘴抿住 |
| 厌恶 | AU9 + AU10 | 鼻子先皱 |
| 专注 | AU4 轻 + AU7 轻 + AU24 | 不是面无表情，眉和嘴都有一点收紧 |

## 五、表情的时序和细节

- **先后**：情绪起来时眉眼先动，嘴后动，大约差几帧到半秒；回落时嘴先松，眉眼后松。
- **不对称**：一边嘴角高一点，一边眉毛动得多一点；轻蔑就是只动一边嘴角。
- **到位后的余动**：表情到了顶点后有轻微回落和颤动，不会定死成一张图。
- **软组织**：笑时鼻唇沟加深、颊脂垫往上鼓；皱眉时眉间的皮肤挤出竖纹。用形态键做大的变化，再用修正形态键和皱纹的法线贴图混合做细纹，按动作单元的强度驱动。
- **眼神**：视线先于头动；看一个东西时眼球快速跳过去再停住，不是匀速滑；思考时视线常往一侧下方移开；眨眼常出现在视线转移和情绪转折的时候。
- **呼吸**：静止时胸口和肩跟着呼吸起伏，每分钟十几次；说话前会吸一口气（本项目无声，但嘴可以有动作）。

## 六、做法

- 形态键按动作单元做，每个只管一块肌肉的动作，再组合；用驱动器把骨骼控制器连到形态键。
- Rigify 的面部骨骼可以管下颌、嘴唇、眼睑和眉毛，形态键补骨骼做不出来的软组织鼓起和皱纹。
- 眼睑用骨骼跟着眼球转，眼球往上看时上眼睑跟着抬一点，往下看时跟着落一点。
