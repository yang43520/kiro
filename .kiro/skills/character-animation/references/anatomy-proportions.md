# 形体比例（人物版 1.0）

主文件里写人物，先写**头身比和身高**，再写几个**标志点**的位置，最后写**体型和个体差异**。比例错了，后面的材质和动作再好也救不回来。

## 一、头身比

| 年龄段或风格 | 头身比 | 说明 |
|---|---|---|
| 婴儿 | 约 4 个头 | 头大、四肢短，腿约占身高的三分之一 |
| 5–6 岁儿童 | 约 5 个头 | 脸的下半部短，额头宽 |
| 10–12 岁 | 约 6 个头 | 四肢开始变长 |
| 成人 | 约 7–7.5 个头 | 写实人物的默认值 |
| 英雄化成人 | 约 8 个头 | 写实动作片的夸张，腿更长 |
| 老人 | 约 7 个头 | 驼背、颈前伸，看上去比年轻时矮一点 |
| 风格化成人 | 4–6 个头 | 动画长片常用 |
| Q 版 | 2–3 个头 | 头接近身体的一半 |

## 二、身体标志点（写实成人，按头高计）

- 下巴在 1 个头处，乳头连线约在 2 个头处，肚脐约在 3 个头处，耻骨约在 4 个头处（身高的一半），膝盖约在 5.5 个头处。
- 肩宽：男性约 2 个头宽，女性约 1.7 个头宽；髋宽女性比肩略宽或相近，男性比肩窄。
- 手臂自然下垂时，肘和腰最细处同高，手腕和耻骨同高，指尖到大腿中部。
- 手长约等于下巴到发际线，脚长约等于前臂长。
- 坐着时，膝盖略高于髋，大腿占坐高的很大一部分；从侧面看，耳朵、肩、髋大致在一条竖线上。

儿童和风格化人物按头身比把这些位置等比例挪，风格化时写清楚改了哪几处（例如"头放大、腿加长，手和脚缩小一点"），其余保持真实关系。

## 三、体型和个体差异

- 写体型时说骨架和软组织：骨架宽窄（肩、髋、手腕粗细）、肌肉和脂肪分布（上臂、腹部、大腿）、姿态习惯（驼背、挺胸、一侧肩高）。
- 每个人都不对称：一侧肩略高、一条腿略承重、脸的两边不一样。
- 年龄写在形体上：老人的肩往前收、膝微屈、手背青筋和关节突出；年轻人的软组织饱满。
- 服装下面也要有身体：衣服的褶从关节和受力点出发，不是贴在身上的一层壳。

## 四、做法

- 起形：用 CC0 的人体基础网格（Blender 官方 Human Base Meshes 或 MPFB2 生成的人体）或自己雕刻；不管从哪起，都要用雕刻和多重分辨率细分重新做出这个角色的骨相、脸和身形。
- 拓扑：关节处（肩、肘、膝、手指）和面部（眼周、嘴周）用环形布线，变形时不出折角；面部按表情需要加密。
- 绑定：Rigify 人形模板，面部用 Rigify 的面部骨骼或形态键，肩和臀部加修正形态键，膝和肘用反向动力学加极向目标。
- **灰模比例自查**：开工前渲三张灰模，正面和侧面各一张，背后放一张按头高画的比例格，再加一张四分之三角度的半身，看头身比、标志点、肩髋宽和脸的骨相，再上材质。
