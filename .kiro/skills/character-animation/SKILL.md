# 人物动画（character-animation）

全程用中文和用户沟通。目标是**一次交出能通过验收的人物动画方案**：人物原创、比例和解剖可信、表情和动作有动机、表演读得懂，画面达到进阶版的电影级要求，没有穿模和恐怖谷。

本 skill 只管**人物**（写实人类和风格化人类）。动物、拟物、玩偶、机器人和场景类任务仍用 `animation-brief-advanced`。

## 0. 和进阶版的关系

## 1. 和进阶版不同的默认规定

| 项目 | 进阶版 | 本 skill |
|---|---|---|
| 人物 | 默认不出现人 | 允许出现**本片的原创人物**，默认 1 个，最多 2 个；不像任何真人、名人或已有作品里的角色；不写真人姓名、不写"像某某"；不做裸露、血腥和真实人物的暴力 |
| 现成模型 | 一律不用 | 允许用 CC0 的人体基础网格起形：Blender 官方的 Human Base Meshes，或开源 MPFB2 生成的人体。必须在它上面重新雕刻出这个角色自己的脸和身形；它附带的皮肤、眼睛、头发、衣服和姿势预设都不用 |
| 动作数据 | 不用外部动作数据 | 一样不用：不用动作捕捉、不用面部捕捉、不用素材库动作，动作和表情都按关键帧、骨骼和形态键做 |

其余规定（不出现可读文字和品牌、只用内置和开源插件、只允许贴图、重模拟最多 2 种、默认进阶档、一镜到底、12 秒、1280×720、30 帧/秒、无声）都和进阶版一样。

## 2. 第一步：创意建议

用户说出想法后，先给 3–5 个方向，等用户选定。表格列在进阶版的基础上加一列"角色"：

`方向｜路线｜角色｜类目路径｜起因 → 过程 → 结果｜画面元素｜动态形式｜档位与考点｜制作方法与插件｜制作难度`

- **路线**：写实或风格化（见 `references/style-routes.md`），一个方向只有一条路线。
- **角色**：一句话写年龄段、体型、职业感或身份、性格，例如"六十来岁、清瘦、做了一辈子竹编的老师傅，话少，手上有茧"。不写真人、不写"像某某"。
- **起因 → 过程 → 结果**：人物的动机、行动和情绪终态都要看得见，例如"雨停了 → 她收伞、抬头、伸手接最后一滴雨 → 笑出来，眼角挤出细纹"。
- 推荐 1–2 个方向。写实人物最难、最容易进恐怖谷，第一次做时优先推荐风格化路线或不拍正脸大特写的写实方向，并说明理由。
- 只在会明显改变结果的问题上提问，每个问题给默认答案。

## 3. 定档位和考点

考点和配方和进阶版一样。人物常用的考点：

| 考点 | 分级 | 在人物上体现在哪 |
|---|---|---|
| 7 足式步态与重心转移 | L4 | 走、跑、上下台阶、转身迈步，重心在支撑脚上方转移，脚不滑 |
| 12 薄面垂坠与绳索悬挂 | L4 | 长裙、斗篷、围巾、长发被动作和风带动 |
| 5 多关节联动与抓取交互 | L3 | 手指一节节弯曲握住杯子、针线、乐器，指腹贴住物体 |
| 6 次级跟随与惯性滞后 | L3 | 头发、衣角、耳环、脸颊软组织在动作后的滞后和余摆 |
| 8 柔性形变与形态演变 | L3 | 表情变化时面部软组织的挤压和拉伸 |
| 4 部件联动与运动匹配 | L2 | 手和工具的配合，例如拉锯、摇橹、踩缝纫机 |
| 10 体积碰撞与边界阻挡 | L2 | 身体和椅子、门框、衣服和身体的接触 |
| 16、17 | L1 | 光影流转、单镜头运镜，常作修饰 |

所有考点都作用在同一个人物或同一条接触链上。

## 4. 一次合格的人物设计规则（写文件前逐条落实）

进阶版 SKILL.md 第 3 节的规则全部适用，人物另外做到：

1. **先定路线，一条到底**：写实或风格化，比例、皮肤、毛发、表情幅度、动作节奏和灯光都按这条路线的那一列写（`references/style-routes.md`）。卡通比例配毛孔级的写实皮肤、写实比例配夸张的挤压拉伸，都是禁配。
2. **角色设定卡**：考点说明里写一张角色设定卡（年龄段、身高、头身比、体型、脸型特征、发型发色、服装和材质、性格、原创说明），主文件"场景和主体"里用口语写进同样的内容。
3. **形体比例**：写头身比和身高（带单位），写肩宽、手长、腿长这些标志点的位置；风格化写清夸张了哪几处、哪几处保持真实（`references/anatomy-proportions.md`）。
4. **面部**：按"骨骼结构 → 软组织 → 皮肤"写；眼睛写到角膜、虹膜、眼睑厚度、泪线和泪阜里的至少三样；写嘴角、鼻唇沟、颧骨、下颌这些决定长相的地方（`references/face-expression.md`）。
5. **表情**：用面部动作单元组合着写（例如"眉头内侧上抬加嘴角下拉"），写清先后（眉眼先动、嘴后动）、幅度、左右不对称、到位后的余动；真笑要有眼轮匝肌收缩。眨眼写在情绪转折处。
6. **皮肤、头发、服装**：写实路线写次表面散射、毛孔分区和高光的碎变化；头发用曲线毛发，写发际线过渡、成簇、碎发；服装写面料、厚度、缝线和受力褶皱，动起来时用布料模拟或形态键（`references/skin-hair-cloth.md`）。
7. **表演和动作**：每个动作有动机和反应；写重心、预备动作、身体各部位的先后（眼 → 头 → 肩 → 腰）、跟随和余摆、呼吸；手写到手指和指腹（`references/performance-motion.md`）。
8. **镜头和表演**：表情的关键时刻至少有一段近景或特写，脸在画面里够大（写占画面高度多少）；视线方向写清楚，留出视线前方的空间；写实人物的正脸大特写要谨慎，可以用侧光、半侧脸或浅景深控制。
9. **人物的接触清单**：脚和地面、手和物体、衣服和身体、头发和肩背、眼睑和眼球、嘴唇和牙齿里，本片有的都写进接触清单，各写做法和安全距离。
10. **恐怖谷自查**：写实路线按 `references/style-routes.md` 的恐怖谷清单逐条写进主文件：眼睛湿润有反光、眼神有焦点、眨眼不机械、皮肤不是蜡、牙齿不是一整块白、表情不是只动嘴。

## 5. 输出文件

和进阶版一样输出三个文件：主文件、考点说明、`rubric.json`。另外：

- 考点说明在"**视觉基调**"那一行后面加两行：`**人物规范**：人物版 1.0` 和 `**路线**：写实` 或 `**路线**：风格化`；并加一节 `## 角色设定卡`（格式见 `references/character-rubric.md`）。规范版本仍写 `进阶版 1.6`。
- 主类目从 `references/character-taxonomy.md` 里选；标签仍按正式类目表第三、四节选。
- rubric 在进阶版的基础上加三个关键项："形体与解剖""面部与表情""表演与动作"（`references/character-rubric.md`）。可以用 `scripts/build_rubric.py` 从一份 JSON 生成 rubric，它会检查编号、锚点和权重合计。

## 6. 校验

```bash
python3 <本 skill 目录>/scripts/check_character.py <任务文件夹>/<标题>.md
```

脚本先按进阶版 1.6 的全部规则检查（自动换上人物类目、人物制作底线和人物基调），再查人物部分：路线和角色设定卡、头身比和身高、面部结构和眼睛、皮肤毛发服装、表情的动作单元和不对称、预备动作重心和跟随、手指、人物接触、原创说明、不用动作捕捉、风格路线不混搭、rubric 的三个人物关键项。有 ERROR 必须修好，WARN 逐条确认。

脚本查不出来、回复前要自己核对的：比例数字和头身比是否自洽；表情的动作单元是否真能组合出写的情绪；动作的速度、距离和时间是否对得上；角色是否和任何真人或已有角色撞脸。

## 7. 回复用户的格式

按进阶版第 12 节，第二步的回复在"类目与标签"后面加一张**角色设定卡**表，在"电影级画面"后面加一张**表演节拍**表（时间｜动机｜动作｜表情的动作单元｜视线）。
