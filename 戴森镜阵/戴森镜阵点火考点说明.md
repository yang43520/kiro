# 戴森镜阵点火考点说明

> 内部校验用，不交给制作方，不属于制作输入。

**主类目**：场景动画/幻想世界/科幻空间

**题目档位**：进阶档（配方：L2 + L2，附带 2 个 L1）

**档位来源**：默认

**耦合链**：同一座环形镜阵上，控制站发出的信号沿圆环依次到达每面镜片，镜片按到达顺序展开再转向；转好的镜片越多，接收站越亮，最后点火射出光束；镜头从近处镜片旁后退升高，收进整个圆环。

| 编号 | 考点 | 分级 | 作用对象与时段 | 在片中的体现 |
|---|---|---|---|---|
| 9 | 结构爆炸拆解与渐进式生长建造 | L2 | 约 2,000 面镜片，2–5 秒 | 每面镜片按支架伸长、外壳退开、六片花瓣依次打开、散热鳍张开的顺序展开，拼成平整的镜面 |
| 14 | 集群协同与波浪相位差 | L2 | 约 2,000 面镜片，1–8 秒 | 信号沿圆环以约 8 公里/秒传开，镜片按离控制站的弧长依次展开，展开后约 0.8 秒依次转向，两道波浪绕圆环推进并汇合 |
| 16 | 光影流转与材质外观演变 | L1 | 镜面、接收站、散热鳍，5–12 秒 | 转好的镜片映出恒星光，接收站从暗红变成橙白色，散热鳍从深灰烧成暗红，最后射出淡金色光束 |
| 17 | 单镜头运镜构图 | L1 | 镜头，0–12 秒 | 从离最近镜片 60 米处后退升高到 25 公里外，前景镜片展开细节、绕圆环的波浪和光束都在画面里，结尾圆环约占画面宽度一半，无剪辑 |

**最高分级**：L2

## 类目与标签

**归类理由**：主体是围绕红巨星的一座环形镜阵和它启动点火的过程，属于幻想世界里的科幻空间。

| 标签组 | 选定标签 | 必要说明 |
|---|---|---|
| 视觉造型 | 写实 | 照片级写实，硬表面结构 |
| 材质质感 | 金属、自发光 | 主材质是镀铝镜面和碳纤维结构；其次是接收站和光束的自发光 |
| 渲染风格 | 真实渲染 | 常规物理渲染 |
| 动态节奏 | 机械节奏 | 镜片分段精确展开、转向，到位后停顿明确 |
| 动画行为 | 主行为：结构与装配/开合联动/折叠展开 | 镜片像花一样展开 |
| 动画行为 | 辅助行为：位移与运动/规律运动/旋转 | 镜片转向对准接收站 |
| 动画行为 | 辅助行为：显隐与外观变化/材质变化/发光亮灭 | 接收站、散热鳍和光束依次亮起 |
| 灯光氛围 | 灯光动画 | 反射光汇聚，接收站由暗到亮 |
| 背景环境 | 完整场景 | 红巨星、行星、卫星和尘埃云完整搭建 |
| 色彩基调 | 不填 | 深灰、红橙、金色和蓝绿色混合 |
| 时序结构 | 多段序列 | 启动信号 → 镜片展开 → 转向聚光 → 焦点点火 → 光束射出 |
| 复杂度等级 | 物理模拟 | 约 2,000 个对象的群组 |
| 应用场景 | 不填 | 没有明确的用途依据 |
