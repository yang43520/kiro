# 平流雾漫城考点说明

> 内部校验用，不交给制作方，不属于制作输入。

**主类目**：场景动画/城市街景/城市鸟瞰

**题目档位**：进阶档（配方：L2 + L2，附带 2 个 L1）

**档位来源**：默认

**耦合链**：同一团平流雾从江面漫上岸，被楼群挡住、堆高、绕流，越涨越高淹没街区；雾的前沿依次到达各段道路，那段车流随之减速、亮双闪；被雾包住的灯光化成光晕、雾面被城市灯光从下照亮；镜头从江面上空推进、下降，收进露出雾面的超高层群。

| 编号 | 考点 | 分级 | 作用对象与时段 | 在片中的体现 |
|---|---|---|---|---|
| 10 | 体积碰撞与边界阻挡｜真实轮廓接触与防穿模 | L2 | 雾和楼群、江堤，2–12 秒 | 雾在楼的迎风面堆高约 30 米，从楼两侧和楼缝绕过去，背风面留下薄雾区；超高层背风面拉出带交替涡旋的尾迹；雾不穿过楼体 |
| 14 | 集群协同与波浪相位差 | L2 | 滨江大道、三条主干道和立交桥上的车流，2–10.5 秒 | 雾的前沿到达哪一段，那段车流就减速、亮双闪，从江边一段段往北传开，立交桥环形光带也随之慢下来 |
| 16 | 光影流转与材质外观演变 | L1 | 路灯、车灯、窗灯和雾面，2–12 秒 | 灯被雾包住后化成光晕，被吞没的街区变柔变暖，雾面被下方灯光照亮成暖橙和冷白 |
| 17 | 单镜头运镜构图 | L1 | 镜头，0–12 秒 | 无人机机位从江面上空 600 米推进、下降到雾面上方 350 米，越过前景超高层楼顶，结尾超高层群约占画面宽度六成，无剪辑 |

**最高分级**：L2

## 类目与标签

**归类理由**：主体是从高空俯瞰的整座滨江城市和漫过它的平流雾，属于城市街景里的城市鸟瞰。

| 标签组 | 选定标签 | 必要说明 |
|---|---|---|
| 视觉造型 | 写实 | 绝对真实的照片级效果 |
| 材质质感 | 玻璃透明、木石天然、自发光 | 主材质是超高层的玻璃幕墙；其次是混凝土和石材立面，以及城市灯光 |
| 渲染风格 | 真实渲染 | 常规物理渲染 |
| 动态节奏 | 自然流畅 | 延时下雾的流动和车流变化平滑 |
| 动画行为 | 主行为：物理与特效/流体粒子/烟火 | 平流雾的流动、绕流和上涨 |
| 动画行为 | 辅助行为：位移与运动/路径运动/沿线移动 | 车流沿车道行驶并减速 |
| 动画行为 | 辅助行为：显隐与外观变化/材质变化/发光亮灭 | 双闪和航空障碍灯闪烁 |
| 灯光氛围 | 夜景月光 | 冷色月光加城市灯光点光源 |
| 背景环境 | 完整场景 | 江、城区、桥和远山完整搭建 |
| 色彩基调 | 不填 | 暖橙城市灯光和冷色月光对比，没有单一的色彩基调 |
| 时序结构 | 多段序列 | 江雾 → 漫上岸 → 淹没街区 → 雾海成形 → 雾海 |
| 复杂度等级 | 物理模拟 | 含大尺度烟雾模拟 |
| 应用场景 | 不填 | 没有明确的用途依据 |
