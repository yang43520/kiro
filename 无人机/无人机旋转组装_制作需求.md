# 无人机旋转组装动画 · 制作需求

制作时同时提供「一、制作 Prompt」和完整的《无人机旋转组装剧本》（见 `无人机旋转组装剧本.md`）。「三、类目与标签」和「四、试做验收要点」不属于制作输入。

## 一、制作 Prompt

```text
使用 Blender 5.0.0 制作一条约 10 秒（允许 8–12 秒，不得少于 8 秒）的无人机“边旋转边瀑布式组装”产品动画，写实渲染风格。画面内容、动作和镜头以《无人机旋转组装剧本》为准。

核心效果：一架原创设计的四旋翼航拍无人机，机身立在一个持续旋转的展示转台上；机臂、电机、电池、上盖、云台相机和螺旋桨从画面上方一件接一件连续落下，在转动中追上各自的安装位置并卡入。组装完成后转台停下，灯光亮起，四个螺旋桨起转，无人机从转台上起飞，升到半空悬停。

不可改变的内容：组装期间转台带着机身持续转动，组装顺序为机臂 → 电机 → 电池 → 上盖 → 云台相机 → 螺旋桨；零件的下落首尾相接，前一件卡入之前下一件已经从画面上方出现；每件零件接近安装位置时先与机身同步转动、对齐，再卡入，卡入后随机身一起转动，不在机身表面滑动；零件之间、零件与机身之间不得相交；起飞必须发生在螺旋桨达到全速之后；对角的两个螺旋桨转向相同，相邻的两个转向相反；画面在无人机悬停时结束。

可调整范围：剧本中的尺寸、角度、速度和时间都是参考值，可在保持比例和观感的前提下调整；各阶段时间点可在总时长内微调，但组装顺序不变，“组装完成 → 转台停下 → 亮灯 → 螺旋桨起转 → 起飞悬停”的先后关系也不变。机身造型、装饰线、转台样式和转台转速可以自行设计。

可选增强：螺旋桨全速时，转台表面的细尘被下洗气流吹向四周；悬停后云台相机轻微转动调平。

禁止：零件在画面内凭空出现或消失，或不经下落直接滑到位置；零件穿模，或卡入后悬空、错位；零件卡入后与机身脱节或在机身表面滑动；螺旋桨在起转后停转、倒转或出现频闪错觉；螺旋桨达到全速之前机身就离开转台；悬停时明显漂移或抖动；镜头抖动；画面闪烁、破面或非设计性的卡顿、抽搐；用停帧或重复动作凑时长；出现真实品牌的标志、文字或外观；整体过曝或暗到看不清机身结构。

输出规格：16:9，1920×1080，30 帧/秒，无声音。最终输出一条完整的动画视频。
```

## 三、类目与标签

**主类目**：载具动画/航空航天/旋翼与无人机

**归类理由**：主要表现对象是一架无人机，类目树中「旋翼与无人机」明确收录无人机；「产品动画/消费电子」的归属边界写明交通工具归「载具动画」。片中以产品展示的方式呈现组装和起飞，展示方式由动画行为标签表达，不改变主类目。

| 标签组 | 选定标签 | 必要说明 |
|---|---|---|
| 视觉造型 | 写实 | |
| 材质质感 | 塑料橡胶（主材质）、金属、自发光 | 机身、机臂、电池和螺旋桨为哑光塑料；电机和云台外壳为金属；状态灯和指示灯亮起后自发光 |
| 渲染风格 | 真实渲染 | |
| 动态节奏 | 机械节奏 | 转台匀速转动，零件卡合干脆利落、没有多余弹跳 |
| 动画行为 | 主行为：结构与装配/拆解组装/拼接归位 | 零件逐件追上安装位置并卡入 |
| 动画行为 | 辅助行为：位移与运动/规律运动/旋转 | 转台带机身转动，螺旋桨高速旋转 |
| 动画行为 | 辅助行为：物理与特效/刚体运动/掉落 | 零件从画面上方落下 |
| 动画行为 | 辅助行为：显隐与外观变化/材质变化/发光亮灭 | 组装完成后状态灯和指示灯亮起 |
| 灯光氛围 | 棚拍三点光 | 主光、辅光、轮廓光齐全 |
| 背景环境 | 无缝影棚 | 深灰色弧面影棚，地面和背景板无缝相连 |
| 色彩基调 | 不填 | 石墨灰加橙色点缀，不完全符合任何一项 |
| 时序结构 | 多段序列 | 组装、停转亮灯、起转、起飞悬停依次衔接 |
| 复杂度等级 | 多元编排 | 约 14 件零件分别编排，同类零件最多 4 件，多种行为错时衔接；不含物理模拟。前提：复杂度定义中的"≥10 对象群组"指大量相似对象成群运动（待确认） |
| 应用场景 | 不填 | 没有明确用途依据 |
