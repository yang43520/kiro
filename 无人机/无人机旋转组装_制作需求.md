# 无人机旋转组装动画 · 制作需求

制作时同时提供「一、制作 Prompt」和完整的《无人机旋转组装剧本》（见 `无人机旋转组装剧本.md`）。「三、类目与标签」和「四、试做验收要点」不属于制作输入。

**本次修改**：
- 零件从约 14 件增加到约 50 件，新增中框、机臂螺丝、电机座螺丝、电调板、散热片、铜柱、主控板、散热风扇、GPS 模块、前后视觉模组、减震球和三轴云台的分件。
- 机身下壳改为顶部敞开，内部零件全部装好后再盖上盖；电池改为装在上盖后部的电池仓。
- 组装分为骨架与机臂、动力、主控与传感、外壳与电池、云台、螺旋桨六个阶段；螺丝改为边旋转边拧入。
- 镜头在主控与传感阶段升高推近，俯看机身内部，之后再拉回。
- 时长由约 10 秒改为约 11.5 秒。
- 复杂度等级由"多元编排"改为"物理模拟"。
- 剧本名称不变，Prompt、类目标签和验收要点已同步更新。

## 一、制作 Prompt

```text
使用 Blender 5.0.0 制作一条约 11.5 秒（允许 10–12 秒，不得少于 8 秒）的无人机“边旋转边瀑布式组装”产品动画，写实渲染风格。画面内容、动作和镜头以《无人机旋转组装剧本》为准。

核心效果：一架原创设计的四旋翼航拍无人机，敞开的机身下壳立在一个持续旋转的展示转台上；约 49 件零件从画面上方像瀑布一样一件接一件落下，在转动中追上各自的安装位置并装入，从金属中框、机臂和螺丝，到电机、电调板、散热片、主控板、风扇、GPS 和视觉模组，再到上盖、电池、三轴云台和螺旋桨，逐层拼出一架内部结构完整的无人机。组装完成后转台停下，灯光亮起，四个螺旋桨起转，无人机从转台上起飞，升到半空悬停。

不可改变的内容：组装期间转台带着机身持续转动；组装按“骨架与机臂 → 动力 → 主控与传感 → 外壳与电池 → 云台 → 螺旋桨”六个阶段进行，所有内部零件都在上盖盖上之前装好；零件的下落首尾相接，前一件装好之前下一件已经从画面上方出现；每件零件接近安装位置时先与机身同步转动、对齐，再装入，装入后随机身一起转动，不在机身表面滑动；螺丝要一边旋转一边拧入；零件之间、零件与机身之间不得相交；主控与传感阶段要能看清机身内部的安装过程；起飞必须发生在螺旋桨达到全速之后；对角的两个螺旋桨转向相同，相邻的两个转向相反；画面在无人机悬停时结束。

可调整范围：剧本中的尺寸、角度、速度和时间都是参考值，可在保持比例和观感的前提下调整；各阶段时间点可在总时长内微调，但阶段顺序不变，“组装完成 → 转台停下 → 亮灯 → 螺旋桨起转 → 起飞悬停”的先后关系也不变。同一阶段内零件的先后可以微调；螺丝、铜柱、芯片等小零件的数量可以增减，但剧本列出的每一类零件都要出现。机身造型、电路板布局、装饰线、转台样式和转台转速可以自行设计。

可选增强：螺旋桨全速时，转台表面的细尘被下洗气流吹向四周；悬停后云台相机轻微转动调平。

禁止：零件在画面内凭空出现或消失，或不经下落直接滑到位置；螺丝不经旋转直接嵌入；零件穿模，或装入后悬空、错位；零件装入后与机身脱节或在机身表面滑动；画面中出现线缆；螺旋桨在起转后停转、倒转或出现频闪错觉；螺旋桨达到全速之前机身就离开转台；悬停时明显漂移或抖动；镜头抖动；画面闪烁、破面或非设计性的卡顿、抽搐；用停帧或重复动作凑时长；出现真实品牌的标志、文字或外观；整体过曝或暗到看不清零件结构。

输出规格：16:9，1920×1080，30 帧/秒，无声音。最终输出一条完整的动画视频。
```

## 三、类目与标签

**主类目**：载具动画/航空航天/旋翼与无人机

**归类理由**：主要表现对象是一架无人机，类目树中「旋翼与无人机」明确收录无人机；「产品动画/消费电子」的归属边界写明交通工具归「载具动画」。片中以产品展示的方式呈现组装和起飞，展示方式由动画行为标签表达，不改变主类目。

| 标签组 | 选定标签 | 必要说明 |
|---|---|---|
| 视觉造型 | 写实 | |
| 材质质感 | 塑料橡胶（主材质）、金属、自发光 | 外壳、机臂、电池和螺旋桨为哑光塑料；中框、散热片、铜柱、螺丝和电机为金属；状态灯、指示灯和电量灯亮起后自发光。电路板、陶瓷天线和玻璃镜头面积较小，受数量上限所限不单独列出 |
| 渲染风格 | 真实渲染 | |
| 动态节奏 | 机械节奏 | 转台匀速转动，零件卡合干脆利落，螺丝拧到位即停 |
| 动画行为 | 主行为：结构与装配/拆解组装/拼接归位 | 约 49 件零件逐件追上安装位置并装入 |
| 动画行为 | 辅助行为：位移与运动/规律运动/旋转 | 转台带机身转动，螺丝旋转拧入，螺旋桨高速旋转 |
| 动画行为 | 辅助行为：物理与特效/刚体运动/掉落 | 零件从画面上方落下 |

| 应用场景 | 不填 | 没有明确用途依据 |
