# 甲虫登茎起飞考点说明

> 内部校验用，不交给制作方，不属于制作输入。

**主类目**：角色动画/动物/昆虫小生物

**题目档位**：上限档（配方：单个 L4，附带 1 个 L2 和 1 个 L1）

**档位来源**：默认

**耦合链**：同一只甲虫上，露珠惊醒它后，它用三角步态爬过苔藓、攀上草茎，身体姿态顺着草茎的弧度调整，重量压弯草茎；爬到茎尖后展开翅膀起飞，草茎随之弹回、震落露珠；镜头一路跟着它移动和升高。

| 编号 | 考点 | 分级 | 作用对象与时段 | 在片中的体现 |
|---|---|---|---|---|
| 7 | 足式步态与重心转移 | L4 | 甲虫六足，2–10 秒 | 三角步态交替迈步，支撑腿着地不滑、不穿；身体随步伐起伏和左右平衡；攀茎时六足交替抓住茎的两侧 |
| 3 | 复杂轨迹与姿态自适应 | L2 | 甲虫身体，4.5–10 秒 | 沿草茎从竖直段爬到弯曲段，身体朝向、俯仰和侧倾跟着茎的切线方向慢慢转过去，始终贴着茎 |
| 17 | 单镜头运镜构图 | L1 | 镜头，0–12 秒 | 从落叶左前方跟着甲虫右移、上升，焦点始终在甲虫身上，起飞后甲虫和颤动的草茎都在画面里，无剪辑 |

**最高分级**：L4

## 类目与标签

**归类理由**：主体是一只甲虫，通过钻出、行走、攀爬和起飞完成一段完整的行为，属于动物里的昆虫小生物。

| 标签组 | 选定标签 | 必要说明 |
|---|---|---|
| 视觉造型 | 写实 | 照片级写实微距 |
| 材质质感 | 木石天然、液体冰晶 | 主材质是落叶、苔藓、草茎和甲虫的天然外壳；其次是露珠 |
| 渲染风格 | 真实渲染 | 常规物理渲染 |
| 动态节奏 | 自然流畅 | 步态、攀爬和起飞都符合真实的重量 |
| 动画行为 | 主行为：位移与运动/路径运动/沿线移动 | 甲虫沿苔藓和草茎爬行 |
| 动画行为 | 辅助行为：结构与装配/开合联动/折叠展开 | 鞘翅张开、膜翅展开 |
| 动画行为 | 辅助行为：形变与生长/形态变化/弯曲扭转 | 草茎被压弯后弹回 |
| 动画行为 | 辅助行为：物理与特效/流体粒子/液体 | 露珠滴落和被震落 |
| 灯光氛围 | 黄昏金色时刻 | 清晨低角度的暖色斜射光，属于同一类光 |
| 背景环境 | 完整场景 | 林下地面完整搭建 |
| 色彩基调 | 不填 | 暖金、嫩绿和栗褐色混合，没有单一的色彩基调 |
| 时序结构 | 多段序列 | 露落 → 钻出 → 攀茎 → 展翅 → 起飞 |
| 复杂度等级 | 物理模拟 | 含柔体、布料和液体模拟 |
| 应用场景 | 不填 | 没有明确的用途依据 |
