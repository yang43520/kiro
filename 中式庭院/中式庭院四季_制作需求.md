制作时同时提供「一、制作 Prompt」和完整的《中式庭院四季剧本》（见 `中式庭院四季剧本.md`）。「三、类目与标签」和「四、试做验收要点」不属于制作输入。

## 一、制作 Prompt

```text
使用 Blender 5.0.0 制作一条约 12 秒（允许 11–13 秒，不得少于 8 秒）的中式庭院四季变化动画，照片级写实渲染，一镜到底。画面内容、动作和镜头以《中式庭院四季剧本》为准。

核心效果：一座原创的江南园林式庭院，白墙黛瓦，中央是叠石砌岸的水池，对岸一座飞檐翘角的四角亭，右侧一条带漏窗的曲廊，池边种着垂柳、鸡爪槭、银杏、红梅、竹林和半池荷花，亭子和曲廊檐下挂着素面纸灯笼，池里游着锦鲤。12 秒内走过四个意境：春是烟雨江南，细雨和薄薄的雨雾笼罩着白墙黛瓦，柳条抽出新绿，雨点落进池中；夏是荷叶荷花，雨停雾散，荷叶铺满半个水池，粉白的荷花一朵朵绽开；秋是秋月映池，夕照中鸡爪槭转红、银杏转黄，随后入夜，灯笼亮起，一轮满月从后墙上方升起，清楚地倒映在平静的池面上，落叶激起的涟漪把月影打碎又合拢；冬是雪花飘落，雪夜里积雪覆盖瓦顶和太湖石，池面从岸边结起薄冰，红梅在灯笼的暖光中开放。镜头从月洞门外开始，透过圆形门洞看向庭院，缓慢推进、穿过门洞，同时升高并向右转，结束时在水池近岸上方略微俯视整个庭院。季节的变化是极度加速的，像压缩了一整年的延时摄影；雨、雪、落叶和游鱼的运动保持正常速度。

质感要求：
- 整体：画面像用电影摄影机在一座真实的江南园林里拍摄的四季延时，任意暂停一帧都应该像一张实拍照片；所有物体按真实尺寸和真实材质制作。
- 尺寸：庭院约 20 米宽、15 米深；月洞门直径约 2.4 米；水池约 8 米长；鸡爪槭高约 5 米，银杏高约 9 米，红梅高约 2.5 米。
- 建筑：亭子是单檐歇山顶的四角亭，飞檐翘角，木柱和梁枋是褪色的朱红色；曲廊下有美人靠，漏窗里是不同的几何花纹；月洞门的门框是灰色的砖雕；灯笼是竹篾骨架外糊米白色的纸，纸面有细微的褶皱和竹骨的阴影，上面没有任何文字和图案。
- 白墙：石灰粉刷的墙面不是纯白，有雨水留下的灰色竖向水痕、墙根的青苔和返潮的斑驳，局部墙皮剥落露出青砖。
- 黛瓦：小青瓦一垄一垄排列，瓦缝里有青苔和小草，屋脊和瓦当有细小的破损。
- 木构件：朱红色的油漆褪色、龟裂，局部露出木纹；亭子的柱础是青石。
- 太湖石：灰白色，表面有天然的孔洞、褶皱和凹槽，凹处更暗、长着青苔。
- 铺地：石板有磨圆的边角和浅浅的凹痕，卵石铺地的花纹清楚，石缝里有泥土和青苔。
- 植物：叶片是一片片单独的叶子，有叶脉，逆光时透光；鸡爪槭、银杏、梅树和柳树的树皮互不相同；同一棵树上的叶色深浅不一，夹杂着少量枯叶。
- 荷叶和荷花：荷叶表面有细绒，雨珠在上面滚成透明的水珠；荷叶边缘起伏、有的微微卷起；荷花的花瓣从花尖的粉色渐变到花底的白色，中间是嫩黄的莲蓬。
- 秋月：满月是一轮清晰的圆月，能看到淡淡的月面明暗；池中的月影清楚、完整，水面被扰动时碎成晃动的银光，随后慢慢合拢。
- 季节变化方式：每种变化都是连续渐变的，花从花苞逐渐开放，叶子从叶尖开始逐渐变色，积雪从薄到厚逐渐堆积，冰面从岸边逐渐向中间扩展。
- 水：池水清澈，靠近岸边能看到池底的卵石和水草；水面倒影清楚，被风、雨点、落叶和游鱼打碎后又恢复。
- 锦鲤：六七条红白和金色的锦鲤，按真实的方式摆尾游动。
- 雨和雪：春雨是细密的雨丝，落进水池激起一片细小的涟漪，瓦当下挂着一串串雨滴；雪花大小不一，缓慢地飘落，在空中轻微地打转；积雪有厚度，墙头和瓦垄上的雪边缘圆润。
- 光影：春天是薄云的阴天，柔和的漫射光；夏天是晴天，太阳较高，影子短而清晰；秋天先是低角度的暖金色夕照，随后入夜，清冷的月光照亮庭院，灯笼亮起暖橙色的光；冬天是雪夜，云层遮住月亮，灯笼的暖光和积雪反射的冷光照亮庭院。
- 光照过渡：光照在季节之间平滑过渡，太阳的高度、方向和颜色、云量和月光都是逐渐变化的，不突然跳变，也不出现明暗闪烁；全片只有一次昼夜变化，在秋季由黄昏入夜。
- 阴影：晴天的阳光和夜里的月光在石板、水面和墙上投下树影和窗影，树影随风晃动；天光、月光和灯笼光作为补光，让阴影里仍能看清材质细节，夜晚不能黑成一片。
- 色彩：春天以白墙黛瓦的黑白灰和柳色的嫩绿为主，夏天以荷叶的浓绿、荷花的粉白和池水的碧绿为主，秋天前半段以鸡爪槭的红和银杏的金黄为主、后半段以月光的银蓝和灯笼的暖橙为主，冬天以雪的白、墙瓦的黑白、红梅的红和灯笼的暖橙为主。
- 曝光与清晰度：受光的白墙、雪面和灯笼不过曝成一片纯白，阴影里仍能看清细节；画面清晰锐利，瓦片、叶片、石面和雪粒的细节都能看清，没有因降噪过度、贴图精度低或采样不足造成的发糊、涂抹或噪点。
- 雨雾：雾气只在春天出现，薄薄的雨雾贴着水面和树间缓慢飘动，远处的竹林和院墙外的树冠变淡，近处的物体仍然清楚，画面不发灰；夏天雨停后雾气散尽，其余季节空气通透。
- 辉光：不加大片的辉光；只有灯笼和月亮周围有轻微、自然的光晕。
- 镜头成像：轻微的景深，画面中部的庭院清晰；运动模糊相当于 180° 快门，飘落的树叶和雪花带自然的拖影。

不可改变的内容：全片是一个连续镜头，中间没有剪辑或转场；季节按“春：烟雨江南 → 夏：荷叶荷花 → 秋：秋月映池 → 冬：雪花”的顺序进行，四季之间连续过渡，没有硬切；每种季节变化都是逐渐发生的；光照随季节平滑变化，全片只在秋季由黄昏入夜一次；秋夜时满月和池中完整的月影同时出现在画面中；镜头从月洞门外推进、穿过门洞进入庭院，穿过时不碰到门框；树和竹子一直随风轻轻摇晃；画面在雪仍在落下、红梅仍在开放时结束。

可调整范围：剧本中的尺寸、角度、数量、速度和时间都是参考值，可在保持比例和观感的前提下调整；各季节的时间点可以微调，但季节的顺序不变。亭子、曲廊、漏窗的具体样式，植物的具体位置，锦鲤的数量和游动路线，镜头的具体路线，都可以自行设计。

可选增强：夏天的阳光把水面的波光映到亭子的檐下；秋夜一缕薄云从月前飘过；冬天一只麻雀落在积雪的梅枝上，抖落一点雪。

禁止：剪辑、转场或跳帧；季节之间硬切、叠化，或画面突然变化；花、叶、雪或冰突然出现或消失，而不是逐渐变化；季节顺序打乱，或变化倒退；出现秋季入夜以外的昼夜变化，或光照突然跳变、明暗闪烁；秋夜看不到月亮的倒影，或月影一直是破碎的；夜晚黑成一片，看不清庭院；照搬拙政园、留园等任何现有园林的具体布局；出现人物，或出现可读文字、匾额文字、楹联文字，或灯笼上有文字和图案；卡通、水墨、三渲二等风格化效果；崭新、干净、颜色均匀的表面，塑料感的高光；肉眼可辨的重复贴图或重复复制的植物；春天以外出现雾气，或春天的雨雾让画面发灰、遮住近处的物体；出现大片的辉光；镜头碰到门框或穿过任何物体；镜头突然加速、急停或抖动；用停帧或重复片段凑时长；画面闪烁、破面或非设计性的卡顿。

输出规格：16:9，1280×720，30 帧/秒，无声音。最终输出一条完整的动画视频。
```

## 三、类目与标签

**主类目**：场景动画/自然环境/四季变化

**归类理由**：
- 本片的表达重点是同一座庭院在一年中的季节变化，「四季变化」的示例是“同一场景树叶由绿渐变为黄并飘落，随后开始落雪”，与本片一致。
- 庭院建筑只是不变的背景，片中没有建筑本身的搭建或展示，所以不归「建筑空间」。
- 庭院没有底座或明确边界，所以不归「微缩模型」。

| 标签组 | 选定标签 | 必要说明 |
|---|---|---|
| 视觉造型 | 写实 | 照片级写实 |
| 材质质感 | 木石天然（主材质）、液体冰晶、自发光 | 白墙、青瓦、木构件、太湖石和石板为木石天然；池水、冰面和积雪为液体冰晶；夜里亮起的灯笼为自发光 |
| 渲染风格 | 真实渲染 |  |
| 动态节奏 | 自然流畅 | 季节变化、风吹、落花落叶和镜头推进都是平滑连续的 |
| 动画行为 | 主行为：形变与生长/生长展开/植物生长 | 柳条和新叶长出、荷叶展开、荷花和红梅开放 |
| 动画行为 | 辅助行为：显隐与外观变化/材质变化/颜色渐变 | 树叶由绿转红转黄，石板由湿变干，积雪让屋瓦变白 |
| 动画行为 | 辅助行为：物理与特效/流体粒子/粒子 | 飘落的树叶和雪花 |
| 动画行为 | 辅助行为：物理与特效/流体粒子/液体 | 春雨落进水池激起涟漪，落叶打碎池中的月影 |
| 灯光氛围 | 灯光动画 | 光照从春日阴天的漫射光、夏日高阳、秋日夕照平滑过渡到秋夜月光和冬夜灯笼光，符合“光照本身随时间平滑变化”的定义 |
| 背景环境 | 完整场景 | 院墙、亭子、曲廊、水池和植物构成完整搭建的环境 |
| 色彩基调 | 不填 | 四季的主色依次变化，全片没有单一的色彩基调 |
| 时序结构 | 多段序列 | 春、夏、秋、冬按顺序衔接 |
| 复杂度等级 | 物理模拟 | 落叶、雨丝和雪花需要粒子系统，锦鲤和竹林属于“≥10 对象群组”。剧本不要求真实的物理模拟 |
| 应用场景 | 不填 | 没有明确用途依据 |

积雪覆盖和结冰也对应“形变与生长/生长展开/逐步生成”，锦鲤游动对应“位移与运动/群体运动/群集”。受动画行为最多 4 个的上限所限，这两项不单独列出。灯笼逐盏亮起对应“显隐与外观变化/材质变化/发光亮灭”，春天的雨雾属于氛围点缀。镜头的推进属于镜头运动，不计入动画行为。
