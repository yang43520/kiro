# 浑天仪瀑布流组装动画 · 制作需求

制作时同时提供「一、制作 Prompt」和完整的《浑天仪瀑布流组装剧本》（见 `浑天仪瀑布流组装剧本.md`）。「三、类目与标签」和「四、试做验收要点」不属于制作输入。

---

## 一、制作 Prompt

```text
使用 Blender 5.0.0 制作一条约 10 秒（允许 8–12 秒，不得少于 8 秒）的浑天仪“瀑布流组装”动画，写实渲染风格。画面内容、动作和镜头以《浑天仪瀑布流组装剧本》为准。

核心效果：一架青铜浑天仪的零件从画面上方一件接一件连续落下，每件落到自己的位置后减速、对齐、卡紧，按“底座 → 外层六合仪 → 中层三辰仪 → 内层四游仪”的顺序从下到上、从外到内拼成完整仪器；组装完成后，中层和内层的环绕极轴缓慢转动。

不可改变的内容：组装顺序不能打乱；零件的下落首尾相接，前一件落定之前下一件已经从画面上方出现，全程没有长时间停顿；每件零件都要经历可见的下落、减速对齐和卡合，卡合时有轻微回弹；零件落定后与已装好的部件保持连接，不再漂移；下落路径从已装部件的空隙中穿过，不得与已装部件相交；最终画面是一架完整的浑天仪，底座和外层保持不动，中层和内层在转动中结束。

可调整范围：剧本中的尺寸、角度和时间都是参考值，可在保持比例和观感的前提下调整；各阶段时间点可在总时长内微调，但不能改变组装顺序，也不能改变“全部落定后再开始转动”的先后关系。立柱造型、纹饰、各层环的截面形状和具体数量可以自行设计，只要三层结构清楚可辨。

可选增强：零件卡合时，已装好的部件可以随冲击轻微震动一下；立柱可以加上浮雕龙纹。

禁止：零件在画面内凭空出现或消失，或不经下落直接滑到位置；零件之间穿模，或落定后悬空、错位；环面上出现可读文字（刻度只用线条）；镜头抖动；画面闪烁、破面或非设计性的卡顿、抽搐；用停帧或重复动作凑时长；整体暗到看不清铜环结构，或高光过曝成一片白。

输出规格：16:9，1920×1080，30 帧/秒，无声音。最终输出一条完整的动画视频。
```

## 三、类目与标签

**主类目**：产品动画/工业设备/仪器仪表

**归类理由**：主要表现对象是浑天仪这件具体的仪器，表达目的是展示它的结构如何逐层组装成型；「工业设备」的纳入范围包括仪器。片中没有演示天体或天文现象，所以不归「科教演示/天文宇宙」；浑天仪是具体器物而不是抽象原理模型，所以不归「科教演示/物理原理」；主体是整件仪器而不是单个零部件，组装动作由动画行为标签表达，所以不归「工业设备/零部件」。浑天仪是古代天文仪器，不是现代工业商品，类目树中没有文物或古器物类目，「仪器仪表」是最接近的正式类目。

| 标签组 | 选定标签 | 必要说明 |
|---|---|---|
| 视觉造型 | 写实 | |
| 材质质感 | 金属（主材质） | 全部部件为青铜；石质地台只是背景，不单独列 |
| 渲染风格 | 真实渲染 | |
| 动态节奏 | 自然流畅 | 下落、减速、轻微回弹和匀速转动都符合物理规律 |
| 动画行为 | 主行为：结构与装配/拆解组装/拼接归位 | 零件逐个落到安装位置并卡合 |
| 动画行为 | 辅助行为：物理与特效/刚体运动/掉落 | 零件从画面上方落下 |
| 动画行为 | 辅助行为：位移与运动/规律运动/旋转 | 成型后中层和内层绕极轴转动 |
| 灯光氛围 | 低调暗黑 | 暗背景，暖色主光加轮廓光；结尾扫光不改变整体氛围 |
| 背景环境 | 无缝影棚 | 地台向外隐入黑暗，地面和背景没有明显分界；表中没有"地面加暗背景"一项，这是最接近的 |
| 色彩基调 | 不填 | 暖金、铜褐加暗绿，不完全符合任何一项 |
| 时序结构 | 多段序列 | 落座、外层成框、中层入轴、内层收尾、运转展示依次衔接 |
| 复杂度等级 | 多元编排 | 多个对象、多种行为、错时编排。前提：复杂度定义中的"≥10 对象群组"指大量相似对象成群运动，不包括约 11 件分别设计动作的零件（待确认） |
| 应用场景 | 不填 | 没有明确用途依据 |
