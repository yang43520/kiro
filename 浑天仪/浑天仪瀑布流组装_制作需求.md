# 浑天仪瀑布流组装动画 · 制作需求

制作时同时提供「一、制作 Prompt」和完整的《浑天仪瀑布流组装剧本》（见 `浑天仪瀑布流组装剧本.md`）。「三、类目与标签」和「四、试做验收要点」不属于制作输入。

**修改记录**

最近一次修改（增加复杂度，强调瀑布式组装）：
- 零件从约 11 件增加到约 53 件。底座加入第二根横梁、端头铜帽、鳌云座和托座；六合仪加入铜销、卡箍和极枢；三辰仪拆成赤经双环、内赤道环、黄道环、白道环和 12 颗铆钉；四游仪加入直距和窥管枢轴。
- 组装阶段由 4 个改为 5 个：底座 → 支柱 → 六合仪 → 三辰仪 → 四游仪，相邻阶段在时间上交叠。
- 剧本新增"零件瀑布"一节，写明瀑布的入画区域、不间断、粗细变化和分流方式。Prompt 把"空中始终至少有 2 件零件在下落"和"小零件成串落下"列为不可改变的内容，禁止项增加"多件零件同时瞬间到位，或组装中途瀑布停顿"。
- 龙柱、横梁、鳌云座和铜帽改为带浮雕纹饰；原来作为可选增强的"立柱浮雕龙纹"已写进剧本。
- 时长由约 10 秒改为约 12 秒，镜头环绕角度由约 30° 改为约 40°，构图为下落的零件瀑布留出画面上方约三分之一。
- 复杂度等级由"多元编排"改为"物理模拟"，原来的待确认问题不再影响本方案。

剧本名称不变。

## 一、制作 Prompt

```text
使用 Blender 5.0.0 制作一条约 12 秒（允许 11–13 秒，不得少于 8 秒）的浑天仪“瀑布式组装”动画，写实渲染风格。画面内容、动作和镜头以《浑天仪瀑布流组装剧本》为准。

核心效果：一架由约 53 件青铜零件组成的浑天仪，从空无一物的地台开始，零件像瀑布一样从画面上方连续倾泻而下：大件如粗水柱般沉沉落下，铜帽、铜销、卡箍、铆钉等小件像水珠一样成串洒落，每件都在下落中翻转，接近安装位置时减速、对齐、卡紧。整架仪器按“底座 → 支柱 → 六合仪 → 三辰仪 → 四游仪”的顺序从下到上、从外到内逐层成型；组装完成后，三辰仪和四游仪绕极轴缓慢转动。

不可改变的内容：瀑布式下落贯穿整个组装过程，从第一件零件入画到窥管落定，空中始终至少有 2 件零件在下落，不出现空档；所有零件都从画面上缘外、浑天仪上方入画，接近竖直地落下；组装顺序不能打乱；每件零件都要经历可见的下落、减速对齐和卡合，卡合时有轻微回弹；小零件必须成串落下，并分别落到各自的孔位或交点上；零件落定后与已装好的部件保持连接，不再漂移；下落路径从已装部件的空隙中穿过，不得与已装部件相交；最终画面是一架完整的浑天仪，底座和六合仪保持不动，三辰仪和四游仪在转动中结束。

可调整范围：剧本中的尺寸、角度、数量和时间都是参考值，可在保持比例和观感的前提下调整；各阶段时间点可在总时长内微调，相邻阶段可以交叠，但不能改变组装顺序，也不能改变“全部落定后再开始转动”的先后关系。同一阶段内零件的先后可以微调；铜帽、铜销、卡箍、铆钉的数量可以随结构设计增减，但剧本列出的每一类零件都要出现。龙柱和鳌云座的纹饰、各道环的截面形状、卡箍和铆钉的样式可以自行设计，只要四大部分清楚可辨。

可选增强：大件落定时，已装好的部件随冲击轻微震动一下；龙柱、地平环等大件落定时扬起少量微尘。

禁止：零件在画面内凭空出现或消失，或不经下落直接滑到位置；多件零件同时瞬间到位，或组装中途瀑布停顿；零件之间穿模，或落定后悬空、错位；环面、龙柱或其他部件上出现可读文字（刻度只用线条）；镜头抖动；画面闪烁、破面或非设计性的卡顿、抽搐；用停帧或重复动作凑时长；整体暗到看不清铜环结构，或高光过曝成一片白。

输出规格：16:9，1920×1080，30 帧/秒，无声音。最终输出一条完整的动画视频。
```

## 三、类目与标签

**主类目**：产品动画/工业设备/仪器仪表

**归类理由**：主要表现对象是浑天仪这件具体的仪器，表达目的是展示它的结构如何逐层组装成型；「工业设备」的纳入范围包括仪器。片中没有演示天体或天文现象，所以不归「科教演示/天文宇宙」；浑天仪是具体器物而不是抽象原理模型，所以不归「科教演示/物理原理」；主体是整件仪器而不是单个零部件，组装动作由动画行为标签表达，所以不归「工业设备/零部件」。浑天仪是古代天文仪器，不是现代工业商品，类目树中没有文物或古器物类目，「仪器仪表」是最接近的正式类目。

| 标签组 | 选定标签 | 必要说明 |
|---|---|---|
| 视觉造型 | 写实 | |
| 材质质感 | 金属（主材质） | 全部零件为青铜；石质地台只是背景，不单独列 |
| 渲染风格 | 真实渲染 | |
| 动态节奏 | 自然流畅 | 下落带重力加速，接近落点减速，卡合轻微回弹，成型后匀速转动，都符合物理规律 |
| 动画行为 | 主行为：结构与装配/拆解组装/拼接归位 | 约 53 件零件逐件落到安装位置并卡合 |
| 动画行为 | 辅助行为：物理与特效/刚体运动/掉落 | 零件从画面上方像瀑布一样连续落下 |
| 动画行为 | 辅助行为：位移与运动/规律运动/旋转 | 成型后三辰仪和四游仪绕极轴转动 |
| 灯光氛围 | 低调暗黑 | 暗背景，暖色主光加轮廓光；结尾扫光不改变整体氛围 |
| 背景环境 | 无缝影棚 | 地台向外隐入黑暗，地面和背景没有明显分界；表中没有"地面加暗背景"一项，这是最接近的 |
| 色彩基调 | 不填 | 暖金、铜褐加暗绿，不完全符合任何一项 |
| 时序结构 | 多段序列 | 底座、支柱、六合仪、三辰仪、四游仪、运转展示依次衔接 |
| 复杂度等级 | 物理模拟 | 12 颗铆钉成串落下，属于"≥10 对象群组"；全片约 53 件零件，不论按群组还是按对象总数理解都达到这一条件。剧本不要求真实的物理模拟 |
| 应用场景 | 不填 | 没有明确用途依据 |
