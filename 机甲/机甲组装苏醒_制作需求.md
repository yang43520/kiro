# 机甲组装苏醒动画 · 制作需求

制作时同时提供「一、制作 Prompt」和完整的《机甲组装苏醒剧本》（见 `机甲组装苏醒剧本.md`）。「三、类目与标签」和「四、试做验收要点」不属于制作输入。

## 一、制作 Prompt

```text
使用 Blender 5.0.0 制作一条约 12 秒（允许 11–13 秒，不得少于 8 秒）的机甲组装动画，写实渲染风格，一镜到底。画面内容、动作和镜头以《机甲组装苏醒剧本》为准。

核心效果：昏暗的机库中央，一具高约 10 米、还没有装甲和头部的人形机甲内骨架站在整备台上。约 30 块深枪灰色的装甲部件从四周的暗处沿弧线悬空飞来，从脚到头依次贴合到骨架上：先是腿部，再是腰部、背包和胸甲，然后是手臂和双手，最后头部从上方降下，装到颈部接口上。每块部件到位时轻微一震、锁紧，溅出一小簇火花。全部装好后，眼灯闪烁两下后亮起，接缝里的青蓝色灯带从胸口向四肢依次亮起，机甲缓缓抬起头、右手握拳，肩部和膝部喷出白色蒸汽。镜头从机甲左前方的腿部开始，跟着组装的位置一边升高一边后退，同时向右环绕，结束时在机甲正前方略微仰视，整台机甲完整出现在画面中。

质感要求：
- 整体：以接近电影实拍加视效的质感为目标，机甲和机库都按真实的工业结构和材质来做。
- 内骨架：由金属骨架、液压杆和成束的线缆组成，关节处能看到转轴和液压缸。
- 装甲：深枪灰色金属，表面有面板接缝、螺栓、散热格栅，边角有磨损露出的亮金属和细小划痕，少量部位有黄黑相间的警示条纹；不能是光滑无细节的表面，也不能有塑料或玩具般的质感。
- 部件结构：每块装甲有真实的厚度，背面能看到内侧的加强筋和卡扣；装上后与骨架和相邻装甲贴合，没有过大的缝隙。
- 机库：灰色混凝土地面带磨损和褪色的黄色定位线，天花板是挂着工作灯和电缆的钢桁架，四周立着钢制检修架。
- 光影：机库整体很暗，三盏顶部工作灯从斜上方照向整备台，在淡淡的雾气中形成光柱；机甲背后有一道冷白色的轮廓光；金属表面能反射工作灯和发光部件的光。
- 发光：眼灯、动力核心和接缝灯带是青蓝色，火花是橙黄色；发光部件不过曝成一片白色，能看清灯带的形状。
- 渲染：暗处的装甲仍能看清接缝和螺栓；画面清晰锐利，没有因降噪过度、贴图精度低或采样不足造成的发糊、涂抹或噪点。

不可改变的内容：全片是一个连续镜头，中间没有剪辑或转场；组装按“腿部 → 躯干 → 手臂 → 头部 → 苏醒”的顺序进行；每块部件都是飞来后贴合上去的；部件到位时有锁紧的一震和火花，锁紧后完全静止；胸甲左右两片像舱门一样合拢，盖住动力核心；苏醒时眼灯亮起、灯带依次亮起、机甲抬头、右手握拳；正在锁紧的部件始终在画面中；画面在蒸汽仍在飘散时结束；结束时整台机甲从头到脚完整位于画面中。

可调整范围：剧本中的尺寸、距离、速度和时间都是参考值，可在保持比例和观感的前提下调整；各段时间点可以微调，但组装的顺序不变。部件的具体数量、分块方式和飞来的方向，机甲的具体造型，机库的细节，镜头环绕的方向，都可以自行设计。

可选增强：部件锁紧时，桁架上垂下的电缆随之轻轻晃动；发光部件的青蓝色光照亮周围的装甲和地面。

禁止：剪辑、转场或跳帧；出现人物、文字或标志；照搬现有动画、电影或游戏中的机甲造型；机甲行走、开火或做出攻击动作；部件凭空出现、瞬移或穿过其他部件；部件装错位置或组装顺序混乱；明显的建模感，如光滑无细节的大块表面、塑料感的高光、肉眼可辨的重复贴图；镜头突然加速、急停或抖动；用停帧或重复片段凑时长；画面闪烁、破面或非设计性的卡顿。

输出规格：16:9，1280×720，30 帧/秒，无声音。最终输出一条完整的动画视频。
```

## 三、类目与标签

**主类目**：载具动画/幻想载具/机甲

**归类理由**：
- 本片的主体是一台带驾驶舱的大型虚构机甲，动作是部件依次组装，与分类表中“机甲部件依次组装”的示例一致。
- 分类表规定“大型可驾驶机甲→载具动画/幻想载具”，所以不归入「角色动画/简易人形/小型机器人」。
- 机甲苏醒后只有抬头和握拳，没有以表演、情绪为目的的动作，不归入「角色动画/幻想生物」。

| 标签组 | 选定标签 | 必要说明 |
|---|---|---|
| 视觉造型 | 写实 | |
| 材质质感 | 金属、自发光 | 金属为主材质；眼灯、动力核心和接缝灯带是自发光 |
| 渲染风格 | 真实渲染 | |
| 动态节奏 | 机械节奏 | 部件飞近、停顿对准、干脆锁紧，停顿明确 |
| 动画行为 | 主行为：结构与装配/拆解组装/拼接归位 | 约 30 块装甲部件逐个飞来，贴合到内骨架上 |
| 动画行为 | 辅助行为：结构与装配/开合联动/打开翻盖 | 左右两片胸甲绕铰链转动合拢 |
| 动画行为 | 辅助行为：显隐与外观变化/材质变化/发光亮灭 | 动力核心变亮，眼灯闪烁后亮起，灯带依次亮起 |
| 动画行为 | 辅助行为：物理与特效/流体粒子/粒子 | 锁紧时的火花和排气口喷出的蒸汽 |
| 灯光氛围 | 低调暗黑 | 机库很暗，三盏工作灯局部照亮整备台，对比强；雾中的光柱是辅助效果，所以不选“体积光” |
| 背景环境 | 完整场景 | 机库的地面、桁架和检修架构成完整搭建的环境 |
| 色彩基调 | 冷色科技 | 整体为冷蓝灰色，发光部件为青蓝色；橙黄色火花只是点缀 |
| 时序结构 | 多段序列 | 腿部、躯干、手臂、头部、苏醒按顺序衔接 |
| 复杂度等级 | 物理模拟 | 装甲部件约 30 块，属于“≥10 对象群组”；火花和蒸汽适合用粒子实现。剧本不要求真实的物理模拟 |
| 应用场景 | 不填 | 没有明确用途依据 |

机甲抬头和握拳是关节转动，没有完全对应的行为标签；部件沿弧线飞来对应“位移与运动/路径运动/沿线移动”，但属于拼接归位的一部分。受动画行为最多 4 个的上限所限，这两项不单独列出。
