# 桌上的微缩雨林生态瓶考点说明

> 内部校验用，不交给制作方，不属于制作输入。

**主类目**：场景动画/微缩模型/场景切片

**题目档位**：上限档（配方：单个 L4，附带 1 个 L2 和 2 个 L1）

**档位来源**：默认

**规范版本**：进阶版 1.5

**视觉基调**：温馨童话

**耦合链**：同一只封口玻璃罐的内壁上，晨光让冷凝水珠长大、合并、从朝阳一侧到背阳一侧依次滑落，每条滑过的地方擦出一道一直留着的清亮水道；蜗牛的腹足贴着同一面内壁往上挪，擦走水珠、留下持续发亮的黏液痕；最后一颗水珠顺旧水道滑下、碰到黏液痕拐弯停在壳口边。光的变暖是水珠滑落和薄雾抬升的起因，整个过程由一条一镜到底的镜头串起来。

| 编号 | 考点 | 分级 | 作用对象与时段 | 在片中的体现 |
|---|---|---|---|---|
| 15 | 接触留痕与表面动态反馈 | L4 | 玻璃内壁上的水道和蜗牛黏液痕，2.5–12 秒 | 水珠滑过留下 2–4 毫米宽、不再雾上的清亮水道；蜗牛腹足擦走水珠，留下约 5 毫米宽、一直亮着的黏液痕，痕沿路线一帧帧往前长；苔藓上被压伏变润的一段；土层边被打湿的返潮水线；最后一颗水珠碰到黏液痕边拐弯 |
| 14 | 集群协同与波浪相位差 | L2 | 内壁上的一排冷凝水珠，2.5–6 秒 | 七八条水珠从朝阳一侧到背阳一侧依次滑落，隔半秒左右一条，形成一道横向推进的相位差 |
| 16 | 光影流转与材质外观演变 | L1 | 晨光、玻璃和薄雾，0–12 秒 | 第 1 秒太阳出云亮一档，整瓶从灰绿变暖金；雾蒙蒙的玻璃被水道一道道擦亮；罐里薄雾抬到瓶肩、变淡 |
| 17 | 单镜头运镜构图 | L1 | 镜头，全片 | 一镜到底：中心构图 → 引导线 → 对角线特写 → 三分法 → 框景，焦点从瓶子到水道、蕨叶尖、蜗牛壳口 |

**最高分级**：L4

## 制作底线清单

**二级类目**：微缩模型

**技术模块**：T1、T2、T5（另用 T3 的动态绘画做法、T4 的局部体积雾、T7 的动物做法）

**本片要用的专业术语**：底座剖面、实例化散布、高度图、置换修改器、雕刻、多重分辨率细分、体素重构网格、岩石节理、几何节点散布、实例化、随机旋转与缩放、叶片次表面散射、半透明背光、二级摆动、生长遮罩、路径生长、斜切倒角、返潮遮罩、顶点颜色混合、动态绘画波纹、折射率、局部体积雾、体积散射、物理天空、骨骼绑定、骨骼链、形态键、缩裹约束、子级约束、粒子系统、环境光遮蔽

**推荐插件**：几何节点（内置）、IvyGen（内置扩展）、Infinigen（开源）

**通用底线**：PBR 贴图或程序化纹理（近景 4K）、倒角、接触阴影、AgX 色彩管理（Base Contrast）、足够采样、100% 查看细节、尺度参照（铅笔）、防重复

**重模拟**：无（水珠用几何节点，水道和黏液痕用动态绘画，薄雾用局部体积雾，细流和水潭用做好形状的水面加动态绘画波纹）

## 类目与标签

**归类理由**：主体是一只封口玻璃罐里自成边界的桌面小世界，罐底隔着玻璃露出砾石、木炭、湿土和苔藓的分层剖面，上面是一整片地上的小地形，属于微缩模型里的场景切片。

| 标签组 | 选定标签 | 必要说明 |
|---|---|---|
| 视觉造型 | 写实 | 照片级写实的玻璃生态瓶 |
| 材质质感 | 玻璃透明、液体冰晶、木石天然 | 主材质是玻璃罐和内壁的水珠；其次是水道和水潭，以及苔藓、土层、卵石和树皮 |
| 渲染风格 | 真实渲染 | 常规物理渲染 |
| 动态节奏 | 自然流畅 | 水珠、蕨叶和蜗牛都按真实速度连贯运动 |
| 动画行为 | 主行为：物理与特效/流体粒子/液体 | 内壁水珠长大、合并、滑落，滴水和细流 |
| 动画行为 | 辅助行为：位移与运动/路径运动/沿线移动 | 蜗牛贴着玻璃往上挪 |
| 动画行为 | 辅助行为：形变与生长/生长展开/路径延伸 | 水道和黏液痕沿路线往前长 |
| 动画行为 | 辅助行为：显隐与外观变化/材质变化/透明度 | 雾蒙蒙的玻璃被一道道擦得清透 |
| 灯光氛围 | 自然日光 | 早上的太阳和天光 |
| 背景环境 | 完整场景 | 书桌、窗户和生态瓶完整搭建 |
| 色彩基调 | 不填 | 绿为主、配暖棕金，不是单一的色彩基调 |
| 时序结构 | 多段序列 | 晨光照进瓶 → 水珠滑落 → 蕨叶点头 → 蜗牛上玻璃 → 雾散 |
| 复杂度等级 | 多元编排 | 几何节点、动态绘画、骨骼、粒子和体积雾编排，不用重模拟 |
| 应用场景 | 不填 | 没有明确的用途依据 |
