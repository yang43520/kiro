## 一、制作 Prompt

```text
使用 Blender 5.0.0 制作一条约 12 秒（允许 11–13 秒，不得少于 8 秒）的战斗机“瀑布式组装”弹射起飞动画，照片级写实渲染，一镜到底。画面内容、动作和镜头以《战斗机组装弹射起飞剧本》为准。

核心效果：晴朗的下午，一艘原创航母在海上航行，舰艏弹射器的起点上空无一物。约 70 件零件从画面上方像瀑布一样连续倾泻而下：大件如粗水柱般沉沉落下，检修口盖和尾喷口调节片像水珠一样成串落下，每件都在下落中缓慢翻转，接近安装位置时减速、摆正、装入，装好时轻微回弹。一架原创的单座双发战斗机按“骨架 → 动力 → 座舱 → 蒙皮与翼面 → 收尾”的顺序逐层成型。组装完成后航行灯亮起，座舱盖合上，偏流板升起，发动机开加力，橙色的尾焰打在偏流板上；弹射器发力，战斗机在约 2 秒内冲过滑轨、冲出舰艏，略微下沉后抬头爬升远去。镜头从左前方略微俯视开始，组装时缓慢环绕并降低，弹射时跟着战斗机转向舰艏。

质感要求：
- 整体：画面像用电影摄影机在真实的航母甲板上实拍、再加视效，任意暂停一帧都应该像一张电影剧照；所有零件按真实尺寸、真实结构和真实材质制作。
- 尺寸与布局：机身长约 19 米，翼展约 13 米，高约 4.8 米；梯形主翼，两片向外倾斜的垂直尾翼，两片全动式水平尾翼；两侧进气道，两个发动机尾喷口；前三点式起落架，前起落架上有弹射连杆。
- 外形：机头细长尖锐，雷达罩是浅灰色；座舱盖是一体式的气泡形；机身和机翼的连接处平滑过渡，板件边缘是锯齿状的；不能是简单的方块或平板拼出的造型。
- 涂装：两种深浅不同的哑光灰色迷彩，机身上方较深，下方较浅；机身上没有任何国籍标志、编号或文字。
- 机身蒙皮：哑光灰色涂层，相邻板件的灰度略有差别；板件边缘是锯齿状的接缝；检修口盖周围有一圈细小的螺钉；涂层上有维护留下的油渍、指印状的污痕和轻微的磨损。
- 座舱盖：带金色镀膜的透明罩，在不同角度下映出天空、舰岛和海面；透过罩能隐约看到弹射座椅和仪表板。
- 尾喷口：钛合金的调节片，边缘有发动机受热留下的蓝紫色、金色和深褐色热变色。
- 起落架：镀铬的减震支柱发亮；轮胎是橡胶，有胎面花纹，接地处略微压扁；收放作动筒和管路清楚可见。
- 进气道与座椅：进气道唇口是锋利的金属边，内壁是白色；弹射座椅有深灰色的座垫和安全带，头部有黄黑相间的拉环。
- 边缘：所有边缘都有真实的小倒角，能接到细细的高光。
- 材质区分：涂层、玻璃、镀铬、钛合金和橡胶各有不同的光泽和纹理，不能看起来都是同一种材质。
- 甲板：深灰色的防滑涂层，有粗糙的颗粒质感；上面画着白色和黄色的标线，有黑色的轮胎印、油渍、磨损，以及一排排嵌在甲板里的系留环；弹射器滑轨是一条嵌在甲板里的长槽，从起点一直延伸到舰艏边缘。
- 海和天：深蓝色的大海上有成片的波浪和白色浪花，阳光在海面上形成一片闪烁的反光；海平线清楚，天空是晴朗的淡蓝色，有几朵积云。
- 光影：晴朗下午的阳光从左前方照来，太阳高度约 35°，是略带暖色的白光；天空的淡蓝色光作为补光，让背光面仍能看清细节；战斗机和零件在甲板上投下清晰的影子，影子方向一致。
- 反光：机腹和机翼下表面带一点海面反射的蓝色和甲板反射的灰色；座舱盖、镀铬支柱和金属边缘上有阳光形成的明亮高光，高光随视角和零件的翻转移动。
- 尾焰：加力时尾焰从暗红色变成明亮的橙色，中心是一串蓝白色的激波环；尾焰打在偏流板上，被向上折开；尾焰后方的空气因为热浪而扭曲。
- 曝光与清晰度：阳光照亮的部分不过曝成一片白色，阴影里仍能看清零件结构；画面清晰锐利，接缝、螺钉和甲板颗粒的细节都能看清，没有因降噪过度、贴图精度低或采样不足造成的发糊、涂抹或噪点。
- 空气与辉光：画面中没有雾，不加大片的辉光；只有加力燃烧室的尾焰和航行灯带一点柔和的光晕；远处的海平线因大气透视略微变淡，但空气通透。
- 镜头成像：组装阶段战斗机始终清晰，背景略虚；运动模糊相当于 180° 快门，下落的零件和弹射中的战斗机带自然的拖影。

不可改变的内容：全片是一个连续镜头，中间没有剪辑或转场；组装按“骨架 → 动力 → 座舱 → 蒙皮与翼面 → 收尾”的顺序进行，所有内部零件都在蒙皮盖上之前装好；所有零件都从画面上缘外、战斗机上方入画，接近竖直地落下；瀑布式下落贯穿整个组装过程，空中始终至少有 3 件零件在下落，不出现空档；每件零件都要经历可见的下落、减速摆正和装入，装好时有轻微回弹；零件之间、零件与已装部件之间不得相交；组装阶段整架战斗机始终完整地位于画面中；“组装完成 → 亮灯 → 座舱盖合上 → 偏流板升起 → 开加力 → 弹射”的先后顺序不变；战斗机冲出舰艏后先略微下沉再爬升；画面在战斗机仍在爬升远去、尾焰仍在燃烧时结束。

可调整范围：剧本中的尺寸、角度、数量、速度和时间都是参考值，可在保持比例和观感的前提下调整；各阶段时间点可以微调，相邻阶段可以略有交叠，但阶段顺序不变。同一阶段内零件的先后可以微调；隔框、检修口盖、调节片等零件的数量可以随结构设计增减，但剧本列出的每一类零件都要出现。战斗机的具体外形、迷彩的图案、航母舰岛的样式、镜头的具体路线，都可以自行设计。

可选增强：大件装好时，已装好的部件随冲击轻微震动一下；弹射时甲板上的细小碎屑被尾焰吹向后方。

禁止：剪辑、转场或跳帧；零件在画面内凭空出现或消失，或不经下落直接滑到位置；多件零件同时瞬间到位，或组装中途瀑布停顿；零件穿模，或装好后悬空、错位、在机身表面滑动；照搬任何真实机型或舰船的外形；出现国籍标志、编号、文字或真实品牌的标志；挂载导弹、炸弹或任何武器；出现人物；外形像玩具或模型，所有材质看起来一样，或金属没有金属反射；弹射时战斗机没有加速感，或冲出舰艏后直接平直飞走；尾焰过曝成一片白色，或尾焰穿过偏流板；出现雾或大片的辉光；整体过曝或暗到看不清零件结构；镜头突然跳动或抖动；用停帧或重复片段凑时长；画面闪烁、破面或非设计性的卡顿。

输出规格：16:9，1280×720，30 帧/秒，无声音。最终输出一条完整的动画视频。
```

## 三、类目与标签

**主类目**：载具动画/航空航天/固定翼飞机

**归类理由**：
- 主要表现对象是一架战斗机，属于固定翼飞机，「固定翼飞机」的示例是“飞机滑跑起飞爬升”。
- 分类表规定交通工具一律归「载具动画」，片中以组装展示的方式呈现，展示方式由动画行为标签表达，不改变主类目。
- 战斗机是原创但真实类型的飞机，不是虚构飞行器，所以不归「幻想载具」；航母只是起飞的场地，所以不归「水上载具」。

| 标签组 | 选定标签 | 必要说明 |
|---|---|---|
| 视觉造型 | 写实 | 照片级写实 |
| 材质质感 | 金属（主材质）、玻璃透明、自发光 | 机身、发动机、尾喷口和起落架为金属；座舱盖为带镀膜的玻璃；尾焰和航行灯为自发光。甲板涂层和橡胶轮胎受数量上限所限不单独列出 |
| 渲染风格 | 真实渲染 |  |
| 动态节奏 | 自然流畅 | 零件带重力加速下落，接近落点减速，装入时轻微回弹；弹射加速和爬升平滑连贯 |
| 动画行为 | 主行为：结构与装配/拆解组装/拼接归位 | 约 70 件零件逐件落到安装位置并装入 |
| 动画行为 | 辅助行为：物理与特效/刚体运动/掉落 | 零件从画面上方像瀑布一样连续落下 |
| 动画行为 | 辅助行为：位移与运动/路径运动/沿线移动 | 战斗机沿弹射滑轨加速，冲出舰艏后爬升 |
| 动画行为 | 辅助行为：物理与特效/流体粒子/烟火 | 加力尾焰和滑轨里喷出的蒸汽 |
| 灯光氛围 | 自然日光 | 晴朗下午的太阳光加天空光 |
| 背景环境 | 完整场景 | 航母甲板、舰岛、海面和天空构成完整搭建的环境 |
| 色彩基调 | 不填 | 灰色、深蓝和淡蓝为主，夹着黄色标线和橙色尾焰，不完全符合任何一项 |
| 时序结构 | 多段序列 | 五个组装阶段、准备、弹射依次衔接 |
| 复杂度等级 | 物理模拟 | 约 70 件零件，检修口盖和调节片成串落下，属于“≥10 对象群组”；尾焰和蒸汽适合用烟火模拟。剧本不要求真实的物理模拟 |
| 应用场景 | 不填 | 没有明确用途依据 |

座舱盖合上和偏流板升起对应“结构与装配/开合联动/打开翻盖”，航行灯亮起对应“显隐与外观变化/材质变化/发光亮灭”。受动画行为最多 4 个的上限所限，这两项不单独列出。
