# 战斗机瀑布式组装动画 · 制作需求

制作时同时提供「一、制作 Prompt」和完整的《战斗机瀑布式组装剧本》（见 `战斗机瀑布式组装剧本.md`）。「三、类目与标签」和「四、试做验收要点」不属于制作输入。

## 一、制作 Prompt

```text
使用 Blender 5.0.0 制作一条约 12 秒（允许 11–13 秒，不得少于 8 秒）的歼-20 战斗机“瀑布式组装”动画，照片级写实渲染，一镜到底。画面内容、动作和镜头以《战斗机瀑布式组装剧本》为准。

核心效果：深灰色的超大型无缝影棚里，约 80 件精细的零件从画面上方像瀑布一样连续倾泻而下：大件如粗水柱般沉沉落下，隔框、翼肋、检修口盖和尾喷口调节片像水珠一样成串落下，每件都在下落中缓慢翻转，露出背面和内部结构，接近安装位置时减速、摆正、装入，装好时轻微回弹。一架歼-20按“起落架与骨架 → 动力 → 航电与座舱 → 蒙皮与翼面 → 收尾”的顺序逐层成型。最后航行灯亮起，防撞灯闪烁，座舱盖合上。镜头先靠近跟着组装的位置移动，看清起落架、发动机和座舱的零件，再慢慢后退，最后以左前方三分之四的角度看到整架战斗机。

质感要求：
- 整体：画面达到高端航空产品广告的质感，所有零件按真实尺寸、真实结构和真实材质制作，任意暂停一帧都应该像一张影棚实拍的照片。
- 参考与模型：使用歼-20 的精细三维模型制作，外形、比例、鸭翼和尾翼的角度、进气道鼓包、座舱盖和板件锯齿接缝都对照实机照片逐项核对；模型按组装需要拆成零件，内部结构按真实战斗机的通用结构合理设计。
- 尺寸与布局：机身长约 20.5 米，翼展约 13 米，高约 4.5 米；鸭式布局：机头两侧一对全动式鸭翼，带边条的三角形主翼，两片向外倾斜的全动式垂直尾翼，尾部下方两片腹鳍，没有水平尾翼；机身两侧是带鼓包的 DSI 进气道，两个发动机尾喷口；前三点式起落架；内置弹舱，舱门全部关闭。
- 外形：机头细长，截面带明显的棱线，雷达罩与机身同色；座舱盖是无前框的一体式气泡形，表面有淡淡的金色镀膜；机身和机翼的连接处平滑过渡，板件边缘是锯齿状的。
- 涂装：按量产型歼-20 的实机涂装，深灰色的哑光隐身涂层，局部颜色略浅的块面按实机照片还原；机身上没有任何国籍标志、编号或文字。
- 零件精细度：所有零件都要做出完整的结构细节，不能是光滑的外壳；每件零件都有真实的厚度；结构件的内侧有加强筋、减重孔、安装凸耳和螺栓孔；零件之间的连接处有卡扣、铰链或螺栓。
- 起落架：镀铬的减震支柱，支柱上有扭力臂和液压管路；主起落架的轮毂里能看到刹车盘；轮毂上有一圈螺栓；轮胎是橡胶，有胎面花纹，接地处略微压扁。
- 隔框和翼肋：铝合金的机加工件，表面有细密的加工纹，中间有一排圆形的减重孔，边缘有一圈螺栓孔。
- 发动机：前端的风扇叶片清楚可见，叶片是带扭转的钛合金；外壳上缠着成束的管路，由一个个卡箍固定；下方挂着附件齿轮箱。
- 加力燃烧室筒体和尾喷口：钛合金，表面有发动机受热留下的蓝紫色、金色和深褐色热变色；尾喷口调节片之间相互搭接。
- 进气道：唇口是锋利的金属边，内壁是白色。
- 雷达与航电：雷达天线阵面是一块圆形的平板，由几百个排成网格的小方块单元组成，背面连着散热片和线束；航电机柜是一格格插着的电子模块，正面有散热孔和连接器。
- 座舱：弹射座椅两侧有导轨，有深灰色的座垫和肩部、腰部的安全带，头部有黄黑相间的拉环；仪表板上有三块黑色的多功能显示屏，每块屏幕的边框上有一圈按键，屏幕不显示内容；平视显示器是一块倾斜的透明组合镜。
- 蒙皮板：外侧是哑光灰色涂层，相邻板件的灰度略有差别，边缘是锯齿状的接缝，沿接缝有一排排细小的螺钉；内侧能看到纵向的桁条。
- 座舱盖：金属框架加一体式的透明罩，框架边缘有黑色的密封胶条；透明罩带金色镀膜，能映出影棚的条形灯。
- 翼面：前缘襟翼、后缘襟副翼、鸭翼和尾翼的转轴处能看到铰链和作动筒。
- 边缘：所有边缘都有真实的小倒角，能接到细细的高光。
- 材质区分：涂层、玻璃、镀铬、铝合金、钛合金、橡胶和皮革各有不同的光泽和纹理，不能看起来都是同一种材质。
- 真实感基准：参照歼-20 的实机照片和航展实拍照片，所有尺寸、结构和材质的反光强度都按真实物体设定，不能有卡通、手办或游戏模型的感觉。
- 细微瑕疵：零件是新的，但不是完美无瑕：铝合金件上有极细的加工刀纹和轻微的氧化色差；钛合金件有细微的划痕；涂层表面有极细的颗粒和轻微的橘皮纹；座舱盖上有淡淡的指纹和灰尘；轮胎上有脱模留下的细小胶毛。
- 物理正确的材质：金属的反射颜色和粗糙度按真实金属设定，铝偏冷白，钛偏暖灰，镀铬接近镜面；玻璃有正确的折射和反射，正对时透明，斜看时反光变强。
- 真实的灯光：柔光箱和条形灯有真实的尺寸和亮度，在金属上映出的形状是矩形和长条；阴影柔和但有方向；物体与地面接触处有深色的接触阴影。
- 地面：深灰色的环氧地坪，有极细的划痕和少量灰尘，能映出战斗机模糊的倒影。
- 镜头质感：像真实的电影摄影机拍摄：画面边缘有极轻微的暗角，高光处没有不自然的光晕，可以加很轻的胶片颗粒。
- 重量感：大件下落和装入时有真实的重量感；大件装好时，整架飞机随冲击轻微下沉一点，起落架的减震支柱略微压缩。
- 场景：深灰色的超大型无缝影棚，地面和背景板以弧面相连，看不到分界线；地面是哑光的深灰色，能映出战斗机模糊的倒影。
- 灯光：经典的影棚三点布光，主光是左前上方一块大面积柔光，辅光是右前方较弱的柔光，后方两盏轮廓光把深灰色机身和深灰色背景清楚地分开；战斗机上方和两侧挂着几条长条形的柔光灯，在机身曲面、座舱盖和金属件上形成连续的长条高光，零件下落和翻转时，高光沿着表面流动；金属件能映出影棚的条形灯和环境。
- 曝光与清晰度：高光不过曝成一片白色，暗部仍能看清零件结构；画面清晰锐利，螺栓、减重孔、加工纹和风扇叶片都能看清，没有因降噪过度、贴图精度低或采样不足造成的发糊、涂抹或噪点。
- 空气与辉光：画面中没有雾，不加大片的辉光；只有航行灯亮起后带一点柔和的光晕。
- 镜头成像：0–7 秒靠近时有轻微的景深，正在装入的零件清晰，远处的部件略虚；7 秒以后整架战斗机都清晰；运动模糊相当于 180° 快门，下落的零件带自然的拖影。

不可改变的内容：全片是一个连续镜头，中间没有剪辑或转场；组装按“起落架与骨架 → 动力 → 航电与座舱 → 蒙皮与翼面 → 收尾”的顺序进行，所有内部零件都在蒙皮盖上之前装好；所有零件都从画面上缘外、战斗机上方入画，接近竖直地落下；瀑布式下落贯穿整个组装过程，空中始终至少有 3 件零件在下落，不出现空档；每件零件都要经历可见的下落、减速摆正和装入，装好时有轻微回弹；零件之间、零件与已装部件之间不得相交；正在装入的零件始终在画面中；7 秒以后整架战斗机始终完整地位于画面中；画面在座舱盖合上、防撞灯闪烁、镜头仍在缓慢环绕时结束。

可调整范围：剧本中的尺寸、角度、数量、速度和时间都是参考值，可在保持比例和观感的前提下调整；各阶段时间点可以微调，相邻阶段可以略有交叠，但阶段顺序不变。同一阶段内零件的先后可以微调；隔框、翼肋、检修口盖、调节片等零件的数量可以随结构设计增减，但剧本列出的每一类零件都要出现。战斗机的具体外形、迷彩的图案、零件的具体结构、条形灯的数量和位置、镜头的具体路线，都可以自行设计。

可选增强：大件装好时，已装好的部件随冲击轻微震动一下；发动机落定后，风扇叶片因惯性缓慢转动一下再停住。

禁止：剪辑、转场或跳帧；零件在画面内凭空出现或消失，或不经下落直接滑到位置；多件零件同时瞬间到位，或组装中途瀑布停顿；零件穿模，或装好后悬空、错位、在机身表面滑动；零件是没有内部结构和连接细节的光滑外壳，或像薄片一样没有厚度；外形偏离歼-20，如缺少鸭翼、加上水平尾翼、进气道没有 DSI 鼓包，或混入其他机型的外形；出现国籍标志、编号、文字或真实品牌的标志；挂载导弹、炸弹或任何武器；出现人物；零件崭新得像塑料，没有任何加工痕迹和细微瑕疵；画面有卡通、手办或游戏模型的感觉；外形像玩具或模型，所有材质看起来一样，或金属没有金属反射；出现雾或大片的辉光；整体过曝或暗到看不清零件结构；镜头突然加速、急停或抖动；用停帧或重复片段凑时长；画面闪烁（设计的防撞灯闪烁除外）、破面或非设计性的卡顿。

输出规格：16:9，1280×720，30 帧/秒，无声音。最终输出一条完整的动画视频。
```

## 三、类目与标签

**主类目**：载具动画/航空航天/固定翼飞机

**归类理由**：
- 主要表现对象是一架战斗机，属于固定翼飞机；分类表规定交通工具一律归「载具动画」。
- 片中以产品广告的方式展示组装过程，展示方式由动画行为标签表达，不改变主类目。
- 歼-20 是真实的战斗机，不是虚构飞行器，所以不归「幻想载具」；主体是整架飞机而不是单个零部件，所以不归「产品动画/工业设备/零部件」。

| 标签组 | 选定标签 | 必要说明 |
|---|---|---|
| 视觉造型 | 写实 | 照片级写实 |
| 材质质感 | 金属（主材质）、玻璃透明、自发光 | 机身、骨架、发动机、起落架为金属；座舱盖和平视显示器为玻璃；航行灯和防撞灯为自发光。橡胶轮胎和座椅受数量上限所限不单独列出 |
| 渲染风格 | 真实渲染 |  |
| 动态节奏 | 自然流畅 | 零件带重力加速下落，接近落点减速，装入时轻微回弹 |
| 动画行为 | 主行为：结构与装配/拆解组装/拼接归位 | 约 80 件零件逐件落到安装位置并装入 |
| 动画行为 | 辅助行为：物理与特效/刚体运动/掉落 | 零件从画面上方像瀑布一样连续落下 |
| 动画行为 | 辅助行为：结构与装配/开合联动/打开翻盖 | 座舱盖最后合上 |
| 动画行为 | 辅助行为：显隐与外观变化/材质变化/发光亮灭 | 航行灯亮起，防撞灯闪烁 |
| 灯光氛围 | 棚拍三点光 | 主光、辅光、轮廓光齐全；条形柔光用来塑造曲面高光，不改变棚拍三点光的整体氛围 |
| 背景环境 | 无缝影棚 | 深灰色弧面影棚，地面和背景板无缝相连 |
| 色彩基调 | 不填 | 以灰色为主，没有明确的色彩基调 |
| 时序结构 | 多段序列 | 五个组装阶段和最后的亮灯、合盖依次衔接 |
| 复杂度等级 | 物理模拟 | 约 80 件零件，隔框、翼肋、口盖和调节片成串落下，属于“≥10 对象群组”。剧本不要求真实的物理模拟 |
| 应用场景 | 不填 | 没有明确用途依据 |
