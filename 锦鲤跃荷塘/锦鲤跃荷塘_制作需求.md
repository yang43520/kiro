## 一、制作 Prompt

```text
使用 Blender 5.0.0 制作一条约 12 秒（允许 11–13 秒，不得少于 8 秒）的锦鲤跃出荷塘动画，照片级写实渲染，一镜到底。画面内容、动作和镜头以《锦鲤跃荷塘剧本》为准。

核心效果：夏日午后，江南园林的荷塘里，二三十片荷叶高低错落，几朵荷花开着，水面漂着浮萍，对岸是白墙黛瓦的院墙、曲廊和垂柳。一条约 60 厘米长的红白锦鲤从池底加速游上来，冲破水面，带起一道弧形的水幕；水幕被拉薄后撕开，碎成水丝和水珠。锦鲤在空中弯成 S 形扭身，尾鳍延迟跟随、用力一甩，甩出一串闪亮的水珠，随后头朝下扎回水里。入水溅起的水花砸在旁边一片大荷叶上，荷叶向下一沉，又弹回来上下晃动；叶面上的水缩成滚圆的水珠，滚向叶心汇成一颗大水珠，从叶边滑落进水里。涟漪一圈圈推开浮萍，其他锦鲤受惊后先后掉头四散。播放速度从正常平滑地放慢到约八分之一，锦鲤入水后再平滑地恢复正常。镜头贴近水面，跟着锦鲤的弧线缓慢向右平移并略微升高。

质感要求：
- 整体：画面像用高速摄影机在一座真实的江南园林荷塘边实拍，任意暂停一帧都应该像一张实拍照片；所有物体按真实尺寸和真实材质制作。
- 播放速度：任何时刻，画面里所有的运动都按同一个速度播放，不能有的快、有的慢；变速是平滑的，没有突然的跳变。
- 锦鲤外形：白色的身体上有几块形状不规则的朱红色斑纹，头顶有一块红斑；嘴边有两对短须。
- 鳞片：排列整齐，每片鳞的边缘颜色稍深，形成一张细密的网纹；鳞片在阳光下有一层珍珠般的光泽。
- 鱼皮与鱼鳍：鱼皮湿润光滑，出水时裹着一层水膜，水膜在鱼身上流动、滑落；胸鳍、腹鳍和尾鳍是半透明的，能看到一根根鳍条，边缘最薄、透光。
- 鱼的运动：鱼身是柔软的，游动和跃起时整条鱼弯成 S 形，头部始终朝着前进的方向；尾鳍和胸鳍随身体的摆动延迟跟随、来回甩动。
- 水：完全透明的清水，表面光滑，由表面张力拉成平滑的水幕和水丝，不是一团团的块状或颗粒；飞溅的水珠是透明的小球，逆光时闪亮；入水处卷入一团细小的气泡。
- 荷叶：叶面有细密的绒毛，不沾水，水落在上面会缩成一颗颗滚圆的水珠，滚动时不留水痕；叶面有从中心向外放射的叶脉，边缘起伏、有的微微卷起；荷梗上有细小的刺；阳光透过薄的叶缘时透出黄绿色。
- 荷叶的弹性：荷叶被水砸中时向下一沉、荷梗弯折，随后弹回、越过原来的高度，再上下晃动几次，幅度越来越小。
- 荷花：花瓣从花尖的粉色渐变到花底的白色，有细细的纵向纹路；中间是嫩黄的莲蓬和一圈花蕊。
- 浮萍与涟漪：浮萍是一片片绿色的小圆叶，随水波起伏和漂移；涟漪经过时，浮萍被推开，荷叶随之上下起伏。
- 鱼群：其他锦鲤被惊动后，按离入水点的远近先后掉头，向不同方向游散。
- 园林：白墙有雨水留下的灰色竖向水痕和墙根的青苔；瓦缝里有青苔和小草；太湖石有孔洞和褶皱；石拱桥的石缝里长着小草。
- 光影：夏日午后的阳光从画面右后方照来，太阳高度约 45°，阳光明亮，略带暖色；天空的淡蓝色光作为补光，让荷叶下方和水面的阴影里仍能看清细节。
- 逆光与倒影：逆光下，飞溅的水珠和鱼身上的水膜闪闪发亮，荷叶和荷花的边缘透光；水面清楚地倒映着荷叶、荷花、院墙和天空，倒影被打碎后又慢慢恢复。
- 池底光纹：池底有阳光透过水面形成的晃动光纹，水面被扰动时光纹也跟着变化。
- 色彩：以荷叶的翠绿、池水的碧绿为主，锦鲤的朱红和白色、荷花的粉白作为点缀，背景是白墙黛瓦的黑白灰。
- 曝光与清晰度：受光的白墙、水珠高光和白色鱼身不过曝成一片纯白，阴影里仍能看清细节；画面清晰锐利，鱼鳞、鳍条、荷叶的叶脉和水珠的细节都能看清，没有因降噪过度、贴图精度低或采样不足造成的发糊、涂抹或噪点。
- 空气与辉光：空气通透，不加雾，也不加大片的辉光。
- 镜头成像：轻微的景深，焦点始终在锦鲤或入水点上；慢动作阶段相当于高速摄影的短快门，水珠清晰锐利，没有拖影；正常速度阶段运动模糊相当于 180° 快门。

不可改变的内容：全片是一个连续镜头，中间没有剪辑或转场；按“静塘 → 破水 → 腾跃 → 入水 → 余波”的顺序进行；锦鲤破水时带起的水幕被拉薄后撕开成水丝和水珠；锦鲤在空中弯成 S 形扭身，尾鳍甩出一串水珠；入水溅起的水花砸在旁边的荷叶上，荷叶下沉后回弹晃动；叶面上的水缩成水珠，汇成大水珠后从叶边滑落；其他锦鲤受惊后先后四散；锦鲤跃起的整个弧线和溅起的水花都在画面中；画面在涟漪仍在扩散、荷叶仍在轻轻晃动时结束。

可调整范围：剧本中的尺寸、距离、角度、数量、速度和时间都是参考值，可在保持比例和观感的前提下调整；各段时间点可以微调，但段落的顺序不变。锦鲤的具体花纹、荷叶和荷花的数量与位置、园林建筑的样式、镜头的具体路线，都可以自行设计。

可选增强：一只蜻蜓原本停在荷花苞上，被水花惊起飞走；锦鲤跃出的一瞬间，水面倒影里也映出它的身影。

禁止：剪辑、转场或跳帧；照搬任何现有园林的具体布局；出现人物，或出现可读文字、匾额文字或楹联文字；卡通、三渲二、水墨等风格化效果；锦鲤像一块僵硬的模型平移，身体不弯曲，或尾鳍不跟随；水是块状、颗粒状或融球拼出来的样子，或不透明、起白色泡沫；水珠凭空出现或消失，而不是从水幕和水丝断开；荷叶被水打湿、水在叶面摊开成一片；荷叶被砸中后不动，或回弹没有余振；同一时刻画面里的运动快慢不一致，或变速突然跳变；鱼、荷叶、荷梗和水之间互相穿插；锦鲤的弧线或水花被画面边缘裁掉；肉眼可辨的重复贴图，或重复复制的荷叶和锦鲤；出现雾或大片的辉光；镜头突然加速、急停或抖动；用停帧或重复片段凑时长；画面闪烁、破面或非设计性的卡顿。

输出规格：16:9，1280×720，30 帧/秒，无声音。最终输出一条完整的动画视频。
```

## 三、类目与标签

**主类目**：现象动画/液体流动/飞溅

**归类理由**：
- 本片的视觉重点是锦鲤跃出和入水时的水幕、水花、水珠和涟漪，「飞溅」的示例“液体冠状飞溅、水滴落下溅起”与本片一致；锦鲤是引起飞溅的主体。
- 分类表规定写实的、依赖复杂骨骼绑定的生物不纳入「角色动画/幻想生物」，锦鲤也不是以表演为目的的角色，所以不归「角色动画」。
- 荷塘园林是飞溅发生的环境，片中没有季节或环境本身的变化，所以不归「场景动画」；鱼群四散只是余波的一部分，所以不归「现象动画/粒子群集/生物群集」。

| 标签组 | 选定标签 | 必要说明 |
|---|---|---|
| 视觉造型 | 写实 | 照片级写实 |
| 材质质感 | 液体冰晶（主材质）、木石天然 | 池水、水幕、水珠为液体；背景的白墙、青瓦、太湖石和石桥为木石天然。锦鲤和荷叶没有对应的材质标签 |
| 渲染风格 | 真实渲染 |  |
| 动态节奏 | 自然流畅 | 锦鲤加速、腾跃、入水都符合重力和惯性；播放速度平滑地变慢再恢复 |
| 动画行为 | 主行为：物理与特效/流体粒子/液体 | 破水的水幕、入水的水冠和水花、涟漪 |
| 动画行为 | 辅助行为：物理与特效/流体粒子/粒子 | 水幕撕开的水珠、尾鳍甩出的水珠、水下的气泡 |
| 动画行为 | 辅助行为：物理与特效/柔性运动/软体 | 锦鲤柔软的身体弯曲、鱼鳍跟随，荷叶被砸后下沉回弹 |
| 动画行为 | 辅助行为：位移与运动/群体运动/群集 | 其他锦鲤受惊后先后四散 |
| 灯光氛围 | 自然日光 | 夏日午后的太阳光加天空光 |
| 背景环境 | 完整场景 | 荷塘、荷叶、院墙、曲廊、太湖石和石拱桥构成完整搭建的环境 |
| 色彩基调 | 不填 | 绿色为主，加上朱红、粉白和黑白灰，不完全符合任何一项 |
| 时序结构 | 多段序列 | 静塘、破水、腾跃、入水、余波按顺序衔接 |
| 复杂度等级 | 物理模拟 | 水幕、飞溅和涟漪需要液体模拟，荷叶回弹需要软体或弹性模拟；荷叶和锦鲤群属于“≥10 对象群组” |
| 应用场景 | 不填 | 没有明确用途依据 |

锦鲤跃起的弧线对应“位移与运动/路径运动/沿线移动”，受动画行为最多 4 个的上限所限，不单独列出。
