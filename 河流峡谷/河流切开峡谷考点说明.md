# 河流切开峡谷考点说明

> 内部校验用，不交给制作方，不属于制作输入。

**主类目**：科教演示/地理地貌/地层剖面

**题目档位**：上限档（配方：单个 L4，附带 2 个 L1）

**档位来源**：默认

**耦合链**：同一块台地上，雨水汇成的河流沿河道一层层刻深地层，刻出的形状持续保留并按岩性形成台阶状谷壁；深切曲流的颈部被切穿后河流改道，留下古河道和孤立山丘；时间加速下的云影和植被变化伴随整个过程；镜头始终同时框住剖面和顶面。

| 编号 | 考点 | 分级 | 作用对象与时段 | 在片中的体现 |
|---|---|---|---|---|
| 15 | 接触留痕与表面动态反馈 | L4 | 河道与地层，2–12 秒 | 河流经过的地方被持续刻深，剖面上 V 形缺口从砂岩一路切到花岗岩顶面；软岩成缓坡、硬岩成陡崖；裁弯后旧河道干涸但形状保留 |
| 16 | 光影流转与材质外观演变 | L1 | 云影、植被，1.5–12 秒 | 云影随时间加速越掠越快再减速；高原植被疏密和颜色缓慢变化 |
| 17 | 单镜头运镜构图 | L1 | 镜头，0–12 秒 | 从左前上方绕到右前上方，正面剖面和台地顶面始终同时在画面里，结尾地块约占画面宽度七成，无剪辑 |

**最高分级**：L4

## 类目与标签

**归类理由**：用一块剖切的地块演示河流下切穿过岩层、形成峡谷的过程，核心观察对象是剖面上的地层，属于地理地貌里的地层剖面。

| 标签组 | 选定标签 | 必要说明 |
|---|---|---|
| 视觉造型 | 写实 | 地形和岩石按真实尺度和质感 |
| 材质质感 | 木石天然、液体冰晶 | 主材质是砂岩、页岩、石灰岩和花岗岩；其次是河水 |
| 渲染风格 | 真实渲染 | 常规物理渲染 |
| 动态节奏 | 自然流畅 | 延时变化平滑加速、减速 |
| 动画行为 | 主行为：形变与生长/形态变化/形状转换 | 台地被河流刻成峡谷，地形形状持续改变 |
| 动画行为 | 辅助行为：物理与特效/流体粒子/液体 | 河水流动 |
| 动画行为 | 辅助行为：物理与特效/流体粒子/粒子 | 雨和泥沙沉积 |
| 动画行为 | 辅助行为：显隐与外观变化/材质变化/颜色渐变 | 植被疏密和颜色变化 |
| 灯光氛围 | 自然日光 | 斜射的阳光加天光 |
| 背景环境 | 无缝影棚 | 地块放在深色石板台面上，背后是深灰色无缝背景 |
| 色彩基调 | 不填 | 岩层颜色各不相同，没有单一的色彩基调 |
| 时序结构 | 多段序列 | 降雨成河 → 切过砂岩 → 深切曲流 → 裁弯取直 → 峡谷成形 |
| 复杂度等级 | 物理模拟 | 含液体和刚体模拟 |
| 应用场景 | 教学讲解 | 地理课的地貌成因讲解 |
