## 一、制作 Prompt

```text
使用 Blender 5.0.0 制作一条约 12 秒（允许 11–13 秒，不得少于 8 秒）的赛博朋克雨夜城市动画，写实渲染风格，一镜到底。画面内容、动作和镜头以《赛博朋克雨夜俯冲剧本》为准。

核心效果：一座原创的高密度未来城市，雨夜，霓虹遍布。镜头从一栋高楼的楼顶上空出发，沿两排高楼之间的峡谷一路下降，依次经过楼顶、三层悬浮车道、横跨峡谷的磁浮列车和巨型全息广告，最后降到贴近积水的街面，在一块竖向霓虹招牌逐段亮起后结束。全片城市本身持续运动：雨不停落下，三层车道的飞行车流持续穿梭，磁浮列车驶过，全息广告切换画面，霓虹闪烁，蒸汽飘散。

质感要求：
- 造型：近处的楼体细节完整，有空调外机、管线、阳台、窗户和架空电缆，不能是简单的方块楼；远处的楼体可以简化，但轮廓要高低错落。
- 材质：所有表面都被雨淋湿，混凝土有水渍和污痕，金属和玻璃有反射；飞行车和列车的漆面带雨滴并映出周围的霓虹。
- 光影：光源全部来自城市本身；霓虹灯管带柔和辉光，并把颜色投到附近墙面和积水上；雨雾越远越浓，车灯和霓虹在雾中形成光晕和光柱；主色是品红和青色，夹着少量琥珀色和暖白色窗光。
- 渲染：开启运动模糊；雨丝在前景清楚可见；积水倒影清晰。

不可改变的内容：全片是一个连续镜头，中间没有剪辑或转场；镜头路线按“楼顶 → 峡谷与车道 → 全息广告 → 街面”的顺序下降；镜头速度平滑渐变，3–6 秒最快，之后逐渐减速，最后约 1 秒几乎停住；镜头始终不穿过楼体、车辆、轨道、招牌或任何模型；雨和车流从第一帧持续到最后一帧；同一层车道的车辆同向行驶，相邻两层方向相反；全息广告切换画面时，原图形碎成光点再重组成新图形；收尾的竖向霓虹招牌从下往上逐段亮起；画面在雨和车流仍在运动时结束。

可调整范围：剧本中的高度、尺寸、速度和时间都是参考值，可在保持比例和观感的前提下调整；各段时间点可以微调，但段落顺序不变。楼体样式、招牌的形状和颜色搭配、飞行车和列车的外形、全息广告的图形内容、车流密度，都可以自行设计。

可选增强：远处超高层顶部的航空警示灯缓慢闪烁；更远处还能看到其他街区的车流光带。

禁止：剪辑、转场或跳帧；镜头穿模，或车辆、列车穿过楼体或彼此穿过；镜头突然加速、急停或抖动；车流或雨中途停止，或用停帧、重复片段凑时长；出现人物；出现真实品牌的标志、文字或外观，或招牌上出现可读文字；楼体像没有细节的方块；所有表面都是干的、没有反射；霓虹和全息广告大片过曝，或暗部黑到看不清楼体结构；画面闪烁（设计的霓虹闪烁除外）、破面或非设计性的卡顿。

输出规格：16:9，1920×1080，30 帧/秒，无声音。最终输出一条完整的动画视频。
```

## 三、类目与标签

**主类目**：场景动画/城市街景/夜景霓虹

**归类理由**：
- 主要表现对象是一片城市街区，表达目的是呈现雨夜霓虹的城市氛围，属于「城市街景」，纳入范围明确包含“夜景霓虹”。
- 「夜景霓虹」的示例是“霓虹招牌依次点亮、雨滴落下、积水泛起涟漪”，与本片的收尾招牌、雨和积水对应。
- 片中没有单独作为主体的车辆，飞行车和磁浮列车都是街景的一部分，因此不适用“以单辆车为主体→载具动画/陆地载具”。
- 「光效能量」的归属边界写明“霓虹招牌作为街景一部分→场景动画/城市街景”。全息广告只是街景中的一个元素，不改归「现象动画/光效能量/全息投影」。
- 雨属于氛围点缀，按「粒子群集」的边界“粒子仅作点缀→按主体归类 + 流体粒子”处理，用动画行为标签表达，不改归「现象动画/粒子群集/雨雪」。
- 镜头从高空降到街面，但主要篇幅在峡谷和街道之间，不以鸟瞰为主，所以不选「城市鸟瞰」；车流是重要的运动元素，但片子的重点是霓虹夜景，而不是道路系统，所以不选「交通路网」。

| 标签组 | 选定标签 | 必要说明 |
|---|---|---|
| 视觉造型 | 写实 | |
| 材质质感 | 自发光（主材质）、木石天然、金属 | 霓虹、全息广告、车灯和窗光决定了画面风格，也是场景的全部光源；楼体以湿混凝土为主（木石天然）；外挂板、飞行车、列车和轨道为金属。玻璃幕墙和积水面积较小，受数量上限所限不单独列出 |
| 渲染风格 | 真实渲染 | 全息广告只是画面中的一个元素，整体不是全息透视风格 |
| 动态节奏 | 自然流畅 | 镜头速度平滑渐变，车流连续行驶，没有停顿 |
| 动画行为 | 主行为：位移与运动/路径运动/沿线移动 | 飞行车沿三层车道行驶，磁浮列车沿轨道驶过 |
| 动画行为 | 辅助行为：物理与特效/流体粒子/粒子 | 雨丝持续落下，积水起涟漪。排气口的蒸汽属于“烟火”，受 4 个行为的上限所限不单独列出 |
| 动画行为 | 辅助行为：位移与运动/群体运动/聚散 | 全息广告的图形碎成光点散开，再重组成新图形 |
| 动画行为 | 辅助行为：显隐与外观变化/材质变化/发光亮灭 | 霓虹招牌闪烁或循环点亮，收尾的竖向招牌逐段亮起 |
| 灯光氛围 | 霓虹赛博 | 光源全部是高饱和霓虹色光，湿表面形成强反射。雨雾中的光晕和光柱属于体积光效果，但灯光氛围只能单选 |
| 背景环境 | 完整场景 | 主体本身就是完整搭建的城市环境 |
| 色彩基调 | 不填 | 品红加青色，夹琥珀色和暖白色窗光。品红和琥珀色不属于“冷色科技”的蓝、青、紫；画面整体偏暗，也不是“高饱和明快”。依据不充分 |
| 时序结构 | 并行多事件 | 雨、车流、列车、全息广告、霓虹和蒸汽各自运动，同时发生。“一镜到底”是镜头方式，时序结构组没有对应选项；四个段落是镜头经过的路线，不是主体动作的先后衔接，所以不选“多段序列” |
| 复杂度等级 | 物理模拟 | 三层车道同时可见 18–36 辆飞行车，属于“≥10 对象群组”；雨也需要粒子系统。剧本不要求真实的物理模拟 |
| 应用场景 | 不填 | 没有明确用途依据 |
