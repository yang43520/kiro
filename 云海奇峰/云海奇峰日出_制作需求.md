## 一、制作 Prompt

```text
使用 Blender 5.0.0 制作一条约 12 秒（允许 11–13 秒，不得少于 8 秒）的云海奇峰日出动画，照片级写实渲染，一镜到底。画面内容、动作和镜头以《云海奇峰日出剧本》为准。

核心效果：一片带有黄山式特征的原创花岗岩奇峰从云海中拔起，主峰顶上的崖边立着一座六角小亭，镜头前方左侧的崖边长着一棵古松。黎明前，深蓝的天光下，云海在群峰之间缓慢流动；太阳从远处的云海边缘升起，第一缕阳光点亮主峰的峰尖，接着一座座峰尖被染成粉金色；暖金色的阳光扫过云海表面，云从主峰左侧的鞍部漫过山脊，像瀑布一样倾泻而下；最后阳光变成暖白，主峰右侧的云海散开一道缺口，露出下方的山脊和深谷，一小群飞鸟掠过云海。镜头像航拍一样缓慢地向前推进、升高，崖边的古松逐渐移出画面。全片按延时摄影的方式加速，约 12 秒走完从黎明前到日出后约 10 分钟的过程；松枝的摇晃和飞鸟的飞行保持自然的速度。

质感要求：
- 整体：画面像用电影摄影机在真实的高山之巅拍摄的日出延时，任意暂停一帧都应该像一张风光摄影作品；所有物体按真实尺寸和真实材质制作。
- 尺寸：主峰露出云海约 250 米，近处的几座山峰露出云海 100–200 米；主峰周围有十几座高矮不一的山峰，远处的群峰越来越小、越来越淡。
- 花岗岩：灰白色到浅褐色，有竖向的节理裂隙，把峰体切成一根根石柱和石块；岩面风化成圆润的块状，表面有细小的颗粒、黑色的水渍条纹和灰绿色的地衣斑块；裂缝里长着小灌木和草。
- 松树：古松从岩缝中长出，树干虬曲，树皮是龟甲状开裂的深褐色鳞片；树冠是一层层平展的针叶簇，像伸出的手掌；针叶是深绿色，一根根针叶在近处清晰可辨；群峰的岩缝和峰顶上也零星长着松树。
- 小亭：六角攒尖顶的石木小亭，青灰色的瓦顶，瓦缝里有青苔；木柱是褪色的暗红色，漆面龟裂；亭边的石栏杆有风化的边角。
- 云的体积：云是有体积的，表面是一团团隆起的云堆，云堆之间有凹陷，不是一张平面贴图，也不是均匀的白雾。
- 云的形态：云的边缘有细碎的卷须，靠近山峰的地方被山体挡住、绕流，沿峰脚翻卷；云海从左向右缓慢漂移，表面不断隆起、翻卷、消散又重新形成。
- 云的光影：逆光时云的边缘透出亮边，云的内部有光线散射形成的明暗层次；山峰在云面上投下影子，影子随太阳升高而移动、变短。
- 远景：远处的群峰因为大气透视而变淡、偏蓝，地平线附近的云海和天空融成一片。
- 光照变化：黎明前只有天光，天空从地平线的橙红渐变到上方的深蓝，山峰是深色的剪影；日出时最先照亮最高的峰尖；随后暖金色的阳光扫过云海和群峰；最后阳光变成暖白色，云海变成明亮的白色。
- 光照过渡：太阳的高度、颜色和天空的颜色都是逐渐变化的，不突然跳变，也不出现明暗闪烁。
- 冷暖对比：受光的岩面和云面是暖色，阴影是冷蓝色；阴影里靠天光仍能看清岩石的纹理。
- 反射光：被阳光照亮的云海把柔和的暖光反射到山峰的下部和崖壁的背光面。
- 轮廓光：太阳出来后，崖边的古松和小亭的轮廓被阳光勾出一圈金色的亮边。
- 曝光与清晰度：太阳本身可以过曝，但它周围的天空有层次；阳光照亮的云面不过曝成一片纯白，能看清云堆的起伏；画面清晰锐利，岩石的节理、松针和瓦片的细节都能看清，没有因降噪过度、贴图精度低或采样不足造成的发糊、涂抹或噪点。
- 空气：云海以上的空气是通透的，不加雾，也不加大片的辉光或光束；只有太阳周围有自然的光晕。
- 镜头成像：远近都清晰，不做浅景深；运动模糊相当于 180° 快门，飞鸟带自然的拖影。

不可改变的内容：全片是一个连续镜头，中间没有剪辑或转场；按“黎明前 → 日出 → 金光 → 云开”的顺序进行；云海从第一帧到最后一帧一直在流动；太阳从远处的云海边缘升起，峰尖按高低依次被点亮；鞍部的云像瀑布一样倾泻而下；光照平滑变化，没有跳变或闪烁；画面在云海仍在流动、飞鸟仍在飞行时结束。

可调整范围：剧本中的尺寸、距离、角度、数量、速度和时间都是参考值，可在保持比例和观感的前提下调整；各段时间点可以微调，但段落的顺序不变。山峰的具体形状、群峰的数量和位置、小亭的样式、飞鸟的数量和路线、镜头的具体路线，都可以自行设计。

可选增强：日出时天顶附近残留一弯淡淡的月牙；云瀑落下的地方，云被风吹起一缕缕细丝。

禁止：剪辑、转场或跳帧；照搬黄山或其他真实山峰、名松、景点的具体造型；出现人物或任何文字；水墨、卡通等风格化效果；云是平面贴图、均匀的白雾或一块块棉花球，没有体积和形态变化；云海静止不动，或流动时突然跳变；光照突然跳变或明暗闪烁；岩石光滑、颜色均匀，像塑料或泥巴；肉眼可辨的重复贴图或重复复制的山峰和松树；整个画面蒙着一层雾而发灰，或出现大片的辉光、光束；松树或飞鸟的运动抖动、不自然；镜头突然加速、急停或抖动；用停帧或重复片段凑时长；画面闪烁、破面或非设计性的卡顿。

输出规格：16:9，1280×720，30 帧/秒，无声音。最终输出一条完整的动画视频。
```

## 三、类目与标签

**主类目**：场景动画/自然环境/地形山地

**归类理由**：
- 本片的主体是从云海中拔起的花岗岩群峰，表达目的是呈现山岳风光，属于「自然环境」，「地形山地」的示例“雪山日照推移”与本片“日出光线在群峰上推移”一致。
- 云海和日出是重要的动态，「天空气象」的示例包括“云层流动、日出日落”，但片中云海始终依附于群峰，画面的视觉中心是主峰、小亭和古松，所以选「地形山地」，不选「天空气象」。
- 小亭只是山顶的点缀，不是建筑展示，所以不归「建筑空间」。

| 标签组 | 选定标签 | 必要说明 |
|---|---|---|
| 视觉造型 | 写实 | 照片级写实 |
| 材质质感 | 木石天然 | 花岗岩、古松和石木小亭；云海没有对应的材质标签 |
| 渲染风格 | 真实渲染 |  |
| 动态节奏 | 自然流畅 | 云海流动、光线推移和镜头推进都是平滑连续的 |
| 动画行为 | 主行为：物理与特效/流体粒子/烟火 | 云海是体积气体的流动，包括绕流、翻卷和云瀑；分类表中“烟火”涵盖气体模拟，是最接近的标签 |
| 动画行为 | 辅助行为：位移与运动/规律运动/摆动 | 古松的枝叶随风摇晃 |
| 动画行为 | 辅助行为：位移与运动/群体运动/群集 | 一小群飞鸟掠过云海 |
| 灯光氛围 | 灯光动画 | 光照从黎明前的蓝调天光、日出的粉金色平滑过渡到暖白的阳光，符合“光照本身随时间平滑变化”的定义 |
| 背景环境 | 完整场景 | 群峰、云海和天空构成完整搭建的环境 |
| 色彩基调 | 不填 | 色彩从深蓝过渡到金色再到白色，没有单一的色彩基调 |
| 时序结构 | 多段序列 | 黎明前、日出、金光、云开按顺序衔接 |
| 复杂度等级 | 物理模拟 | 云海需要体积和流体模拟；十几座山峰和飞鸟群属于“≥10 对象群组”。剧本不要求真实的物理模拟 |
| 应用场景 | 不填 | 没有明确用途依据 |

峰尖被阳光依次点亮属于光照变化，已由灯光氛围“灯光动画”表达；镜头的推进属于镜头运动，不计入动画行为。
