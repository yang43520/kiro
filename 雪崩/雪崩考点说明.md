# 雪崩考点说明

> 内部校验用，不交给制作方，不属于制作输入。

**主类目**：场景动画/自然环境/地形山地

**题目档位**：上限档（配方：单个 L4，附带 1 个 L2 和 1 个 L1）

**档位来源**：默认

**规范版本**：进阶版 1.1

**视觉基调**：自然纪录

**耦合链**：同一次雪崩里，冰檐断下来砸在雪坡上，雪面上一道裂缝横着拉开，整片雪板断开、裂成一块块往下滑；滑落的雪块越快扬起的粉雪越多，长成粉雪云；粉雪云推到哪里，哪里的冷杉就一排接一排被压弯、撞倒；雪雾扑到谷底挡住太阳，落下以后阳光重新照亮滑痕。

| 编号 | 考点 | 分级 | 作用对象与时段 | 在片中的体现 |
|---|---|---|---|---|
| 13 | 破碎崩解与离散粒子 | L4 | 冰檐、雪板和雪块，1–10 秒 | 冰檐断下来砸在坡上；裂缝横着拉开，一米多厚的雪板先整块下沉、再裂成几百块，翻滚撞碎、越滑越快，扬起粉雪 |
| 14 | 集群协同与波浪相位差 | L2 | 山腰几百棵冷杉，7.5–10 秒 | 粉雪云推到哪里，哪里的冷杉先被压弯、再被撞倒，一排接一排往下倒，像一道往山下推的浪 |
| 16 | 光影流转与材质外观演变 | L1 | 整座山的光和雪，8.5–12 秒 | 雪雾挡住太阳时画面变暗发蓝，落下以后阳光重新照亮；雪崩走过的地方雪变灰，留下一道滑痕 |

**最高分级**：L4

## 制作底线清单

**二级类目**：自然环境

**技术模块**：T1、T2、T3、T4

**本片要用的专业术语**：高度图地形、侵蚀模拟、置换修改器、多重分辨率细分、岩石节理、坡度遮罩、三平面投影贴图、几何节点散布、实例化、随机旋转与缩放、叶片次表面散射、二级摆动、风力场、体积散射、多重散射、VDB 体积、空气透视、物理天空

**推荐插件**：Infinigen（开源）、A.N.T. Landscape（内置）、几何节点散布（内置）

**通用底线**：PBR 贴图或程序化纹理（近景 4K）、倒角、接触阴影、AgX 色彩管理（Base Contrast）、足够采样、100% 查看细节、尺度参照（二十来米高的冷杉）、防重复

**重模拟**：刚体模拟（只用在雪板和雪块上）、烟雾模拟（只用在粉雪云和雪雾上）

## 类目与标签

**归类理由**：主体是一座雪山的雪坡在一次板状雪崩里断开、滑落、卷起粉雪云的过程，属于自然环境里的地形山地。

| 标签组 | 选定标签 | 必要说明 |
|---|---|---|
| 视觉造型 | 写实 | 照片级写实的高山纪录 |
| 材质质感 | 液体冰晶、木石天然 | 主材质是雪、冰檐和雪块；其次是冷杉和岩石 |
| 渲染风格 | 真实渲染 | 常规物理渲染 |
| 动态节奏 | 自然流畅 | 雪崩越滑越快，雪雾慢慢落下 |
| 动画行为 | 主行为：物理与特效/破碎解体/坍塌 | 雪板断开、裂成块往下滑 |
| 动画行为 | 辅助行为：物理与特效/流体粒子/烟火 | 粉雪云和雪雾 |
| 动画行为 | 辅助行为：位移与运动/群体运动/群集 | 冷杉一排排倒下 |
| 动画行为 | 辅助行为：显隐与外观变化/材质变化/颜色渐变 | 滑痕上的雪变灰 |
| 灯光氛围 | 自然日光 | 晴天上午的阳光和蓝天 |
| 背景环境 | 完整场景 | 雪山、松林、山谷和远处雪峰完整搭建 |
| 色彩基调 | 不填 | 白、蓝为主，没有单一的色彩基调 |
| 时序结构 | 多段序列 | 冰檐断裂 → 雪板断开 → 粉雪云 → 吞没松林 → 尘埃落定 |
| 复杂度等级 | 物理模拟 | 含刚体模拟和烟雾模拟 |
| 应用场景 | 不填 | 没有明确的用途依据 |
