# 舰队跃迁抵达考点说明

> 内部校验用，不交给制作方，不属于制作输入。

**主类目**：场景动画/幻想世界/科幻空间

**题目档位**：上限档（配方：单个 L4，附带 1 个 L2 和 1 个 L1）

**档位来源**：默认

**耦合链**：同一支舰队按编队顺序依次跃迁抵达，每艘抵达时推出的冲击波依次扫到行星环，把冰块推开、撞碎、飞散；旗舰最后抵达，推出最大的冲击波扫过镜头附近的环带；镜头从环带里升起、后退，始终框住抵达的舰船和被推开的冰环。

| 编号 | 考点 | 分级 | 作用对象与时段 | 在片中的体现 |
|---|---|---|---|---|
| 13 | 破碎崩解与离散粒子 | L4 | 行星环的冰块和碎石，3.5–12 秒 | 冲击波经过时冰块和碎石被向外推开形成波纹，互相碰撞后大冰块崩下碎片、小冰块碎成冰晶，碎片翻滚减速、继续漂散，环带留下扩散的缺口 |
| 14 | 集群协同与波浪相位差 | L2 | 40 艘舰船，1.2–10 秒 | 按弧线上离第一艘的距离依次跃迁，相邻约 0.1 秒，护卫舰在前排、巡洋舰在后排；冲击波光环一圈套一圈扩开；最后排成整齐的弧形阵列 |
| 17 | 单镜头运镜构图 | L1 | 镜头，0–12 秒 | 从环带冰块之间往前飘、升高到中心面上方约 400 米并后退，旗舰掠过时不被冰块遮挡，结尾旗舰约占画面宽度三成，无剪辑 |

**最高分级**：L4

## 类目与标签

**归类理由**：主体是行星环旁的太空场景和在其中发生的舰队抵达事件，属于幻想世界里的科幻空间。

| 标签组 | 选定标签 | 必要说明 |
|---|---|---|
| 视觉造型 | 写实 | 照片级写实，舰船按真实硬表面结构 |
| 材质质感 | 金属、液体冰晶、自发光 | 主材质是舰船装甲；其次是环带冰块，以及光痕和推进器的自发光 |
| 渲染风格 | 真实渲染 | 常规物理渲染 |
| 动态节奏 | 自然流畅 | 舰船冲出后平稳减速，冰块翻滚减速 |
| 动画行为 | 主行为：位移与运动/群体运动/编队 | 40 艘舰船按编队顺序抵达并列阵 |
| 动画行为 | 辅助行为：物理与特效/破碎解体/碎裂 | 冰块被冲击波推开后撞碎 |
| 动画行为 | 辅助行为：结构与装配/开合联动/折叠展开 | 旗舰的跃迁翼分三段折叠收起 |
| 动画行为 | 辅助行为：显隐与外观变化/材质变化/发光亮灭 | 推进器和航行灯依次亮起 |
| 灯光氛围 | 低调暗黑 | 漆黑太空中一道强恒星光，阴影很硬 |
| 背景环境 | 完整场景 | 行星环、巨行星、卫星和星云完整搭建 |
| 色彩基调 | 冷色科技 | 深灰、冷蓝为主 |
| 时序结构 | 多段序列 | 裂隙 → 编队抵达 → 旗舰降临 → 收翼列阵 → 舰队就位 |
| 复杂度等级 | 物理模拟 | 含刚体碎裂和大量粒子，40 艘舰船 |
| 应用场景 | 不填 | 没有明确的用途依据 |
