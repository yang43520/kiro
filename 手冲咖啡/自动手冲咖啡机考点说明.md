# 自动手冲咖啡机考点说明

> 内部校验用，不交给制作方，不属于制作输入。

**主类目**：产品动画/家居日用/小家电

**题目档位**：上限档（配方：L3 + L2，附带 1 个 L1）

**档位来源**：默认

**规范版本**：进阶版 1.3

**视觉基调**：微距美食

**耦合链**：同一台咖啡机里，刀盘的转速决定豆子往下滚和粉落下的快慢，粉在滤纸里堆起来；注水臂沿一圈圈的轨迹浇水，水打到哪里粉就湿到哪里，整个粉层随之鼓成圆顶、冒泡、开裂再塌回；第二次注水后咖啡从滤杯底滴进分享壶，侧逆光让咖啡液变成琥珀色。

| 编号 | 考点 | 分级 | 作用对象与时段 | 在片中的体现 |
|---|---|---|---|---|
| 8 | 柔性形变与形态演变 | L3 | 滤杯里的粉层，4.5–10 秒 | 粉被打湿后颜色变深，慢慢鼓成一个约 1 厘米高的圆顶，冒泡、边缘开裂，再慢慢塌回去 |
| 4 | 部件联动与运动匹配｜防打滑 | L2 | 刀盘、豆子和落粉，注水臂和水柱，0–10 秒 | 刀盘的转速和豆子下滚、落粉的快慢对得上；注水臂绕圈的轨迹和水落下的位置对得上 |
| 16 | 光影流转与材质外观演变 | L1 | 咖啡粉和咖啡液，4.5–12 秒 | 粉从浅棕被打湿成深棕；咖啡液在侧逆光里亮成琥珀色，木底座上出现一片晃动的琥珀色光 |

**最高分级**：L3

## 制作底线清单

**二级类目**：家居日用

**技术模块**：T5、T8

**本片要用的专业术语**：模块化建模、斜切倒角、阵列修改器、铰链约束、曲线挤出、实体化修改器、几何节点实例化、程序化木纹、织物绒面、柔体模拟

**推荐插件**：Archimesh（内置扩展）、柔体模拟（内置）、MACHIN3tools（开源）、Mantaflow 液体（内置）

**通用底线**：PBR 贴图或程序化纹理（近景 4K）、倒角、接触阴影、AgX 色彩管理（Punchy）、足够采样、100% 查看细节、尺度参照（咖啡豆）、防重复

**重模拟**：液体模拟（只包住滤杯和分享壶）

## 类目与标签

**归类理由**：主体是一台原创的桌面自动手冲咖啡机，展示的是它磨豆、注水、闷蒸和滴滤的过程，属于家居日用里的小家电。

| 标签组 | 选定标签 | 必要说明 |
|---|---|---|
| 视觉造型 | 写实 | 照片级写实的产品广告 |
| 材质质感 | 液体冰晶、玻璃透明、金属 | 主材质是咖啡液和水；其次是玻璃豆仓和分享壶，以及不锈钢注水臂和黑铝机身 |
| 渲染风格 | 真实渲染 | 常规物理渲染 |
| 动态节奏 | 自然流畅 | 落粉、注水、鼓起和滴落都缓慢平滑 |
| 动画行为 | 主行为：形变与生长/形态变化/挤压拉伸 | 粉层闷蒸时鼓起、开裂、塌回 |
| 动画行为 | 辅助行为：结构与装配/开合联动/机械传动 | 刀盘转动带动落豆落粉 |
| 动画行为 | 辅助行为：物理与特效/流体粒子/液体 | 注水、漩涡和落滴 |
| 动画行为 | 辅助行为：位移与运动/路径运动/沿线移动 | 注水臂一圈圈绕着浇水 |
| 灯光氛围 | 自然日光 | 清晨从窗户斜照进来的阳光 |
| 背景环境 | 完整场景 | 窗边的木桌、托盘和窗户完整搭建 |
| 色彩基调 | 暖色温馨 | 深棕、米白和琥珀色 |
| 时序结构 | 多段序列 | 磨豆 → 落粉 → 闷蒸 → 二次注水 → 落滴 |
| 复杂度等级 | 物理模拟 | 含液体模拟 |
| 应用场景 | 不填 | 没有明确的用途依据 |
