# 梯田放水考点说明

> 内部校验用，不交给制作方，不属于制作输入。

**主类目**：场景动画/自然环境/地形山地

**题目档位**：上限档（配方：单个 L4，附带 1 个 L2 和 1 个 L1）

**档位来源**：默认

**耦合链**：同一片梯田水系上，竹筒装满后杠杆拉开木闸，水流进最上一层，漫过的田面由干泥变成湿泥再变成水镜并保持；漫满后从缺口溢进下一层，一层层往下推；日出的金光随延时升起，被水镜映出。

| 编号 | 考点 | 分级 | 作用对象与时段 | 在片中的体现 |
|---|---|---|---|---|
| 15 | 接触留痕与表面动态反馈 | L4 | 各层田面，2–12 秒 | 水的前沿漫过的地方，龟裂干泥先被浸湿变深、裂缝灌满，再被约 10 厘米深的水盖住成为水镜，漫过的地方一直保持湿的状态 |
| 14 | 集群协同与波浪相位差 | L2 | 约 20 层梯田，2–11 秒 | 每层在上一层漫满溢出后才开始进水，水镜亮带从山顶沿山坡一层层往下延伸 |
| 16 | 光影流转与材质外观演变 | L1 | 天空、田埂、水镜，0–12 秒 | 天色由日出前的橙粉变成金色，第 7.5 秒太阳升起照亮田埂，已注满的水镜映出金色的太阳和朝霞 |

**最高分级**：L4

## 类目与标签

**归类理由**：主体是一面山坡上的梯田和它被逐层注水的过程，属于自然环境里的地形山地。

| 标签组 | 选定标签 | 必要说明 |
|---|---|---|
| 视觉造型 | 写实 | 照片级写实 |
| 材质质感 | 木石天然、液体冰晶 | 主材质是泥地、田埂和石砌水渠；其次是水面 |
| 渲染风格 | 真实渲染 | 常规物理渲染 |
| 动态节奏 | 自然流畅 | 延时下水的推进和光的变化平滑 |
| 动画行为 | 主行为：物理与特效/流体粒子/液体 | 水流漫灌梯田 |
| 动画行为 | 辅助行为：显隐与外观变化/材质变化/颜色渐变 | 田面由干变湿变成水镜 |
| 动画行为 | 辅助行为：结构与装配/开合联动/机械传动 | 竹杠杆拉开木闸 |
| 灯光氛围 | 灯光动画 | 日出前到日出后光照随时间变化 |
| 背景环境 | 完整场景 | 梯田、云海、远山和村寨完整搭建 |
| 色彩基调 | 不填 | 朝霞的橙粉、金色和田埂的绿混合 |
| 时序结构 | 多段序列 | 竹筒开闸 → 首层注满 → 层层下灌 → 日出 → 满山水镜 |
| 复杂度等级 | 物理模拟 | 含液体模拟 |
| 应用场景 | 不填 | 没有明确的用途依据 |
