## 一、制作 Prompt

```text
使用 Blender 5.0.0 制作一条约 12 秒（允许 11–13 秒，不得少于 8 秒）的直升机“瀑布式组装”起飞动画，照片级写实渲染，一镜到底。画面内容、动作和镜头以《直升机瀑布式组装起飞剧本》为准。

核心效果：深灰色的超大型无缝影棚中央有一个圆形起降平台。约 60 件零件从画面上方像瀑布一样连续倾泻而下：大件如粗水柱般沉沉落下，螺栓和重复件像水珠一样成串落下，每件都在下落中缓慢翻转，接近安装位置时减速、摆正、装入，装好时轻微回弹。一架原创的轻型双发直升机按“骨架 → 动力 → 驾驶舱 → 蒙皮 → 旋翼”的顺序逐层成型：先是滑橇、底板、隔框和尾梁骨架，再是发动机、主减速器和传动轴，然后是仪表板和座椅，接着蒙皮、风挡、舱门和尾翼把机身包起来，最后装上主旋翼和尾桨，螺栓一边旋转一边拧紧。组装完成后航行灯亮起，旋翼起转到全速，平台上的细尘被下洗气流吹成一圈圈尘雾，直升机离地后平稳地垂直上升。镜头从左前方略微俯视开始，绕平台向右缓慢转动约 40° 并逐渐降低，起飞时略微上仰跟着直升机上升。

质感要求：
- 整体：画面达到高端航空产品广告的质感，所有零件按真实尺寸、真实结构和真实材质制作，任意暂停一帧都应该像一张影棚实拍的照片。
- 尺寸：机身长约 12 米（含尾梁），旋翼直径约 11 米，高约 3.6 米；四片桨叶的主旋翼，两片桨叶的尾桨，滑橇式起落架。
- 外形：机头圆润，前风挡是两块大面积的弧形玻璃；机舱两侧各有两扇带窗的舱门；尾梁细长，末端有垂直尾翼和两侧的水平安定面；不能是简单的方块或胶囊拼出的造型。
- 涂装：深海军蓝色为主色，机身两侧有一条白色的腰线，腰线上方有一条细细的橙色线；机身上没有任何文字、编号或标志。
- 机身蒙皮：涂装下是铝合金蒙皮，表面有清漆的光泽和极细的金属闪粉；蒙皮之间有均匀的板件缝隙，缝隙两侧有一排排细小的铆钉。
- 风挡和舱窗：透明玻璃带一点淡淡的茶色，边缘有黑色的密封胶条；玻璃上能映出影棚的条形灯；透过玻璃能看到驾驶舱里的仪表板和座椅。
- 主桨叶：碳纤维复合材料，表面是哑光深灰色；前缘包着一条发亮的金属防护条；桨尖略微后掠。
- 动力部件：涡轴发动机的外壳是钛合金和钢，排气口一圈有发动机受热留下的蓝紫色和金色的热变色；主减速器的铸铝外壳带细密的砂铸纹理，桨毂的金属件有机加工的同心圆纹。
- 驾驶舱：座椅是深灰色的皮革和织物，有自然的褶皱；仪表板上的屏幕是黑色的，不显示内容。
- 滑橇：喷涂的铝管，底部有磨损和划痕。
- 边缘：所有边缘都有真实的小倒角，能接到细细的高光。
- 材质区分：漆面、玻璃、碳纤维、钛合金、铸铝、皮革各有不同的光泽和纹理，不能看起来都是同一种材质。
- 灯光：经典的影棚三点布光，主光是左前上方一块大面积柔光，辅光是右前方较弱的柔光，后方两盏轮廓光把深色机身和深灰色背景清楚地分开；机身上方和两侧挂着几条长条形的柔光灯，在机身的曲面、风挡和桨叶上形成连续的长条高光，零件转动和下落时，高光沿着表面流动；金属件能映出影棚的条形灯和环境。
- 航行灯：左侧是红色航行灯，右侧是绿色航行灯，尾部是白色航行灯；机腹和尾梁上各有一盏红色的防撞灯；组装时所有灯都不亮。
- 下洗气流：起飞时平台上的细尘从平台中心向四周扩散成一圈圈尘雾，贴着地面向外推开。
- 曝光与清晰度：高光不过曝成一片白色，暗部仍能看清零件结构；画面清晰锐利，铆钉、板件缝隙和金属纹理都能看清，没有因降噪过度、贴图精度低或采样不足造成的发糊、涂抹或噪点。
- 空气与辉光：画面中没有雾，不加大片的辉光；只有航行灯亮起后带一点柔和的光晕。
- 镜头成像：直升机始终清晰，背景略虚；运动模糊相当于 180° 快门，下落的零件和旋转的旋翼带自然的拖影。

不可改变的内容：全片是一个连续镜头，中间没有剪辑或转场；组装按“骨架 → 动力 → 驾驶舱 → 蒙皮 → 旋翼”的顺序进行，所有内部零件都在蒙皮盖上之前装好；所有零件都从画面上缘外、直升机上方入画，接近竖直地落下；瀑布式下落贯穿整个组装过程，空中始终至少有 3 件零件在下落，不出现空档；每件零件都要经历可见的下落、减速摆正和装入，装好时有轻微回弹；螺栓要一边旋转一边拧入；零件之间、零件与已装部件之间不得相交；旋翼达到全速之后直升机才离地；整架直升机始终完整地位于画面中，包括旋翼的整个旋转范围；画面在直升机仍在上升、旋翼仍在高速旋转时结束。

可调整范围：剧本中的尺寸、角度、数量、速度和时间都是参考值，可在保持比例和观感的前提下调整；各阶段时间点可以微调，相邻阶段可以略有交叠，但阶段顺序不变，“组装完成 → 亮灯 → 旋翼起转 → 全速 → 离地上升”的先后关系也不变。同一阶段内零件的先后可以微调；隔框、侧板、螺栓等零件的数量可以随结构设计增减，但剧本列出的每一类零件都要出现。直升机的具体曲面、舱门和窗的形状、驾驶舱布局、条形灯的数量和位置，都可以自行设计。

可选增强：大件装好时，已装好的部件随冲击轻微震动一下；起飞时气流吹得影棚地面上的细尘向远处飘散。

禁止：剪辑、转场或跳帧；零件在画面内凭空出现或消失，或不经下落直接滑到位置；多件零件同时瞬间到位，或组装中途瀑布停顿；螺栓不经旋转直接嵌入；零件穿模，或装好后悬空、错位、在机身表面滑动；照搬任何真实机型的外形；出现人物，或出现真实品牌的标志、注册号或任何文字；外形像玩具或模型，所有材质看起来一样，或金属没有金属反射；旋翼在起转后停转、倒转，或出现桨叶静止、倒转的频闪错觉；旋翼达到全速之前直升机就离地；直升机离地后左右漂移或抖动；旋翼或尾梁被画面边缘裁掉；出现雾或大片的辉光；整体过曝或暗到看不清零件结构；镜头突然加速、急停或抖动；用停帧或重复片段凑时长；画面闪烁（设计的防撞灯闪烁除外）、破面或非设计性的卡顿。

输出规格：16:9，1280×720，30 帧/秒，无声音。最终输出一条完整的动画视频。
```

## 三、类目与标签

**主类目**：载具动画/航空航天/旋翼与无人机

**归类理由**：
- 主要表现对象是一架直升机，「旋翼与无人机」的示例包括“直升机旋翼转动”。
- 分类表规定交通工具一律归「载具动画」，片中以产品广告的方式展示组装和起飞，展示方式由动画行为标签表达，不改变主类目。
- 直升机是原创的真实类型飞机，不是虚构飞行器，所以不归「幻想载具」。

| 标签组 | 选定标签 | 必要说明 |
|---|---|---|
| 视觉造型 | 写实 | 照片级写实 |
| 材质质感 | 金属（主材质）、玻璃透明、织物皮革 | 漆面铝合金蒙皮、发动机、减速器、桨毂和滑橇为金属；风挡和舱窗为玻璃；座椅为皮革和织物。碳纤维桨叶没有对应的材质标签 |
| 渲染风格 | 真实渲染 |  |
| 动态节奏 | 自然流畅 | 零件带重力加速下落，接近落点减速，装入时轻微回弹，旋翼平滑加速 |
| 动画行为 | 主行为：结构与装配/拆解组装/拼接归位 | 约 60 件零件逐件落到安装位置并装入 |
| 动画行为 | 辅助行为：物理与特效/刚体运动/掉落 | 零件从画面上方像瀑布一样连续落下 |
| 动画行为 | 辅助行为：位移与运动/规律运动/旋转 | 螺栓旋转拧入，主旋翼和尾桨高速旋转 |
| 动画行为 | 辅助行为：物理与特效/流体粒子/粒子 | 起飞时平台上的细尘被下洗气流吹成尘雾 |
| 灯光氛围 | 棚拍三点光 | 主光、辅光、轮廓光齐全；条形柔光用来塑造曲面高光，不改变棚拍三点光的整体氛围 |
| 背景环境 | 无缝影棚 | 深灰色弧面影棚，地面和背景板无缝相连 |
| 色彩基调 | 不填 | 深海军蓝、白色和橙色点缀，加上影棚的深灰色，不完全符合任何一项 |
| 时序结构 | 多段序列 | 五个组装阶段、亮灯、旋翼起转、离地上升依次衔接 |
| 复杂度等级 | 物理模拟 | 8 颗螺栓成串落下，全片约 60 件零件，属于“≥10 对象群组”；尘雾适合用粒子实现。剧本不要求真实的物理模拟 |
| 应用场景 | 不填 | 没有明确用途依据 |

航行灯和防撞灯亮起对应“显隐与外观变化/材质变化/发光亮灭”，直升机离地上升对应“位移与运动/路径运动/沿线移动”。受动画行为最多 4 个的上限所限，这两项不单独列出。
