# 天空变成海考点说明

> 内部校验用，不交给制作方，不属于制作输入。

**主类目**：场景动画/幻想世界/魔法场景

**题目档位**：上限档（配方：L3 + L2，附带 1 个 L1）

**档位来源**：默认

**耦合链**：同一头鲸鱼的游动路线决定"海"从哪里、按什么顺序扩开和退去；边界按距离依次经过窗户，触发鱼群一扇扇出窗并跟着鲸鱼的尾流绕塔；鲸鱼转弯和加速时，胸鳍、尾鳍和海藻产生滞后、甩出和回荡；月光随"海"的范围变成焦散，气泡升过屋顶后变成星带。

| 编号 | 考点 | 分级 | 作用对象与时段 | 在片中的体现 |
|---|---|---|---|---|
| 6 | 次级跟随与惯性滞后 | L3 | 鲸鱼的胸鳍、尾鳍和三缕海藻，0–12 秒 | 摆尾从躯干传到尾鳍、越往后越慢半拍；绕塔急转时尾鳍甩向外侧，海藻先滞后、再甩出、最后荡回 |
| 14 | 集群协同与波浪相位差 | L2 | "海"的边界和约 800 条小鱼，2–12 秒 | 边界按到鲸鱼路线的距离依次扩开，边界先到的窗户先出鱼；鱼群保持间距绕塔，退去时按相反顺序回窗 |
| 16 | 光影流转与材质外观演变 | L1 | 屋顶月光、烟囱、气泡，2–12 秒 | 月光变成晃动的水下焦散再变回平静；烟变成气泡，气泡升过屋顶后变成稳定的星点连成星带 |

**最高分级**：L3

## 制作底线清单

**二级类目**：幻想世界

**技术模块**：T1、T4、T10（另用 T5 的建筑做法、T7 的生物做法）

**本片要用的专业术语**：模块化建模、阵列修改器、几何节点实例化、斜切倒角、雕刻、多重分辨率细分、三平面投影贴图、置换修改器、空气透视、局部体积雾、体积散射、体积光、自发光强度、粒子拖尾、IES 灯光、光度单位、辉光阈值、骨骼绑定、权重绘制、次表面散射、曲率遮罩、环境光遮蔽

**推荐插件**：几何节点（内置）、物理天空纹理（内置）、Bloom 辉光（内置）、Rigify（内置）、Wiggle 2（开源）、Building Tools（开源）

**通用底线**：PBR 贴图或程序化纹理（近景 4K）、倒角、接触阴影、AgX 色彩管理、足够采样、100% 查看细节、尺度参照（猫、窗户、路灯）、防重复

**重模拟**：无（海藻用柔体，鱼群和气泡用粒子）

## 类目与标签

**归类理由**：主体是整座老城和鲸鱼游过时在城里发生的超现实变化（天空像变成了海），属于幻想世界里的魔法场景。

| 标签组 | 选定标签 | 必要说明 |
|---|---|---|
| 视觉造型 | 写实 | 造型和材质都是真的，奇幻感来自光和动作 |
| 材质质感 | 木石天然、自发光、液体冰晶 | 主材质是石墙和石板瓦；其次是鲸鱼光斑和星点的自发光，以及透明的气泡 |
| 渲染风格 | 真实渲染 | 常规物理渲染 |
| 动态节奏 | 自然流畅 | 鲸鱼游动、鱼群和气泡都带缓入缓出 |
| 动画行为 | 主行为：位移与运动/路径运动/沿线移动 | 鲸鱼沿路线游进老城、绕塔、离开 |
| 动画行为 | 辅助行为：位移与运动/群体运动/群集 | 鱼群出窗、绕塔、回窗 |
| 动画行为 | 辅助行为：物理与特效/流体粒子/粒子 | 气泡上浮并变成星点 |
| 动画行为 | 辅助行为：物理与特效/柔性运动/毛发绳索 | 海藻的拖曳和甩动 |
| 灯光氛围 | 夜景月光 | 冷色月光主光加窗灯和路灯点光源 |
| 背景环境 | 完整场景 | 老城、运河、钟楼完整搭建 |
| 色彩基调 | 不填 | 冷蓝月光和暖黄窗灯对比，没有单一的色彩基调 |
| 时序结构 | 多段序列 | 鲸入城 → 化海 → 鱼群出窗 → 绕塔 → 海退成星 |
| 复杂度等级 | 物理模拟 | 含柔体模拟和约 800 个对象的群集 |
| 应用场景 | 不填 | 没有明确的用途依据 |
