# 雪花水晶球考点说明

> 内部校验用，不交给制作方，不属于制作输入。

**主类目**：场景动画/微缩模型/玩具城镇

**题目档位**：上限档（配方：单个 L4，附带 1 个 L2 和 1 个 L1）

**档位来源**：默认

**规范版本**：进阶版 1.2

**视觉基调**：温馨童话

**耦合链**：同一只八音盒水晶球里，发条松开带动齿轮、音筒和转盘，转盘带着水晶球和小镇一起转；球里的水跟不上，像一股水流扫过小镇，把屋顶和街上的雪卷起；转盘停下以后水还在转，雪花被带着打旋、慢慢落回屋顶和街道，落定以后小镇的窗户一扇扇亮起。

| 编号 | 考点 | 分级 | 作用对象与时段 | 在片中的体现 |
|---|---|---|---|---|
| 13 | 破碎崩解与离散粒子 | L4 | 球里的雪花，4.5–12 秒 | 屋顶边的雪先被掀起，接着街上和广场的雪被卷起，绕着小镇打转；停转后水还转约 3 秒，雪花一圈圈打着旋、一秒落 1 厘米左右，落回屋顶和街道停住 |
| 4 | 部件联动与运动匹配｜防打滑 | L2 | 发条钥匙、齿轮、音筒、钢片和转盘，2–10 秒 | 钥匙倒转、齿轮一个带一个按齿数转、音筒的小钉拨过钢片、转盘约 4 秒一圈，齿咬着转不打滑，最后慢慢停下 |
| 16 | 光影流转与材质外观演变 | L1 | 小镇的窗户和球里的光，10–12 秒 | 雪落定后窗户从广场往外一扇扇亮起暖黄，照亮窗下的雪 |

**最高分级**：L4

## 制作底线清单

**二级类目**：微缩模型

**技术模块**：T1、T2、T5

**本片要用的专业术语**：模块化建模、阵列修改器、木作与瓦作、斜切倒角、顶点颜色混合、贴花、几何节点散布、实例化、随机旋转与缩放、坡度遮罩、置换修改器、空气透视、几何节点实例化

**推荐插件**：Building Tools（开源）、几何节点（内置）、Archimesh（内置扩展）

**通用底线**：PBR 贴图或程序化纹理（近景 4K）、倒角、接触阴影、AgX 色彩管理（Punchy）、足够采样、100% 查看细节、尺度参照（松果）、防重复

**重模拟**：无（雪花用粒子系统加涡流力场和阻力，齿轮用驱动器）

## 类目与标签

**归类理由**：主体是装在水晶球里、有底座和边界的一座微缩雪镇，展示的是八音盒转动时球里下起暴风雪的过程，属于微缩模型里的玩具城镇。

| 标签组 | 选定标签 | 必要说明 |
|---|---|---|
| 视觉造型 | 写实 | 照片级写实的水晶球和微缩小镇 |
| 材质质感 | 玻璃透明、木石天然、金属 | 主材质是玻璃球和里面的水；其次是胡桃木底座和小镇的树脂房子，以及黄铜发条和齿轮 |
| 渲染风格 | 真实渲染 | 常规物理渲染 |
| 动态节奏 | 自然流畅 | 雪被卷起和落下都慢而平滑 |
| 动画行为 | 主行为：物理与特效/流体粒子/粒子 | 球里的雪花被卷起、打旋、落下 |
| 动画行为 | 辅助行为：结构与装配/开合联动/机械传动 | 发条、齿轮、音筒和转盘联动 |
| 动画行为 | 辅助行为：位移与运动/规律运动/旋转 | 水晶球和旋转木马跟着转盘转 |
| 动画行为 | 辅助行为：显隐与外观变化/材质变化/发光亮灭 | 小镇的窗户一扇扇亮起 |
| 灯光氛围 | 夜景月光 | 窗外冷蓝的雪夜加屋里暖色的台灯和蜡烛 |
| 背景环境 | 完整场景 | 窗台、窗户和水晶球完整搭建 |
| 色彩基调 | 暖色温馨 | 暖琥珀为主，配窗外的蓝 |
| 时序结构 | 多段序列 | 冬夜窗台 → 发条松开 → 暴风雪 → 停转 → 雪落灯亮 |
| 复杂度等级 | 多元编排 | 粒子、力场、驱动器和自发光编排 |
| 应用场景 | 不填 | 没有明确的用途依据 |
