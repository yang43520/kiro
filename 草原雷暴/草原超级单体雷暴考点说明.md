# 草原超级单体雷暴考点说明

> 内部校验用，不交给制作方，不属于制作输入。

**主类目**：场景动画/自然环境/天空气象

**题目档位**：上限档（配方：单个 L4，附带 1 个 L2 和 2 个 L1）

**档位来源**：默认

**规范版本**：进阶版 1.1

**视觉基调**：自然纪录

**耦合链**：同一场雷暴里，阵风锋先到，同一股风把麦田压出一道道往镜头推的麦浪、把麦秆和尘土卷起来；紧跟着的冰雹和雨丝在风里斜着落下，在柱顶、铁丝和麦穗上弹跳、积起来；雨幕推进把麦田打湿，被夕阳照着的雨幕前浮现彩虹。

| 编号 | 考点 | 分级 | 作用对象与时段 | 在片中的体现 |
|---|---|---|---|---|
| 13 | 破碎崩解与离散粒子 | L4 | 冰雹、雨丝、麦秆和尘土，2.5–12 秒 | 冰雹带风向斜着落下，在柱顶上弹起二三十厘米、滚进裂缝、越积越多；麦秆和尘土被阵风卷起打旋；雨丝随雨幕推进 |
| 14 | 集群协同与波浪相位差 | L2 | 麦田和椋鸟群，2–12 秒 | 麦浪约每秒 15 米朝镜头推进，相邻麦株按距离错开；椋鸟群惊起后拧成一股飞走、彼此不重叠 |
| 16 | 光影流转与材质外观演变 | L1 | 麦田、云底和彩虹，7.5–12 秒 | 闪电照亮云底，雨把麦田一片片打湿变深，雨幕前浮现彩虹 |
| 17 | 单镜头运镜构图 | L1 | 镜头，全片 | 一镜到底：三分法 → 引导线 → 对角线特写 → 剪影 → 层次纵深 |

**最高分级**：L4

## 制作底线清单

**二级类目**：自然环境

**技术模块**：T1、T2、T3、T4

**本片要用的专业术语**：高度图地形、置换修改器、几何节点散布、坡度遮罩、实例化、随机旋转与缩放、叶片次表面散射、半透明背光、风力场、二级摆动、颜色渐变、体积云、VDB 体积、体积散射、多重散射、银边、局部体积雾、空气透视、物理天空、折射率

**推荐插件**：Infinigen（开源）、A.N.T. Landscape（内置）、几何节点散布（内置）、物理天空纹理（内置）

**通用底线**：PBR 贴图或程序化纹理（近景 4K）、倒角、接触阴影、AgX 色彩管理（Medium High Contrast）、足够采样、100% 查看细节、尺度参照（风车、围栏柱子）、防重复

**重模拟**：无（麦浪用几何节点和骨骼，冰雹和雨用粒子系统，云用几何节点生成的体积）

## 类目与标签

**归类理由**：主体是一场压过麦田的超级单体雷暴和它带来的阵风、冰雹、雨幕和彩虹，属于自然环境里的天空气象。

| 标签组 | 选定标签 | 必要说明 |
|---|---|---|
| 视觉造型 | 写实 | 照片级写实，像自然纪录片 |
| 材质质感 | 木石天然、液体冰晶 | 主材质是麦田、木围栏和风化的木头；其次是冰雹和雨 |
| 渲染风格 | 真实渲染 | 常规物理渲染 |
| 动态节奏 | 自然流畅 | 麦浪、云墙和雨幕的推进都平滑 |
| 动画行为 | 主行为：位移与运动/群体运动/群集 | 麦浪一道道推进，椋鸟群惊飞 |
| 动画行为 | 辅助行为：物理与特效/流体粒子/粒子 | 冰雹、雨丝、麦秆和尘土 |
| 动画行为 | 辅助行为：位移与运动/规律运动/旋转 | 风车叶轮越转越快 |
| 动画行为 | 辅助行为：显隐与外观变化/材质变化/颜色渐变 | 麦田被雨打湿变深，彩虹浮现 |
| 灯光氛围 | 黄昏金色时刻 | 低角度的暖色夕阳 |
| 背景环境 | 完整场景 | 麦田、风车、谷仓和雷暴云完整搭建 |
| 色彩基调 | 不填 | 冷暖对比，没有单一的色彩基调 |
| 时序结构 | 多段序列 | 云墙压境 → 阵风锋 → 冰雹 → 闪电与雨幕 → 彩虹 |
| 复杂度等级 | 多元编排 | 几何节点、粒子、体积和骨骼编排 |
| 应用场景 | 不填 | 没有明确的用途依据 |
