# 雨夜隧道楔形超跑追逐考点说明

> 内部校验用，不交给制作方，不属于制作输入。

**主类目**：载具动画/陆地载具/乘用车

**题目档位**：上限档（配方：单个 L4，附带 1 个 L2 和 2 个 L1）

**档位来源**：默认

**规范版本**：进阶版 1.9

**视觉基调**：夜景都市

**耦合链**：同一条隧道：超跑撞进伸缩缝漏下的水帘，水被斜着的前挡铲起、贴着车顶往后甩、到车尾翻成水幕再碎成水珠，轿跑紧跟着撞穿；两车并排抢道；警示灯转起来后闸门匀速落下，轿跑按刹车距离提前刹车，超跑撞穿第二道水帘、在闸门下沿离地约 1.4 米时钻出去；钠灯在珠光漆上一道道滑过，镜头一镜到底跟完全程。

| 编号 | 考点 | 分级 | 作用对象与时段 | 在片中的体现 |
|---|---|---|---|---|
| 13 | 破碎崩解与离散粒子 | L4 | 两道水帘和两辆车，3–4 秒、9.5–10.5 秒 | 每秒约 9 米落下的水帘被每秒 25 米的车撞穿，水被铲起、贴车面往后甩，到车尾翻成水幕再碎成 1–5 毫米的水珠；车头更竖的轿跑把水拍得更高 |
| 19 | 多事件时序协同与无缝循环 | L2 | 闸门、超跑和轿跑，7.5–12 秒 | 闸门每秒约落 0.5 米，第 10.5 秒下沿约 1.4 米，车高约 1.07 米的超跑刚好钻过；车高约 1.4 米的轿跑第 8.5 秒就按约 45 米的刹车距离开始刹，停在闸门前约 3 米 |
| 16 | 光影流转与材质外观演变 | L1 | 钠灯、警示灯和珠光漆，0–12 秒 | 钠灯一盏盏在特征线上拉出橙色亮线；珠光漆转到斜面泛金；警示灯的琥珀光扫起来 |
| 17 | 单镜头运镜构图 | L1 | 镜头，全片 | 一镜到底：引导线特写 → 对角线 → 对称 → 层次纵深 → 中心构图 |

**最高分级**：L4

## 制作底线清单

**二级类目**：陆地载具

**技术模块**：T4、T6、T7（另用 T9 的粒子做法）

**本片要用的专业术语**：细分曲面、支撑边、倒角修改器、加权法线、布尔运算、硬表面建模、FLIP 液体、模拟域、流入、障碍物、表面张力、体素、二次粒子、关键帧、限制位置约束、路径跟随、驱动器、骨骼、阻尼、涂层、高度遮罩、粒子系统、运动模糊、自发光、空气透视

**推荐插件**：Rigacar（开源）、MACHIN3tools（开源）、Bool Tool（内置扩展）

**通用底线**：PBR 贴图或程序化纹理（近景 4K）、倒角、接触阴影、AgX 色彩管理（Base Contrast）、足够采样、100% 查看细节、尺度参照（车道线、约 8 米的灯盒间距、闸门）、防重复

**重模拟**：FLIP 液体（只包住两道水帘前后约 6 米）

## 类目与标签

**归类理由**：主体是两辆原创跑车在雨夜隧道里的追逐，展示车身造型、车轮和车身姿态以及车冲破水帘，按规则交通工具归载具，属于陆地载具里的乘用车。

| 标签组 | 选定标签 | 必要说明 |
|---|---|---|
| 视觉造型 | 写实 | 按写实电影质感做的车和隧道 |
| 材质质感 | 金属、液体冰晶、玻璃透明 | 主材质是珠光漆和金属漆车身；其次是水帘；车窗和灯罩 |
| 渲染风格 | 真实渲染 | 常规物理渲染 |
| 动态节奏 | 自然流畅 | 追逐、撞水帘、刹车都有缓入缓出 |
| 动画行为 | 主行为：位移与运动/路径运动/沿线移动 | 两车沿隧道追逐 |
| 动画行为 | 辅助行为：物理与特效/流体粒子/液体 | 车撞穿水帘 |
| 动画行为 | 辅助行为：位移与运动/规律运动/旋转 | 车轮转动、警示灯转动 |
| 动画行为 | 辅助行为：物理与特效/流体粒子/粒子 | 渗水、雨和水珠 |
| 灯光氛围 | 霓虹赛博 | 钠灯、警示灯、应急灯带和车灯 |
| 背景环境 | 完整场景 | 隧道、水帘和闸门完整搭建 |
| 色彩基调 | 不填 | 暖橙隧道和冷蓝出口，没有单一的色彩基调 |
| 时序结构 | 多段序列 | 进隧道 → 第一道水帘 → 抢道 → 闸门落下 → 钻出闸门 |
| 复杂度等级 | 物理模拟 | 含液体模拟 |
| 应用场景 | 不填 | 用于考察载具制作 |
