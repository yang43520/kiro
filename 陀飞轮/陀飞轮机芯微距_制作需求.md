## 一、制作 Prompt

```text
使用 Blender 5.0.0 制作一条约 10 秒（允许 8–12 秒，不得少于 8 秒）的陀飞轮机芯微距特写动画，真实渲染风格，营造精密严谨的高级制表工业美学氛围。画面内容、动作和镜头以《陀飞轮机芯微距剧本》为准。

核心效果：一枚镂空陀飞轮机芯在柔和的工作室侧光下运转。四个镜头沿动力传递的方向依次展示发条、齿轮组、陀飞轮框架和擒纵核心：发条缓缓释放动力，带动各组齿轮啮合旋转；陀飞轮框架平稳匀速自转；游丝随摆轮规律地收缩与舒张，擒纵轮一步一步精准跳动。抛光精钢、拉丝金属和黄铜的倒角边缘随运动闪出锐利细腻的高光。景深较浅，背景柔化，但每个镜头的主体部件完整清晰。

不可改变的内容：游丝、擒纵轮、发条和齿轮组都要结构独立、清晰可辨，每一个都在至少一个镜头中作为主体完整清晰地呈现；镜头顺序为发条 → 齿轮组 → 陀飞轮 → 擒纵核心，最后一个镜头锁定擒纵核心；啮合的齿轮齿与齿真实咬合，相邻齿轮转向相反、转速符合齿数比；擒纵轮是走一步停一下的步进，每一步都与擒纵叉换向同步；陀飞轮框架匀速自转；游丝的收缩舒张与摆轮摆动同步。镜头一和镜头二为加速表现，让慢速部件的转动看得见；镜头三和镜头四为真实速度。

可调整范围：剧本中的尺寸、角度、速度和时间都是参考值，可在保持比例和观感的前提下调整；各镜头时长可在总时长内微调，但镜头顺序不变。齿数、辐条数量和造型、夹板镂空形状可以自行设计。镜头一和镜头二的加速倍数可以调整，只要转动清楚可见且没有频闪错觉。摆轮频率可在每秒 2–3 次往复之间调整。

可选增强：夹板表面可以加日内瓦波纹装饰；螺丝可以做成蓝钢。

禁止：零件穿模；齿轮边缘融化、变形或齿形模糊；任何部件呈现塑料质感；镜头晃动；当前镜头的主体部件失焦；啮合齿轮转向或转速不符；齿轮、摆轮出现倒转或频闪错觉；擒纵轮连续平滑转动而不是步进；游丝的圈与圈相互粘连或穿插；画面闪烁、破面或非设计性的卡顿、抽搐；用停帧或重复动作凑时长；整体过曝或暗到看不清金属结构。机芯上不出现品牌标志或可读文字。

输出规格：16:9，1920×1080，30 帧/秒，无声音。最终输出一条完整的动画视频。
```

## 三、类目与标签

**主类目**：产品动画/美妆配饰/包袋眼镜腕表

**归类理由**：主要表现对象是机械腕表的机芯，表达目的是展示高级制表的工业美学。「产品动画/消费电子」的归属边界写明"机械腕表→产品动画/美妆配饰"，「美妆配饰」的纳入范围包括机械腕表，「包袋眼镜腕表」的示例中也有"机械表齿轮转动"。表中对机械腕表有明确归属，所以不归「产品动画/工业设备/机械传动」；这是具体的制表产品，不是抽象的原理讲解，所以不归「科教演示/物理原理」。

| 标签组 | 选定标签 | 必要说明 |
|---|---|---|
| 视觉造型 | 写实 | |
| 材质质感 | 金属（主材质）、玻璃透明 | 抛光精钢、拉丝夹板和黄铜都属于金属；红色宝石叉瓦和宝石轴承属于水晶类 |
| 渲染风格 | 真实渲染 | |
| 动态节奏 | 机械节奏 | 陀飞轮框架匀速转动，擒纵轮走一步停一下，停顿明确 |
| 动画行为 | 主行为：结构与装配/开合联动/机械传动 | 发条经齿轮组驱动陀飞轮和擒纵，整条传动链按齿数比联动 |
| 动画行为 | 辅助行为：位移与运动/规律运动/旋转 | 陀飞轮框架自转 |
| 动画行为 | 辅助行为：位移与运动/规律运动/摆动 | 摆轮往复摆动 |
| 动画行为 | 辅助行为：形变与生长/形态变化/弯曲扭转 | 游丝收缩和舒张，发条内圈松开 |
| 灯光氛围 | 低调暗黑 | 暗背景，左侧柔光加右后方轮廓光，没有辅光，不符合"棚拍三点光"的主光、辅光、轮廓光组合 |
| 背景环境 | 纯色渐变 | 暗灰到近黑的柔和渐变，没有地面 |
| 色彩基调 | 不填 | 银白、暖金加深灰，不完全符合任何一项 |
| 时序结构 | 并行多事件 | 各部件同时联动运转；四个镜头只是依次切换观看对象，动作本身不是先后衔接 |
| 复杂度等级 | 多元编排 | 多个对象、多种行为，靠齿速比联动；没有物理模拟 |
| 应用场景 | 不填 | 没有明确用途依据 |
