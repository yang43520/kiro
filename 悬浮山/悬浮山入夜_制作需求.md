## 一、制作 Prompt

```text
使用 Blender 5.0.0 制作一条约 12 秒（允许 11–13 秒，不得少于 8 秒）的外星悬浮山动画，写实渲染风格，一镜到底。画面内容、动作和镜头以《悬浮山入夜剧本》为准。

核心效果：一颗原创外星行星的高空中，一组长满巨型植被的悬浮山漂浮在云海之上，各自缓慢上下浮动。主山边缘有瀑布倾泻而下，在半空化成水雾；山体下方垂着长长的根须和藤蔓，随风轻摆。镜头绕主山飞行，画面从黄昏过渡到夜晚：太阳沉入云海后，山上的植被从底部的根须开始，一层层向上亮起青蓝色和紫色的生物荧光，直到山顶树冠全部亮起；发光孢子从植物间飘起，越来越多。画面在整组悬浮山于夜空中发光时结束。天色变化是加速的，瀑布、藤蔓和孢子的运动保持正常速度。

质感要求：
- 造型：山体是陡峭的层状岩石，有裂隙、悬垂的岩檐和水流冲刷的痕迹，底部向下收成不规则的尖锥，不能是光滑的圆锥或简单的倒置山形；植被分层，山顶是伞状树冠的巨树林，崖壁上是螺旋卷曲的巨型蕨类和管状花丛，岩面覆盖苔藓。
- 材质：岩石有湿润与干燥的区别，瀑布经过的崖壁颜色更深、带反光；叶片在黄昏逆光下有透光感；瀑布是半透明的水流，顶部有白色水花。
- 光影：黄昏时低角度的暖色阳光从侧后方照来，山体边缘和水雾被勾出金色轮廓；入夜后主要光源变成植物荧光，荧光照亮周围的岩石、水雾和孢子；空气中有薄雾，远处的悬浮山逐渐变淡。
- 渲染：荧光带柔和辉光，但亮部不糊成一片；入夜后能看到星空。

不可改变的内容：全片是一个连续镜头，中间没有剪辑或转场；画面按“黄昏 → 日落 → 荧光逐层亮起 → 夜晚”的顺序变化；荧光按“根须与藤蔓 → 崖壁植物 → 山顶树冠”的顺序自下而上亮起，亮起的前沿清楚可见；最暗的时刻也能看清山体轮廓；每座悬浮山都在缓慢上下浮动，较小的悬浮山浮动幅度更大，肉眼可见；瀑布和藤蔓全程保持运动；画面中只有植物、瀑布和孢子表现生命感；画面在整组悬浮山于夜空中发光时结束。

可调整范围：剧本中的尺寸、距离、速度和时间都是参考值，可在保持比例和观感的前提下调整；各段时间点可以微调，但段落顺序和荧光亮起的顺序不变。悬浮山的具体形态、植物的具体造型、荧光的具体色彩搭配（以青蓝和紫色为主）、远处悬浮山的数量、气态行星的外观，都可以自行设计。

可选增强：瀑布散成的水雾被荧光照成一团青蓝色的光雾；远处两座悬浮山之间有长藤相连。

禁止：剪辑、转场或跳帧；出现动物、人物或任何生物；出现建筑、飞行器等人造物，或任何文字和标志；照搬现有电影中的外星生物、植物或山体造型；悬浮山穿模或彼此碰撞；荧光整体同时亮起，而不是逐层亮起；荧光亮起后整体熄灭；日落后画面黑到看不清山体；瀑布或藤蔓突然停住；镜头突然加速、急停或抖动；用停帧或重复片段凑时长；画面闪烁、破面或非设计性的卡顿。

输出规格：16:9，1920×1080，30 帧/秒，无声音。最终输出一条完整的动画视频。
```

## 三、类目与标签

**主类目**：场景动画/幻想世界/浮空岛屿

**归类理由**：
- 主要表现对象是一组虚构的悬浮山，属于「幻想世界」，纳入范围明确包含“浮空岛屿”；该三级类目的示例“浮岛缓慢上下漂浮、瀑布从岛边倾泻”与本片的悬浮和瀑布直接对应。
- 片中没有生物，不涉及「角色动画/幻想生物」；也没有飞船等载具，不涉及「载具动画/幻想载具」。
- 「异星地表」表现的是外星的地面景观，本片的主体是悬浮在空中的山体，不以地表为主，所以不选。
- 场景是虚构的外星世界，不属于「自然环境」。

| 标签组 | 选定标签 | 必要说明 |
|---|---|---|
| 视觉造型 | 写实 | |
| 材质质感 | 木石天然（主材质）、自发光、液体冰晶 | 山体岩石面积最大，黄昏段也以岩石和植被为主；植物荧光是入夜后的主要光源；瀑布和水雾为液体。植被没有对应的标签，按画面中最接近的材质归入岩石与荧光两项 |

| 动画行为 | 辅助行为：物理与特效/流体粒子/粒子 | 发光孢子从植物间飘起 |

| 色彩基调 | 不填 | 前半段是暖金色，后半段是青蓝紫色，全片没有单一的色彩基调 |

| 复杂度等级 | 物理模拟 | 瀑布需要液体或粒子效果，孢子是“≥10 对象群组”。剧本不要求真实的物理模拟 |
| 应用场景 | 不填 | 没有明确用途依据 |

藤蔓与根须的摆动对应“位移与运动/规律运动/摆动”，受动画行为最多 4 个的上限所限，不单独列出。
