# 金属球阵列拼出浪花考点说明

> 内部校验用，不交给制作方，不属于制作输入。

**主类目**：图形动画/几何图形/阵列矩阵

**题目档位**：进阶档（配方：L2 + L2，附带 2 个 L1）

**档位来源**：默认

**规范版本**：进阶版 1.5

**视觉基调**：产品广告

**耦合链**：同一块 64×64 钢球阵列上，落珠砸进中心四颗球之间，托窝下凹的那一帧触发涟漪，涟漪按到落点的距离逐颗延迟往外传；随后浪从左边缘推起、边走边长高，定格后各球按到冠圈的远近错时聚拢成水冠，中心球柱升起把落珠托到半空，再托着它落回窝里、荡出最后一圈涟漪；落珠全程架在四颗托球上，托球的相位决定落珠的高度，落珠的触球时刻又决定涟漪的起点，相位差和接触互相制约；顶灯倒影、扫光亮带和球面映出的颜色随球高变化，镜头一镜到底跟完全程。

| 编号 | 考点 | 分级 | 作用对象与时段 | 在片中的体现 |
|---|---|---|---|---|
| 14 | 集群协同与波浪相位差 | L2 | 4,096 颗钢球和钢杆，1.5–12 秒 | 涟漪按到落点的距离每颗慢两三帧往外传、越外越矮；浪从左边缘一排接一排推起、边走边长高；水冠按到冠圈的远近错时聚拢；结尾小涟漪从窝边再次外传 |
| 10 | 体积碰撞与边界阻挡｜真实轮廓接触与防穿模 | L2 | 落珠与中心四颗托球、钢球与底板、钢杆与孔，1.5 秒、9–11 秒和全片 | 落珠落进四颗球之间，托窝下凹、落珠弹一次后坐稳，不陷不浮；球柱托着落珠升降，加速度小于重力、落珠不脱开；波谷里球底离底板至少 5 毫米，钢杆始终在孔里同轴 |
| 16 | 光影流转与材质外观演变 | L1 | 顶灯、扫光、球面倒影，0–12 秒 | 顶灯平移让 4,096 个小方块倒影一起挪；第 5 秒扫光亮带横扫阵列；升高的球映进更多背景板、颜色变深；第 7.5 秒主光亮半档 |
| 17 | 单镜头运镜构图 | L1 | 镜头，全片 | 一镜到底：中心构图特写 → 对称全景 → 对角线低位 → 负空间推近 → 三分法收尾 |

**最高分级**：L2

**第二个 L2 的取舍**：没有选 9「结构爆炸拆解与渐进式生长建造」，因为片中没有拆开再复位的结构，也没有从无到有的建造，球只是改变高度排法；选 10，是因为落珠由阵列托住、随相位升降，正是出题指南进阶档示例 2（方柱矩阵波浪顶起上方木块，发生体积碰撞）的同类结构，接触直接受波浪相位约束。

## 制作底线清单

**二级类目**：几何图形

**技术模块**：T9

**本片要用的专业术语**：阵列、几何节点、实例化、相位差、驱动器、约束、缓入缓出、运动曲线、硬表面建模、倒角修改器、加权法线、各向异性、环境光遮蔽、粒子系统、力场、生命周期

**推荐插件**：内置几何节点（内置）、AnimAide（开源）、Extra Mesh Objects（内置扩展）

**通用底线**：PBR 贴图或程序化纹理（近景 4K）、倒角、接触阴影、AgX 色彩管理（Medium High Contrast）、足够采样、100% 查看细节、尺度参照（胡桃木托盘和 2 厘米备用钢球）、防重复

**重模拟**：无（阵列高度用几何节点和驱动器，落珠用关键帧加约束，备用钢球用关键帧，浮尘用粒子系统）

## 类目与标签

**归类理由**：主体是 4,096 颗规整排列的钢球组成的阵列，靠相位差和错时编排拼出涟漪、浪头和水冠，属于几何图形里的阵列矩阵；本类允许直接用球和杆，但按写实产品广告的材质和光来做。

| 标签组 | 选定标签 | 必要说明 |
|---|---|---|
| 视觉造型 | 写实 | 照片级写实的镜面钢球和影棚 |
| 材质质感 | 金属、木石天然 | 主材质是抛光不锈钢球、拉丝钢杆和阳极氧化铝底板；其次是胡桃木托盘 |
| 渲染风格 | 真实渲染 | 常规物理渲染 |
| 动态节奏 | 自然流畅 | 涟漪、浪和水冠都带缓入缓出，落珠按重力下落 |
| 动画行为 | 主行为：位移与运动/群体运动/聚散 | 钢球聚拢成水冠再散回平面 |
| 动画行为 | 辅助行为：位移与运动/规律运动/往复 | 钢杆带着球在孔里上下伸缩 |
| 动画行为 | 辅助行为：形变与生长/形态变化/形状转换 | 球顶拼出的面从平面变成涟漪、浪头、水冠 |
| 动画行为 | 辅助行为：物理与特效/刚体运动/掉落 | 落珠落进阵列、弹一次后坐稳 |
| 灯光氛围 | 低调暗黑 | 深蓝暗棚，顶上大柔光加暖色轮廓光和扫光 |
| 背景环境 | 无缝影棚 | 深蓝渐变的弧形无缝背景板 |
| 色彩基调 | 冷色科技 | 深海军蓝加银白，只有一点暖金点缀 |
| 时序结构 | 多段序列 | 落珠 → 涟漪 → 浪头 → 水冠 → 回落余波 |
| 复杂度等级 | 多元编排 | 4,096 个实例、几何节点加驱动器的错时编排，不含模拟 |
| 应用场景 | 不填 | 没有明确的用途依据 |
