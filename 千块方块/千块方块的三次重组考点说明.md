# 千块方块的三次重组考点说明

> 内部校验用，不交给制作方，不属于制作输入。

**主类目**：图形动画/几何图形/堆叠翻滚

**题目档位**：上限档（配方：L3 + L2，附带 1 个 L1）

**档位来源**：默认

**耦合链**：同一批方块上，钢珠的撞击引发涟漪，方块按到撞击点的距离依次染色、排成色带，波浪按列延迟传过色带；波浪把末端方块推过重心，引发一块接一块的翻滚连锁，堆成拱桥；拱桥合拢时最后一列碰下钢珠，钢珠过桥压出一串下沉回弹。

| 编号 | 考点 | 分级 | 作用对象与时段 | 在片中的体现 |
|---|---|---|---|---|
| 11 | 刚体连锁反应 | L3 | 方块和钢珠，7–12 秒 | 末端方块越过重心翻倒，一块碰倒下一块地翻滚过去，被挡住后一层层叠成拱桥，拱心落下合拢；最后一列碰下钢珠，钢珠过桥落进小碗 |
| 14 | 集群协同与波浪相位差 | L2 | 约 1,000 块方块，2–7 秒 | 涟漪按到撞击点的距离依次触发染色和落位；色带波浪逐列延迟约 0.04 秒从砖红端传到雾蓝端 |
| 17 | 单镜头运镜构图 | L1 | 镜头，0–12 秒 | 从正前方平移，升高转到右前上方斜俯视，所有阶段和结尾的拱桥、钢珠、小碗都在画面里，无剪辑 |

**最高分级**：L3

## 类目与标签

**归类理由**：主体是一批几何方块，通过排序、波浪、翻滚堆叠完成三次组织变化，属于几何图形里的堆叠翻滚。

| 标签组 | 选定标签 | 必要说明 |
|---|---|---|
| 视觉造型 | 半写实 | 基础方块造型，材质和光影真实 |
| 材质质感 | 塑料橡胶、金属、木石天然 | 主材质是哑光塑料方块；其次是不锈钢钢珠和陶瓷小碗 |
| 渲染风格 | 真实渲染 | 常规物理渲染 |
| 动态节奏 | 自然流畅 | 涟漪、波浪和翻滚都带缓入缓出和真实的重量 |
| 动画行为 | 主行为：结构与装配/拆解组装/组合成形 | 方块翻滚堆叠成拱桥 |
| 动画行为 | 辅助行为：位移与运动/群体运动/聚散 | 散乱的方块被涟漪排成色带 |
| 动画行为 | 辅助行为：物理与特效/刚体运动/滚动 | 钢珠落下、弹开和过桥 |
| 动画行为 | 辅助行为：显隐与外观变化/材质变化/颜色渐变 | 方块由米白色染成渐变色 |
| 灯光氛围 | 棚拍三点光 | 主光、轮廓光和背景光 |
| 背景环境 | 无缝影棚 | 浅暖灰色弧面影棚 |
| 色彩基调 | 低饱和柔和 | 砖红到雾蓝的柔和渐变 |
| 时序结构 | 多段序列 | 落珠 → 涟漪排序 → 色带波浪 → 翻滚成桥 → 珠过拱桥 |
| 复杂度等级 | 物理模拟 | 含刚体模拟，约 1,000 个对象 |
| 应用场景 | 不填 | 没有明确的用途依据 |
