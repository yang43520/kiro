# 静止的雨与纸鹤考点说明

> 内部校验用，不交给制作方，不属于制作输入。

**主类目**：场景动画/幻想世界/魔法场景

**题目档位**：上限档（配方：单个 L4，附带 1 个 L2 和 1 个 L1）

**档位来源**：默认

**耦合链**：同一条巷子里，路灯一闪让所有雨滴停在半空；纸鹤沿起伏的路线在静止的雨里飞行，碰到的雨滴被推开碎成小水珠，留下一条通道；纸鹤落窗后路灯再闪，雨重新落下，通道的形状在雨里隐约可见。

| 编号 | 考点 | 分级 | 作用对象与时段 | 在片中的体现 |
|---|---|---|---|---|
| 13 | 破碎崩解与离散粒子 | L4 | 约 20 万颗雨滴，1.2–12 秒 | 雨滴停在半空，被纸鹤碰到的雨滴碎成 3–6 颗小水珠飞出一小段后停住；重新落下时平滑加速拉成雨丝 |
| 3 | 复杂轨迹与姿态自适应 | L2 | 纸鹤，2–10 秒 | 沿起伏、向左绕过晾衣杆的弧线飞行，上升抬头、转弯向内侧倾，降落时抬身张翅减速 |
| 17 | 单镜头运镜构图 | L1 | 镜头，0–12 秒 | 从窗台旁的纸鹤近景后退、跟随、升高，最后停在巷子中间，纸鹤和通道全程清楚，无剪辑 |

**最高分级**：L4

## 制作底线清单

**二级类目**：幻想世界

**技术模块**：T1、T4、T10（另用 T5 的建筑做法、T9 的粒子做法）

**本片要用的专业术语**：模块化建模、阵列修改器、斜切倒角、三平面投影贴图、置换修改器、几何节点实例化、空气透视、局部体积雾、体积散射、体积光、自发光、IES 灯光、光度单位、辉光阈值、折射率、骨骼绑定、形态键、二级跟随、路径跟随、次表面散射、环境光遮蔽

**推荐插件**：几何节点（内置）、物理天空纹理（内置）、Bloom 辉光（内置）、Building Tools（开源）

**通用底线**：PBR 贴图或程序化纹理（近景 4K）、倒角、接触阴影、AgX 色彩管理、足够采样、100% 查看细节、尺度参照（花盆、木门、自行车）、防重复

**重模拟**：无（雨滴和水珠用粒子和几何节点）

## 类目与标签

**归类理由**：主体是一条雨夜老巷，以及雨滴停在半空、纸鹤穿行的魔法事件，属于幻想世界里的魔法场景。

| 标签组 | 选定标签 | 必要说明 |
|---|---|---|
| 视觉造型 | 写实 | 照片级写实，只有雨停是魔法 |
| 材质质感 | 纸艺、液体冰晶、木石天然 | 主材质是和纸折的纸鹤；其次是雨滴和水坑，以及石墙和石板路 |
| 渲染风格 | 真实渲染 | 常规物理渲染 |
| 动态节奏 | 自然流畅 | 纸鹤飞行和雨的停落都平滑 |
| 动画行为 | 主行为：位移与运动/路径运动/沿线移动 | 纸鹤沿路线穿行 |
| 动画行为 | 辅助行为：物理与特效/流体粒子/粒子 | 雨滴停住、碎开、重新落下 |
| 动画行为 | 辅助行为：结构与装配/开合联动/折叠展开 | 纸鹤翅膀沿折痕张开和收拢 |
| 动画行为 | 辅助行为：显隐与外观变化/材质变化/发光亮灭 | 路灯闪烁 |
| 灯光氛围 | 夜景月光 | 冷色夜空加暖色路灯和窗灯点光源 |
| 背景环境 | 完整场景 | 老巷完整搭建 |
| 色彩基调 | 不填 | 暖橙路灯和冷蓝夜色对比 |
| 时序结构 | 多段序列 | 雨停 → 纸鹤起飞 → 穿行 → 落窗 → 雨落 |
| 复杂度等级 | 多元编排 | 大量粒子、骨骼和形态键编排 |
| 应用场景 | 不填 | 没有明确的用途依据 |
