# 木偶的玩具钢琴独奏考点说明

> 内部校验用，不交给制作方，不属于制作输入。

**主类目**：角色动画/简易人形/关节木偶

**题目档位**：上限档（配方：L3 + L2，附带 2 个 L1）

**档位来源**：默认

**规范版本**：进阶版 1.2

**视觉基调**：温馨童话

**耦合链**：同一只木偶的手指一节节弯下去，指尖贴住琴键一起下沉；琴键像杠杆一样带着后面的小锤抬起、敲在音条上再弹回，音条被敲以后慢慢颤停；琶音时手指依次落下，小锤和音条跟着同一个顺序动起来；台灯照着的音条随颤动一闪一闪。

| 编号 | 考点 | 分级 | 作用对象与时段 | 在片中的体现 |
|---|---|---|---|---|
| 5 | 多关节联动与抓取交互 | L3 | 木偶的手臂、手腕和十根三节手指，2–12 秒 | 手指从指根往指尖一节节弯下，指尖对准并贴住要按的琴键，按下的深度和琴键下沉一致；抬起时琴键先弹回，手指再离开 |
| 4 | 部件联动与运动匹配｜防打滑 | L2 | 十八组琴键、小锤和音条，2–12 秒 | 琴键绕支点转，小锤按杠杆比例跟着抬起、敲到音条停住再弹回；按哪个键动哪组，各组独立 |
| 16 | 光影流转与材质外观演变 | L1 | 黄铜音条的反光，2–12 秒 | 音条被敲后颤动，台灯在上面的反光跟着一闪一闪、慢慢平息 |
| 17 | 单镜头运镜构图 | L1 | 镜头，全片 | 一镜到底：三分法 → 引导线特写 → 负空间 → 对角线横移 → 中心构图 |

**最高分级**：L3

## 制作底线清单

**二级类目**：简易人形

**技术模块**：T6、T7

**本片要用的专业术语**：骨骼绑定、父子级绑定、关节约束、反向动力学、正向动力学、二级动画、骨骼约束、驱动器、形态键、硬表面建模、细分曲面、支撑边、倒角修改器、加权法线、次表面散射、IES 灯光

**推荐插件**：Rigify（内置）、MACHIN3tools（开源）、Wiggle 2（开源）

**通用底线**：PBR 贴图或程序化纹理（近景 4K）、倒角、接触阴影、AgX 色彩管理（Punchy）、足够采样、100% 查看细节、尺度参照（积木块、小木凳）、防重复

**重模拟**：无（手指和琴键用骨骼和驱动器，音条用形态键）

## 类目与标签

**归类理由**：主体是一只手指能一节节弯的枫木关节木偶，表演的是弹玩具钢琴，属于简易人形里的关节木偶。

| 标签组 | 选定标签 | 必要说明 |
|---|---|---|
| 视觉造型 | 写实 | 照片级写实的木偶和玩具钢琴 |
| 材质质感 | 木石天然、金属 | 主材质是枫木木偶和红漆木琴壳；其次是黄铜音条 |
| 渲染风格 | 真实渲染 | 常规物理渲染 |
| 动态节奏 | 自然流畅 | 手指按键越来越顺，身子跟着节奏摇 |
| 动画行为 | 主行为：结构与装配/开合联动/机械传动 | 手指按下琴键，琴键带动小锤敲音条 |
| 动画行为 | 辅助行为：位移与运动/规律运动/摆动 | 身子和头跟着节奏摇 |
| 动画行为 | 辅助行为：位移与运动/群体运动/编队 | 琶音时一排小锤依次抬起敲下 |
| 动画行为 | 辅助行为：位移与运动/规律运动/旋转 | 星星夜灯转动 |

| 色彩基调 | 暖色温馨 | 暖黄、枫木色和红 |
| 时序结构 | 多段序列 | 坐定 → 试音 → 越弹越顺 → 一串琶音 → 最后的和弦 |
| 复杂度等级 | 多元编排 | 几十个关节、十八组联动的骨骼和驱动器编排 |
| 应用场景 | 不填 | 没有明确的用途依据 |
