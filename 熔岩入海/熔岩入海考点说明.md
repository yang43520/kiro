# 熔岩入海考点说明

> 内部校验用，不交给制作方，不属于制作输入。

**主类目**：现象动画/液体流动/黏稠流淌

**题目档位**：上限档（配方：单个 L4，附带 1 个 L2 和 1 个 L1）

**档位来源**：默认

**耦合链**：同一股熔岩上，岩壳被顶破后熔岩涌出，被玄武岩巨石挡住、堆起、分流；流过的地方冷却成新的黑色熔岩带，入海处和海水接触喷出蒸汽并堆出新岩台，浪再把岩台边缘打碎成黑沙；熔岩的颜色随温度和冷却时间变化。

| 编号 | 考点 | 分级 | 作用对象与时段 | 在片中的体现 |
|---|---|---|---|---|
| 15 | 接触留痕与表面动态反馈 | L4 | 熔岩流过的坡面和海岸，2–12 秒 | 流过的地方留下持续存在的新黑色熔岩带；入海处堆出伸进海里的黑色新岩台；浪打碎岩台边缘留下黑沙 |
| 10 | 体积碰撞与边界阻挡｜真实轮廓接触与防穿模 | L2 | 熔岩和玄武岩巨石、岩台，2–10 秒 | 熔岩在巨石上坡一侧堆高约半米后从两侧绕开，不穿进石头和地面；越过 3 米岩台边缘落进浪里 |
| 16 | 光影流转与材质外观演变 | L1 | 熔岩表面，1–12 秒 | 熔岩从橙黄冷却成橙红、暗红再到黑色，薄壳开裂时又露出亮橙色，蒸汽柱被熔岩照成橙色 |

**最高分级**：L4

## 类目与标签

**归类理由**：主体是黏稠的熔岩流，片子围绕它的流淌、分流、冷却和入海展开，属于液体流动里的黏稠流淌。

| 标签组 | 选定标签 | 必要说明 |
|---|---|---|
| 视觉造型 | 写实 | 照片级写实 |
| 材质质感 | 自发光、木石天然、液体冰晶 | 主材质是发光的熔岩；其次是玄武岩和旧熔岩，以及海水 |
| 渲染风格 | 真实渲染 | 常规物理渲染 |
| 动态节奏 | 自然流畅 | 熔岩黏稠缓慢，浪和蒸汽自然 |
| 动画行为 | 主行为：物理与特效/流体粒子/液体 | 熔岩的黏稠流淌 |
| 动画行为 | 辅助行为：物理与特效/流体粒子/烟火 | 入海时的蒸汽柱 |
| 动画行为 | 辅助行为：显隐与外观变化/材质变化/颜色渐变 | 熔岩冷却变色 |
| 动画行为 | 辅助行为：物理与特效/破碎解体/碎裂 | 浪把新岩台边缘打碎成黑沙 |
| 灯光氛围 | 低调暗黑 | 日落后的暗环境，熔岩是局部的强光源 |
| 背景环境 | 完整场景 | 火山海岸完整搭建 |
| 色彩基调 | 不填 | 黑、橙红和青蓝色对比，没有单一的色彩基调 |
| 时序结构 | 多段序列 | 破壳 → 分流 → 结壳 → 入海 → 新岩台 |
| 复杂度等级 | 物理模拟 | 含液体、烟雾和刚体模拟 |
| 应用场景 | 不填 | 没有明确的用途依据 |
