# 雨夜码头电动轿跑追逐考点说明

> 内部校验用，不交给制作方，不属于制作输入。

**主类目**：载具动画/陆地载具/乘用车

**题目档位**：上限档（配方：单个 L4，附带 1 个 L2 和 2 个 L1）

**档位来源**：默认

**规范版本**：进阶版 1.9

**视觉基调**：夜景都市

**耦合链**：同一段追逐：两车在箱墙车道里甩过 S 弯，车身按弯道侧倾、前轮按阿克曼关系转；轿跑刹车点头后撞上仓库门口的 PVC 软门帘，门帘被顶起、贴着车顶滑过、掉下后像长摆一样回荡、相邻两条互相拍打并甩下水珠；GT 一秒后撞开还在荡的门帘；两车穿过仓库、从岸桥吊着的集装箱下驶出；各色灯光在珍珠白车漆上流转，镜头一镜到底跟完全程。

| 编号 | 考点 | 分级 | 作用对象与时段 | 在片中的体现 |
|---|---|---|---|---|
| 12 | 薄面垂坠与绳索悬挂 | L4 | 几十条 PVC 软门帘，5.5–12 秒 | 每条约 30 厘米宽、3 毫米厚、5 米长、顶端挂在挂钩上；被每秒 15 米的车顶起、弯成弧贴着车顶滑过，掉下后来回摆一次约 3 秒、相邻两条互相拍打；GT 再次顶开时门帘还在荡 |
| 3 | 复杂轨迹与姿态自适应 | L2 | 轿跑和 GT 的车身，2.5–7.5 秒 | 在约 5 米宽的车道里甩过 S 弯，每次向外侧倾约 3°、换向时先回正；刹车点头约 3 厘米；GT 在弯里车尾稍滑 |
| 16 | 光影流转与材质外观演变 | L1 | 高杆灯、霓虹、顶灯和珍珠白车漆，0–12 秒 | 高杆灯在白漆上拉出长高光，霓虹色斑滑过，仓库顶灯一盏盏滑过车顶，珍珠白斜面泛粉金 |
| 17 | 单镜头运镜构图 | L1 | 镜头，全片 | 一镜到底：引导线特写 → 对角线 → 中心构图 → 层次纵深 → 负空间 |

**最高分级**：L4

## 制作底线清单

**二级类目**：陆地载具

**技术模块**：T6、T7、T8（另用 T9 的粒子做法）

**本片要用的专业术语**：细分曲面、支撑边、倒角修改器、加权法线、布尔运算、阵列修改器、布料模拟、固定顶点组、弯曲刚度、自碰撞、碰撞距离、碰撞物、质量步数、骨骼、二级摆动、路径跟随、阿克曼关系、阻尼、涂层、高度遮罩、曲率遮罩、粒子系统、动态绘画波纹、运动模糊、自发光、空气透视

**推荐插件**：Rigacar（开源）、MACHIN3tools（开源）、Building Tools（开源）

**通用底线**：PBR 贴图或程序化纹理（近景 4K）、倒角、接触阴影、AgX 色彩管理（Medium High Contrast）、足够采样、100% 查看细节、尺度参照（约 12 米长的集装箱、5 米长的门帘、车道线）、防重复

**重模拟**：布料模拟（只用在仓库前门的 PVC 软门帘上）

## 类目与标签

**归类理由**：主体是两辆原创跑车在雨夜码头和仓库里的追逐，展示车身造型、车轮和车身姿态以及车撞开软门帘，按规则交通工具归载具，属于陆地载具里的乘用车。

| 标签组 | 选定标签 | 必要说明 |
|---|---|---|
| 视觉造型 | 写实 | 按写实电影质感做的车和码头 |
| 材质质感 | 金属、塑料橡胶、玻璃透明 | 主材质是珍珠白和哑光军绿车身；其次是 PVC 门帘和轮胎；车窗和灯罩 |
| 渲染风格 | 真实渲染 | 常规物理渲染 |
| 动态节奏 | 自然流畅 | 追逐、过弯、撞帘都有缓入缓出 |
| 动画行为 | 主行为：位移与运动/路径运动/沿线移动 | 两车沿箱墙车道和仓库追逐 |
| 动画行为 | 辅助行为：物理与特效/柔性运动/布料 | PVC 门帘被顶开又荡回 |
| 动画行为 | 辅助行为：位移与运动/规律运动/旋转 | 车轮转动 |
| 动画行为 | 辅助行为：物理与特效/流体粒子/粒子 | 雨和门帘甩下的水珠 |
| 灯光氛围 | 霓虹赛博 | 高杆灯、霓虹、岸桥灯、顶灯和车灯 |
| 背景环境 | 完整场景 | 集装箱堆场、仓库和岸桥完整搭建 |
| 色彩基调 | 冷色科技 | 深蓝灰为主，暖白灯光，品红、青和琥珀点缀 |
| 时序结构 | 多段序列 | 箱墙直道 → S 弯 → 撞门帘 → 追进仓库 → 出后门 |
| 复杂度等级 | 物理模拟 | 含布料模拟 |
| 应用场景 | 不填 | 用于考察载具制作 |
