# 初号机冷却池苏醒考点说明

> 内部校验用，不交给制作方，不属于制作输入。

**主类目**：载具动画/幻想载具/机甲

**题目档位**：进阶档（配方：L2 + L2，附带 2 个 L1）

**档位来源**：默认

**规范版本**：进阶版 1.9

**视觉基调**：科幻未来

**还原说明**：用户明确要求还原 EVA 初号机，用途是个人学习或内部测试，已提示版权风险（公开发布或商用需版权方授权）；造型按 TV 版和新剧场版共有的特征来做，不照搬具体的名场面；机体结构借仿生机器人 skill 的规则（以人为原型的比例、关节自由度、装甲间隙和联动）。

**耦合链**：同一套束缚架和同一台初号机：卡销一根接一根退出，液压臂按行程把肩部卡箍拉开约 70°，腰部卡架滑开；束缚松开，机体往下一沉，液面涌起；眼睛亮起，视线先动、头抬起、肩耸起、膝伸直，装甲按骨骼联动、颈甲一片片错开再合拢；上半身升出液面，冷却液从装甲边缘和分缝泻下；警示灯和探照灯在湿装甲上流转，镜头一镜到底跟完全程。

## 机体设定（借仿生机器人 skill 的设定卡）

| 项目 | 内容 |
|---|---|
| 原型 | 人（比例拉长：头小、颈长、腰窄、四肢细长、驼背前倾） |
| 尺寸和比例 | 身高约 40 米，约 9 个头高，肩宽约两个头半 |
| 外观 | 紫色主装甲、荧光绿条纹、少量橙色；细长头盔、额头一根独角、能张开的下颌护甲、肩部一对大挂架、后颈插入栓接口、背部电缆 |
| 驱动方式 | 装甲下的肌肉（关节缝里露出的肌肉纤维束），装甲是刚性的独立硬壳 |
| 自由度 | 颈 2（俯仰约 ±45°、左右约 ±70°）、肩 3（前举约 170°）、肘 1（0–140°）、膝 1（0–130°）、手指每指 3 节 |
| 装甲间隙 | 相邻装甲约 3–5 厘米，转到限位时刚好不碰 |

## 制作底线清单

**二级类目**：幻想载具

**技术模块**：T6、T7、T3（另用 T9 的粒子做法）

**本片要用的专业术语**：硬表面建模、细分曲面、支撑边、倒角修改器、加权法线、父子级绑定、驱动器、旋转限制约束、阻尼追踪、拉伸到约束、反向动力学、地板约束、修正形态键、形态键、雕刻、多重分辨率细分、液体模拟、模拟域、障碍物、二次粒子、海洋修改器、动态绘画波纹、体积吸收、曲率遮罩、环境光遮蔽、次表面散射、局部体积雾

**推荐插件**：MACHIN3tools（开源）、Rigify（内置）、Extra Mesh Objects（内置扩展）

**通用底线**：PBR 贴图或程序化纹理（近景 4K）、倒角、接触阴影、AgX 色彩管理（Medium High Contrast）、足够采样、100% 查看细节、尺度参照（1.1 米高的栈桥栏杆和检修车）、防重复

**重模拟**：液体模拟（只用在机体周围泻下的冷却液上）

## 类目与标签

**归类理由**：主体是一台巨型人形机甲在整备库里解除束缚、苏醒站起，按类目表"以机甲为主体→载具动画/幻想载具"归到机甲。

| 标签组 | 选定标签 | 必要说明 |
|---|---|---|
| 视觉造型 | 写实 | 按写实电影的质感做的机甲和整备库 |
| 材质质感 | 金属、液体冰晶 | 主材质是漆面装甲和钢结构；其次是冷却液 |
| 渲染风格 | 真实渲染 | 常规物理渲染 |
| 动态节奏 | 自然流畅 | 起身和抬头带缓入缓出，有生命的身体没有机械的过冲 |
| 动画行为 | 主行为：结构与装配/开合联动/打开翻盖 | 束缚架的卡箍依次打开 |
| 动画行为 | 辅助行为：形变与生长/形态变化/弯曲扭转 | 机体抬头、伸膝站直 |
| 动画行为 | 辅助行为：物理与特效/流体粒子/液体 | 从装甲上泻下的冷却液 |
| 动画行为 | 辅助行为：显隐与外观变化/材质变化/发光亮灭 | 眼睛亮起、警示灯旋转 |
| 灯光氛围 | 低调暗黑 | 昏暗整备库里的探照灯和警示灯 |
| 背景环境 | 完整场景 | 冷却池、束缚架、栈桥和库顶桁架完整搭建 |
| 色彩基调 | 冷色科技 | 深灰和暗青为主，紫色机体，琥珀点缀 |
| 时序结构 | 多段序列 | 待机 → 解锁 → 苏醒 → 站直 → 站在池中 |
| 复杂度等级 | 物理模拟 | 含液体模拟 |
| 应用场景 | 不填 | 个人学习和内部测试 |
