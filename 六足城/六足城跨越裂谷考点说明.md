# 六足城跨越裂谷考点说明

> 内部校验用，不交给制作方，不属于制作输入。

**主类目**：载具动画/幻想载具/机甲

**题目档位**：上限档（配方：单个 L4，附带 1 个 L2 和 1 个 L1）

**档位来源**：默认

**耦合链**：同一座六足城镇上，三角步态交替让六条腿按前、中、后的顺序跨过裂谷，每条腿的关节转角带动液压缸伸缩，落脚时平台微倾、岩石碎落；全部跨过后液压缸一起收缩、平台压低；镜头在南岸跟着平移、升高。

| 编号 | 考点 | 分级 | 作用对象与时段 | 在片中的体现 |
|---|---|---|---|---|
| 7 | 足式步态与重心转移 | L4 | 六条腿和平台，0–10 秒 | 三角步态交替，支撑腿脚掌钉住不滑不穿；跨裂谷的那步抬得更高，落点都在崖边 5 米以外；平台的高度和倾斜随支撑腿变化，重心落在三条支撑腿之间 |
| 4 | 部件联动与运动匹配｜防打滑 | L2 | 液压缸和关节，0–12 秒 | 每根液压缸的伸缩由两端关节转角决定，始终连在铰点上；落脚时缸被压短、平台微倾；站稳时所有缸一起收缩、平台压低约 2 米 |
| 17 | 单镜头运镜构图 | L1 | 镜头，0–12 秒 | 在南岸侧面 170 米外跟着城镇平移并升高到 70 米，每条腿跨越裂谷都在画面里，结尾城镇约占画面宽度一半，无剪辑 |

**最高分级**：L4

## 类目与标签

**归类理由**：主体是一座靠六条机械腿行走的移动城镇，属于幻想载具；它靠足式机构运行，最接近类目表里的机甲。

| 标签组 | 选定标签 | 必要说明 |
|---|---|---|
| 视觉造型 | 写实 | 照片级写实，硬表面结构 |
| 材质质感 | 金属、木石天然 | 主材质是锈蚀的钢结构；其次是砂岩崖壁 |
| 渲染风格 | 真实渲染 | 常规物理渲染 |
| 动态节奏 | 自然流畅 | 步伐沉重，有重量感和缓入缓出 |
| 动画行为 | 主行为：位移与运动/路径运动/沿线移动 | 城镇向北行进跨过裂谷 |
| 动画行为 | 辅助行为：结构与装配/开合联动/伸缩 | 液压缸随关节伸缩 |
| 动画行为 | 辅助行为：物理与特效/破碎解体/碎裂 | 落脚砸碎崖边岩石 |

| 背景环境 | 完整场景 | 异星沙漠和裂谷完整搭建 |
| 色彩基调 | 不填 | 赭红、暗灰和淡蓝紫混合，没有单一的色彩基调 |
| 时序结构 | 多段序列 | 崖边探腿 → 前腿跨越 → 中腿跨越 → 后腿跨越 → 站稳 |
| 复杂度等级 | 物理模拟 | 含刚体碎裂和烟雾模拟 |
| 应用场景 | 不填 | 没有明确的用途依据 |
