# 黑洞视界环绕动画 · 制作需求

制作时同时提供「一、制作 Prompt」和完整的《黑洞视界环绕剧本》（见 `黑洞视界环绕剧本.md`）。「三、类目与标签」和「四、试做验收要点」不属于制作输入。

## 一、制作 Prompt

```text
使用 Blender 5.0.0 制作一条约 12 秒（允许 11–13 秒，不得少于 8 秒）的黑洞动画，写实渲染风格，一镜到底。画面内容、动作和镜头以《黑洞视界环绕剧本》为准。

核心效果：深空中，一个孤立的黑洞被一圈明亮的吸积盘环绕。吸积盘内快外慢地旋转，几团热斑随盘面绕黑洞运行。黑洞的引力把吸积盘背面的光弯折过来，在纯黑的阴影上方和下方各形成一道光弧，阴影边缘紧贴着一圈细亮的光子环。镜头从几乎贴着吸积盘平面的侧面开始，一边环绕一边升高，光弧的形状随之连续变化，背景星空在阴影边缘被扭曲、拉长；最后镜头平稳地推近视界，画面在吸积盘仍在旋转时结束。

质感要求：
- 整体：以接近真实天文观测和写实科幻电影的质感为目标，外观参考真实的天体物理，不要求精确的物理计算，但画面要符合引力透镜、光子环、多普勒增亮和内快外慢旋转的规律。
- 阴影：纯黑的圆形阴影，不是被照亮的黑色球体，表面没有高光、反光或轮廓光；光子环连续不断地包住整个阴影。
- 吸积盘：很薄的高温气体盘，内缘边界清楚，外缘逐渐变暗、变稀；亮度从内向外递减，内缘接近白色，向外变成金色、橙色和暗橙红色；盘面由沿旋转方向拉长的气体纹路组成，有亮的丝缕、暗的空隙和成团的亮斑，疏密不均；不能是均匀的同心圆环或贴图的平面圆盘。
- 引力透镜：上下两道光弧是吸积盘本身的像，纹路和颜色与盘面一致；靠近阴影边缘的星星被拉成细小的弧线，离阴影越远扭曲越弱。
- 多普勒增亮：朝向镜头转来的一侧明显更亮、偏白，远离镜头的一侧更暗、偏橙红，较暗的一侧仍能看清纹路。
- 星空：密集的星空和一条斜穿画面的银河光带；星星大小、亮度和颜色各不相同，没有重复的图案。
- 光影：吸积盘是画面的主要光源；吸积盘最亮的内缘不过曝成一片纯白，阴影是纯黑，背景星空相对暗淡但清楚可见。
- 渲染：吸积盘带柔和的辉光，辉光不会盖住阴影的边缘和光子环；画面清晰锐利，没有因降噪过度或采样不足造成的发糊、涂抹或噪点。

不可改变的内容：全片是一个连续镜头，中间没有剪辑或转场；吸积盘全程旋转，而且内快外慢；热斑全程绕黑洞运行；镜头按“侧面 → 环绕升高 → 推近视界”的顺序运动；上下两道光弧的形状随镜头角度连续变化；吸积盘两侧的亮度差肉眼明显可见；阴影始终位于画面中央附近；画面在吸积盘仍在旋转时结束。

可调整范围：剧本中的尺寸、距离、角度、转速和时间都是参考值，可在保持比例和观感的前提下调整；各段时间点可以微调，但镜头运动的顺序不变。吸积盘纹路的具体形态、热斑的数量和位置、银河光带的走向和星云的样子，都可以自行设计。实现引力透镜的方法不限。

可选增强：热斑转到黑洞正后方时，在上方的光弧中被放大、变亮一下。

禁止：剪辑、转场或跳帧；出现飞船、人物、文字、标志或任何人造物；出现行星或其他被照亮的天体；照搬现有电影中的黑洞镜头构图或飞船；把黑洞做成漩涡、漏斗或发光的球体；阴影带高光或轮廓光；光子环断开；吸积盘停转或整体同速旋转；吸积盘两侧亮度相同；画面出现镜头眩光和光斑；明显的建模感，如光滑无细节的大块表面、肉眼可辨的重复纹理或重复图案；镜头突然加速、急停或抖动；用停帧或重复片段凑时长；画面闪烁、破面或非设计性的卡顿。

输出规格：16:9，1280×720，30 帧/秒，无声音。最终输出一条完整的动画视频。
```

## 三、类目与标签

**主类目**：场景动画/幻想世界/科幻空间

**归类理由**：
- 本片的目的是营造近距离观看黑洞的科幻场景，镜头悬停在现实中无法到达的位置，属于「幻想世界」纳入范围中的“科幻空间”。该三级类目的示例是空间站舱门和走廊，与本片的画面不同，但二级定义写明包括“科幻空间等虚构场景”。分类表中没有专门对应黑洞的三级类目，这是最接近的选项。
- 「科教演示/天文宇宙」定义为“天体与宇宙现象的示意演示”，本片不做标注、讲解或示意，而且该二级下的行星公转、自转昼夜、月相、星系旋转都不对应黑洞，所以不选。
- 「现象动画/光效能量」的纳入范围是光束激光、能量脉冲护盾、电弧闪电、全息投影，吸积盘是天体结构，不在其中，所以不选。
- 画面中没有飞船，不涉及「载具动画」。
