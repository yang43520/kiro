# 赛博朋克台风港考点说明

> 内部校验用，不交给制作方，不属于制作输入。

**主类目**：场景动画/城市街景/夜景霓虹

**题目档位**：上限档（配方：单个 L4，附带 1 个 L2 和 2 个 L1）

**档位来源**：默认

**规范版本**：进阶版 1.3

**视觉基调**：夜景都市

**耦合链**：同一场台风里，强风把楼顶的布面广告扯开一角、让它整块翻起来猎猎拍打；同一道巨浪砸上防波堤、炸起白浪、漫过码头，浪花打到码头边的霓虹招牌，招牌从水边往里一块接一块闪烁熄灭；霓虹一灭，港口的光就一片片暗下去。

| 编号 | 考点 | 分级 | 作用对象与时段 | 在片中的体现 |
|---|---|---|---|---|
| 12 | 薄面垂坠与绳索悬挂 | L4 | 楼顶三十多米宽的布面广告，4.5–12 秒 | 左上角的绳先断开，布从这一角撕开、整块翻起来，在强风里像一面巨大的旗一样猎猎翻飞、一阵阵拍打，撕开的边拉出纤维 |
| 14 | 集群协同与波浪相位差 | L2 | 码头边和楼墙上的一排排霓虹招牌，7.5–10 秒 | 浪花打中最近的一块，它先闪两下再灭，接着沿码头一块接一块往楼墙深处传，大约 1 秒一块 |
| 16 | 光影流转与材质外观演变 | L1 | 整个港口的光，3.5–12 秒 | 白浪被霓虹照成冰青；霓虹熄灭以后港口一大半暗下去，只剩远处几块招牌、灯塔和航标灯 |
| 17 | 单镜头运镜构图 | L1 | 镜头，全片 | 一镜到底：引导线 → 对角线 → 前景框景 → 特写 → 负空间 |

**最高分级**：L4

## 制作底线清单

**二级类目**：城市街景

**技术模块**：T5、T10

**本片要用的专业术语**：程序化楼群、几何节点实例化、湿表面反射、自发光、自发光强度、光度单位、辉光阈值、体积光、模块化建模、斜切倒角、返潮遮罩、雨水流痕、顶点颜色混合、贴花、钉固顶点组、自碰撞、海洋修改器、FLIP 液体模拟、二次粒子、体积散射

**推荐插件**：Building Tools（开源）、几何节点（内置）、Bloom 辉光（内置）

**通用底线**：PBR 贴图或程序化纹理（近景 4K）、倒角、接触阴影、AgX 色彩管理（Medium High Contrast）、足够采样、100% 查看细节、尺度参照（渔船、灯塔）、防重复

**重模拟**：液体模拟（只包住防波堤和码头）、布料模拟（只用在楼顶的广告布上）

## 类目与标签

**归类理由**：主体是一座挂满霓虹的赛博朋克港口城市在台风夜里被巨浪冲击的过程，属于城市街景里的夜景霓虹。

| 标签组 | 选定标签 | 必要说明 |
|---|---|---|
| 视觉造型 | 写实 | 照片级写实的灾难电影镜头 |
| 材质质感 | 液体冰晶、自发光、织物皮革 | 主材质是海水、白浪和雨；其次是霓虹灯管和布面广告；质感重点是被海浪啃粗的混凝土和藤壶、浸透的帆布、玻璃钢船舷和旧橡胶护舷 |
| 渲染风格 | 真实渲染 | 常规物理渲染 |
| 动态节奏 | 自然流畅 | 浪涌、布翻飞和霓虹熄灭都连贯，撞堤是瞬间的爆发 |
| 动画行为 | 主行为：物理与特效/柔性运动/布料 | 广告布撕开、翻飞、拍打 |
| 动画行为 | 辅助行为：物理与特效/流体粒子/液体 | 巨浪撞堤、白浪、漫过码头 |
| 动画行为 | 辅助行为：显隐与外观变化/材质变化/发光亮灭 | 霓虹一块块闪烁熄灭 |
| 动画行为 | 辅助行为：物理与特效/流体粒子/粒子 | 横飞的暴雨和水沫 |
| 灯光氛围 | 霓虹赛博 | 高饱和的霓虹光和湿表面的强反射 |
| 背景环境 | 完整场景 | 港湾、防波堤、码头和霓虹楼墙完整搭建 |
| 色彩基调 | 冷色科技 | 墨蓝灰为主、霓虹冰青为辅，玫红、航标红和钠黄点缀 |
| 时序结构 | 多段序列 | 台风夜 → 巨浪撞堤 → 漫堤与撕布 → 霓虹熄灭 → 退浪 |
| 复杂度等级 | 物理模拟 | 含液体模拟和布料模拟 |
| 应用场景 | 不填 | 没有明确的用途依据 |
