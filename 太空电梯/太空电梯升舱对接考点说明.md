# 太空电梯升舱对接考点说明

> 内部校验用，不交给制作方，不属于制作输入。

**主类目**：载具动画/航空航天/火箭卫星

**题目档位**：上限档（配方：L3 + L2，附带 1 个 L1）

**档位来源**：默认

**耦合链**：同一节电梯舱上，爬升轮夹紧缆带后转动，转速和上升距离匹配；电梯舱爬过云层和大气，天色随高度变化；到达中转站下方减速停稳后，机械臂的肩、肘、腕协调伸出抓住对接环，爬升轮松开，机械臂把电梯舱拉进对接舱锁住。

| 编号 | 考点 | 分级 | 作用对象与时段 | 在片中的体现 |
|---|---|---|---|---|
| 5 | 多关节联动与抓取交互 | L3 | 机械臂和电梯舱，9–12 秒 | 肩、肘、腕三关节协调伸出，抓手对准并扣住对接环的三个凸耳；电梯舱静止 → 随机械臂移动 → 锁进舱口 |
| 4 | 部件联动与运动匹配｜防打滑 | L2 | 上下爬升轮组，0.4–10 秒 | 爬升轮夹紧时轮胎微扁，转速按上升速度和轮径算出，加速、减速和停下都同步，不打滑；抓住后才松开 |
| 16 | 光影流转与材质外观演变 | L1 | 天空、地平线、舱体外壳，3.5–11 秒 | 天色从浅蓝到深蓝再到黑色，地平线弯成弧线并出现大气辉光；穿云结霜、越过大气后霜剥落成冰晶；对接灯由黄转绿 |

**最高分级**：L3

## 类目与标签

**归类理由**：主体是一节沿缆带爬升进入太空的运载舱，属于航天运载工具，归入航空航天里最接近的火箭卫星。

| 标签组 | 选定标签 | 必要说明 |
|---|---|---|
| 视觉造型 | 写实 | 照片级写实，硬表面结构 |
| 材质质感 | 金属、玻璃透明、塑料橡胶 | 主材质是复合材料外壳和钛合金构件；其次是舷窗和爬升轮的聚合物轮胎 |
| 渲染风格 | 真实渲染 | 常规物理渲染 |
| 动态节奏 | 机械节奏 | 爬升、减速、抓取和对接分段精确 |
| 动画行为 | 主行为：位移与运动/路径运动/沿线移动 | 电梯舱沿缆带爬升 |
| 动画行为 | 辅助行为：位移与运动/规律运动/旋转 | 爬升轮转动 |
| 动画行为 | 辅助行为：结构与装配/开合联动/伸缩 | 机械臂伸出、收回，散热板展开、折叠 |
| 动画行为 | 辅助行为：显隐与外观变化/材质变化/发光亮灭 | 对接灯由黄转绿 |
| 灯光氛围 | 灯光动画 | 天色和光照随高度变化 |
| 背景环境 | 完整场景 | 海面平台、云层、地球弧线和中转站完整搭建 |
| 色彩基调 | 不填 | 从蓝天到黑色太空，没有单一的色彩基调 |
| 时序结构 | 多段序列 | 启动 → 穿云 → 越过大气 → 减速抓取 → 拉入对接 |
| 复杂度等级 | 多元编排 | 多对象、骨骼反向动力学、驱动器和时间变速编排 |
| 应用场景 | 不填 | 没有明确的用途依据 |
