# 被自然收回的城市街角动画 · 制作需求

制作时同时提供「一、制作 Prompt」和完整的《被自然收回的城市街角剧本》（见 `被自然收回的城市街角剧本.md`）。「三、类目与标签」和「四、试做验收要点」不属于制作输入。

## 一、制作 Prompt

```text
使用 Blender 5.0.0 制作一条约 12 秒（允许 11–13 秒，不得少于 8 秒）的微缩场景动画，照片级写实渲染，一镜到底。画面内容、动作和镜头以《被自然收回的城市街角剧本》为准。

核心效果：请制作一个「被自然收回的城市街角」微缩场景，以第三视角观察整个场景，画面是一块从真实城市里完整切下来的街角，悬浮在空中，没有任何 UI 界面元素。地面为一个完整的正方形底座，所有元素都搭建在这个底座上，底座侧壁可见断裂的柏油路面剖面、裸露的混凝土与钢筋、以及从边缘垂落的盘结树根与藤蔓，构图紧凑、层次清晰，整体呈现出精致的微缩景观构图。全片用延时生长表现自然收回城市的过程：开场是一个几乎没有绿色的荒废 L 形街角，有龟裂的柏油路、褪色的斑马线和水洼，一栋三层水泥小楼，一辆锈蚀的废弃小轿车，歪斜的红绿灯、下垂的电线和褪色的自动售货机。随后裂缝里冒出草芽，青草沿裂缝蔓延，青苔铺满楼顶和车顶，爬山虎爬满一侧外墙，藤蔓缠上红绿灯杆再沿电线垂下；人行道上的小树苗长成一棵大树，树根掀翻地砖，树根和藤蔓从底座边缘垂落；最后野花和引擎盖上的小白花开放，生长停下。结尾一阵风从底座左侧吹到右侧，草丛形成一道波浪，树冠和藤蔓随风摆动，叶子和花瓣被卷起，有几片飘出底座边缘落下。树冠长成后，阳光从叶缝里射下一道道丁达尔光束，照在街面上，光束里飘着被照亮的尘埃和花粉。两只淡黄色的蝴蝶全程在底座上空飞舞，中途落在小白花旁停一下，再绕着红绿灯飞。镜头从左前方绕底座向右缓慢转动约 90°，同时轻微推近，整个底座始终完整地出现在画面中。植物的生长是极度加速的，像压缩了几十年的延时摄影；风、滴水和蝴蝶的运动保持正常速度。

质感要求：
- 整体：切块里的一切都按真实世界来做，任意暂停一帧都应该像一张真实的照片；越逼真越好。
- 尺寸：场景按真实尺寸搭建，单位为米；切块边长 20 米，厚约 3 米；小楼高约 10 米，大树长成后高约 14 米、主干底部直径约 1.2 米，草高 15–50 厘米，所有物体之间的比例与真实街道一致。
- 底座断面：柏油路面的断面能看到黑色沥青里的碎石骨料，下面是浅灰色的碎石基层和褐色的压实土层；断面边缘参差，有掉落的碎块，土层表面松散；混凝土断面粗糙，锈蚀的钢筋从断面伸出、向外弯折，锈水在下方留下橙褐色的痕迹；土层里能看到断开的铸铁水管、电缆和穿进土里的树根。
- 柏油路面：能看到沥青里的碎石骨料、油渍、颜色较深的修补块和磨损的车道线；裂缝连成网，裂缝里积着泥土、细沙和枯叶；有的路面碎块翘起，断口露出骨料。
- 混凝土外墙：灰白色的水泥表面有雨水从窗台下流出的黑色竖向水痕，潮湿处有发绿的霉斑；墙皮风化剥落，露出下面的红砖；墙上有细裂缝；金属件下方有锈水流下的橙褐色痕迹。
- 建筑细节：外墙上有窗台、雨水管和两台空调外机，楼顶有水箱和锈蚀的栏杆；破窗处残留的玻璃碎片卡在窗框上，窗内是昏暗的室内，能看到倒下的家具和杂物；招牌表面没有文字。
- 锈蚀金属：汽车的锈蚀分好几层，有残留的褪色旧漆、橙色的浮锈、深褐色的厚锈，局部锈穿成孔洞；轮胎的橡胶老化开裂；车里的座椅已经腐烂；红绿灯杆、电线杆的金属件、栏杆、卷帘门和钢筋都有程度不同的锈蚀。
- 路边设施：红绿灯有三个不亮的灯头；电线杆有横担、绝缘子和一个变压器，四根电线松垮地下垂；街角散落着一辆生锈的自行车、一块倒在地上的空白路牌和几个破塑料箱。
- 植物：叶片是一片片单独的叶子，有叶脉，逆光时透光；绿叶中夹杂着黄叶、枯叶和被虫咬过的叶子；草丛里夹着枯黄的草叶；青苔有细密的绒毛质感，潮湿背阴处更绿、更厚，会从台阶、车顶和楼顶边缘溢出、垂下。
- 大树：树皮有纵向的沟纹和青苔；树枝逐级分叉、越往外越细；树冠由许多枝叶团块组成，团块之间有透光的空隙，能看到里面的枝干。
- 植被密度：最终植被覆盖底座顶面约六成，越靠近大树越茂密；路面裂缝里长满青草、狗尾草和蒲公英，人行道和台阶上长着蕨类和低矮的野草；侧壁外垂落的树根和藤蔓不少于 15 束，粗细和长短不一，有的树根上还挂着土块。
- 生长方式：每株植物都是从小到大逐渐长出来的，草从草芽长成草丛，青苔从小块向外铺开，爬山虎和藤蔓沿着墙面、杆子和电线一段段向前爬，大树逐渐长高、变粗、分枝、长出枝叶。
- 水：水洼的边缘有一圈颜色更深的湿痕；水面清楚地倒映天空、小楼和树；水滴是透明的，落下时能看到折射和高光。
- 地面杂物：路面和人行道上散落着落叶、碎玻璃、小石子和泥土，没有大块干净空着的平面。
- 蝴蝶：两只淡黄色的蝴蝶，按真实尺寸制作，翼展约 8 厘米；翅膀一下下扇动，飞行路线忽高忽低，不是直线；按真实尺寸，蝴蝶在画面中只是两个淡黄色的小亮点，看不清翅膀。
- 背景：柔和的渐变背景，上方是淡天蓝色，下方是暖米白色；底座悬浮在画面中央，周围没有地面和其他物体。
- 光照：用真实的天空光照明，画面背景显示为渐变；午后的暖阳从切块的左后方照来，太阳高度约 20°，光色是暖金色；光照全片保持不变，延时生长不表现昼夜交替。
- 丁达尔光：切块上方的空气里有一层很淡的薄雾，只存在于切块范围内，越靠近地面越浓；阳光穿过树冠的缝隙、小楼的破窗和电线之间，形成一道道清晰的暖金色光束，斜着照到街面和墙上；树冠长成前，光束主要来自小楼的破窗和楼顶栏杆的缝隙；树冠长成后，光束从树叶的缝隙里射下来，数量更多；风吹动树冠时，光束随着叶片的晃动闪动、移动；光束里能看到缓慢飘浮的细小尘埃和花粉，被阳光照亮；薄雾不能让画面发灰，切块外的渐变背景保持干净，没有雾；薄雾只分布在切块顶面以上约 8 米的高度内，而且非常稀薄：20 米外的物体仍然清楚，画面整体不能像蒙了一层白纱；光束只在背光和阴影区域里看得出来，每道光束宽约 0.2–1 米，边缘清楚；不能出现一大团模糊发亮的光柱，也不能有光束挡在镜头前、遮住小楼或街面；光束的亮度明显低于阳光直射的地面，只是空气中淡淡的光痕。
- 阴影与反光：物体投下方向一致、边缘带柔和过渡的长影子；树冠在街面上投下斑驳的树影；墙根、车底和草丛根部有自然的接触阴影；阳光照在树冠、楼顶和藤蔓的边缘，形成金黄色的亮边；逆光的树叶和草叶透出暖色的光；绿叶下方的墙面和地面带一点绿色的反光。
- 色彩：色彩以通透的翠绿、青苔绿与暖阳金黄为主调，辅以水泥灰白、锈红作为点缀与对比；开场时绿色很少，随着植物生长，绿色逐渐成为主调。
- 对比度与清晰度：画面有完整的明暗层次：最暗的阴影接近黑色但仍能看清细节，最亮的受光面接近白色但不过曝；辉光只出现在水面反光、玻璃碎片等极小的高光点上，范围很小；不能让物体边缘发虚，也不能出现大片光晕；静止的物体在每一帧都完全清晰，运动模糊只出现在被风吹动的叶子和飘落的花瓣上；降噪不能抹掉草叶、叶片、裂缝和锈斑的细节；体积光的噪点要用足够的采样消除，而不是靠强降噪糊掉；近处的贴图要足够清晰，以 100% 尺寸查看时看不出模糊的贴图；渐变背景的颜色要准确：上方是淡天蓝，下方是暖米白，不能被雾染成灰色。
- 镜头成像：整个切块都清晰，不做会让画面显得像玩具模型的移轴浅景深；运动模糊相当于 180° 快门。
- 曝光与清晰度：阳光照亮的部分不过曝成一片白色，阴影里仍能看清材质的细节；画面清晰锐利，没有因降噪过度、贴图精度低或采样不足造成的发糊、涂抹或噪点。

不可改变的内容：全片是一个连续镜头，中间没有剪辑或转场；所有元素都搭建在一个完整的正方形底座上；整个底座始终完整地出现在画面中；生长按“草芽冒出 → 青苔和藤蔓蔓延 → 大树长成 → 开花”的顺序进行，每个阶段连续衔接；生长在开花后停下，之后场景保持最终状态；一阵风从底座一侧吹到另一侧，草丛、树冠和藤蔓按风经过的先后依次摆动；两只蝴蝶从第一帧到最后一帧都在画面中飞；断开的水管从第一帧到最后一帧持续滴水；树冠长成后，阳光穿过叶缝形成丁达尔光束；画面在草木仍在摆动、叶子仍在飘落时结束。

可调整范围：剧本中的尺寸、角度、速度和时间都是参考值，可在保持比例和观感的前提下调整；各段时间点可以微调，但生长的顺序不变。小楼、大树、汽车和路边设施的具体造型，植物的具体种类和分布，蝴蝶的飞行路线，镜头转动的方向，都可以自行设计。

可选增强：爬山虎和藤蔓攀爬时，卷须先探出再缠上；落进水洼的叶子随涟漪轻轻转动；侧壁的土层偶尔有细小的土粒掉落。

禁止：剪辑、转场或跳帧；出现按钮、光标、坐标轴、网格、文字说明等任何 UI 界面元素；出现人物，或出现可读文字和真实品牌的标志；照搬现有电影、游戏或动画中的场景；卡通、三渲二、描边、色阶着色或低多边形等任何风格化效果；看起来像玩具、积木或手工模型；用光滑球体堆成树冠、用圆球当灌木、用圆片当青苔、用排成一行的尖刺当草；崭新、干净、颜色均匀的表面，塑料感的高光；肉眼可辨的重复贴图或重复复制的植物；植被稀疏，底座顶面大片空着；物体比例失调；植物突然出现，而不是生长出来；生长停住后又继续，或生长倒退；光照随生长出现昼夜变化或明暗闪烁；薄雾让画面发灰，或雾气超出切块范围、遮住背景；光束过曝成一片白色，或光束的方向与太阳方向不一致；画面整体发灰、发白，像蒙了一层雾；大团模糊发亮的光柱，或光束挡住小楼和街面；辉光让物体边缘发虚，或出现大片光晕；降噪过度把草叶和细节抹成一片；没有方向感的平光；元素超出底座范围（垂落的树根和藤蔓、飘出的叶子除外）；物体互相穿插或穿过底座，或蝴蝶穿过物体；镜头突然加速、急停或抖动；用停帧或重复片段凑时长；画面闪烁、破面或非设计性的卡顿。

输出规格：16:9，1280×720，30 帧/秒，无声音。最终输出一条完整的动画视频。
```

## 三、类目与标签

**主类目**：场景动画/微缩模型/地块岛屿

**归类理由**：
- 本片的主体是一块有正方形边界、悬浮在空中的街角切块，属于「微缩模型」，分类表的定义是“被呈现为可摆放物件的桌面级小世界（有底座或明确边界）”。画面改成照片级写实后，切块仍有明确的底座边界，归类不变。
- 三级类目中，「地块岛屿」的示例是“方形地块上树木、房屋依次弹出生长”，与本片“正方形切块上植物逐步长满街角”一致。
- 侧壁断面只是切块的边缘细节，画面的重点是顶面的街角，所以不选「场景切片」；场景是荒废的街角，没有在运行的玩具城镇，所以不选「玩具城镇」。
- 分类表规定“无边界的完整城市/建筑→场景动画/城市街景”，本片有明确的切块边界，所以不归「城市街景」。
- 植物生长是整个街角的环境变化，不是对单棵植物的讲解，所以不归「科教演示」。

| 标签组 | 选定标签 | 必要说明 |
|---|---|---|
| 视觉造型 | 写实 | 照片级写实，越逼真越好 |
| 材质质感 | 木石天然、金属 | 水泥、柏油、砖、土层和混凝土为主材质；锈蚀的汽车、钢筋、窗框、灯杆和电线杆为金属。植物和水没有对应的材质标签 |
| 渲染风格 | 真实渲染 |  |
| 动态节奏 | 自然流畅 | 植物生长、风吹、蝴蝶飞行和镜头转动都是平滑连续的 |
| 动画行为 | 主行为：形变与生长/生长展开/植物生长 | 草、青苔、大树从小到大长出，最后开花 |
| 动画行为 | 辅助行为：形变与生长/生长展开/路径延伸 | 爬山虎沿墙面、藤蔓沿红绿灯杆和电线一段段向前爬 |
| 动画行为 | 辅助行为：位移与运动/规律运动/摆动 | 草丛、树冠和藤蔓随风来回摆动 |
| 动画行为 | 辅助行为：物理与特效/流体粒子/粒子 | 被风卷起的树叶和花瓣 |
| 灯光氛围 | 黄昏金色时刻 | 午后低角度的暖阳，符合该标签“低角度暖色斜射光”的定义；光照全片不变，所以不选“灯光动画”。丁达尔光束属于“体积光”，但灯光氛围只能单选，画面的主要光线仍是低角度暖阳 |
| 背景环境 | 纯色渐变 | 淡天蓝到暖米白的渐变背景，没有地面 |
| 色彩基调 | 不填 | 翠绿、青苔绿和暖阳金黄在写实画面里饱和度不高，开场又以灰白和锈色为主，“高饱和明快”“暖色温馨”都不贴切 |
| 时序结构 | 多段序列 | 草芽冒出、青苔和藤蔓蔓延、大树长成、开花、风起按顺序衔接 |
| 复杂度等级 | 物理模拟 | 草丛、枝叶、藤蔓和飘落的叶子都是“≥10 对象群组”；叶子和花瓣适合用粒子实现。剧本不要求真实的物理模拟 |
| 应用场景 | 不填 | 没有明确用途依据 |

蝴蝶绕红绿灯飞行对应“位移与运动/路径运动/绕行”，水管滴水对应“物理与特效/流体粒子/液体”，垂落的藤蔓和电线摆荡对应“物理与特效/柔性运动/毛发绳索”。受动画行为最多 4 个的上限所限，这三项不单独列出。镜头的转动和推近属于镜头运动，不计入动画行为。

## 四、试做验收要点

| 来源 | 要求原文 | 通过时应看到的表现 | 检查位置或方法 |
