# 被自然收回的城市街角动画 · 制作需求

制作时同时提供「一、制作 Prompt」和完整的《被自然收回的城市街角剧本》（见 `被自然收回的城市街角剧本.md`）。「三、类目与标签」和「四、试做验收要点」不属于制作输入。

## 一、制作 Prompt

```text
使用 Blender 5.0.0 制作一条约 12 秒（允许 11–13 秒，不得少于 8 秒）的微缩场景动画，三渲二风格，一镜到底。画面内容、动作和镜头以《被自然收回的城市街角剧本》为准。

核心效果：请制作一个「被自然收回的城市街角」微缩场景，以第三视角观察整个场景，整体像一件摆在桌面上的微缩三维模型 / 小型景观，没有任何 UI 界面元素。地面为一个完整的正方形底座，所有元素都搭建在这个底座上，底座侧壁可见断裂的柏油路面剖面、裸露的混凝土与钢筋、以及从边缘垂落的盘结树根与藤蔓，构图紧凑、层次清晰，整体呈现出小巧、精致、可收藏的模型感。全片用延时生长表现自然收回城市的过程：开场是一个几乎没有绿色的荒废 L 形街角，有龟裂的柏油路、褪色的斑马线和水洼，一栋三层水泥小楼，一辆锈红色的小轿车，歪斜的红绿灯、下垂的电线和褪色的自动售货机。随后裂缝里冒出草芽，青草沿裂缝蔓延，青苔铺满楼顶和车顶，爬山虎爬满一侧外墙，藤蔓缠上红绿灯杆再沿电线垂下；人行道上的小树苗长成一棵大树，树根掀翻地砖，树根和藤蔓从底座边缘垂落；最后野花和引擎盖上的小白花开放，生长停下。结尾一阵风从底座左侧吹到右侧，草丛形成一道绿色波浪，树冠和藤蔓随风摆动，叶子和花瓣被卷起，有几片飘出底座边缘落下。两只淡黄色的小蝴蝶全程在底座上空飞舞，中途落在小白花旁停一下，再绕着红绿灯飞。镜头从左前方绕底座向右缓慢转动约 90°，同时轻微推近，整个底座始终完整地出现在画面中。植物的生长是极度加速的，像压缩了几十年的延时摄影；风、滴水和蝴蝶的运动保持正常速度。

质感要求：
- 整体：画面风格为三渲二，强调浓厚的日式二次元动画氛围，材质干净，轮廓明确，像动画电影里的手绘背景被做成了立体模型。
- 着色：明暗分为 2–3 个色阶，色阶交界清楚，边缘略柔；阴影带青蓝或青绿的色调，不是灰黑色；高光是干净的色块，不是写实的反光。
- 描边：外轮廓有清晰的描边，线条颜色是比物体固有色更深的同色系，不是统一的纯黑；远处和细小的物体线条更细；镜头转动和植物生长时线条粗细稳定，不抖动、不断裂、不闪烁。
- 底座：底座侧壁从上到下依次是断裂的柏油路面、浅灰色的碎石基层和褐色的土层；裸露的混凝土块断面粗糙，锈红色的钢筋从断面伸出、向外弯折；底座下沿是整齐的直边。
- 生长方式：每株植物都是从小到大逐渐长出来的，草从草芽长成草丛，青苔从小块向外铺开，爬山虎和藤蔓沿着墙面、杆子和电线一段段向前爬，大树逐渐长高、变粗、分枝、长出叶簇。
- 树和植被：树叶是一团团的叶簇，每团有亮面、暗面和受光一侧透亮的边，叶簇之间有透光的空隙；最终青草、青苔、蕨类和零星的小野花遍布路面裂缝、人行道、台阶、车顶和楼顶，越靠近大树越茂密。
- 建筑和物件：水泥外墙有雨水流下的痕迹和墙皮剥落的地方，都画成干净的色块；窗框生锈，部分玻璃破碎，卷帘门是锈红色；招牌只有色块，没有文字。
- 蝴蝶：两只淡黄色的小蝴蝶，翅膀一下下扇动，飞行路线忽高忽低，不是直线。
- 构图：最终状态下元素紧凑地布满底座，前低后高，从任何角度看都层次清晰。
- 背景：柔和的渐变背景，上方是淡天蓝色，下方是暖米白色；底座悬浮在画面中央，周围没有地面和其他物体。
- 光影：午后的暖阳从模型的左后方以较低的角度照来，给树冠、楼顶和藤蔓勾出金黄色的亮边；树冠长成后在街面上投下斑驳的树影；天光作为补光，让暗部保持通透的青色；光照全片保持不变，延时生长不表现昼夜交替。
- 色彩：色彩以通透的翠绿、青苔绿与暖阳金黄为主调，辅以水泥灰白、锈红作为点缀与对比；开场时绿色很少，随着植物生长，翠绿和青苔绿逐渐成为主调。
- 渲染：高光处有柔和、轻微的辉光；亮部不过曝成一片白色，暗部仍能看清物体的形状；画面清晰锐利，轮廓线和阴影边缘没有锯齿，也没有因降噪过度或采样不足造成的发糊、涂抹或噪点。

不可改变的内容：全片是一个连续镜头，中间没有剪辑或转场；所有元素都搭建在一个完整的正方形底座上；整个底座始终完整地出现在画面中；生长按“草芽冒出 → 青苔和藤蔓蔓延 → 大树长成 → 开花”的顺序进行，每个阶段连续衔接；生长在开花后停下，之后场景保持最终状态；一阵风从底座一侧吹到另一侧，草丛、树冠和藤蔓按风经过的先后依次摆动；两只蝴蝶从第一帧到最后一帧都在画面中飞；断开的水管从第一帧到最后一帧持续滴水；画面在草木仍在摆动、叶子仍在飘落时结束。

可调整范围：剧本中的尺寸、角度、速度和时间都是参考值，可在保持比例和观感的前提下调整；各段时间点可以微调，但生长的顺序不变。小楼、大树、汽车和路边设施的具体造型，植物的种类和分布，蝴蝶的飞行路线，镜头转动的方向，都可以自行设计。

可选增强：爬山虎和藤蔓攀爬时，卷须先探出再缠上；落进水洼的叶子随涟漪轻轻转动。

禁止：剪辑、转场或跳帧；出现按钮、光标、坐标轴、网格、文字说明等任何 UI 界面元素；出现人物，或出现可读文字和真实品牌的标志；照搬现有动画作品中的场景；照片级写实渲染，或写实的脏污、噪点和颗粒；统一的粗黑描边；植物突然出现，而不是生长出来；生长停住后又继续，或生长倒退；光照随生长出现昼夜变化或明暗闪烁；元素超出底座范围（垂落的树根和藤蔓、飘出的叶子除外）；物体互相穿插或穿过底座，或蝴蝶穿过物体；镜头突然加速、急停或抖动；用停帧或重复片段凑时长；画面闪烁、破面或非设计性的卡顿。

输出规格：16:9，1280×720，30 帧/秒，无声音。最终输出一条完整的动画视频。
```

## 三、类目与标签

**主类目**：场景动画/微缩模型/地块岛屿

**归类理由**：
- 本片的主体是一件有正方形底座的桌面级小场景，属于「微缩模型」，分类表的定义是“被呈现为可摆放物件的桌面级小世界（有底座或明确边界）”。
- 三级类目中，「地块岛屿」的示例是“方形地块上树木、房屋依次弹出生长”，与本片“正方形底座上植物逐步长满街角”一致。
- 底座侧壁的剖面只是模型的边缘细节，画面的重点是底座上方的街角，所以不选「场景切片」；场景是荒废的街角，没有在运行的玩具城镇，所以不选「玩具城镇」。
- 分类表规定“无边界的完整城市/建筑→场景动画/城市街景”，本片有明确的底座边界，所以不归「城市街景」。
- 植物生长是整个街角的环境变化，不是对单棵植物的讲解，所以不归「科教演示」。

| 标签组 | 选定标签 | 必要说明 |
|---|---|---|
| 视觉造型 | 半写实 | 街道、建筑和底座剖面保留真实结构，造型和着色做了二次元风格化；不是夸张比例、圆润造型的“卡通” |
| 材质质感 | 木石天然、金属 | 水泥、柏油、土层和混凝土为主材质；锈蚀的汽车、钢筋、窗框和灯杆为金属。植物和水没有对应的材质标签 |
| 渲染风格 | 平涂描边 | 三渲二：色阶着色加轮廓描边 |
| 动态节奏 | 自然流畅 | 植物生长、风吹、蝴蝶飞行和镜头转动都是平滑连续的 |
| 动画行为 | 主行为：形变与生长/生长展开/植物生长 | 草、青苔、大树从小到大长出，最后开花 |
| 动画行为 | 辅助行为：形变与生长/生长展开/路径延伸 | 爬山虎沿墙面、藤蔓沿红绿灯杆和电线一段段向前爬 |
| 动画行为 | 辅助行为：位移与运动/规律运动/摆动 | 草丛、树冠和藤蔓随风来回摆动 |
| 动画行为 | 辅助行为：物理与特效/流体粒子/粒子 | 被风卷起的树叶和花瓣 |
| 灯光氛围 | 黄昏金色时刻 | 午后低角度的暖阳，符合该标签“低角度暖色斜射光”的定义；光照全片不变，所以不选“灯光动画” |
| 背景环境 | 纯色渐变 | 淡天蓝到暖米白的渐变背景，没有地面 |
| 色彩基调 | 高饱和明快 | 用户要求“通透的翠绿、青苔绿与暖阳金黄”，二次元动画的配色鲜明明快 |
| 时序结构 | 多段序列 | 草芽冒出、青苔和藤蔓蔓延、大树长成、开花、风起按顺序衔接 |
| 复杂度等级 | 物理模拟 | 草丛、叶簇、藤蔓和飘落的叶子都是“≥10 对象群组”；叶子和花瓣适合用粒子实现。剧本不要求真实的物理模拟 |
| 应用场景 | 不填 | “可收藏的模型感”是画面风格，不是明确的用途 |

蝴蝶绕红绿灯飞行对应“位移与运动/路径运动/绕行”，水管滴水对应“物理与特效/流体粒子/液体”，垂落的藤蔓和电线摆荡对应“物理与特效/柔性运动/毛发绳索”。受动画行为最多 4 个的上限所限，这三项不单独列出。镜头的转动和推近属于镜头运动，不计入动画行为。
