## 一、制作 Prompt

```text
使用 Blender 5.0.0 制作一条约 12 秒（允许 11–13 秒，不得少于 8 秒）的微缩场景动画，三渲二风格，一镜到底。画面内容、动作和镜头以《被自然收回的城市街角剧本》为准。

核心效果：请制作一个「被自然收回的城市街角」微缩场景，以第三视角观察整个场景，整体像一个可以自由拖拽、旋转、缩放观看的微缩三维模型 / 小型景观，没有任何 UI 界面元素。地面为一个完整的正方形底座，所有元素都搭建在这个底座上，底座侧壁可见断裂的柏油路面剖面、裸露的混凝土与钢筋、以及从边缘垂落的盘结树根与藤蔓，构图紧凑、层次清晰，整体呈现出小巧、精致、可收藏的模型感。底座上是一个被植物重新占领的 L 形街角：龟裂的柏油路、褪色的斑马线和水洼，一栋爬满爬山虎的三层水泥小楼，一棵从人行道里长出来的大树，一辆长满青草的锈红色小轿车，被藤蔓缠绕的歪斜红绿灯、下垂的电线和褪色的自动售货机。场景本身一直在动：微风中草木轻轻摇晃，断开的水管不停滴水；一阵风从底座左侧吹到右侧，草丛形成一道绿色波浪，树冠、爬山虎、电线和垂落的树根藤蔓依次摆动，叶子和花瓣被卷起，飘落到路面和水洼里，有几片飘出底座边缘落下；之后风势减弱，恢复微风。镜头像有人在拖拽模型观看一样，从左前方绕底座向右缓慢转动约 90°，同时轻微推近，整个底座始终完整地出现在画面中。

质感要求：
- 整体：画面风格为三渲二，强调浓厚的日式二次元动画氛围，材质干净，轮廓明确，像动画电影里的手绘背景被做成了立体模型。
- 着色：明暗分为 2–3 个色阶，色阶交界清楚，边缘略柔；阴影带青蓝或青绿的色调，不是灰黑色；高光是干净的色块，不是写实的反光。
- 描边：外轮廓有清晰的描边，线条颜色是比物体固有色更深的同色系，不是统一的纯黑；远处和细小的物体线条更细；镜头转动时线条粗细稳定，不抖动、不断裂、不闪烁。
- 底座：底座侧壁从上到下依次是断裂的柏油路面、浅灰色的碎石基层和褐色的土层；裸露的混凝土块断面粗糙，锈红色的钢筋从断面伸出、向外弯折；底座下沿是整齐的直边。
- 树和植被：树叶是一团团的叶簇，每团有亮面、暗面和受光一侧透亮的边，叶簇之间有透光的空隙；青草、青苔、蕨类和零星的小野花遍布路面裂缝、人行道、台阶、车顶和楼顶，越靠近大树越茂密。
- 建筑和物件：水泥外墙有雨水流下的痕迹和墙皮剥落的地方，都画成干净的色块；窗框生锈，部分玻璃破碎，卷帘门是锈红色；招牌只有色块，没有文字。
- 构图：元素紧凑地布满底座，前低后高，从任何角度看都层次清晰。
- 背景：柔和的渐变背景，上方是淡天蓝色，下方是暖米白色；底座悬浮在画面中央，周围没有地面和其他物体。
- 光影：午后的暖阳从模型的左后方以较低的角度照来，给树冠、楼顶和藤蔓勾出金黄色的亮边；树冠在街面上投下斑驳的树影；天光作为补光，让暗部保持通透的青色。
- 色彩：色彩以通透的翠绿、青苔绿与暖阳金黄为主调，辅以水泥灰白、锈红作为点缀与对比。
- 渲染：高光处有柔和、轻微的辉光；亮部不过曝成一片白色，暗部仍能看清物体的形状；画面清晰锐利，轮廓线和阴影边缘没有锯齿，也没有因降噪过度或采样不足造成的发糊、涂抹或噪点。

不可改变的内容：全片是一个连续镜头，中间没有剪辑或转场；所有元素都搭建在一个完整的正方形底座上；整个底座始终完整地出现在画面中；风从底座一侧吹到另一侧，草丛、树冠和藤蔓按风经过的先后依次摆动；断开的水管从第一帧到最后一帧持续滴水；场景里的草木从第一帧到最后一帧一直在动；画面在草木仍在摆动、叶子仍在飘落时结束。

可调整范围：剧本中的尺寸、角度、速度和时间都是参考值，可在保持比例和观感的前提下调整；各段时间点可以微调，但“微风 → 起风 → 风过 → 平静”的顺序不变。小楼、大树、汽车和路边设施的具体造型，植物的种类和分布，镜头转动的方向，都可以自行设计。

可选增强：两只淡黄色的小蝴蝶绕着红绿灯飞舞；落进水洼的叶子随涟漪轻轻转动。

禁止：剪辑、转场或跳帧；出现按钮、光标、坐标轴、网格、文字说明等任何 UI 界面元素；出现人物，或出现可读文字和真实品牌的标志；照搬现有动画作品中的场景；照片级写实渲染，或写实的脏污、噪点和颗粒；统一的粗黑描边；元素超出底座范围（垂落的树根和藤蔓、飘出的叶子除外）；整个场景静止不动，只靠镜头运动制造动态；物体互相穿插或穿过底座；镜头突然加速、急停或抖动；用停帧或重复片段凑时长；画面闪烁、破面或非设计性的卡顿。

输出规格：16:9，1280×720，30 帧/秒，无声音。最终输出一条完整的动画视频。
```

## 三、类目与标签

**主类目**：场景动画/微缩模型/地块岛屿

**归类理由**：
- 本片的主体是一件有正方形底座的桌面级小场景，属于「微缩模型」，分类表的定义是“被呈现为可摆放物件的桌面级小世界（有底座或明确边界）”。
- 三级类目中，「地块岛屿」的示例是“方形地块上树木、房屋依次弹出生长”，与本片“正方形底座上的街角、小楼和大树”一致。
- 底座侧壁的剖面只是模型的边缘细节，画面的重点是底座上方的街角，所以不选「场景切片」；场景是一个荒废的街角，没有在运行的玩具城镇，所以不选「玩具城镇」。
- 分类表规定“无边界的完整城市/建筑→场景动画/城市街景”，本片有明确的底座边界，所以不归「城市街景」。

| 标签组 | 选定标签 | 必要说明 |
|---|---|---|
| 视觉造型 | 半写实 | 街道、建筑和底座剖面保留真实结构，造型和着色做了二次元风格化；不是夸张比例、圆润造型的“卡通” |
| 材质质感 | 木石天然、金属 | 水泥、柏油、土层和混凝土为主材质；锈蚀的汽车、钢筋、窗框和灯杆为金属。植物和水没有对应的材质标签 |
| 渲染风格 | 平涂描边 | 三渲二：色阶着色加轮廓描边 |
| 动态节奏 | 自然流畅 | 风吹草木、叶子飘落和镜头转动都是平滑连续的 |
| 动画行为 | 主行为：位移与运动/规律运动/摆动 | 草丛、树冠、爬山虎和野花随风来回摆动 |
| 动画行为 | 辅助行为：物理与特效/柔性运动/毛发绳索 | 垂落的树根、藤蔓和下垂的电线摆荡 |
| 动画行为 | 辅助行为：物理与特效/流体粒子/粒子 | 飘落的树叶、花瓣和蒲公英绒毛 |
| 动画行为 | 辅助行为：物理与特效/流体粒子/液体 | 断开的水管滴水，水洼起涟漪 |
| 灯光氛围 | 黄昏金色时刻 | 午后低角度的暖阳，符合该标签“低角度暖色斜射光”的定义 |
| 背景环境 | 纯色渐变 | 淡天蓝到暖米白的渐变背景，没有地面 |
| 色彩基调 | 高饱和明快 | 用户要求“通透的翠绿、青苔绿与暖阳金黄”，二次元动画的配色鲜明明快 |
| 时序结构 | 并行多事件 | 风吹草木、叶子飘落、水管滴水同时发生；“微风 → 起风 → 风过 → 平静”是风的强弱变化，不是不同主体的动作先后衔接，所以不选“多段序列” |
| 复杂度等级 | 物理模拟 | 草丛、叶簇和飘落的叶子都是“≥10 对象群组”；叶子和水滴适合用粒子实现。剧本不要求真实的物理模拟 |
| 应用场景 | 不填 | “可收藏的模型感”是画面风格，不是明确的用途 |

起风和平静对应风的强弱变化，没有单独的行为标签；镜头的转动和推近属于镜头运动，不计入动画行为。
