# 赛博朋克断桥飞离动画 · 制作需求

制作时同时提供「一、制作 Prompt」和完整的《赛博朋克断桥飞离剧本》（见 `赛博朋克断桥飞离剧本.md`）。「三、类目与标签」和「四、试做验收要点」不属于制作输入。

## 一、制作 Prompt

```text
使用 Blender 5.0.0 制作一条约 12 秒（允许 11–13 秒，不得少于 8 秒）的赛博朋克飞车动画，写实渲染风格，一镜到底。画面内容、动作和镜头以《赛博朋克断桥飞离剧本》为准。

核心效果：雨夜的未来城市里，一辆深石墨色的跑车在两排高楼之间的高架快速路上疾驰，两辆闪着红蓝警灯的警车紧追在后。前方的桥面已经断开，警车急刹，在断口前斜停；跑车加速冲出断口，腾空后开始下坠，并在空中变形：四个车轮翻转成水平朝下的涵道推进器，车身两侧伸出短翼，尾翼分开立成两片尾鳍。推进器点燃，止住下坠，飞行器抬头拉升，飞进楼群远去。镜头先在跑车前方回头跟拍追击，然后升高转向前方，越过警车冲出断口，跟着飞行器向下俯冲，最后平飞减速，目送飞行器远去。

质感要求：
- 整体：以接近电影实拍加视效的质感为目标，车辆、桥面和城市都按真实的结构和材质来做。
- 逃逸车：低趴双门跑车，深石墨色哑光漆，表面挂着雨珠并映出周围的霓虹；车头是白色灯带，车尾是红色灯带，两侧有细窄的青色灯带；车窗是深色的，看不到车内。
- 变形：每个部件都沿着铰链转动或沿着滑轨伸出，能看出它从车身的哪个位置展开；部件有真实的厚度和内部结构，不是薄片。
- 警车：深蓝色和白色相间的涂装，没有文字和标志；车顶警灯红蓝交替闪烁，把红光和蓝光投到湿路面、护栏和逃逸车上。
- 场景：桥面是湿透的沥青，有积水和反光；断口处的混凝土碎裂，钢筋外露，电缆垂下，边缘有闪烁的琥珀色警示灯；两侧高楼布满霓虹招牌、窗光和外挂管线，远处的楼体在雨雾中越来越淡。
- 运动：车辆的加速、刹车、腾空和下坠都有惯性和重量感；车轮在路面上转动，轮胎在积水上卷起水雾和水花。
- 光影：光源全部来自城市和车辆本身；主色是品红和青色，夹着警灯的红蓝光和警示灯的琥珀色光；车灯和霓虹在雨雾中形成光晕和光柱。
- 渲染：开启运动模糊；霓虹和推进器的亮部不过曝成一片白色，暗处的车身和桥体结构仍能看清；画面清晰锐利，没有因降噪过度、贴图精度低或采样不足造成的发糊、涂抹或噪点。

不可改变的内容：全片是一个连续镜头，中间没有剪辑或转场；动作按“追击 → 断桥 → 变形 → 飞走”的顺序进行；警车在断口前停住，没有冲出断口；逃逸车冲出断口后先下坠，推进器点燃后才止住下坠；变形按“车轮翻转 → 短翼伸出和尾鳍立起 → 推进器点燃”的顺序进行；变形过程完整地出现在画面中；雨从第一帧持续到最后一帧；画面在飞行器仍在加速远去时结束。

可调整范围：剧本中的尺寸、距离、速度和时间都是参考值，可在保持比例和观感的前提下调整；各段时间点可以微调，但段落顺序和变形顺序不变。车辆的具体造型、变形部件的具体结构、城市楼体和招牌的样式、镜头的具体路线，都可以自行设计。

可选增强：断口垂下的电缆偶尔迸出火花；推进器点燃时，气流把下方楼面上的雨水吹成一圈水雾。

禁止：剪辑、转场或跳帧；出现人物，或能看到车内；出现可读文字或真实品牌的标志；照搬现有电影、游戏或真实车型的造型；发生碰撞、爆炸或开火；车辆像没有重量一样飘，或腾空后不下坠；变形部件凭空出现、瞬移或互相穿插；车轮在行驶时不转动；所有表面都是干的、没有反射；明显的建模感，如光滑无细节的大块表面、塑料感的高光、肉眼可辨的重复贴图；镜头突然加速、急停或抖动；用停帧或重复片段凑时长；画面闪烁（设计的警灯、警示灯和霓虹闪烁除外）、破面或非设计性的卡顿。

输出规格：16:9，1280×720，30 帧/秒，无声音。最终输出一条完整的动画视频。
```

## 三、类目与标签

**主类目**：载具动画/幻想载具/变形载具

**归类理由**：
- 本片的主体是一辆被追击的车，高潮是它在空中变形为飞行器，与分类表中「变形载具」的示例“汽车变形展开为飞行器”一致。
- 分类表规定“交通工具一律归载具”。逃逸车最终变成虚构的飞行器，属于虚构载具，所以归「幻想载具」，不归「陆地载具/乘用车」。
- 城市和高架只是追击发生的环境，表达重点是车辆的追逃和变形，所以不归「场景动画/城市街景/夜景霓虹」。

| 标签组 | 选定标签 | 必要说明 |
|---|---|---|
| 视觉造型 | 写实 | |
| 材质质感 | 金属（主材质）、自发光 | 逃逸车、警车和变形部件为金属；霓虹、车灯、警灯和推进器为自发光。湿路面和积水面积较大，但没有对应的材质标签 |

| 复杂度等级 | 物理模拟 | 雨和水雾需要粒子系统；三辆车、变形部件和城市构件属于“≥10 对象群组”。剧本不要求真实的物理模拟 |

腾空后的下坠对应“物理与特效/刚体运动/掉落”，警灯、警示灯和推进器点亮对应“显隐与外观变化/材质变化/发光亮灭”。受动画行为最多 4 个的上限所限，这两项不单独列出。
