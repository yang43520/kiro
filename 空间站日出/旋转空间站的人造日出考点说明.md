# 旋转空间站的人造日出考点说明

> 内部校验用，不交给制作方，不属于制作输入。

**主类目**：场景动画/幻想世界/科幻空间

**题目档位**：上限档（配方：单个 L4，附带 1 个 L2 和 2 个 L1）

**档位来源**：默认

**规范版本**：进阶版 1.3

**视觉基调**：科幻未来

**耦合链**：同一座旋转的空间站里，人造日出的灯带从远到近一节节亮起、照亮大地；灯带亮到头顶以后，喷灌阵列顺着旋转方向一根接一根开喷；同一个旋转让每道水柱受科里奥利力往旋转方向偏、弯成不对称的弧、落在喷头右边约 6.5 米，再打碎成水雾，被逆光照亮。

| 编号 | 考点 | 分级 | 作用对象与时段 | 在片中的体现 |
|---|---|---|---|---|
| 13 | 破碎崩解与离散粒子 | L4 | 喷灌水柱的水珠和水雾，4.5–12 秒 | 水珠以约每秒 17 米喷出、升到约 14 米，受离心力和科里奥利力弯成往右倒的不对称弧，约 3.3 秒落在喷头右边约 6.5 米，落地打碎成水雾慢慢飘落 |
| 14 | 集群协同与波浪相位差 | L2 | 40 节灯带和约 20 根喷灌立管，2–7.5 秒 | 灯带从远到近约每秒 3 公里依次亮起，照亮大地的亮光跟着扫过来；喷灌从左到右间隔约 0.15 秒依次开喷 |
| 16 | 光影流转与材质外观演变 | L1 | 大地、状态灯和水雾，全片 | 大地从暗到亮，状态灯由琥珀变绿，水雾在逆光里发亮 |
| 17 | 单镜头运镜构图 | L1 | 镜头，全片 | 一镜到底：中心构图特写 → 引导线 → 三分法 → 对角线 → 对称 |

**最高分级**：L4

## 制作底线清单

**二级类目**：幻想世界

**技术模块**：T1、T4、T10

**本片要用的专业术语**：高度图地形、置换修改器、多重分辨率细分、坡度遮罩、三平面投影贴图、空气透视、体积散射、体积云、VDB 体积、银边、自发光、自发光强度、光度单位、辉光阈值、几何节点散布、叶片次表面散射

**推荐插件**：A.N.T. Landscape（内置）、几何节点（内置）、Bloom 辉光（内置）

**通用底线**：PBR 贴图或程序化纹理（近景 4K）、倒角、接触阴影、AgX 色彩管理（Base Contrast）、足够采样、100% 查看细节、尺度参照（灌溉立管、农舍）、防重复

**重模拟**：无（水柱和水雾用粒子系统加几何节点的模拟区域，云用几何节点生成的体积）

## 类目与标签

**归类理由**：主体是一座虚构的旋转圆柱形空间站的内部世界和它的人造日出，属于幻想世界里的科幻空间。

| 标签组 | 选定标签 | 必要说明 |
|---|---|---|
| 视觉造型 | 写实 | 照片级写实的硬科幻 |
| 材质质感 | 木石天然、液体冰晶、金属 | 主材质是土地、作物和农田；其次是水柱和水雾，以及喷头和端壁的金属 |
| 渲染风格 | 真实渲染 | 常规物理渲染 |
| 动态节奏 | 自然流畅 | 灯带、喷灌和小车都平滑推进 |
| 动画行为 | 主行为：物理与特效/流体粒子/粒子 | 水柱的水珠弯着落下、打碎成水雾 |
| 动画行为 | 辅助行为：显隐与外观变化/材质变化/发光亮灭 | 灯带一节节亮起，状态灯变色 |
| 动画行为 | 辅助行为：位移与运动/路径运动/沿线移动 | 小车沿弯曲的轨道爬坡 |
| 灯光氛围 | 灯光动画 | 人造日出让光从远到近平滑扫过整片大地 |
| 背景环境 | 完整场景 | 圆柱形的大地、中轴和端壁完整搭建 |
| 色彩基调 | 冷色科技 | 冷青白和青绿为主，只有一点琥珀色 |
| 时序结构 | 多段序列 | 夜 → 日出 → 喷灌 → 小车 → 圆柱世界 |
| 复杂度等级 | 多元编排 | 几何节点模拟区域、粒子、自发光和路径编排 |
| 应用场景 | 不填 | 没有明确的用途依据 |
