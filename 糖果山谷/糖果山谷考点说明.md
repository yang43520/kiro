# 糖果山谷考点说明

> 内部校验用，不交给制作方，不属于制作输入。

**主类目**：场景动画/幻想世界/魔法场景

**题目档位**：上限档（配方：单个 L4，附带 1 个 L2 和 1 个 L1）

**档位来源**：默认

**耦合链**：同一颗彩虹硬糖球从山顶滚下，在软糖霜上压出越滚越深的槽，撞开路线上的软糖、彼此不穿透，再砸进果冻湖激起一圈圈晃动；晃动传到糖桥，把糖粉一段段震落，露出的硬糖被阳光照透，把彩色的光投到地上。

| 编号 | 考点 | 分级 | 作用对象与时段 | 在片中的体现 |
|---|---|---|---|---|
| 15 | 接触留痕与表面动态反馈 | L4 | 糖球滚过的糖霜坡和果冻湖，2–12 秒 | 糖霜上留下由浅变深、由窄变宽的槽，槽边隆起、留有彩色印子；果冻落点凹坑和一圈圈反弹叠加的波纹，结尾仍在轻晃 |
| 10 | 体积碰撞与边界阻挡｜真实轮廓接触与防穿模 | L2 | 糖球和约 40 颗软糖滴，4.5–10 秒 | 糖球撞开软糖，软糖倒下、滚动、叠在一起，都不互相穿透、不陷进地面、不隔空弹开 |
| 16 | 光影流转与材质外观演变 | L1 | 彩虹硬糖桥，10–12 秒 | 糖粉从桥脚那段开始一段段震落，发白的糖桥变成透亮的硬糖，地上出现彩色光斑 |

**最高分级**：L4

## 制作底线清单

**二级类目**：幻想世界

**技术模块**：T1、T4、T10

**本片要用的专业术语**：高度图地形、雕刻、置换修改器、多重分辨率细分、三平面投影贴图、坡度遮罩、空气透视、VDB 体积、体积云、体积散射、银边、物理天空、辉光（Bloom）阈值、动态绘画、刚体模拟、晶格、形态键、焦散阴影

**推荐插件**：几何节点（内置）、A.N.T. Landscape（内置）、物理天空纹理（内置）、Bloom 辉光（内置）

**通用底线**：PBR 贴图或程序化纹理（近景 4K）、倒角、接触阴影、AgX 色彩管理（Punchy 观感）、足够采样、100% 查看细节、尺度参照（软糖滴、糖针）、防重复

**重模拟**：刚体模拟（只用在糖球和约 40 颗软糖上）

## 类目与标签

**归类理由**：主体是一座全部由糖果组成的童话山谷，现实中不存在，属于幻想世界里的魔法场景。

| 标签组 | 选定标签 | 必要说明 |
|---|---|---|
| 视觉造型 | 写实 | 真实尺寸的糖果，照片级微距质感 |
| 材质质感 | 玻璃透明、塑料橡胶、木石天然 | 主材质是透亮的硬糖和果冻；其次是软糖，以及饼干和巧克力 |
| 渲染风格 | 真实渲染 | 常规物理渲染 |
| 动态节奏 | 自然流畅 | 糖球滚动和果冻晃动符合真实物理 |
| 动画行为 | 主行为：物理与特效/刚体运动/滚动 | 糖球滚下山坡、穿过软糖林 |
| 动画行为 | 辅助行为：物理与特效/刚体运动/碰撞弹跳 | 软糖被撞开、倒下、滚动 |
| 动画行为 | 辅助行为：物理与特效/柔性运动/软体 | 软糖和果冻湖的晃动 |
| 动画行为 | 辅助行为：显隐与外观变化/材质变化/透明度 | 糖桥的糖粉震落、硬糖变透亮 |
| 灯光氛围 | 自然日光 | 晴天下午的阳光和天光 |
| 背景环境 | 完整场景 | 糖霜山、软糖林、果冻湖和糖桥完整搭建 |
| 色彩基调 | 高饱和明快 | 彩虹色硬糖、软糖和蓝绿色果冻 |
| 时序结构 | 多段序列 | 焦糖拉丝 → 滚下糖霜坡 → 撞开软糖林 → 砸进果冻湖 → 彩虹桥亮起 |
| 复杂度等级 | 物理模拟 | 含刚体模拟 |
| 应用场景 | 不填 | 没有明确的用途依据 |
