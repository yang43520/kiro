# 海边小镇的飞艇启航考点说明

> 内部校验用，不交给制作方，不属于制作输入。

**主类目**：载具动画/幻想载具/魔法飞行器

**题目档位**：上限档（配方：单个 L4，附带 1 个 L2 和 1 个 L1）

**档位来源**：默认

**耦合链**：同一艘飞艇上，铜钟荡起后系留缆依次解开、垂荡并被绞盘收回；螺旋桨起转后飞艇沿弧线绕过钟楼、掠过屋顶，跟着飞艇移动的螺旋桨风按经过的先后吹动衣物、旗子和海鸥；镜头在露台上跟着飞艇从码头转向海面。

| 编号 | 考点 | 分级 | 作用对象与时段 | 在片中的体现 |
|---|---|---|---|---|
| 12 | 薄面垂坠与绳索悬挂 | L4 | 系留缆、床单、衣物、三角旗，0.8–12 秒 | 缆绳解开后松垂成悬链线、被风甩成波浪、被绞盘收回；床单衬衫被风鼓起翻卷、夹子弹开后衬衫挂在绳上飘；风过后慢慢落回 |
| 3 | 复杂轨迹与姿态自适应 | L2 | 飞艇，2–12 秒 | 离开码头后升高并转向，以约 40 米半径绕钟楼时向弯里侧倾约 8°，掠过屋顶后在海面上空回正，速度从 2 米/秒平滑加到 12 米/秒 |
| 17 | 单镜头运镜构图 | L1 | 镜头，0–12 秒 | 从露台朝码头看，跟着飞艇往右转到海面，飞艇掠过头顶时不出画，结尾约占画面宽度三成多，无剪辑 |

**最高分级**：L4

## 类目与标签

**归类理由**：主体是一艘原创的鱼形飞艇，自己解缆、起飞、转弯和航行，属于幻想载具里的魔法飞行器。

| 标签组 | 选定标签 | 必要说明 |
|---|---|---|
| 视觉造型 | 半写实 | 立体造型和光影，材质是手绘质感 |
| 材质质感 | 织物皮革、木石天然、金属 | 主材质是帆布气囊和晾晒的布；其次是木吊舱、石墙红瓦，以及铜钟和铜绞盘 |
| 渲染风格 | 真实渲染 | 物理渲染加手绘质感的程序化纹理 |
| 动态节奏 | 自然流畅 | 飞艇起飞、转弯和布的翻飞都轻快自然 |
| 动画行为 | 主行为：位移与运动/路径运动/沿线移动 | 飞艇沿路线起飞、绕塔、出海 |
| 动画行为 | 辅助行为：物理与特效/柔性运动/布料 | 床单、衣物和旗子被风吹动 |
| 动画行为 | 辅助行为：物理与特效/柔性运动/毛发绳索 | 系留缆垂荡和收回 |
| 动画行为 | 辅助行为：位移与运动/规律运动/旋转 | 螺旋桨和绞盘转动 |
| 灯光氛围 | 自然日光 | 夏天午后的阳光加天光 |
| 背景环境 | 完整场景 | 山坡小镇、钟楼、港口和海面完整搭建 |
| 色彩基调 | 高饱和明快 | 明亮通透的蓝天、白墙、红瓦和蓝绿色海面 |
| 时序结构 | 多段序列 | 钟响解缆 → 螺旋桨起转 → 绕过钟楼 → 掠过屋顶 → 驶向海面 |
| 复杂度等级 | 物理模拟 | 含布料和柔体模拟 |
| 应用场景 | 不填 | 没有明确的用途依据 |
