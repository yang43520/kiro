# 立体书里的城市考点说明

> 内部校验用，不交给制作方，不属于制作输入。

**主类目**：场景动画/微缩模型/场景切片

**题目档位**：上限档（配方：单个 L4，附带 1 个 L2 和 1 个 L1）

**档位来源**：默认

**耦合链**：同一本立体书上，窗外的风翻开书页，书页张开的角度通过 V 形折和平行折机关驱动纸结构一层层立起；书页完全摊平时拉直底下的纸拉条，带动纸转盘让纸火车绕城转；台灯光在立起的纸房子之间投下层层影子。

| 编号 | 考点 | 分级 | 作用对象与时段 | 在片中的体现 |
|---|---|---|---|---|
| 12 | 薄面垂坠与绳索悬挂 | L4 | 封面、书页和纸片，0.5–12 秒 | 封面和书页被风翻动时弯成弧、翻过后一弹；纸结构沿折痕弯折、展开，折痕锐利、平面平整；托云月的纸条弯起摇晃 |
| 9 | 结构爆炸拆解与渐进式生长建造 | L2 | 纸城市，2–9 秒 | 按河和桥 → 房子和树 → 钟楼 → 云和月亮的顺序随书页张开一层层立起，立到底时轻轻一顿 |
| 16 | 光影流转与材质外观演变 | L1 | 纸房子和书页，4.5–12 秒 | 立起的纸结构在台灯下投出层层影子，薄纸被照透透出颜色，纸月亮被冷光勾出亮边 |

**最高分级**：L4

## 制作底线清单

**二级类目**：微缩模型

**技术模块**：T1、T2、T5（另用 T8 的布料做法）

**本片要用的专业术语**：移轴景深、实例化散布、模块化建模、阵列修改器、斜切倒角、几何节点实例化、分枝生成、随机旋转与缩放、风力场、半透明背光、次表面散射、布料模拟、驱动器、父子级绑定、约束、路径跟随、IES 灯光、光度单位、曲率遮罩、环境光遮蔽

**推荐插件**：几何节点（内置）、Building Tools（开源）

**通用底线**：PBR 贴图或程序化纹理（近景 4K）、倒角、接触阴影、AgX 色彩管理、足够采样、100% 查看细节、尺度参照（铅笔、剪刀）、防重复

**重模拟**：布料模拟（只用在被风翻动的封面、书页和窗帘上）

## 类目与标签

**归类理由**：主体是一本立体书和书页上立起的一座纸做的微缩城市，属于微缩模型里的场景切片。

| 标签组 | 选定标签 | 必要说明 |
|---|---|---|
| 视觉造型 | 写实 | 照片级写实的纸和书桌 |
| 材质质感 | 纸艺、织物皮革、木石天然 | 主材质是立体书的纸；其次是布面封面，以及胡桃木书桌 |
| 渲染风格 | 真实渲染 | 常规物理渲染 |
| 动态节奏 | 自然流畅 | 书页翻开和纸结构立起都平滑 |
| 动画行为 | 主行为：结构与装配/开合联动/折叠展开 | 纸结构沿折痕立起 |
| 动画行为 | 辅助行为：物理与特效/柔性运动/布料 | 书页和窗帘被风吹动 |
| 动画行为 | 辅助行为：位移与运动/路径运动/沿线移动 | 纸火车沿轨道绕城 |
| 动画行为 | 辅助行为：结构与装配/开合联动/机械传动 | 拉条带动纸转盘 |
| 灯光氛围 | 低调暗黑 | 深夜书房，台灯局部照亮 |
| 背景环境 | 完整场景 | 书桌、书架、窗和台灯完整搭建 |
| 色彩基调 | 暖色温馨 | 台灯暖黄色为主 |
| 时序结构 | 多段序列 | 风翻书页 → 河与桥 → 城市立起 → 云月升起 → 纸城夜色 |
| 复杂度等级 | 物理模拟 | 含布料模拟 |
| 应用场景 | 不填 | 没有明确的用途依据 |
