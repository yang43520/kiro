# 赛博朋克垂直城寨考点说明

> 内部校验用，不交给制作方，不属于制作输入。

**主类目**：场景动画/城市街景/夜景霓虹

**题目档位**：上限档（配方：单个 L4，附带 1 个 L2 和 2 个 L1）

**档位来源**：默认

**规范版本**：进阶版 1.2

**视觉基调**：夜景都市

**耦合链**：同一口天井里，下了一夜的雨一路落到底，在每层铁皮雨棚里攒成一汪水；单轨列车车轮压过桥上的接缝，桥一震，桥下第一层雨棚把兜着的水翻倒下去，水帘砸中下一层，下一层也一沉一翻，一层接一层往下传，最后一道水帘砸进井底积水，揉碎整口天井的倒影。

| 编号 | 考点 | 分级 | 作用对象与时段 | 在片中的体现 |
|---|---|---|---|---|
| 13 | 破碎崩解与离散粒子 | L4 | 一百二十米深天井里的雨和水，0–12 秒 | 雨滴按重力一路落到底，打在雨棚上溅出更小的水点，在卷边攒成水珠坠落；水帘边缘散成水点；落进积水打出涟漪和水花 |
| 14 | 集群协同与波浪相位差 | L2 | 天井四壁一层层的铁皮雨棚，5.5–12 秒 | 桥下第一层先翻倒，水帘约 1 秒落到下一层，下一层一沉一翻再倒，一层追一层往下传，每层翻倒的快慢和水量各不相同 |
| 16 | 光影流转与材质外观演变 | L1 | 整口天井的光，4.5–12 秒 | 车头灯把整口井扫亮一下；每道水帘被旁边的霓虹染成青蓝或洋红；结尾积水把整口井的光倒过来 |
| 17 | 单镜头运镜构图 | L1 | 镜头，全片 | 一镜到底且全程不停：中心构图 → 引导线 → 对角线 → 三分法特写 → 对称倒影 |

**最高分级**：L4

## 制作底线清单

**二级类目**：城市街景

**技术模块**：T5、T10（另用 T6 的硬表面做法、T8 的布料做法、T9 的粒子和约束做法）

**本片要用的专业术语**：程序化楼群、几何节点实例化、路径跟随、湿表面反射、自发光、体积光、模块化建模、斜切倒角、返潮遮罩、雨水流痕、顶点颜色混合、贴花、硬表面建模、倒角修改器、加权法线、骨骼约束、铰链约束、弹簧约束、布料模拟、钉固顶点组、自碰撞、悬链线、曲线挤出、粒子系统、风力场、动态绘画、曲率遮罩、环境光遮蔽、薄膜干涉、体积散射、灯光树

**推荐插件**：Building Tools（开源）、几何节点（内置）、Bloom 辉光（内置）

**通用底线**：PBR 贴图或程序化纹理（近景 4K）、倒角、接触阴影、AgX 色彩管理（Base Contrast）、足够采样、100% 查看细节、尺度参照（窗户、防盗网、空调外机）、防重复

**重模拟**：布料模拟（只用在桥边的两块防水油布上）

## 类目与标签

**归类理由**：主体是一座挂满霓虹的赛博朋克城寨和它中间的深天井，镜头在雨夜里从楼顶一路下坠到井底，属于城市街景里的夜景霓虹。

| 标签组 | 选定标签 | 必要说明 |
|---|---|---|
| 视觉造型 | 写实 | 照片级写实的下坠穿行镜头 |
| 材质质感 | 金属、自发光、液体冰晶 | 主材质是镀锌铁皮的白锈红锈、铝散热片和列车；其次是霓虹灯管的玻璃和荧光粉，以及雨、水帘和带油膜的积水 |
| 渲染风格 | 真实渲染 | 常规物理渲染 |
| 动态节奏 | 自然流畅 | 下坠有加减速，雨、列车和水帘的接力连贯 |
| 动画行为 | 主行为：物理与特效/流体粒子/粒子 | 一路落到底的雨、溅点、水珠和水帘 |

| 色彩基调 | 冷色科技 | 青蓝和洋红为主 |
| 时序结构 | 多段序列 | 楼顶的缝 → 坠进线网 → 列车过桥 → 擦过猫形招牌 → 井底 |
