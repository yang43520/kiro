# 废墟巨人苏醒动画 · 制作需求

制作时同时提供「一、制作 Prompt」和完整的《废墟巨人苏醒剧本》（见 `废墟巨人苏醒剧本.md`）。「三、类目与标签」和「四、试做验收要点」不属于制作输入。

## 一、制作 Prompt

```text
使用 Blender 5.0.0 制作一条约 12 秒（允许 11–13 秒，不得少于 8 秒）的巨型机体苏醒动画，照片级写实渲染，一镜到底。画面内容、动作和镜头以《废墟巨人苏醒剧本》为准。

核心效果：黄昏时分，一座被水淹没多年的废城里，一台高约 40 米、锈迹斑斑的原创人造巨人单膝跪在浅水中，头部低垂，十几只白鹭停在它的肩上。它带有 EVA 式的风格：细长的人形比例、生物与机械混合的装甲、背后垂着一根断开的粗电缆。眼部灯组闪两下后亮起琥珀色的光，机体一震，水面荡开同心波纹，锈屑和锈皮从装甲上落下，白鹭受惊飞起。巨人缓慢抬头，右手撑进水里，然后撑起身体站起来，水从大腿、腰部和手臂上成片倾泻而下，周围的水面被推出一圈圈波浪。镜头从巨人左前方贴近水面的位置开始，缓慢后退、上升，结束时以仰视角度拍下站直的巨人，夕阳从它的右肩后方照出一圈亮边。

质感要求：
- 整体：画面像用电影摄影机在真实的黄昏实拍、再加视效，任意暂停一帧都应该像一张电影剧照；所有物体按真实尺寸和真实材质制作。
- 重量感：巨人的动作符合它的体量，每个动作都缓慢、沉重、带惯性，不能像人一样轻快。
- 机体结构：外层是一块块弧形的装甲板，贴着身体的肌肉轮廓；关节处露出深色的、像肌腱一样的成束结构和液压缸；头部窄长，没有角，正面有一条横向的护目镜缝；颈后有一个圆形的驾驶舱舱口。
- 锈迹分层：最外层是褪色、发白、粉化的旧漆；漆层破损处露出灰色的底漆；再往下是橙色的新锈和深褐色、层层剥落的厚锈，局部锈穿成孔洞。
- 锈迹细节：漆面下方的锈把漆顶起，形成一个个鼓包和裂开的漆皮；金属表面有密集的锈蚀麻点；锈水从装甲接缝、螺栓和边缘向下流，沿重力方向留下一道道橙褐色的竖向锈痕。
- 锈迹分布：接缝、凹处、朝上的平面和水位线以下最重，凸起和被雨水冲刷的平面较轻；不能是整体均匀的一层锈色。
- 风化痕迹：齐腰高的位置有一圈旧水位线，线以下颜色更深，挂着干掉的泥浆、白色的矿物结晶和黄绿色的藻痕；装甲的凹槽和接缝里积着泥土，长着青苔和地衣；经常被摩擦的边缘和棱角磨掉了漆和锈，露出发亮的金属。
- 干湿：湿的部位颜色更深、更有光泽；干的部位是哑光的；水位线以下和刚被水淋过的地方是湿的。
- 场景：半浸在水中的废弃楼房墙面开裂、窗户空洞，楼顶长着杂草和小树；一座倒塌的高压电塔斜插在水里；水面上漂着零星的碎木和塑料浮渣。
- 高光反光：湿的装甲、磨亮的金属边缘和水面上，有夕阳形成的明亮高光；巨人和镜头之间的水面上，有一条从远处延伸到近处的夕阳反光带；高光跟着视角和巨人的动作移动，不是画死在贴图上的。
- 二次反光：夕阳照在水面上再反射上去，照亮巨人装甲的底面、下巴和手臂内侧，这些部位带着暖色的反光，以及随水波晃动的波光纹理；天空的灰蓝色光照在朝上的平面上；相邻装甲板之间互相反射，凹进去的地方能看到旁边装甲映出的暖色；锈红色的装甲把一点橙红色的光反射到旁边的电缆和关节上。
- 眼部灯光：眼部灯亮起后，琥珀色的光照亮护目镜周围的装甲和下方的水面，水面上映出它的倒影。
- 暗部：背光面不是一片死黑，靠天光和二次反光仍能看清锈迹的细节。
- 水：水面清楚地倒映巨人、楼房和天空，波纹会打碎倒影；倾泻的水流形成水帘和水流，在水面砸出白色的水花。
- 曝光与清晰度：夕阳的高光和反光带不过曝成大片白色；画面清晰锐利，锈迹、漆皮和麻点的细节都能看清，没有因降噪过度、贴图精度低或采样不足造成的发糊、涂抹或噪点。
- 空气与辉光：画面中没有雾，也不加大片的辉光；只有夕阳附近和眼部灯周围有轻微、自然的光晕。
- 镜头成像：远处的楼群略虚，巨人始终清晰；运动模糊相当于 180° 快门。

不可改变的内容：全片是一个连续镜头，中间没有剪辑或转场；动作按“沉睡 → 苏醒 → 抬头 → 站起”的顺序进行；眼部灯先闪两下再稳定亮起；巨人的每个动作都缓慢、沉重；苏醒时水面荡开同心波纹，锈屑和锈皮从装甲上落下；巨人站起时水从身上成片倾泻而下；巨人始终完整地位于画面中；画面在巨人身上仍在淌水、水面仍在波动时结束。

可调整范围：剧本中的尺寸、距离、速度和时间都是参考值，可在保持比例和观感的前提下调整；各段时间点可以微调，但动作的顺序不变。巨人装甲的具体造型和分块、废城楼房的样式、白鹭的数量和飞行路线、镜头的具体路线，都可以自行设计。

可选增强：站起时，水底的淤泥被搅起，巨人脚边的水变得浑浊；倾泻的水流打在下方的装甲上，再溅开成细碎的水花。

禁止：剪辑、转场或跳帧；照搬任何现有动画、电影或游戏中的机体造型、配色或标志，包括原作 EVA 各机体的头部造型和涂装；出现人物，或出现可读文字和真实品牌的标志；卡通、三渲二或描边等风格化效果；看起来像玩具或手办；巨人动作轻快、像人一样灵活，或没有重量感；锈迹是整体均匀的一层颜色，或像贴上去的重复贴图；崭新、干净的表面，塑料感的高光；高光画死在贴图上，不随视角移动；背光面黑成一片；水面没有倒影，或倒影不随波纹变化；出现雾或大片的辉光；巨人被画面边缘裁掉；物体互相穿插，或水流穿过机体；镜头突然加速、急停或抖动；用停帧或重复片段凑时长；画面闪烁（设计的眼部灯闪烁除外）、破面或非设计性的卡顿。

输出规格：16:9，1280×720，30 帧/秒，无声音。最终输出一条完整的动画视频。
```

## 三、类目与标签

**主类目**：载具动画/幻想载具/机甲

**归类理由**：
- 本片的主体是一台带驾驶舱舱口的大型虚构机体。分类表规定“大型可驾驶机甲→载具动画/幻想载具”，「机甲」在幻想载具的纳入范围内。
- 角色动画/幻想生物的归属边界写明“写实龙、兽人等依赖复杂骨骼绑定的造型→不纳入”，本片巨人是写实风格、需要复杂绑定，而且是被驾驶的机体，所以不归角色动画。
- 废城只是巨人所在的环境，表达重点是巨人的苏醒和站起，所以不归「场景动画」。

| 标签组 | 选定标签 | 必要说明 |
|---|---|---|
| 视觉造型 | 写实 | 照片级写实 |
| 材质质感 | 金属（主材质）、液体冰晶、自发光 | 锈蚀的装甲和电缆为金属；浅水、倒影和倾泻的水流为液体；眼部灯组为自发光。废城楼房的混凝土受数量上限所限不单独列出 |
| 渲染风格 | 真实渲染 |  |
| 动态节奏 | 自然流畅 | 巨人的动作缓慢、沉重、带惯性，起止平滑 |
| 动画行为 | 主行为：位移与运动/路径运动/沿线移动 | 巨人的身体从跪姿沿弧线升起到站立。分类表没有“关节动作”或“站起”这类标签，这是最接近的选项，请确认 |
| 动画行为 | 辅助行为：物理与特效/流体粒子/液体 | 水从机体上倾泻而下，水面荡开波纹和波浪 |
| 动画行为 | 辅助行为：物理与特效/刚体运动/掉落 | 锈屑、锈皮和泥土从装甲上掉进水里 |
| 动画行为 | 辅助行为：显隐与外观变化/材质变化/发光亮灭 | 眼部灯组闪两下后亮起 |
| 灯光氛围 | 黄昏金色时刻 | 太阳高度约 8° 的橙金色夕阳，符合“低角度暖色斜射光”的定义 |
| 背景环境 | 完整场景 | 被水淹没的废城、楼房、电塔和天空构成完整搭建的环境 |
| 色彩基调 | 暖色温馨 | 画面以夕阳的橙金色和锈蚀的橙褐色为主，符合该标签“橙、黄、米色暖调”的色彩定义；氛围本身并不温馨 |
| 时序结构 | 多段序列 | 沉睡、苏醒、抬头、站起按顺序衔接 |
| 复杂度等级 | 物理模拟 | 倾泻的水流和水面波浪适合用液体模拟；锈屑和十几只白鹭属于“≥10 对象群组”。剧本不要求真实的物理模拟 |
| 应用场景 | 不填 | 没有明确用途依据 |

白鹭群飞起对应“位移与运动/群体运动/群集”，断电缆在水面晃动对应“物理与特效/柔性运动/毛发绳索”。受动画行为最多 4 个的上限所限，这两项不单独列出。
